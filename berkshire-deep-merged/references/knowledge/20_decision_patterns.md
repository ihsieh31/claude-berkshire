# 20 決策模式庫：買進、賣出、拒絕與交易結構

> **定位**：本檔是思考背景，不是規則；與 `../../SKILL.md`、`../procedure/`、`../rulebook.md`、`../rule_index/` 衝突時一律以前者為準（SKILL.md 優先序）。尤其：前半（步 0–8、G1–G6、閘門 3 問卷）價格盲，本檔以價格、市值、倍數為條件的句子只能在 G7 起使用；宿主（小資金模擬）不做套利、困境債、統計籃子、優先股／可轉債、試探部位；持有與賣出依 SKILL §6。

> 何時讀：當你面對一個具體的交易型態（例如「危機中有公司來要資金」「家族要賣公司」「持股大漲了要不要賣」「某商品價格大漲帶動某公司」）時，對照過去反覆出現的決策模式與判斷要點。
>
> 來源：從大量歷史個案中抽象出的模式。依使用者要求，這裡**刻意不列任何公司名稱或年份**——只保留觸發條件、關鍵檢查事實與價格特徵。
>
> **執行限制**：本檔的優先股、套利、垃圾債／困境債、衍生品與放空模式只作辨識用；自動交易只做上市普通股，這些一律不動作、不自動交易。

## 模式總覽：哪些模式可靠、哪些模式危險

| 模式 | 結論 |
|---|---|
| 家族／創辦人出售、留任經營者、高 ROE 的全資收購 | **最可靠的模式之一**，但產業結構仍是前提；失敗集中在零售、百貨與被產業結構拖累者 |
| 小型、低資本需求、高現金產出的品牌或消費業務 | 非常可靠（但本身無法大量再投資） |
| 能力圈內優秀大型企業的長期非控制持股（讓回購自然提高持股） | 可靠；負面多為事後護城河改變或付價過高 |
| 危機中提供資金給「體質正常、被迫融資」的優秀企業（高股息優先股＋權證＋贖回溢價） | 可靠，前提是發行人體質與產業經濟健全 |
| 恐慌中買入龍頭與資產品質好的金融機構 | 可靠，但必須真正看懂資產端；負面來自不理解的放款（例如土地開發貸款） |
| 受監管基礎設施、逐步取得控制 | 可靠但報酬有上限，監管協議是前提 |
| 低成本保險業務，在困境時買入並逐步加碼 | 可靠，但需先確認管理問題已解決 |
| 價格補償風險的海外低倍數企業（本益比個位數、高股息、零負債） | 可靠，前提是價格「便宜到荒謬」 |
| 分階段控股（先多數、少數股權以公式定價） | 可靠；結構要簡單，最好一開始就買足 |
| 被投資公司被收購時以股換股（換到優秀企業的股票） | 可靠，條件是換到的股票值得長期持有 |
| 困境債、破產重整、被迫出售的複雜證券 | 以組合看期望值，偶有大損失；舊管理層不留任才行 |
| 深度價值（低於資產價值、靠價值實現路徑） | **好壞參半**：只適合小資金且有清楚實現路徑 |
| **以自己股票支付收購** | **危險**，預設用現金 |
| **以商品價格、產業週期、「看起來便宜」為主要前提買入** | **危險** |
| **大型保險／再保險併購（承保紀律不明）** | **危險** |
| **流動性差、受資訊限制、產業經濟差的優先股** | **危險** |
| **為現金需求、情緒、宏觀恐懼而賣出優秀企業** | **危險**，幾乎全部被事後判為錯誤 |
| **因價格上漲一點就停止加碼／因價格「稍高」而拒絕優秀企業** | **危險**——價格紀律用在好企業上要有分寸 |
| **能力圈外拒絕** | 原則仍正確；後悔集中在「其實能理解卻沒去理解」的業務 → 要持續擴大能力圈，而不是放寬標準 |
| **以槓桿（保證金）加碼「荒謬地好」的機會** | 極端例外，絕大多數人應避免 |
| 因費率不足而拒絕承保 | 原則不變；但要定期重估「費率不足」的判斷 |

## 一、買進模式

### B1 家族或創辦人出售的優質私人企業（永久之家）
- **觸發**：賣方是家族或創辦人，想為企業找「永久的家」，重視員工、文化、交易確定性與速度，而不只是最高價；經營者願意留任。
- **檢查**：經營者的誠信與能力（直接會面＋向同業、客戶、供應商打聽）；ROE 高於同業；單店或單位經濟優於同業；業務簡單；是否依賴特定景氣循環。
- **價格**：通常是「中等、合理」的價格；常以數倍稅前盈餘成交；價格紀律仍在（曾為一點點差價差點放棄）。
- **結構**：全資或高比例、現金為主、少盡調文件、握手即交易；不做拍賣。
- **失敗與後悔集中在**：(1) 價格建立在樂觀的「正常化盈餘」上；(2) 收購後依賴協同效應；(3) 未取得創辦人的競業禁止條款；(4) 產業結構不良（零售、百貨、受低成本進口衝擊的製造業）；(5) 依賴政策配合。
- **警告**：如果經營者不願留任、業務需要轉型、或強烈依賴景氣，模式不適用。「好人＋好生意」兩者都要；好人救不了壞產業，也救不了付太多的價格。

### B2 小型、低資本、高現金產出的品牌或零售業務
- **觸發**：幾乎不需再投資；盈餘可以全數上繳；品牌或消費記憶穩定；經營者誠信。
- **價格**：數倍稅前盈餘也可以是「非常好的價格」。
- **特性**：本身無法大規模再投資——它的價值在於提供現金給其他投資。

### B3 能力圈內優秀企業的長期非控制持股
- **觸發**：大型、獲利穩定、有護城河、股東導向（持續回購）的企業，價格合理或低於內在價值。
- **檢查**：品牌與市占；單位成長；回購對持股比例的影響；經營者品質。
- **價格**：可接受較高本益比，但要求長期單位成長支撐；價格過高時不加碼但也不賣。
- **常見失敗原因**：護城河事後改變或買價過高。
- **補充**：「被投資公司持續回購，我們不用多出一毛錢就提高持股比例」是重要的報酬來源。

### B4 危機中的流動性提供者
- **觸發**：信用或流動性危機中，一家「經營體質仍正常、但被迫融資」的優秀企業需要大額資金；能「一天內付款」的買方極少。
- **檢查**：業務本質是否健全、問題是否只是暫時的融資；發行人能否支付股息與贖回；經營者是否可信；監理機關是否會限制贖回或配息。
- **結構**：高股息（約 8–12%）優先股或次順位證券，附認股權證（行使價接近危機時股價、期限長），加上贖回溢價；後期版本加入不可贖回期以換取較低股息與更多權證。
- **收益來源**：股息＋贖回溢價＋權證增值。**失敗集中在**產業經濟本身很差、或流動性差的發行人。
- **警告**：被提前贖回時失去高收益；股東仍可能被稀釋或抹除（不要把政府救助當作股東的保障）。

### B5 恐慌中買入優秀企業或優質金融機構的普通股
- **觸發**：市場恐慌使優秀企業或資產品質優於同業的金融機構以極低價格出售（例如整體估值跌到私人所有者價值的一小部分）。
- **檢查**：價值是否仍遠高於價格；資產品質與風險文化；不是「價格低是因為業務本身不可靠」。
- **要點**：「在低迷時從被迫的賣家手中買入」。失敗來自沒有真正理解資產端（例如在小型經濟體中大量放出的土地開發貸款）、或相信了不可信的報表。
- **立場**：明確反對「價格下跌代表風險升高」的觀點——價格越低，越應積極評估。

### B6 價格已補償風險的海外或國有背景企業
- **觸發**：本益比個位數、高股息（且已實際支付）、零或低負債、資產或儲量被低估、與國際同業相比「折價到荒謬」。
- **檢查**：盈餘與資產是否真實；股利是否實際支付；政治、法律與治理風險是否已被價格完整補償。
- **價格**：買入價遠低於保守估計價值，不需精確估值也成立。
- **警告**：若只是「相對便宜」但政治與法律風險高，放棄。價格回到同業水準時就賣出。（宿主覆寫：價格不得寫成失效條件；失效條件必須是可觀察的企業事實，價格型賣出只走 SKILL §6(2)(3)，D02）

### B7 低成本保險業務在困境中的買入
- **觸發**：靠低成本直銷取得客戶的保險業務，因短期虧損、帳務疑慮、管理失誤而被低估。
- **檢查**：成本優勢是否結構性、可持續；承保紀律；管理問題是否已解決；投資部位由誰管理。
- **判斷**：不被第一年虧損嚇到，比較「未來獲利的現值」與價格。
- **常見失誤**：早年因資金需要而太早賣出。

### B8 受監管基礎設施
- **觸發**：受監管、資本密集、債務不追索母公司、可長期穩定部署資本。
- **結構**：先取得影響力（權益法持股），再逐步全資。
- **要點**：報酬「不錯而非驚人」；後期也出現監管協議惡化帶來的重大錯誤（見 12）。

### B9 工業與製造業的領導者
- **觸發**：產業領導者或細分市場的規模優勢；可以整合降本；經營者留任；有補強收購機會。
- **價格**：可以為領導地位付較高價格，但後期最大的錯誤正是對「正常化平均盈餘」過度樂觀。
- **常見失敗原因**：原料與售價落差、或產業週期低谷比預期更差。

### B10 困境債、破產重整、複雜或被迫出售的證券
- **觸發**：以遠低於面值或清算價值的價格取得；擔保品價值高於市價；價格折扣來自複雜度與流動性。
- **條件**：破產重整時，「如果要接手舊管理層，一塊錢都不買」；特殊責任（例如大規模訴訟）必須已被切割或由賣方保留。
- **要點**：偶有大損失，以組合方式承擔。

### B11 深度價值（小資金時代）
- **觸發**：市價低於保守估算的資產價值，且有可驗證的價值實現路徑（清算、重組、控制權）。
- **要點**：好壞參半。成功者靠清楚的價值實現路徑（清算、控制權、資產轉換）；失敗者是結構性衰退的生意，折價被時間吃掉。後期轉向「好企業＋合理價」，因為機會消失、規模不容。

### B12 高確定性機會：以目標部位建立
- **規則**：一旦判斷完成，設定目標部位，**不因價格小幅上漲而中途停止**（現價高於買價上限時不買）——這是代價最高的錯誤之一。

### 警示型買進：以單一商品價格或產業週期為前提
- **型態**：買進理由主要是某商品價格上漲、某產業週期翻身、或股價「看起來很低」，而不是企業本身的長期品質。
- **常見失敗**：在商品價格高點大量買入、對產業前景的專家意見短期內反覆、在結構性衰退產業中長期撐住。
- **規則**：若投資論點依賴單一外生價格變數，(1) 要求極大的安全邊際；(2) 只在價格處於週期低點或價格本身已極低時；(3) 事先寫好前提失效時的退出條件（宿主：失效條件寫企業事實〔如單位成本、市占、合約〕，不寫外生價格點位或股價，D02）。

## 二、賣出模式

### S1 競爭優勢或產業結構改變
- 「它仍是好公司，但優勢已經改變」——賣出理由是護城河的變化（技術、通路、消費行為、監管、風險特性），而不是股價。
- 結果：判斷優勢改變而賣出時，有時事後證明是對的（風險特性改變的金融機構）；但多次「太早判斷優勢消失」被事後稱為巨大錯誤——賣出前要確認改變是結構性的。

### S2 價格已完全反映價值
- 價格上漲到與同業一致、不再比同類便宜、或超過估計的內在價值時出售，但保留日後再買的權利。
### S3 基本面結構性惡化
- 管理層承諾不可持續、會計不健全、風險不可管理、股利或現金流被削減、產業商品化——減持或全數出清，「不因虧損而硬撐」。

### S4 管理層誠信、激勵扭曲或文化問題
- 減持或不買；但若管理層迅速承認並修正，可以繼續持有並重新評估。

### S5 被投資公司回購或公開收購時賣回
- 價格合理、公司的現金用在回購比其他用途好時，可以把股票賣回給公司（同時維持持股比例或接受下降）。

### S6 被動減持
- 監管門檻、持股上限、稅務或規則限制——不是基本面判斷，事後說明「不是對公司的負面判斷」。

### S7 事件完成
- 套利或清算交易在事件完成時結束。

### 不應出現的賣出（事後幾乎都被判為錯誤）
- 為了短期現金需求賣出優秀企業；
- 因宏觀、地緣、疫情等恐懼情緒賣出（除非產業需求結構真的改變）；
- 為了實現利得或稅務理由減持仍被低估的優秀企業；
- 因為部位太小嫌麻煩而賣出；
- 價格下跌但業務優勢未變時賣出。

### 持有原則
- 預設長期持有；股價大跌而優勢未變時不賣（甚至在被投資公司回購時視為好事）。
- 估值極度偏高時可以部分減持，但不要因為「價格有點高」就賣掉一家優秀企業。
- 減損若反映業務價值下降（而非市價波動），要重新評估。

## 三、拒絕模式

> 拒絕的事後結果提醒：因「價格稍高」而拒絕優秀企業，事後多半被判為錯失；因能力圈外而拒絕，後悔集中在「其實能理解、只是沒花時間理解」的業務。所以：價格紀律要以內在價值為基礎，而不是以「看起來高」為基礎，並定期重估被拒絕的好企業；能力圈要靠學習擴大，而不是放寬。

| 拒絕理由 | 說明 |
|---|---|
| 能力圈外 | 無法判斷十年以上的現金流與競爭格局（科技、生技、平台、新潮流）——即使公司很好或很熱門 |
| 價格不足 | 業務好但價格沒有安全邊際；「看起來差不多就放棄」；價格高於內在價值時不買、不回購、拒絕高價要約 |
| 管理層平庸 | 即使價格便宜，管理層平庸就不買 |
| 商品化、資本密集、無差異 | 除非產業集中化或價格極低 |
| 拍賣、敵意收購、無報價、需長時間維持報價、高額分手費 | 不參與；直接談判才有效率 |
| 轉型或轉機 | 不買需要被修復的生意 |
| 過度槓桿的競價 | 不以槓桿收購者的方式出價；「寧可放棄有趣的機會也不過度槓桿」 |
| 承保費率不足、尾端無上限、聚合風險無法估計 | 減少或拒絕 |
| 高槓桿、高費用、複雜金融結構 | 拒絕 |
| 法律、道德、聲譽或政策扭曲的風險 | 即使獲利也拒絕 |
| 監理限制使交易無法完成 | 不硬做 |
| 新發行垃圾債、過度樂觀的套利、單位信託式的投機商品 | 拒絕 |
| 救援案中股東權益可能被抹除 | 不把政府救助當作股東的保障 |
| 市場結構與流動性不足以建立有意義部位 | 放棄 |

## 四、交易結構模式

### T1 全現金、快速、少條件
- 數小時到數週內完成；無融資條件；不做繁複的法律盡調（以經營者與價格判斷取代）；可信的付款能力是賣方選擇的原因。

### T2 全資收購、經營者留任、無正式聘僱合約
- 依賴經營者的熱愛與誠信，而非合約。

### T3 分階段控股
- 先取得多數（例如 60–90%），少數股權保留給經營者或家族，後續以盈餘公式、put／call 選擇權、或換股取得剩餘股份。
- 好處：經營者留任並保有利益；價格難以一次確定時保護雙方。
- 失敗與混合來自：選擇權結構設計不當（事後承認「一開始就該買足」）、少數股權無法影響決策而管理層的併購付價過高、收購後整合困難。

### T4 權益法持股（約 20–50%）
- 取得重大影響力而不合併；可作為日後全資控制的前奏。
- 警告：權益法持股的大額減損需要重新評估業務價值（不是只看市價）。

### T5 優先股、可轉換優先股與權證
- 固定收益為主、轉換權或權證為上方；條款決定結果：股息率、贖回時點與溢價、轉換價、權證行使價與期限、是否可強制轉換。
- 發行人的信用與產業經濟決定下方；流動性差、董事身分受資訊限制的優先股經濟性不吸引人。
- 對真正有信心的優秀企業，事後常發現直接買普通股更好。

### T6 以自己股票支付
- 只在自己的股票未被低估、收到的內在價值不低於付出時；賣方可能因稅務偏好股票。
- 結果：以混合為主，負面者損失巨大（收購標的競爭優勢在幾年內消失、或承保紀律崩潰，交出的內在價值遠大於得到的）；即使後來整體結果尚可，事後仍評為「用股票支付是錯誤」——預設用現金。

### T7 被收購時以股換股
- 換到值得長期持有的優秀企業股票時，接受股票（延後課稅）。

### T8 承諾性融資、擔保與承諾費
- 對重整或需要確定資金的企業提供承諾，收取承諾費；結構上要求高擔保與股票折價；要控制觸發條件與上限。

### T9 合資與共同控制
- 與有能力、自己也承擔風險的夥伴共同收購；以持股門檻維持治理權。

### T10 賣出衍生品
- 只在定價明顯錯誤、預收權利金、無擔保品觸發、期限長、最壞損失可承受時；賣出賣權時，只選擇願意以行權價持有的優秀企業（事後常發現直接買更好）。
- 機械公式定價多數時候可能正確；只在不同意其結論時出手。

### T11 被動少數持股與持股上限承諾
- 對海外優質企業做長期被動持股，承諾不超過某個比例、不尋求控制，換取管理層與市場的信任。

## 五、如何使用這個模式庫

1. 先辨認你面對的是哪一種模式（買進 B1–B12、賣出 S1–S7、拒絕、結構 T1–T11）。
2. 查看模式總覽：如果它屬於「危險」類，要求更高的安全邊際或直接放棄。
3. 逐項跑該模式的「檢查」條件；任何一項不成立，模式就不適用。
4. 對照 15（錯誤模式）確認不是已知的陷阱。
5. 在投資紀錄中寫下：屬於哪個模式、依據哪些檢查、前提失效時怎麼做。
