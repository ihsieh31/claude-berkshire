# 19 量化門檻與經驗數字速查表

> **定位**：本檔是思考背景，不是規則；與 `../../SKILL.md`、`../procedure/`、`../rulebook.md`、`../rule_index/` 衝突時一律以前者為準（SKILL.md 優先序）。尤其：前半（步 0–8、G1–G6、閘門 3 問卷）價格盲，本檔以價格、市值、倍數為條件的句子只能在 G7 起使用；宿主（小資金模擬）不做套利、困境債、統計籃子、優先股／可轉債、試探部位；持有與賣出依 SKILL §6。

> 何時讀：需要具體數字作為判斷錨點時（要求報酬、安全邊際大小、ROE 門檻、部位大小、現金底線、回購條件、承保指標、費用、回撤準備等）。
>
> **使用警告**：這些數字是原始資料中反覆出現的**經驗錨點**，不是精確公式。它們多數隨利率、通膨、資金規模與時代而改變——使用時一定要對照「適用前提」欄。框架本身強調：「若需要計算機才能分辨 9.6% 與 9.8%，就放棄」「估值只能在幾個百分點內一致，不可能在 1% 內」。實際持股資料的統計校準見 16。
>
> 本檔數字為經驗錨點：只作加分、確定性與合理性檢查，不得當排除門檻或買進理由；與 SKILL.md、procedure/、rulebook.md 衝突時以後者為準。

## 一、企業品質門檻

| 指標 | 經驗錨點 | 適用前提／說明 |
|---|---|---|
| 股東權益報酬率（未過度槓桿） | 長期 5–6%：長期持有效果差；長期 20–25% 並可持續：優秀 | 必須是在低負債下取得；與當時長期公債殖利率比較 |
| ROE 相對利率 | 長期公債約 5% 時，10% 左右的 ROE 已是好企業；長期公債 4–5% 時，有形權益報酬 20%+ 才是門檻 | 利率高低改變門檻 |
| 有形資本報酬 | 頂級企業：稅後有形淨資產報酬數十個百分點到 100% 以上；良好：12–20%+ | 評估企業本身品質時用有形資本；評估管理層時含商譽 |
| 資本報酬與長期股東報酬 | 長期維持 6% 資本報酬的企業，股東長期報酬也約 6%；長期維持 18% 的企業，即使買價看起來偏貴，結果也很好 | 前提是高報酬能持續 20 年以上 |
| 異常高 ROE 的可持續性 | 名目 GDP 只成長約 4–5% 時，長期維持 20%+ ROE 的企業必須大量分配盈餘；有形權益報酬接近 30% 不應被視為可持續 | 尤其銀行與高槓桿企業 |
| 保險業平均 ROE | 長期顯著低於一般大型企業平均 | 只有前段班例外 |
| 受監管公用事業 | 允許的股東權益報酬約 9–12% | 由監管決定，無超額利潤 |
| 重資產運輸（鐵路） | 投入資本報酬約一成即「不是瘋狂的數字」 | 低於此不值得投入 |
| 實證：主要決策者實際買入 | 非金融買入的 ROE 中位數約 24%，約位於大型股的前四分之一 | 見 16；校準用，不是門檻 |

## 二、資本配置門檻

| 指標 | 經驗錨點 | 說明 |
|---|---|---|
| 留存盈餘測試 | 每留存 1 元，在約五年滾動期間創造 ≥ 1 元市值（以內在價值衡量） | 修正版：帳面成長是否超越大盤、股價是否持續高於帳面 |
| 股利 vs 留存 | 能以 > 1 元價值再投資就留存；否則回購或配發 | 不採固定配息率 |
| 回購（現行） | 價格低於**保守估計**內在價值、且現金充足 | 低於內在價值約一成即可考慮；低 25–30% 可大量買入 |
| 回購效益 | 回購 2% 股份、折價 25%，每股內在價值只增約 0.5% | 小額小折價效益有限 |
| 回購（歷史代理） | 一段時間曾以「帳面價值 1.1–1.2 倍以下」為上限 | 已被宣告過時，只是代理指標 |
| 發行股票 | 只有收到的內在價值 ≥ 付出的內在價值；「至少三分之二的發股收購是可怕的主意」 | 預設用現金 |
| 收購預測 | 經驗上實際獲利常只有收購時預測的一小部分 | 對協同與成長假設打大折扣 |

## 三、估值與要求報酬

| 指標 | 經驗錨點 | 說明 |
|---|---|---|
| 折現率 | r_d = max(10%, 30 年期公債殖利率 + 3 個百分點)；用安全邊際處理風險 | 固定公式，不因確定性另行調降 |
| 要求報酬（稅前） | 「高度機率」的約 10% 稅前報酬是合理的股權門檻 | 依利率環境調整 |
| 與公債比較 | 公債 2% 時不買預期 3–3.5% 的生意；公債 4–5% 時要求「相當多」的超額報酬 | 機會成本思維 |
| 壓力測試 | 假設市場關閉兩年、利率上升 100–200 基點，仍對所買滿意 | 買入前必做 |
| 長期市場報酬預期 | 合理長期名目約 6–7%（名目 GDP + 股利），扣摩擦成本更低；「15% 是夢想」 | 長期期待應保守 |
| 市場長期歷史 | 長期名目約 10%（稅前含股利），實質約 7%；但未來可能更低 | 不外推 |
| 盈餘長期成長 | 宣稱每股盈餘長期年增 15% 的大型企業，極少數能做到 | 對長期高成長預測打折 |
| 景氣循環股收購 | 寧可在壞年以 10–12 倍本益比買，也不要在好年以 8 倍買 | 用正常化盈餘 |
| 高品質企業容忍度 | 2–3 倍帳面仍可能是好交易；數十倍盈餘（例如正常化本益比 ≥50 倍）對多數企業是「愚蠢價格」；達此荒謬級估值線時至少賣出一半 | 極少數超級企業例外 |
| 實證：主要決策者實際買入 | 本益比中位數約 15，位於大型股便宜的四分之一；約九成買入時盈餘殖利率高於 10 年公債 | 見 16；校準用，不是門檻 |

## 四、安全邊際

| 指標 | 經驗錨點 | 說明 |
|---|---|---|
| 經典 | 以 40–60 美分買 1 美元價值（早期更嚴：20–40 美分；清算價值的三分之一或更低） | 深度價值時代 |
| 好企業 | 以接近但低於內在價值的價格買入可接受；理想仍是明顯折價 | 「好企業合理價」 |
| 不追求精確 | 不要以 0.93–0.95 元去買 1 元；但為優秀企業不因小差價錯過（宿主覆寫：自動買進上限＝min(P2′, k×`IV_base`)，k＝A 0.95／B 0.85〔ASK-1＝B〕，以 `IV_base` 計 0.95 是設計值；對 `IV_cons` 上限常在 1.2–1.3 倍，SKILL §3） | 兩個錯誤都要避免 |
| 賠率 | 「4 比 1 的賠率、五五波」是價值投資的型態 | 不對稱報酬 |
| 加碼準備 | 買入後若再跌 25–30%，要有資金與意願加碼 | 不要用到最後一塊錢 |
| 承重比喻 | 能承重一萬磅的橋，只讓九千八百磅以下的車通過——邊際要大到能吸收估計誤差 | 誤差越大，邊際越大 |

## 五、整體市場價位

| 指標 | 經驗錨點 | 說明 |
|---|---|---|
| 總市值／國民生產總值 | 70–80%：很可能是好的買入區；接近 200%：危險 | 須同時看利率 |
| 企業利潤占 GDP | 長期多在 4–6.5%；明顯高於此不可長期持續 | 高利潤率 + 高估值要特別審視 |
| 利率效應 | 長期利率從 6% 降至 3%，可讓合理估值約倍增 | 反之亦然 |
| 市場不被高估的條件 | 利率維持或下降，且企業 ROE 維持高檔 | 兩者都不保證 |

## 六、部位大小與集中

| 指標 | 經驗錨點 | 說明 |
|---|---|---|
| 小資金深度價值組合 | 五、六檔各佔 5–10%，另十到十五檔小部位；單一部位上限曾達淨值 40% | 早期四類工具框架 |
| 集中 | 「三家好企業就足以讓你非常富有」；持有 30–50 檔是「瘋狂」（對能深入研究者） | 前提：能力圈內、充分研究 |
| 實證 | 前五大持股長期約占組合 70–80%，有效持股數約 7–8 檔；部位大小與持有期間正相關 | 見 06、16；校準用，不是門檻 |
| 個人一生的決策數 | 像一張只能打 20 個孔的卡片；真正好的點子一年一兩個 | 慎選 |
| 市場衝擊 | 買入量約為日成交量兩成內不會明顯推高價格；單一公司持股常在 5–10% 以下（受申報與監管門檻限制） | 大資金特有限制 |
| 單筆投資最低規模 | 大資金需要能投入有意義的金額，否則不值得研究 | 規模越大，門檻越高 |
| 套利部位 | 同時約五到十五個；曾占淨值 30–40% | 與市場相關性低 |
| 借款 | 只對套利組合適度借款（自設上限如淨值四分之一）；對一般持股借款很危險 | 個人：不借 |

## 七、流動性、槓桿與尾端

| 指標 | 經驗錨點 | 說明 |
|---|---|---|
| 現金底線 | 設定「最壞情境現金需求 + 緩衝」的絕對底線；實際水位高於底線 | 歷史上底線被多次上調 |
| 現金比例（實證） | 現金約占總資產中位數 15%，市場昂貴時上升至近三成 | 見 16；校準用，不是門檻 |
| 利息保障 | 以稅前盈餘（EBIT）÷ 利息計算；穩健的重資產企業約 6–10 倍 | 不用 EBITDA |
| 槓桿反例 | 數十倍的槓桿（20–30 倍以上）是聰明人破產的典型原因 | 避免 |
| 個人借款 | 18% 的信用卡利率不可能致富；即使 12% 也不要借 | 個人守則 |
| 房貸 | 頭期款 ≥ 20%，月付 ≤ 收入約 30%，收入要驗證 | 健全標準 |
| 永久虧損 | 單一有價證券的永久虧損極少超過淨值約 1%；已實現損失通常 ≤ 淨值 0.5–2% | 部位與研究紀律 |
| 尾端 | 可以接受損失相當於淨值的幾個百分點，但絕不接受會威脅存續的損失 | 尾端原則，不以金額衡量 |
| 回撤準備 | 準備好股價下跌 50% 甚至更多；歷史上曾有指數跌近九成 | 無法承受者不應持股 |
| 機率 | 每年 1/30 機率的事件，百年內至少發生一次的機率約 97% | 小機率 ≠ 零 |
| 簡單命題 | 十個各有九成機率的獨立假設同時成立的機率約三成五 | 少假設、單鏈 |

## 八、保險指標

| 指標 | 經驗錨點 | 說明 |
|---|---|---|
| 浮存金成本 | 承保損失 ÷ 平均浮存金；長期應 ≤ 0 或明顯低於長期公債殖利率 | 承保打平即零成本 |
| 綜合比率 | 高利率時代，綜合比率略高於 100（約 106–112）加投資收益可打平；利率下降後不再適用 | 依當期利率重算 |
| 優秀承保者 | 十年平均綜合比率約 93：每 100 元保費約 23 元費用、約 70 元損失（進入浮存金）、約 7 元利潤 | 承保紀律的樣子 |
| 長尾業務 | 綜合比率 100 也可能虧損；115 不是定價目標 | 依準備金品質判斷 |
| 產業保費成長 | 保費成長需跟上損失成本成長（歷史上約一成），否則承保結果惡化 | 看相對關係 |
| 浮存金萎縮 | 健全的長期浮存金每年萎縮幅度有限（例如至多約 3%） | 浮存金品質 |
| 超額責任再保 | 事故當年通常只有約一成多的最終理賠被通報 | 長尾的延遲 |
| 巨災定價 | 保費應反映事件機率乘以保額（期望損失）；定價不足時，多年可能看似獲利，但尾端未被補償 | 依暴險定價 |
| 巨災暴險上限 | 單一事件最大損失控制在淨值的低個位數百分比（例如 3–5%） | 尾端紀律 |
| 低成本承保者 | 承保利益率目標約 4%（高於目標時降價擴大優勢）；費用率領先數個百分點 | 個人汽車險型 |
| 留存率 | 留存率提升 1 個百分點，對大型汽車保險人內在價值影響可達十億元級 | 調整業務組合後判讀 |

## 九、費用與摩擦

| 指標 | 經驗錨點 | 說明 |
|---|---|---|
| 摩擦成本 | 投資人整體每年約 1.5–2%；可吃掉企業盈餘的相當比例 | 降低交易與中介 |
| 費用結構 | 2% 管理費 + 20% 績效費：10% 毛報酬時，經理人約拿 3.6 個百分點，投資人淨約 6.4%；再加一層基金中基金費用，大部分超額報酬被拿走 | 費用確定、績效不確定 |
| 主動 vs 被動 | 長期十年期比較中，低成本指數大幅勝過高費用的基金組合 | 多數人應指數化 |
| 能持續打敗指數的經理人 | 扣除成本後約只有一成以下（約 5%） | 極少數 |
| 低成本結構 | 優秀控股公司的營運成本可低於資產的千分之一；共同基金常 ≥ 1% | 成本差異的長期複利 |
| 換手率 | 換手率 100% 時，摩擦每年約吃掉淨值 2% | 低換手 |

## 十、持有期間與評估

| 指標 | 經驗錨點 | 說明 |
|---|---|---|
| 持股 | 至少以五年視角持有；假設市場關閉五年 | 長期所有權 |
| 績效評估 | 三年是絕對最低，五年較佳；大跌年少跌比大漲年多漲更能說明能力 | 不以單年論成敗 |

| 指標 | 經驗錨點 | 說明 |
|---|---|---|
| 最低盈餘 | 隨規模提高（例如稅前數千萬美元以上），除非可併入既有單位 | 依自身規模調整 |

| 支付 | 偏好現金；不做敵意收購 | 見 09 |

| 指標 | 經驗錨點 | 說明 |
|---|---|---|

## 使用這些數字的五條規則

1. **先確認前提**（利率、規模、產業、時代），再使用數字。
2. **數字是錨點，不是篩子**：未達數字不得直接排除；達到數字只可加分，代表值得深入研究。
3. **寧可粗略正確**：若結論需要依賴小數點，代表安全邊際不夠。
4. **用多個數字交叉驗證**：例如高 ROE + 低負債 + 現金轉換好 + 合理本益比 + 盈餘殖利率高於公債，同時成立才有說服力。
5. **把數字寫進投資紀錄**，事後檢討時比較假設與實際。
