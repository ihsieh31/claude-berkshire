# 07 賣出、減碼與持有

> **定位**：本檔是思考背景，不是規則；與 `../../SKILL.md`、`../procedure/`、`../rulebook.md`、`../rule_index/` 衝突時一律以前者為準（SKILL.md 優先序）。尤其：前半（步 0–8、G1–G6、閘門 3 問卷）價格盲，本檔以價格、市值、倍數為條件的句子只能在 G7 起使用；宿主（小資金模擬）不做套利、困境債、統計籃子、優先股／可轉債、試探部位；持有與賣出依 SKILL §6。

> 何時讀：手上持股要不要賣、要不要減碼、股價大漲或大跌時、基本面出現疑慮時、需要資金換更好機會時。

## 總則：好公司預設永久持有

- 買進時就以「可以永遠持有」為標準篩選。持有期間是買進決策的一部分，不是事後才決定的。
- 持有的依據是企業的基本經濟特性、競爭地位與管理層仍然良好，而不是股價。只要這些特性仍有利，就不因市場價格波動而動搖。
- 賣出從來不會讓你更富有；它只是把一個資產換成另一個資產，還要交稅、付摩擦成本，而且你必須「買對一次、賣對一次、再買對一次」。
- 理想的情況是：一生找到幾家真正優秀的公司，全力買進，然後什麼都不做。
- 「買比賣容易」。沒有明確的停損規則，也沒有目標價出場規則；不要自行推導這類規則。

## 賣出理由的八個類別

在任何賣出決定之前，先把理由歸類。不同類別的判斷標準完全不同。

### A. 企業經濟特性結構性惡化（最主要的正當理由）
判斷訊號（必須是結構性的，不是暫時的）：
1. 競爭優勢（護城河）被侵蝕：你不再認為它的競爭優勢像原先想的那麼強。注意：侵蝕通常是漸進的，信念也應該漸進調整。
2. 業務的風險特性改變：例如金融機構開始追求成長或績效目標、承擔原本不承擔的風險。
3. 過去穩定的產業不再穩定：要定期重新檢查「這個產業十年前的穩定性，今天還成立嗎？」（例如被新技術、新通路取代）。
4. 永久性的現金流出：業務將持續虧損、不再產生營運現金。
5. 產業結構性衰退且無法修復：只能把現金擠出來轉投他處。
6. 管理層持續把資本投入沒有前景的產業：「在糟糕產業裡再做大額投資，就像在流沙中掙扎」。

處理原則：
- 轉機很少成功。如果你坐在一艘持續漏水的船上，把精力花在換船上，比修補漏洞有效。
- 對控股企業，先考慮能否換經理人或交給更好的經營者；不行就逐步收掉。
- 最常見的錯誤是處理得太晚，而不是太早。

### B. 管理層問題
判斷訊號：
1. 管理層說謊、欺騙，或在業務上做出不誠實的事。最高決策者本人可查證的不誠實是立即的賣出理由；組織內事件且高層處理迅速者，降一級並列失效條件。
2. 有盈餘操弄的跡象或誘因。你可能不知道它們會不會是壞投資；但單純擔心管理層不構成退出理由，須查證後依上一條處理。
3. 對管理層失去信心（須有可查證的事實，單純擔心不構成退出理由）。
4. 管理層令你失望之後，業績逐月惡化（市佔下滑、利潤率收縮、會計問題浮現）。壞消息通常會連續出現。
5. 普遍且長期的勞資衝突。
6. 管理層不正視衰退。這是警示訊號，本身不是賣出理由，但要提高警覺。

不構成理由：
- 「只是業績未達原始預期」不是賣出理由。
- 管理層的判斷以行為為準，而不是以業績好壞為準。在逆風中做得好的經營者，比順風中業績亮眼的經營者更值得信任。

### C. 估值過高
這一類最需要細分：
- **真正優秀、可長期複利的企業**：價格看起來偏高（高於基準情境價值）時，通常續抱：好企業的長期複利通常勝過賣出後再找替代品的成本與稅；高於基準價值只觸發賣出檢視（是否有明顯更好的用途），不是自動賣出。
- **但有極限**：正常化本益比 ≥50 倍時，至少賣一半（宿主：新買進第一年內 → 停止加碼並完整複查，不機械減半；價格回到線下之前只減一次，SKILL §6、D01）。未在泡沫期減碼，是事後常被承認的錯誤。
- **一般持股（非「永久持有」等級）**：當價格已達到或超過你對內在價值的保守估計，相對低估的理由消失，就可以賣出。這是早期與一般持股的主要賣出理由。（宿主覆寫：價格達 `IV_cons` 不是賣出理由；現價 ≥ `IV_base`〔`sell_review_above`〕只觸發賣出檢視，有 G8／P-53 證明的更好用途才減碼或換股，減到 G8 勝出的權重為止；不採「普通／良好企業全清」，SKILL §6(2)、D01）
- **套利或事件型部位**：價格接近或超過你判斷的結果價值時，減持或出清。（宿主不做套利與事件型部位，SKILL §9）

判斷方法：
1. 先問：這家公司是「永久持有」等級，還是一般持股？（真正的永久持有等級，一個組合裡只有極少數。）
2. 再問：目前價格相對於保守內在價值，偏離有多大？
3. 最後問：如果賣掉，我能把錢放在明顯更好的地方嗎？還是只能放現金？

### D. 需要資金做明顯更好的機會
判斷訊號：
- 有大型收購或明顯更好的投資需要現金，且不願借錢時。
- 替代機會必須「明顯」更好。比較的是相對低估程度：價格對內在價值的折扣差距要夠大。
- 這種賣出不代表對被賣標的有負面判斷。

限制：
- 不因「另一家可能更好」就賣掉一家優秀企業。差距要明顯。
- 稅負只有在兩個選項差異不大時才是重要因素；差異顯著時，稅負是次要的。
- 已被你歸類為「永久持有」的部位，原則上不因為有更好用途而賣。

### E. 原始分析錯誤或能力圈判斷錯誤
判斷訊號：
1. 買進時的關鍵假設已經失效。
2. 公司或管理層已改變，不再符合原本的買進準則。
3. 持有一段時間後，表現明顯不如你的預期，而你回頭檢查發現推理有誤。

處理原則：
- 「有疑慮」不等於「確認錯誤」。有疑慮時繼續持有並加強研究；確認錯誤後才賣。
- 確認錯誤後要果斷。拖延的代價很高，而且壞消息常是連續的。不要抱著「等回本再賣」的心態。
- 用好資產去挽救一個正在失敗的計畫，是典型的心理錯誤（損失厭惡 + 承諾一致性偏誤）。
- 不要被帳面虧損或別人的看法動搖；要以你自己理解的道理來決定持有或賣出。
- 檢討標準：如果你的賣出決策長期不比買進決策好，就應該減少賣出。

### F. 監管、政治、地緣與法規限制
- 持股比例觸及法規門檻時，被迫減碼。這類賣出不是估值判斷，也不代表看壞企業，分析時要分開。
- 受監管產業的報酬機制破裂（主管機關不再允許合理報酬、成本無法轉嫁）時，不再投入新資本，必要時退出。
- 地緣政治風險：如果一家經營良好的公司所在地的風險讓你不安，可以把資本移到你更放心的地方。這是個人判斷，不要擴大解讀為「所有地緣風險都要賣」。
- 聲譽風險：如果持有某企業會讓股東承受你不願承擔的聲譽風險，可列為出售理由。

### G. 部位過大或集中度
- 文本中沒有「因為單一持股太大而賣」的明確規則。大部位本身不是自動觸發減碼的理由。
- 唯一接近的是法規持股門檻（見 F）。宿主另有單檔硬上限：權重超過宿主／使用者硬上限或法律、監管門檻 → 只減到解除限制；因上漲超過等級上限 → 不賣、停止加碼，>25% 完整複查（SKILL §6(4)、D01）。
- 不要自己發明集中度停損門檻。

### H. 稅負考量（次要但不能忽略）
- 稅負是次要因素，但在差異不大時可能決定時機。
- 稅率已確定改變時（不以預測為依據），調整實現損益的時點：稅率下降，就先實現虧損、延後實現利得；稅率上升，可以提前實現利得。
- 有多個成本不同的批次時，先賣高成本批次來實現虧損以節稅。
- 長期不賣本身就是一種報酬來源：遞延稅負相當於政府給你的無息貸款，讓複利在更大的基數上滾動。
- 要警覺「為了稅而持有」與「為了價值而持有」的差別。如果你持有一個部位的唯一理由是怕繳稅，你要明白這不是價值判斷。

## 什麼情況下「不」賣（優先檢查）

以下情況在來源中被明確視為不應賣出：
1. 好企業（經濟特性、管理、勞資關係都良好）：正常化本益比未達 50 倍前，不因價格而賣（達 50 倍見 C；宿主第一年內荒謬級不機械減半，改停止加碼＋完整複查，D01）。
2. 股價下跌、市場大跌、媒體負面新聞：本身不是理由。如果災難性新聞會讓你恐慌賣出，你就不該持有這類資產。
3. 業績未達原始預期，但基本面沒有變。
4. 「別處可能有更好的標的」，但差距不明顯。
5. 只因為已經漲很多，或已經持有很久。
6. 只因為有人出了高價。
7. 為了讓某段期間的報表好看。實現利得對分析沒有意義。
8. 因為對宏觀環境的猜測。放棄你擅長的事，去猜宏觀，毫無道理。
9. 把優秀且你理解的企業的一部分賣掉去「再平衡」，通常是愚蠢的。

## 執行紀律

1. 不要為了行動而行動。抵抗人類想要做點什麼的天性。
2. 不要在真正喜歡的公司之間跳進跳出。
3. 不要讓自己處於「被迫賣出」的位置（例如借錢、需要短期資金）。
4. 壞消息要提早面對，只有好消息可以等。
5. 可以逐步出清，不必一次全賣；但這是執行方式，不能用來拖延已確認的錯誤。（宿主覆寫：業務類〔論點證偽、最高決策者失信、會計問題，核對通過〕→ 全清，自下一交易日以市價開始，不等反彈；分批只用於估值類減碼〔掛限價＝觸發線〕，SKILL §6、D02／D03）
6. 決策速度來自事前定義好的參數：多年思考後，判斷條件已經清楚，所以可以快速決定。
7. 買進時就想好：什麼情況出現時，代表我錯了？
8. 要賣就直接賣，不要用複雜的衍生工具。
9. 持續重新評估每一項投資的理由，但不要因此頻繁交易。

## 被動出場（非主動決策）

- 被收購、被換股、優先股或債券被發行人贖回、衍生合約提前解約時，你的部位會被動實現。這時的判斷重點是：收到的現金能不能找到同樣好的再投資機會？高收益的工具被提前贖回，通常是不受歡迎的。
- 被換成另一家公司的股票時，要重新評估新公司是否值得持有，而不是自動接受。

## 數據告訴我們的賣出行為（實際持倉統計，校準用，不是門檻）

- **清倉的時間**：從持股峰值到清倉，中位數約 3 季。約 60% 是先減碼再分批出清，約 40% 是一次清空。
- **短期出場幾乎都是小部位**：持有不到 4 季就出清的部位，98% 在組合中的峰值不到 1%。大部位極少快速出場。換句話說，快速認錯發生在試探性小部位上。
- **賣出前最一致的前兆是盈餘成長放緩**，而不是本益比擴張。將賣出與同一標的先前的買進配對，賣出時本益比中位數幾乎沒變；但約 65% 的配對，淨利 5 年年化成長率下降（中位數約下降 3.6 個百分點）。另一組數據顯示，約 59% 的賣出前 ROE 下滑。
  - 含義：「盈餘成長或資本報酬率持續放緩」比「本益比超過某門檻」更能代表實際的賣出動機。
- **賣出是否賣早了**：主要決策者賣出後，1 年與 3 年內約有 57%–63% 的股票仍跑贏大盤，顯示有「賣得太早」的傾向；授權經理人的賣出則多半正確（賣出後明顯落後大盤）。
  - 含義：對基本面仍好、只是價格偏高的優秀企業，部分減碼通常優於全部清倉。
- **年度換手率很低**：每年賣出金額中位數約為組合的 7.5%。

## 過早賣出的教訓

- 過早賣出優秀企業，是常見的昂貴錯誤之一。
- 共同模式：當時賣出的理由是「已經賺到不錯的報酬」或「需要錢做別的事」，而不是企業變差了。
- 教訓：如果賣出的理由不是企業本身變差，就要非常小心。優秀企業的長期複利，往往遠超出你在賣出當下的想像。

## 賣出前的檢查清單

- [ ] 我的賣出理由屬於哪一類（A–H）？
- [ ] 如果是 A 或 B：證據是結構性的，還是暫時的？
- [ ] 如果是 C：這是「永久持有」等級的企業嗎？價格偏離保守內在價值多少？
- [ ] 如果是 D：替代機會是「明顯」更好，還是只是「可能」更好？
- [ ] 如果是 E：我是「有疑慮」，還是已經「確認錯誤」？
- [ ] 如果是 F：這是制度約束，還是對企業的負面判斷？
- [ ] 賣出後，我要把錢放在哪裡？那裡真的比較好嗎？
- [ ] 稅負與交易成本是多少？
- [ ] 如果不是企業變差，我是否在重複「過早賣出好企業」的錯誤？
- [ ] 這個決定，是不是受到股價波動、新聞或別人意見的影響？
