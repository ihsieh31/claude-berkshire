# 18 方法的演進、適用版本與人物差異

> **定位**：本檔是思考背景，不是規則；與 `../../SKILL.md`、`../procedure/`、`../rulebook.md`、`../rule_index/` 衝突時一律以前者為準（SKILL.md 優先序）。尤其：前半（步 0–8、G1–G6、閘門 3 問卷）價格盲，本檔以價格、市值、倍數為條件的句子只能在 G7 起使用；宿主（小資金模擬）不做套利、困境債、統計籃子、優先股／可轉債、試探部位；持有與賣出依 SKILL §6。

> 何時讀：當你需要決定「該用哪一個時期的方法」（小資金 vs 大資金、深度價值 vs 品質複利）；當兩條原則看起來互相矛盾時；當你想知道巴菲特與芒格（以及接班團隊）在哪些議題上看法不同時。
>
> 核心觀念：這套框架不是一套靜止的教條，而是**經過數十年事實修正的方法**。修正的驅動力始終是「事實或前提改變」，而不是短期績效。正確使用它的方式，是理解每一條原則成立的**前提**，然後判斷你目前的情境符合哪一個前提。

## 一、方法的主要演進軸線

### 1. 從「便宜」到「好企業的合理價格」
- **早期（小資金）**：以葛拉漢的量化方法為主——買價格低於淨流動資產、低於帳面、統計上便宜的股票（雪茄菸蒂）；以私人所有者價值為錨；分散在數十檔。
- **轉變的原因**：
  1. 符合條件的深度價值股越來越少；
  2. 資金規模變大，小型便宜股無法容納；
  3. 經營或持有爛生意的痛苦經驗：「不能把豬耳朵變成絲綢」；
  4. 合夥人的勸告：「加入以合理價格買到的優秀企業，放棄以優秀價格買到的普通企業」；
  5. 質化研究（拜訪管理層、詢問競爭者與供應商）的價值被證實。
- **後期（大資金）**：「以合理價格買優秀企業」為預設；「先要生意好，再要經理人好」；「所有投資都是價值投資」——價值不再只是低本益比或低市淨率，而是「現在付出」與「未來現金」的比較。
- **保留的部分**：價格紀律從未放棄；而且這個轉變沒有清楚的分界，有時仍會回到撿便宜的老習慣，結果從還可以到很糟。

**適用指引**：
- 資金很小（能投入小型、冷門標的）、且願意下功夫時，深度價值與雪茄菸蒂仍可能有效。（宿主覆寫：宿主雖是小資金，仍不用統計便宜籃子與雪茄菸蒂，C 級最多觀察，SKILL §9、rulebook §5.0）
- 資金大、或希望長期持有複利時，以品質優先、合理價格為預設。
- 不論哪一種，「便宜」本身永遠不是單獨的買入理由（見 15 錯誤二）。

### 2. 規模：從優勢到最大的限制
- 「規模是績效的錨」；「胖錢包是優異投資結果的敵人」；「隨著資產增加，預期報酬下降」。
- 小資金時，一個好點子可以讓年報酬提高一大截；大資金時，同樣的點子幾乎沒有影響。
- 規模迫使：只能買大型企業或大企業的一部分；收購門檻（規模與最低稅前盈餘）隨之上升；部位下限提高；機會越來越少。
- 小資金時期的合夥人甚至主動限制規模、拒絕新資金，因為新資金會稀釋報酬。
- **適用指引**：評估任何投資人或公司的未來報酬時，以「規模會壓低報酬」為前提，不要用過去的高報酬外推；小資金投資人反而擁有大資金沒有的機會集合。

### 3. 績效期望：持續下修
- 早期設定「每年領先指數十個百分點」的目標，之後多次承認這個領先幅度無法長期維持，再下修為「年報酬九成或領先指數五個百分點，取其小者」，最後完全放棄相對目標，改以每股內在價值成長與保守的絕對報酬為基準。
- 後期：「豐收的年代永遠不會再回來」；若實際報酬只有中個位數，也應該滿意。
- 評估期間：三年是絕對最低，五年較佳。
- **適用指引**：不要以「打敗指數 N 個百分點」為目標；以保守、可檢驗的絕對報酬與內在價值為準。

### 4. 衡量指標
- 從「單年營業盈餘 ÷ 股東權益」改為「經濟盈餘」、「透視盈餘」與「每股內在價值」；
- 從以每股帳面價值作為主要追蹤指標，改為放棄帳面——因為業務從有價證券轉向全資擁有的企業，帳面嚴重低估；回購也會讓每股帳面下降、每股內在價值上升。
- 留存盈餘測試從「每留存一元創造一元市值（以市價計）」修正為更穩健的版本（以內在價值、多年期間判斷）。
- **適用指引**：會計數字是起點，內在價值是終點；每次比較時檢查指標定義是否改變。

### 5. 回購
- 從積極主張回購 → 長期停滯（價格不夠低）→ 以帳面價值倍數作為上限（一段時間內設為帳面的一點一倍、一點二倍）→ 最終改為「價格低於保守估計的內在價值、且現金充足」兩個條件，帳面門檻被宣告「過時」。
- 即使股價有明顯折價，若不比先前更有吸引力，仍不回購。
- **適用指引**：以內在價值判斷；帳面倍數只是歷史上的權宜代理指標。

### 6. 收購的支付方式
- 早期曾用自己的股票收購 → 多次承認是錯誤（付出的比得到的多）→ 「寧可去做大腸鏡檢查也不要發行股票」→ 只在極少數特殊情況（自己的股票被高估、或標的極具戰略價值）例外。
- 收購門檻隨規模不斷提高；內部再投資的報酬預設優於外部收購。

### 7. 保險與浮存金
- 從「浮存金幾乎免費」的高峰語氣 → 改為條件式：「只有在承保打平或獲利、利率正常時，浮存金成本才接近零」。
- 巨災承保：從大量承接 → 價格不足時大幅縮減 → 承認曾經沒有為人為巨災定價 → 最新立場是「價格不足時就收縮，價格合理時大量承接」。

### 8. 衍生品與槓桿
- 早期即警告衍生品風險 → 稱其為「金融大規模毀滅性武器」並退出一個龐大且看不懂的衍生品帳簿 → 在嚴格條件下選擇性地「賣出」定價錯誤、預收權利金、幾乎不需擔保品的長期合約（以保險的眼光看待）→ 當新規要求全額擔保時明確停止。
- 借款槓桿：始終極低；「年輕人知道規則，老年人知道例外」——即使承認少量槓桿在例外中可用，仍主張大多數人應避免。

### 9. 能力圈與科技
- 早期：完全不碰科技（「我們不懂」「不在能力圈」）→ 用簡單可檢驗的測試（例如「它明年能不能賺到某個數字」）區分泡沫 → 承認錯過了幾家具有可理解經濟特性的科技公司 → 把具備生態系與定價權的消費科技當作「消費品公司」來理解並大量持有 → 最新：「不會因為是科技股就排除，但必須理解營運、加值來源與資本強度；不為 AI 而 AI」。
- 產業標籤不是永久的：某些過去被視為「爛產業」的行業，在結構集中後可能改善；但改善不等於值得永久持有。
- **適用指引**：能力圈是底線，但能力圈可以透過學習擴大；不要因為產業標籤而永久排除，也不要因為潮流而越界。

### 10. 總經與通膨
- 長期擔心通膨與利率上升，但多次承認「我一直錯了」（例如沒有預期到零利率會維持多年）。
- 結論被強化而不是推翻：**不要以總經預測做決策**；估值以「股東權益報酬與利率能否維持」為條件。

### 11. 海外與外匯
- 從幾乎不投資海外 → 一度大量持有外匯部位看空本國貨幣（承認持有成本昂貴）→ 改為偏好在多種貨幣賺錢的企業 → 對個別海外市場（尤其股東權益報酬改善、價格極低的市場）以單一公司為單位評估，並以當地貨幣負債融資達到貨幣中性。
- 從「低市淨率市場不吸引人（因為 ROE 低）」到「當價格荒謬地低、公司開始回饋股東時大量買入並長期持有」——前提改變了。

### 12. 指數化
- 早期懷疑 → 承認「對多數人是合理預設」→ 同時提醒：如果幾乎所有人都指數化，它就不會一直有效；指數基金掌握投票權的治理問題。

### 13. 股利
- 唯一一次發放股利被事後稱為錯誤；原則穩定為「能以高於一元的價值再投資就保留；不能時就回購或配發」。

### 14. 接班與資本配置
- 從「由控制股東延續哲學」→「股份分期捐給基金會、家族不參與經營」→ 資本配置責任完全交給接班的執行長，董事會監督並在必要時修正錯誤。
- 文化與股權結構是延續的主要防線。

## 二、互相矛盾的原則：如何調和

| 看似矛盾 | 調和方式 |
|---|---|
| 「便宜」vs「好企業合理價」 | 好企業優先；只在小資金、明確低於清算價值、且不需長期持有時才考慮雪茄菸蒂（宿主不做） |
| 「集中」vs「分散」 | 有能力深入研究、能力圈內高確信者集中；不積極或無法研究者廣泛分散於低成本指數 |
| 「長期持有」vs「賣出」 | 好企業長期持有；只有在基本面改變、價格極度高估、有明顯更好機會、或管理層誠信出問題時賣出（見 07） |
| 「不預測總經」vs「承認利率決定估值」 | 不預測利率方向；但以當前利率與保守假設估值，並測試利率上升時的韌性 |
| 「現金不是好資產」vs「永遠保有大量現金」 | 最低流動性是硬性防線；超過防線的現金是「找不到好東西」的殘值，應持續尋找用途，但不為用掉而用掉 |
| 「衍生品是毀滅性武器」vs「曾賣出衍生品」 | 只有定價錯誤、預收權利金、無擔保品觸發、期限長、最壞損失可承受時才可能考慮；預設避免 |
| 「不懂不買」vs「買過不太了解的東西」 | 能力圈是底線；以結構保護（例如優先股）進入能力圈邊緣，或承認是錯誤 |
| 「不碰科技」vs「大量持有消費科技」 | 判斷依據是經濟特性能否被理解（生態系、定價權、可預測性），不是產業標籤 |
| 「低市淨率不吸引人」vs「在低市淨率市場大量買入」 | 前提不同：當股東權益報酬改善、價格荒謬地低、公司開始回饋股東時，前提改變 |
| 「不發行股票」vs「曾用股票收購」 | 承認多數是錯誤；只有收到的內在價值不低於付出時才例外 |

**通則**：當兩條原則衝突時，選擇**前提最符合當下事實**的那一條，並寫下為什麼。若前提無法判斷，選擇較保守、較不可能造成永久損失的那一條。（宿主：規則衝突只依 SKILL.md 優先序裁決——SKILL ＞ procedure ＞ rulebook ＞ rule_index ＞ knowledge；本通則只用於規則未涵蓋的思考題，不得用來推翻上位規則）

## 三、修正的方法論

1. **只因邏輯失效而改判，不因短期績效改判**：只要仍理解方法的邏輯，即使它很難應用也不放棄，即使這意味著錯過大量看似容易的利潤。
2. **事實改變時必須改判**：應刻意培養改變先前結論的能力，因為沒有它，災難常常會來。
3. **改判要寫下來並附行動**：退出、縮減、或重新檢驗前提，並在給股東（或給自己）的紀錄中說明。
4. **檢查改判是否受誘因驅動**：若改判恰好發生在誘因迫使改變的時候，而非事實改變之時，應視為可疑。
5. **承認錯誤是常態**：越後期，公開承認的錯誤越多、越具體（「那是我的錯」）。

## 四、人物差異

### 一般版本（品質複利、能力圈優先）
- 方法從深度價值演進到品質複利；切換依前提判斷。
- 重點檢查：能力圈、管理品質、長期持有、監管協議（對受監管產業）。
- 錯誤須公開、具體承認；對科技與 AI 不懂就不買。
- 對個案中的審慎經營者可給予較高信任；危機中以資產品質判斷是否買入銀行。
- 不以總經、通膨與利率預測做決策，此類判斷可能錯誤。
- 價格紀律過嚴（為小差價錯過大機會）是常見錯誤類型之一。

### 集中派變體（重誘因與心理誤判）
- 方法由「便宜的普通企業」轉向「合理價格的優秀企業」，集中派變體以此為推動方向。
- **集中派變體的重點**：誘因的力量、心理誤判、多元思維模型、逆向思考、避免愚蠢、產業結構。
- 對會計、金融業、投資銀行、衍生品、高費用資產管理、加密資產採較嚴格立場。
- 新興市場與其企業可較早積極；平台型企業的未來報酬容易被高估，需打折。
- 集中持股可到兩三檔；對個人指數化的偏好較弱，但承認它對多數人合理。
- 槓桿：大多數人應避免。
- 對銀行：投資銀行股須有多項有利因素才進場（銀行比好的銀行家多）。
- 應擅長主動摧毀自己錯誤的想法。

### 接班執行長（營運型資本配置者）
- 「風險先行」：先看風險再看報酬，風險不清楚就不做；重大案子先準備一頁紙列出主要風險。
- 以十年視窗檢查安全邊際：十年後是否仍有安全邊際？
- 營運卓越、技術與 AI 的務實應用（「不為 AI 而 AI」：人仍參與重要決策、結果可重現、必須加值）。
- 對受監管產業強調「像監管者一樣思考」、只在風險與報酬平衡時投入、新增需求的成本由需求方承擔。
- 延續文化、分權模式與財務實力；明確寫下價值觀。
- 在回購上加入向大股東直接收購大宗股份的手段。

### 保險負責人（大型異常風險承保者）
- 「大部分時候要說不」，但偶爾有值得大量投入的機會。
- 無資料風險的承保流程：先用歷史數據 → 主觀估計並保守化 → 設定曝險上限 → 只在安全邊際足夠時承保 → 由最終資本負責人確認。
- 不搶第一：「我們不是最快或第一個行動者」——無法建模的新風險（例如網路保險的聚合風險）暫不進入。

### 投資組合經理人（較年輕的接班投資人）
- 管理一部分有價證券組合，承襲同樣的價值框架；部分持股（尤其中小型、或經理人自有判斷的標的）可能不完全代表主要決策者的風格。
- **含意**（見 16）：分析這套框架的實證持股資料時，要區分主要決策者的部位與其他經理人的部位；後者在估值或品質特徵上可能與主要風格不同。

### 兩位創辦者的共識（最重要）
- 能力圈、安全邊際、市場先生、長期所有權、誠信第一、避免槓桿與致命風險、不預測總經、理性高於聰明、持續學習與修正。

## 五、使用本框架時的版本選擇（給 agent）

1. **先問資金規模與流動性需求**：小資金可以使用古典的四類工具（見 17；宿主不用，SKILL §9）；大資金以優秀企業的長期所有權為主。
2. **先問投資人的能力與時間**：無法深入研究者，以低成本指數為預設；能深入研究者，集中於能力圈內的少數高確信標的。
3. **以後期修正過的原則為預設**（品質優先、內在價值回購、現金收購、條件式浮存金、衍生品避免、不以帳面為主指標）。
4. **早期原則只在其前提成立時使用**（小資金、深度折價、可清算資產）；套利、優先股等工具依執行限制不動作。
5. **遇到矛盾時**，回到第二節的調和表；仍無法判斷時，選擇較不可能造成永久損失的一方（宿主：規則衝突只依 SKILL.md 優先序裁決——SKILL ＞ procedure ＞ rulebook ＞ rule_index ＞ knowledge；本通則只用於規則未涵蓋的思考題，不得用來推翻上位規則）。
6. **任何修正都要有事實依據並記錄**。
