# 17 特殊情境與其他工具

> 何時讀：當機會不是「以合理價格買入優秀企業的普通股」這種標準形式時——併購套利與公司事件（workouts）、控制型投資、雪茄菸蒂型低價股、危機中的優先股／可轉換證券／附認股權證的融資、困境債與垃圾債、零息債與長期公債、衍生性商品（買或賣）、外匯與商品部位、指數基金與個人理財、稅務、集團結構與股東政策。
>
> 核心立場：這些工具**都只是在特定條件下的補充**。它們的共同前提是：價格明顯錯誤、風險可量化、最壞情況可承受、自己理解結構。主力永遠是能力圈內優秀企業的長期所有權。
>
> **執行限制**：本檔只作辨識用。自動交易只做上市普通股；併購套利、優先股、可轉債、垃圾債、衍生品、放空、首次公開發行一律不動作、不自動交易。

## 一、投資類別的古典框架（小資金時期的完整工具箱）

早期以四類投資組成組合；它們的**長期預期報酬相近，差別在於與市場的關係與風險型態**。這個框架對小資金、願意下功夫的投資人仍然有效。

### 1. 一般低估股（Generals）——兩種
**(a) 相對私人所有者價值低估（Private Owner Basis）**
- 入門條件：整家企業的市場估值**大幅低於**仔細分析後「私人所有者願意付的價值」。
- 質性條件（次於量化，但重要）：「我們喜歡好的管理層、像樣的產業、原本沉寂的管理層或股東群出現一定的『騷動』——但我們要求價值。」
- 兩條獲利路徑（「弓上有兩根弦」）：市場重估，或累積到足以影響控制權、甚至被私人買家整體收購。
- 理想狀態：公司持續進步，但股價在你持續買進的數月甚至數年間一動不動。
- 風險：與大盤同步波動，**在下跌市場中最脆弱**；「便宜不代表不會跌」。
- 典型配置：五、六檔各佔總資產 5–10%，另有十到十五檔較小部位。
- 規模劣勢：大資金很難買到足量的小型低估股。

**(b) 相對低估（Relatively Undervalued）**
- 以相對同業便宜的價格買入品質相當或更好的公司。
- 特有風險：**估值標準整體改變**——同業估值整體下修時，即使買價看似合理，股價也可能長期停滯。要用方法降低這種重估風險。
- 承認這類判斷較「飄渺」，成果較不扎實。

### 2. 公司事件套利（Workouts）
- 結果取決於公司行動（合併、清算、重組、分拆、回購、要約收購），而不是市場漲跌。
- **只做已公開宣布的事件**：「我們等到能在報紙上讀到才行動」；不做謠言，不做內線，「不賭尚未發生的事」。
- 典型來源：大公司收購小公司、清算、要約收購、重組。
- 與市場關係：大跌時表現相對好、大漲時拖累績效；可以抵銷一般低估股的市場風險。
- **風險來源**：反壟斷或其他政府行動、股東反對、稅務裁定未下來、融資失敗、更高出價者退出、交易延宕。「一個案子失敗時，市值縮水很大，所以你承擔不起太多錯誤。」
- **借款**：對一籃子套利部位可以適度借款（因為與市場相關性低、期限可預測），但對一般低估股借款是非常危險的做法。自設借款上限（例如淨值的四分之一）。
- 部位數：通常同時持有五到十五個；但大資金時期因為分散很少，單一交易對年度結果影響很大。
- 經驗：「交易常比原先預期花更長時間，但報酬平均略好於估計。」
- 修正原則：**不要把「應該發生」和「會發生」混為一談。**

### 3. 控制型投資（Controls）
- 取得控制權時，「資產與盈利能力立即成為價值的主導因素；我們擁有的是一門生意，而不是一張股票」。
- 與大盤關係最弱，要以數年衡量。
- 資金越大，這類機會越多。
- 即使價格便宜，管理層平庸就不買；控制後可能需要換掉經理人、把不良資產轉換成較好的資產（例如把製造業的營運資產變現，轉成有價證券組合）。

### 4. 雪茄菸蒂（深度價值的終點）
- 以遠低於清算價值的價格買入：現金按全額、應收帳款打折、存貨大幅打折計算調整後淨值，價格仍顯著低於它。
- 一次性的「最後一口煙」，不是長期持有的標的。
- **後期修正**：除非資金很小、且你願意承擔管理與清算的麻煩，否則「以合理價格買好企業」遠優於「以便宜價格買爛企業」（見 15 錯誤二）。

### 類別配置
- 依市場水準調整：市場整體低估時偏重一般低估股（甚至適度借款）；市場明顯高估時，在獲利出現時減少一般低估股、提高套利部位。
- 各類別的組合結果「很大程度是運氣」，不要只用單一類別衡量一年的結果。

## 二、併購套利：四個問題與價格紀律

每一筆套利交易都要回答：
1. **事件發生的機率有多高？**
2. **資金會被綁住多久？**（年化報酬取決於時間）
3. **有沒有更好出價出現的可能？**（上方選擇權）
4. **如果事件失敗，會怎樣？**（下方損失——通常是主要風險）

### 規則
- 只做公開宣布的交易；不在消息階段卡位。
- 只在喜歡賠率時參與；市場過度樂觀、價差被壓縮、參與者蜂擁時站在場外（「蠢人衝進去的地方」）。
- 不參與反映過度樂觀的槓桿收購或「更大傻瓜」式的交易。
- 偶爾可以為了「上方選擇權」加碼（例如標的資產價值有一部分「介於零與很多之間」，偏向後者時）。
- 在套利研究過程中，若發現標的本身是一家由卓越經營者以清楚、理性策略經營的企業，可以把套利部位轉成長期持有。
- 要預期偶爾虧損；以組合（或長期大量交易）來看期望值，而不是單筆。

### 何時大量做套利
- 找不到好的長期普通股、手上有閒置現金、短期利率又很低時，套利是「停放資金」的合理去處——它的報酬來自交易完成，而不是市場上漲。
- 長期普通股機會多時，套利的優先順序下降。

## 三、優先股、可轉換證券與附認股權證的融資

### 適用情境
- **能力圈的邊緣**：對某些產業（投資銀行、航空、造紙等）是「不可知論者」——不完全看得懂、無法預測其盈餘，但信任經營者，就用可轉換特別股之類的結構參與：拿固定收益的保護，加上轉換權的上方。
- **危機中的流動性提供者**：當市場凍結、別人急需資金而只有你能「一通電話、當天付款」時，可以要求高票息優先股 + 認股權證（或股權參與）+ 有利的贖回溢價。
- **合作收購中的資本結構**：在與合夥人共同收購時，以高票息優先股（附權證）作為資本的一部分。

### 評估原則
1. **固定收益價值是主體**：「優先股的價值絕大部分在於它的固定收益特性」；轉換權是額外的價值。不要用轉換後普通股的市值直接定價。「這類證券的價值不會低於它作為非轉換優先股的價值。」
2. **發行人的信用是第一位**：這是一張優先證券，但不是安全資產——如果發行人的產業經濟很差，優先證券也可能損失大部分本金（「因為買的是優先證券而鬆懈分析、或因為自負，是馬虎的分析」）。
3. **產業經濟仍然重要**：在一個股東整體淨報酬為負的產業裡，即使是優先股，也可能連續多年不配息、需要大幅減值。
4. **條款**：
  - 票息（危機中可以要求高個位數到兩位數）；
  - 轉換價或權證行使價（愈接近危機低點愈好）；
  - 權證期限（愈長愈好，長期權證是巨大的選擇權價值）；
  - **贖回條款**：發行人可以提前贖回（甚至強迫你轉換），會讓你失去未來的上方——要求贖回溢價，或盡量延長不可贖回期；
  - 是否累積（非累積型對持有人較弱）；
  - 完全表決權（以轉換後計算）；
  - 是否受監理機關限制贖回或配息。
5. **流動性**：私下議定的優先股流動性很差；如果你是董事，還有資訊限制，不能自由交易。
6. **與直接買普通股比較**：事後檢視時，常常發現「如果當時直接買普通股，會多賺很多」——對真正有信心的優秀企業，**優先股的保護可能讓你付出巨大的機會成本**（事後最常見的後悔）。對有疑慮的企業，優先股才是合理選擇。
7. **用轉換權當作投資理由**是糟糕的決定；投資理由應該是企業本身與固定收益保護。
8. 被提前贖回是「不受歡迎的好消息」——收到溢價，但失去高收益。

### 檢查清單
- [ ] 若沒有轉換權，這個固定收益證券值得買嗎？
- [ ] 發行人在最壞情境下付得起票息與本金嗎？產業經濟會不會侵蝕它？
- [ ] 票息、贖回溢價、權證條件相對風險是否足夠？
- [ ] 贖回條款是否會在最壞時點剝奪我的上方？
- [ ] 如果我對這家公司真的有信心，直接買普通股是否更好？
- [ ] 我能在何種條件下退出？

## 四、債券：公債、零息債、垃圾債、困境債

### 一般原則
- 政府債券與短期國庫券「不是好投資，只是放錢的地方」。
- **只在兩種情況買固定收益**：(1) 信用錯定價（恐慌中的優質或可存活債券）；(2) 利率高到能補償通膨並有資本利得空間。
- 長期零息政府債在利率極高時可以鎖定高報酬，且在利率下降時有巨大資本利得；但它是對利率的部位，「利率上升你會慘重損失」——只在利率明顯偏高時、規模受控地做。
- 通膨保值債券可以用來表達對通膨的看法（例如相對做空一般公債），但這是少見的總經交易。

### 垃圾債與困境債
- **從不買新發行的垃圾債**：「新發行的垃圾債只有在沒有 y 的日子才能買」——新發行時價格最貴、條款最差、發行者最有資訊優勢。
- 不買弱信用者的新發行債券。
- **在市場恐慌時買已發行、深度折價、但企業仍有價值的困境債**：例如以面值的一半左右買入仍有資產與現金流支撐的債券。垃圾債市場崩潰、殖利率衝到極高水準時（極為罕見），是巨大機會。
- 與股票不同：買股票時預期每一筆都成功（因為只買保守融資、有競爭優勢、誠實能幹經營的企業）；**買垃圾債時預期偶爾會有大損失**，靠組合的整體期望值獲利。因此要分散、要估計每一筆的回收率、要有安全邊際。
- 當市場恢復、「昨日的雜草被定價為花朵」時，就不再有吸引力——停止買入。
- **陷阱**：
  - 「不付息就不可能違約」的結構（零息、實物支付 PIK）是危險錯覺；若稅前盈餘（扣除必要資本支出）無法覆蓋利息，就該「拉上錢包」。
  - 以 EBITDA 衡量償債能力。
  - 買入時未理解發行人產業的消費融資或信用環境已經惡化。
  - 把恐慌價格的高收益證券當成安全資產。
  - 為了追收益而在低利率時買低品質債或非流動替代資產。

### 自己發債
- 只在有大量機會可用、且能以低成本長期固定利率借入時；結構要避免讓股東受損（例如轉換權過度便宜）。若條件變得不利，提前贖回。

## 五、衍生性商品

### 一般立場
- 衍生品常製造而不是轉移風險；大規模、複雜、依模型估值、跨大量對手方的衍生品帳簿是「金融大規模毀滅性武器」：它們注入大量槓桿、讓對手風險不透明、應收應付可能極大。
- 「容易進場，很難離場。」看不懂的衍生品帳簿，唯一答案是退出——越早越好。
- 對金融市場的「現代化」或「創新」說法應保持高度警覺。

### 可以考慮「賣出」衍生品的嚴格條件（保險式思維）
只有同時符合以下條件，才可能把衍生品當作一種保險業務來承做：
1. **定價明顯錯誤**：市場的標準模型（例如對極長期的指數賣權）系統性高估了你判斷的風險。
2. **預先收取全部權利金**，形成類似浮存金的長期資金。
3. **不提供或只提供極少擔保品**：不能有在評等下降或價格不利時要求立即交出大量現金的條款。
4. **期限很長**、且只在到期時結算（避免中途的強制平倉）。
5. **最壞情境的損失可承受**（即使標的指數腰斬甚至更糟）。
6. 數量少、自己知道每一份合約。
7. 接受帳面盈餘因為按市值計價而劇烈波動。
- 即使如此，也要承認：其中某些部分可能虧錢；「放棄一些額外權利金，換取較小的尾端暴露，是值得的」。

### 賣出賣權作為買入工具
- 對願意以更低價格買入的優秀企業，可以賣出賣權收取權利金——但事後檢視常發現「若當初直接買股票會更好」；對真正想擁有的企業，直接買通常勝過賣賣權。

### 避險
- 為保護正常經營風險的避險（例如經營中的匯率或燃料暴露）是正常的；**為平滑盈餘而避險不是好理由**。
- 母公司層級不對商品做避險；營運子公司自行決定。

## 六、外匯、黃金與商品部位

- 外匯：不押注匯率；長期對所有法定貨幣的購買力保持懷疑，但這通常不轉化為部位。曾持有的大型外匯部位因利差成本，是「昂貴的表達方式」。以海外盈餘的企業提供自然避險；以當地貨幣負債為海外部位融資以達接近貨幣中性。
- 黃金：非生產性資產，不持有。
- 商品：極少數情況下，當供需明顯失衡（例如需求長期超過產量加回收、庫存持續耗用）時曾直接持有實物或期貨；結果承認「買太早、賣太早」，且「我們對商品價格所知甚少」。不作為常態工具。
- 詳見 13。

## 七、指數基金與個人投資者

- **對不積極或不專業的投資人，低成本的廣泛指數基金是預設答案**：長期持有、定期投入、不擇時，幾乎會勝過大多數專業管理人與顧問（因為費用與摩擦）。
- 費用的力量：每年 1% 的費用，在數十年間會讓最終財富減少相當大的比例；扣除所有成本後，只有極少數經理人能長期打敗指數。
- 對願意投入大量時間、有能力與氣質的個人：「最好的個人投資方式是以合理價格買入少數優秀企業」，持有兩三檔到少數幾檔就夠；「小規模地尋找被忽略的機會」是可行的方法，大規模則越來越難。
- 沒有一體適用的策略：每個人要依自己的能力、邊際效用與心理選擇；先誠實評估自己的能力水準。
- 理性與紀律本身就帶來一定的順風；不必寫複雜的系統。
- 個人理財守則：
  - 不用選擇權、不用保證金、不借錢投資；
  - 遠離高利信用卡債務（能穩定賺到高於信用卡利率的報酬者極少）；
  - 最好的投資是投資自己（技能、健康、名聲）；
  - 個人負債只用於可負擔的房貸；
  - 降低期望是最好的防衛。
- 投資管理行業：整體而言，扣除費用後對所有客戶合計沒有附加價值；少數人能加值，前提是集中重倉、敢於「叫牌並下重注」。被相對基準衡量、可隨時被客戶開除的經理人，很難做到集中與長期。

## 八、稅務

- 稅是真實成本，必須納入稅後報酬與估值；但「過度節稅是真正愚蠢錯誤的主要來源之一」。
- 不為了節稅而買賣、不為了延後納稅而持有已經不值得持有的部位、也不為了實現利得而賣出仍被低估的優秀企業。
- 長期持有的稅務優勢：未實現增值的遞延稅等於一筆無息貸款，讓複利在更大的基數上進行——這是低換手率的重要好處。
- 公司結構與稅：在雙重課稅結構下持有某些資產（例如房地產）效率低；集團內部資本可以在無稅下移動，是集團結構的優勢。
- 稅收抵免型投資（例如再生能源、低收入住宅）只有對有足夠應稅所得的投資人才有經濟效益——評估時要問：這筆投資的經濟性是否完全依賴稅收抵免？抵免政策改變會怎樣？
- 依賴「法律意見」的避稅結構不能免除責任；把規則彎到接近詐欺是品格紅旗。
- 預期未來稅率上升時，可以把稅率背景納入出售決策（但這是特定情境，不是通則）。

## 九、集團結構、控股公司與股東政策（評估控股公司或設計自己組合時）

### 集團形式的優點（謹慎使用時）
- 資本可以在無稅、低摩擦下，從再投資機會有限的業務移到更有前景的地方。
- 不受單一產業的歷史偏見與既得利益束縛。
- 可以同時購買整家企業與優秀企業的部分股權，選擇面極廣。
- 小總部、分權營運：資本配置集權、營運分權。

### 集團形式的壞名聲（應得的）
- 經營者用高估的股票換低本益比公司的股份，藉會計讓每股盈餘「自動」成長；為了維持這個遊戲，只能不斷收購越來越平庸的生意。評估任何集團時，問：成長來自真正的經濟價值，還是來自估值差與會計？

### 評估控股公司的問題
- 總部是否很小？營運是否真的分權？
- 資本配置者是否理性、以每股內在價值為唯一目標？
- 收購用現金還是股票？
- 子公司經理人是否有自主權、長期留任、像所有人一樣思考？
- 是否幾乎不賣子公司、不強迫經理人退休、不頻繁調動？
- 低負債、幾乎完美的信用、在危機中仍有現金與信用可用？
- 文化是否能在創辦人離開後延續（價值觀明確、股權結構能防止文化被改變）？
- 接班人是否已選定，董事會是否能在必要時修正錯誤？

### 股東政策的訊號
- 好的訊號：不提供盈餘指引；所有股東同時、平等取得資訊；不與分析師私下溝通；不評論傳聞；吸引長期個人股東；不為了刺激交易而拆股或做市值管理。
- 壞的訊號：管理層希望股票頻繁交易、追求股價最大化而非價格貼近內在價值、頻繁發布預測與「指引」、選擇性揭露。

## 十、危機中的特殊機會（綜合）

- 危機時有三種機會同時出現：
  1. 優秀企業的普通股被錯殺；
  2. 優質但急需資金的企業願意以高成本融資（高票息優先股、附權證、次順位債）；
  3. 恐慌中被拋售的信用工具（垃圾債、困境債、結構商品）。
- 優勢來自：可信的即時付款能力（「我們的支票一定兌現」）、不需要任何人批准、能在一天內做出大額決定。
- 要點：
  - 平時保持大量流動性與完美信用，才能在危機中成為「最後一站」；
  - 只做能估值、能理解結構的交易；對收到的大量求援電話保持選擇性；
  - 不因為價格便宜就忽略發行人的長期經濟；
  - 不要把危機中的高收益證券當作安全資產。

## 十一、特殊情境總檢查清單

- [ ] 這筆交易的報酬來源是什麼（企業成長、事件完成、信用回收、利率、波動權利金）？我理解它嗎？
- [ ] 如果是套利：機率、時間、上方、下方各是多少？事件已公開宣布嗎？
- [ ] 如果是優先股／可轉債：沒有轉換權時值得買嗎？贖回條款是否不利？發行人產業經濟如何？
- [ ] 如果是困境債：回收率估計？這是新發行（不買）還是已發行的恐慌拋售？我是否以組合方式承擔偶爾的大損失？
- [ ] 如果是衍生品：權利金預收嗎？有擔保品條款嗎？期限多長？最壞損失是多少？我能說出每一份合約嗎？
- [ ] 是否有隱藏的槓桿或期限錯配？
- [ ] 這筆交易是否只是在追逐收益或刺激？
- [ ] 跟「以合理價格買入優秀企業普通股」相比，它真的更好嗎？
