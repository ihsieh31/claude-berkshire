# 05 安全邊際、買進價格紀律與買點

> **定位**：本檔是思考背景，不是規則；與 `../../SKILL.md`、`../procedure/`、`../rulebook.md`、`../rule_index/` 衝突時一律以前者為準（SKILL.md 優先序）。尤其：前半（步 0–8、G1–G6、閘門 3 問卷）價格盲，本檔以價格、市值、倍數為條件的句子只能在 G7 起使用；宿主（小資金模擬）不做套利、困境債、統計籃子、優先股／可轉債、試探部位；持有與賣出依 SKILL §6。

> 何時讀：已經判斷一家公司是好生意、也估出價值區間，現在要決定「這個價格能不能買」「要等嗎」「要買多快、多少」時。

## 一、核心原則

**價值 > 價格，而且差距要大到足以吸收你的估值誤差。** 這就是安全邊際。價格是買方唯一能控制的保護。

- 「買價要便宜到即使只是平庸地賣出，也有好結果；好的賣出只是錦上添花。」不要指望做出好的賣出。
- 價格越低，風險越小、報酬越大。這和學術上「高報酬必須高風險」的說法相反。
- 價值只比價格高一點點（例如價值 83、價格 80）不算有安全邊際。
- 「你可以付太多而把任何投資變成爛交易；但你無法因為付得少，就把任何投資變成好交易。」
- 同樣的行為，在一個價格是聰明的，在另一個價格是愚蠢的。

## 二、安全邊際要多大：取決於不確定性

- **理解越完整、企業越可預測，需要的安全邊際越小；業務波動越大、越不確定，需要的安全邊際越大。**
- 橋樑比喻：不要把 9,800 磅的卡車開上標示承重 10,000 磅的橋；要找標示 15,000 磅的橋。若橋跨越的是大峽谷（後果嚴重），要更大的餘裕。
- 極度可預測、不太可能嚴重估錯的優秀企業，可以接受較小的折扣。
- **如果一家企業的競爭結構不確定到連數字都算不出來，不要用「更大的安全邊際」去補，而是去理解更好的東西。**
- 安全邊際有四種來源：
  1. 現價低於自動買進上限（＝min(P2′, k × IV_base)；P2′＝g_impl ≤ 10% 的最高價，k＝A 0.95／B 0.85，見 SKILL §3 與 procedure/05_valuation_caps.md）；
  2. 估值時採用悲觀假設（例如假設負面趨勢會加速）；
  3. 財務實力（夠多的股東資本、不靠借款），讓你能熬過短期波動；
  4. 單筆的折價（以買價上限為準），加上組合中少數但獨立的部位。
- 最新的表述：安全邊際要問「十年後還在不在」。如果十年後這筆投資已經沒有安全邊際，現在就不要做。先問「風險在哪裡？我們真的理解風險嗎？」

## 三、經驗數字（校準用，不是門檻；買進依據仍是買價上限）

| 情境 | 價格相對於估計內在價值 |
|---|---|
| 理想但罕見 | 約 40%–50%（以 40 美分買 1 美元） |
| 會「花很多錢」的區間 | 低於估計價值約 25%–30% |
| 很難出錯 | 約 80% 以下 |
| 對回購（自家股票）而言，以 90 美分買 1 美元有幫助；以 1.10 美元買則傷害股東 | |
| 葛拉漢式強安全邊際 | 市值 ≤ 私人擁有者估計價值的 1/3 |
| 大部分實際買進 | 往往只比價值低一些（「我們喜歡 40 美分，但大部分是接近 1 美元買進」）——差距小時必須依靠企業品質與可預測性 |

其他經驗值：
- 價值 1,000 卻只賣 350：仍須確認低於買價上限，但不需要多做精算；價值 400 只賣 350：要非常仔細地分析。
- 估值區間是 30–110 這麼寬時，區間本身沒什麼用；只有現價低於買價上限才行動。
- 景氣循環企業：以正常化盈餘判斷價格，不在好年份以高點盈餘買。
- 報酬參考（校準用，不是門檻）：「至少約 10% 稅前（約 6.5%–7% 稅後）的高度機率」只作參考，不作排除篩子（折現與門檻見 SKILL §3 `r_d`）。
- 整體市場：總市值/GNP 等指標僅作環境參考，不作買賣或擇時依據（見 knowledge/13、rule_index/06 MKT-010～015；SKILL §1 鐵律 7）。

## 四、好企業的合理價 vs 平庸企業的便宜價

- **「以合理價格買一家好企業，遠勝於以好價格買一家普通企業。」** 這是整個方法最重要的演進。
- 便宜的平庸企業（「菸蒂」）只能抽一口：折價會隨時間消失，因為企業沒有再投資的能力；時間是平庸企業的敵人。好企業持續產生更多現金，時間是它的朋友，複利不依賴再找到一次便宜價。
- 統計上便宜的方法：
  - 在小規模、冷門市場仍然可行；
  - 規模大時不可行；
  - 符合條件的機會隨市場學習而越來越少；
  - 低 ROE 的企業即使買得便宜，長期也不會有好結果。
- 實證：主要決策者實際買進的公司中，「便宜但 ROE 低」的組合幾乎不存在（見 16）。
- 好企業不會一直便宜。必須在它被普遍承認之前辨認出來；等到人人都知道它是好公司，價格往往已經很貴（公認的優秀成長股若被追到高倍數，常見大幅回落）。
- 但：好公司若付出過高的價格，報酬仍會很糟。好生意不等於好投資。

## 五、等待肥球

- 投資沒有「好球必打」的規則。你可以一直看球，只在最佳的好球帶揮棒。揮最好的格子打擊率可以很高，亂揮最差的格子則很低。
- **沒有符合條件的機會，就什麼都不做。** 「不能因為今天找不到東西，就一定要做點什麼。」
- 不為了「錢進來了」而強迫投資。資金流入不是買進的理由。
- 不因為價格只便宜了 5%–10% 就改變決策，也不因為某天的價格就降低標準。
- 「耐心」不是「永遠不行動」。機會出現時，要極端果斷、下大注。「極端耐心加上極端果斷。」
- 「你無法讓天下雨，但下雨時你必須到場。」也就是平時要保留能力（現金、流動性、清醒的頭腦）。
- 「魚在哪裡就去哪裡釣」：有些市場或時期魚很多，不需要很好的釣技；有些已被過度捕撈，再好的技術也沒用。後期機會越來越少，往往只能取得微小的優勢。

## 六、市場先生

- 市場每天報一個價格給你，他情緒化：狂喜時報高價，恐慌時報低價。**他是來服務你的，不是來指導你的。** 他不介意被忽略。他越躁鬱，對你越有利。
- 「如果你不確定自己比市場先生更懂、更會評估這家企業，你就不該參與這個遊戲。」
- 投資成功的來源：良好的商業判斷，加上把自己的想法與行為和極具傳染性的群眾情緒隔離的能力。
- 「樂觀是理性買家的敵人。」在一片樂觀的共識中，你要付很高的價格。
- 逆向本身也是愚蠢的：「需要的是思考，而不是民調。」不是為了和別人相反而相反。
- 不設僵化的本益比門檻。設下數字門檻的人群，反而是機會的來源。
- 「因為股價上漲、或鄰居都賺錢而去買，是最危險的。」
- 「看看其他聰明人在買什麼」可以作為篩選線索，但不能成為決策依據。

## 七、大跌、恐慌與危機

- **市場下跌對長期買家是好事**，就像食品降價對持續買食品的人是好事。
  - 整體企業價格下降，同樣的錢可以買到更多價值；
  - 持有的好公司可以用更低的價格回購股票；
  - 已持有的好公司可以用更低價格加碼。
- 下跌時，先確認企業價值是否改變。若企業仍然表現令人滿意，且現價仍低於買價上限，下跌可成為加碼機會：既不恐慌，也不哀悼。
- 「普遍的恐懼是投資人的朋友，因為它端出便宜貨；狂熱的世界是你的敵人。」
- 買進理由只看現價是否低於買價上限，不看宏觀憂慮的高低（SKILL §1 鐵律 7、knowledge/13）。
- 「當天上下金子時，要拿水桶，不要拿頂針。」機會罕見，來時要大規模行動；事後回顧，常見的自我批評是「應該買更多」。
- **前提**：
  1. 必須有現金、沒有債務。「大跌的機會只屬於沒有債務負擔的人。」
  2. 必須能理解所買的東西。
  3. 必須有快速決定的能力與意願。在危機中，很多有錢的人因「癱瘓」而什麼都沒做。
- 現實：不可能買在最低點。危機中的買進常被事後評為「太早」，但只要價格遠低於價值，結果仍然好。期待保留全部資金、在谷底全部投入，是不切實際的標準。
- 實證：在幾次大空頭中，「大跌一定大買」並不成立；大跌期間的買進，多集中在大型、現金流穩定、資產負債表強健的企業，並常附帶保護性的交易條件（見 17）。
- 在困境中，通常應該買股票而不是買債（但條件極佳的債券或優先股也可以，見 17）。

## 八、不擇時、不預測，但價差出現時立刻行動

- 不因為市場會怎樣而買或賣，只看價格與內在價值。沒有人靠預測市場走勢而發大財。
- 不試圖抓底；「價格是我們的遊戲」。
- 不擇時 ≠ 不看價格：現價低於買價上限時，依建倉規則（目標部位 ≥3%，見 06）行動。
- 「在你得到很多價值時就買。」

## 九、狂熱與過高價格

- 現價高於買價上限時一股都不買，不因企業好而放寬。
- 但「我們最不想做的，就是以 100 倍盈餘買一家盈餘無法成長的公司」。
- 「在過熱市場買入，可能要很長時間，企業價值才追得上價格。」
- 狂熱不會自動製造低估：泡沫時期，高估值的地方不會同時出現大幅低估的好機會，沒有就不做。
- 檢查「是否過度擁擠」：一個好點子被太多人使用時，就變得危險。

## 十、買進時的心態測試與檢核

**心態測試**：「如果今天下午股市關閉五年，我仍然樂意持有它嗎？」「我不在乎明天或一年後的股價，我在乎的是企業經營得如何。」

**唯一應有的買進理由**：現價低於自動買進上限（min(P2′, k × IV_base)，SKILL §3）。

**買進前檢核**：
1. 價格、成交量與交易成本是否可行？會不會推高價格？
2. 有沒有即將公布的重大事件或敏感時點？
3. 是否需要借款？（答案應為否）
4. 有沒有更好的資金用途？（機會成本）
5. 如果錯了，我會在什麼訊號出現時知道？
6. 我能否承受買進後股價再跌 50% 以上？

## 十一、快速決定（以長期準備為前提）

- 「如果我們不能在五分鐘內做決定，五個月也做不出來。」
- 「你必須願意 5 秒掛斷，也必須願意 5 秒說 yes。」
- 錯價通常很短暫，所以要快速行動；一旦符合原則，就依建倉規則（首批為目標 50%）迅速行動。
- 快速的前提是：多年的閱讀與研究，已經事先定義好判斷參數，而且這門生意在你的能力圈內。不熟悉的東西，再便宜也不能快速決定。
- 「要敢下大口，只在邊緣打轉就是瘋狂。」

## 十二、遺漏的錯誤（Omission）

- 最昂貴的錯誤常常不是「買錯」，而是「看懂了、價格也對，卻沒買或買太少」。
- 常見的形式：
  - 因為現價已低於買價上限卻遲遲不建倉，結果錯過了長期複利；
  - 現價低於買價上限、而且無需借款、幾乎沒有虧損風險時，卻因為不願賣掉其他持股而猶豫。
- 遺漏的錯誤不會出現在財報上，但代價可能比看得見的錯誤大得多。只有在能力圈內才算遺漏；圈外的不行動不是錯誤。

## 十三、既有持股的加碼與換股

- **最好的買進，常是自己已經喜歡、已經理解的公司，價格回到買價上限以下。**
- 個股現價回到買價上限以下時，先加碼最喜歡的持股。
- 把價格較低的舊持股賣掉，換成同樣價格較低的新持股，沒有意義。
- 存在一個「不買也不賣」的區間：現價不值得加碼，但也沒有理由賣。
- 持續買進者希望股價下跌，以便買得更多。
- 心理陷阱：「賣掉之後想等跌回 85%–90% 再買回，結果永遠沒有再買。」
- 實證（校準用，不是門檻）：早期的加碼常發生在股價已經上漲、但估值相對初買時並未惡化的時候；後期加碼較常發生在股價下跌的季度。重點是**估值是否仍然有吸引力**，不是股價漲或跌。

## 十四、收購整間企業時的價格紀律

- 價格未知就不談，要求賣方先開價。
- 不參加拍賣。拍賣中的價格被社會證明與「怕失去」的心理推高。
- 控制型投資必須「內建利潤」：價格要留下寬的獲利空間，看起來接近就放棄。
- 不以綜效說服自己付高價，幾乎從不把綜效計入。
- 不會為同一筆交易出兩次價；被拒絕就走開。
- 「策略買家」往往是付太多的人；私募基金多手轉賣後的數字不可信。
- 部分持股在公開市場上常能以遠低於整間收購的價格取得同樣的盈餘能力，因為股市是會出現極端價格的拍賣市場；整間收購則經過談判，很少便宜。新上市股票（IPO）則是賣方挑選時機、接近談判價格的市場，很難找到便宜貨。

## 十五、財務面的安全邊際

- 不用保證金，不借錢買股票，「不讓任何人能把地毯從你腳下抽走」。
- 「第一原則永遠是，不論發生什麼事，明天都還要能繼續玩。」
- 要買就直接買，要賣就直接賣；不用選擇權的花招進出（例如想用賣出賣權「便宜一點」進場），因為股價常先跑掉，你就錯過了機會。

## 十六、買點決策流程（給 agent）

1. 確認在能力圈內、是好企業、管理層可信（01–03）。
2. 估出保守的價值區間（04）。
3. 以自動買進上限（min(P2′, k × IV_base)；P2′＝g_impl ≤ 10% 的最高價，見 SKILL §3 與 procedure/05_valuation_caps.md）為買價；現價必須低於上限才可買。等級係數 × 保守內在價值僅為報告欄位：
  - A、B 級（確定性）：現價低於上限即可考慮；
  - C 級：最多觀察，記錄上限；D 級：不做；
  - 看不清楚：不買，不要用更大折扣硬補。
4. 比較機會成本（G8，procedure/06 §2）：預期報酬（業主盈餘殖利率＋保守 g0）× 確定性係數，是否勝過加碼最佳持股（只算權重仍 < min(目標 T, 等級上限) 者，D14）、國庫券、大盤與觀察名單次佳？
5. 檢查財務面：是否需要借款？能否承受再跌 50%？
6. 檢查情緒面：我是因為恐慌、狂熱、別人在買、或股價剛漲才想買嗎？
7. 若通過：依確定性決定目標部位（06，目標部位 ≥3% 才建倉），分批買進，首批為目標 50%，這是執行節奏而非試探。
8. 若不通過：記錄「什麼價格我會買」，然後等待。

## 檢查清單

- [ ] 現價是否低於自動買進上限（min(P2′, k × IV_base)）？
- [ ] 企業的可預測性有多高？我需要多大的安全邊際？
- [ ] 這是「好企業的合理價」，還是「平庸企業的便宜價」？
- [ ] 景氣循環企業：我是否用了高點盈餘來算本益比？
- [ ] 我是在等肥球，還是因為手上有錢、想做點什麼？
- [ ] 這個買進是否依賴預測市場或總經？
- [ ] 若股價明天再跌 50%，我會加碼還是恐慌？
- [ ] 我是否因為現價剛好高於上限而想放寬？（若是，一股都不買。）
