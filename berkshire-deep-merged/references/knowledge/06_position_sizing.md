# 06 部位大小、集中與組合建構

> **定位**：本檔是思考背景，不是規則；與 `../../SKILL.md`、`../procedure/`、`../rulebook.md`、`../rule_index/` 衝突時一律以前者為準（SKILL.md 優先序）。尤其：前半（步 0–8、G1–G6、閘門 3 問卷）價格盲，本檔以價格、市值、倍數為條件的句子只能在 G7 起使用；宿主（小資金模擬）不做套利、困境債、統計籃子、優先股／可轉債、試探部位；持有與賣出依 SKILL §6。

> 何時讀：決定「買多少」、檢視組合集中度、判斷要分散還是集中、決定建倉節奏時。

## 核心立場

集中是刻意的設計，不是疏忽。只把錢投入通過三道篩選（優秀經濟特性、誠實能幹的管理層、合理價格）的少數公司，而且每一家都投入「有意義的金額」。沒有通過篩選的公司，不會因為「需要分散」而買進。

理由有四：
1. 好主意本來就稀少。真正有強烈長期信念的機會，一生只有少數幾個；遇到了卻只放一點點，等於浪費這次機會。
2. 分散會稀釋最好決策的效果。第 N 檔股票降低的波動，抵不過它拉低的整體期望報酬。
3. 集中逼你提高思考強度。要把大比例資金放進去，你必須比一般持股想得更深、更確定。這種強度本身就降低了風險。
4. 集中帶來較大的年度波動。這是可接受的代價，只要你能承受波動，就能換到更好的長期結果。

## 決定部位大小的判斷步驟

### 第一步：先問自己是否有評估能力
- 能理解企業並評估其價值的人：分散到「任何程度」都是錯誤，因為會稀釋最好的想法。
- 不能評估的人：應廣泛分散（低成本指數），定期、分批、等額投入，盡量少交易。不擇時、不在大小型股或國內外之間輪動。
- 「知道自己有限制的笨錢，就不再是笨錢。」承認不懂而分散，是理性的行為。

### 第二步：大部位的四個前提（全部要成立）
1. 對業務理解深入到「本質上幾乎沒有風險」的程度。
2. 理解到「願意買下整間公司」的程度。
3. 確定度高到不需要用高折現率來補償不確定性。確定度不夠，就縮小部位或不買，不要用更高的折現率硬算出一個價格。
4. 判斷是自己形成的，不是來自別人的推薦。

可以轉成三個自問：「我真的懂這門生意嗎？」「如果能買下整家公司，我會買嗎？」「我的把握是否足以承受一個大部位出錯的後果？」

### 第三步：用「最壞情境」定上限，而不是用固定比例
- 不採用現代投資組合理論的最佳化配置；固定上限依自動模式規則（確定性 A 級 15%、B 級 10%、C/D 不開倉）。
- 上限的思考方式：把單一部位（或高度相關的一組部位）讓整個組合大幅落後基準的機率，壓到極小。
- 第一名與第八名的想法要配置多少，取決於兩者的期望值差距，以及第一名出現極差結果的機率。
- 單檔權重 >15% 不加碼，>25% 完整複查（自動模式）。歷史上曾出現淨值約 40% 的單一部位，條件是：(a) 事實與推理正確的機率極高，(b) 任何事情大幅改變標的基本價值的機率極低（校準用，不是門檻）。超過 25% 的部位只在非常罕見的情況下出現（約每兩年一次，校準用，不是門檻）。
- 對個人或小資金而言，即使遇到「幾乎穩賺」的機會，自動模式下單檔上限仍依 A 級 15%。但這種機會一生只有幾次，不能把普通的好機會當成穩賺。

### 第四步：檢查流動性與進出成本
- 大部位建倉與出場都會推動價格。粗略的經驗值：每天只買到約該股日成交量的 20%，才不會明顯推高價格。
- 部位越大，越不能「靈活進出」。因此大部位的判斷，必須在買進前就完成；買進後的調整空間很小。
- 建立或處分一個大部位，可能要花一年以上。
- 大部位會被市場察覺並跟隨，提高建倉成本。

### 第五步：檢查持股比例的法規與約定門檻
- 持有被投資公司股權達到某些法定門檻（例如內部人申報、短線交易利得歸入、銀行控制權變更等），會帶來限制與成本。
- 這類門檻造成的減碼是「制度性」的，不代表看壞企業。分析時要把它和估值判斷分開。

## 組合層面的經驗分布（來自實際持倉數據）

以下是波克夏實際組合的統計特徵，可作為「集中到什麼程度」的參考，校準用，不是門檻：

| 指標 | 實際分布 |
|---|---|
| 前五大持股占股票組合 | 長期約 55%–80%，多數時間約 65%–75% |
| 前一大持股占股票組合 | 常見 17%–35%，高峰曾近一半 |
| 有效持股數（以 HHI 換算） | 約 7–8 檔 |
| 名目持股檔數 | 數十檔，但大部分是極小部位 |
| 主要決策者自己的子組合 | 前五大約 80%，比整體更集中 |
| 授權給其他經理人的子組合 | 前五大約 58%，較分散 |

從數據得到的部位規則：
1. **部位大小和持有期間高度相關**（相關係數約 0.53，校準用，不是門檻）。峰值低於組合 1% 的小部位，中位數只持有約 6 季，近半在一年內出場；峰值 3%–10% 的部位中位數持有約 26 季；10% 以上的部位中位數持有約 51 季。
  - 含義：大部位必須是你預期持有多年的公司。如果你沒有準備抱很多年，就不該建立大部位。
  - 含義：小的試探性部位可以存在，但要事先定義「要驗證什麼、驗證不成立就出場」。
2. **新部位的峰值大小**：中位數約占組合 0.4%，第 90 百分位約 2.5%。主要決策者的第 90 百分位約 5.3%。也就是說，真正的大部位是少數，而且是被「升級」上去的（校準用，不是門檻）。
3. **建倉節奏**：從第一季到峰值，中位數約 3 季；62% 的部位在第一季就買到峰值股數的一半以上。不是長時間慢慢攤平。執行上分批：首批為目標部位的 50%，其餘每批都要論點完好且價格低於買價上限（上述統計校準用，不是門檻）。
4. **加碼時的價格**：加碼的季度中，股價下跌的比例（約 49%）明顯高於沒有動作的季度（約 41%）。加碼只看現價是否低於買價上限，不以「股價下跌」本身為理由（上述統計校準用，不是門檻）。
5. **換手率**：每年賣出金額中位數約為組合市值的 7.5%。

## 先加碼舊的，再找新的

- 資金有限時，先考慮加碼既有的好公司，再考慮新標的。
- 機會成本的比較對象，是你手上「最不吸引的那一檔」。只有新機會明顯優於它，才賣它換新的。
- 「錢比點子多」時，不必一直重新檢視持股；「點子比錢多」時，要隨時比較手上最弱的持股和新機會。

## 「少數大決策」原則

- 一生的投資成果，來自極少數的大決策（大約五到十個）。
- 打孔卡思考：假設一生只能做 20 個投資決策，每做一個就少一個孔。這會逼你只在最有把握的地方下注，並且下重注。
- 一年找到一個好主意就足夠。沒有好機會時，就什麼都不做。
- 如果你真的懂企業，核心持股以 5–10 檔為限、最多 12 檔；如果不懂，就應廣泛分散。

## 資金規模決定策略型態

- 小資金（例如百萬美元以下）：可投資的範圍大得多，可以做小型冷門股、清算價值以下的股票、合併套利、特殊債券等。這些機會的報酬可能遠高於大型優質公司，但需要大量苦工。
- 大資金：只能做大型交易，可選範圍急劇縮小，規模會成為績效的敵人。
- 應用：投資 agent 必須先知道資金規模，再決定可用的策略工具。大型優質公司的長期持有策略，對小資金不一定是最高報酬的做法。

## 持股型態的偏好

- 寧可擁有優秀公司的一部分（非控股但可觀），也不要擁有平庸公司的全部。
- 部分持股在公開市場買進，價格受市場非理性影響，因此買進時機很重要；全資收購則在協商中定價，通常要付控制權溢價。

## 槓桿與集中的關係

- 不用借款放大集中部位。集中部位的風險，要靠「部位大小 + 買進價格 + 確定度」來控制。
- 槓桿的危險不在機率，而在極端情境：只要一次歸零，之前所有的成功都會被乘以零。
- 理論上，對「判斷正確時就是穩賺」的極少數情況，有人會主張用到 100% 以上的淨值；但幾乎所有人都應避免這麼做。

## 個人資產與機構資產的差別

- 個人（尤其是不需要再累積財富、而是要守住財富的人）：目標是安全感與流動性，不是報酬最大化。這時把大部分資產放在低成本指數、小部分放在短期政府債，是理性的選擇。
- 有能力且長期持有的人：可以高度集中於少數理解透徹的企業。

## 常見錯誤（檢查清單）

- [ ] 因為「要分散」而買了沒有通過篩選的公司？
- [ ] 對一個你不準備抱很多年的公司，建立了大部位？
- [ ] 用高折現率「補償」不確定性，而不是縮小部位？
- [ ] 對真正罕見的高把握機會，只放了一點點？
- [ ] 用借款放大了集中部位？
- [ ] 忽略了流動性：這個部位真的能在需要時進出嗎？
- [ ] 把法規門檻造成的減碼，誤判成對企業的負面訊號？
