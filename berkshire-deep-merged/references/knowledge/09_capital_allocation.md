# 09 資本配置：留存、回購、股利、併購與現金

> **定位**：本檔是思考背景，不是規則；與 `../../SKILL.md`、`../procedure/`、`../rulebook.md`、`../rule_index/` 衝突時一律以前者為準（SKILL.md 優先序）。尤其：前半（步 0–8、G1–G6、閘門 3 問卷）價格盲，本檔以價格、市值、倍數為條件的句子只能在 G7 起使用；宿主（小資金模擬）不做套利、困境債、統計籃子、優先股／可轉債、試探部位；持有與賣出依 SKILL §6。

> 何時讀：評估一家公司的管理層怎麼使用股東的錢；判斷回購是好是壞、股利政策是否合理、併購是否創造價值；以及設計自己組合的資金使用順序時。

## 一、總原則

- **資本配置是投資人與 CEO 的第一號工作。** 判斷標準永遠是機會成本：最佳用途要用「次佳用途」來衡量。
- 每一個配置決策的唯一檢驗：**它是否提高了每股內在價值？** 避免任何會降低每股內在價值的行動。
- 「資本配置的第一定律：在某個價格聰明的事，在另一個價格是愚蠢的。」不論錢是用在併購還是回購。
- 活動不等於成果。資本配置者多半時間是在等電話響。
- 為了「把錢用掉」而投資，是多數資本配置失敗的原因。

## 二、留存盈餘測試：每留一塊錢，要創造至少一塊錢市值

- 盈餘留在公司裡，只有在每留存一美元能為股東創造至少一美元市值（以多年滾動期間檢驗）時才合理。做不到，就應該分配出去（回購或股利）。
- 「留下一塊只值九毛錢的錢，是沒有道理的。」
- **要以結果事後檢驗**，因為每個管理層都會說「我們會用這些錢做很棒的事」。
- 不適用於短期（三個月、半年、一年），市場短期波動會讓檢驗失真。修正後的版本是看：(1) 多年期間帳面價值成長是否優於大盤；(2) 股價是否持續以溢價於帳面價值交易。
- 有的公司把留存的每一美元變成五毛，有的變成兩塊。這個差異決定了長期股東報酬。
- 留存不等於可信度：多留存、不配息，本身不證明管理層會善用資金。
- 規模越大，這個測試越難通過。

## 三、評估一家公司資本配置的判準

### 資金使用的理想順序
1. 把所有能有效（以高於資本成本的報酬）投入本業的資金用掉——這通常是最優先、報酬最高的用途；
2. 能以創造價值的價格做併購（偏好用現金、偏好買理解的業務、偏好擴充已知好經理人的業務）；
3. 回購價格低於內在價值時大量回購（評分口徑依 P-26a：回購均價 ≤ `IV_base` 不扣分、≤ 等級上限 −0.10 加分、> `IV_base` 且為主要資本用途扣分；屬價格面，前半 G5 只看回購級距與資金來源，價格面由 FULL_B 補評，見 procedure/02 §2、rule_index/06 MKT-064）；
4. 剩下的以股利分配。

### 判斷問題
1. **增量資本報酬**：每年再投資的錢，賺到多少報酬？本業能吸收多少資本？
2. **維持性與成長性資本支出的區分**：管理層能否說清楚哪些支出只是維持現有資產與競爭地位、哪些是真正的成長？維持性支出往往高於帳面折舊。
3. **資本效益的「第二步」**：一項投資計畫說「三年回本」只算了第一步；第二步要問：效益會留在公司，還是被競爭與客戶拿走？在商品化產業中，新設備的效益通常全部流向顧客，股東只拿到很低的報酬。若成功也不會讓股東受益的擴張，不該做。
4. **好錢不丟給壞錢**：管理層是否持續把資本投入報酬差的業務以「挽救」它？
5. **核心業務的高報酬是否掩蓋其他業務的爛投資**：一家公司若核心業務很好，管理層常把錢投到報酬很差的周邊業務；整體 ROE 看起來不錯，但增量報酬很差。這時寧可分配給股東，讓股東增加在優秀業務中的權益，避免參與次級業務。
6. **長期市值相對保留資本**：長期下來，市值增加是否與保留的資本相稱？若長期以低於保留資本的價格被定價，就是不利的判決。
7. **集團內資本調度能力**：能否把好業務多出來的現金，有效率、低稅負地移到別處的好機會？大多數企業做不到這點。

## 四、回購

### 好的回購
- **唯一判準**：回購後，留下的股東是否比回購前更富有。只有在股價明顯低於保守估計的內在價值時，回購才提高每股內在價值。
- 「若一家好公司在市場上的價格遠低於內在價值，還有什麼比擴大所有股東在此折價中的權益，更確定或更有利的資本用途？」
- 回購可以用遠低於收購整間公司的價格，取得同樣的盈餘能力（因為公開市場會給出極端價格，而整間收購要付控制權溢價）。
- 最成功的資本配置者往往很少做併購，常以回購作為最佳資本用途。
- 優秀企業（極少數真正的超級企業）在合理的高估值下回購，仍可能是好用途；但多數回購的企業是普通或平庸的企業。
- 子公司或被投資公司自己回購時，股東不用出錢就能提高持股比例。

### 壞的回購（紅旗）
- 在股價高時買、低時發股或發選擇權：「先低賣，後高買」。
- 為了抵銷選擇權稀釋而回購（不管價格多高）。
- 為了穩定或撐住股價而回購；為了讓每股盈餘好看而回購。
- 因為「公司有多餘現金」或「投資人關係部門建議」就回購。歷史上大量回購並非為了股東利益。
- 把資產負債表做到極限、借錢回購。
- 公司自身業務還需要資金、或有明顯更好的投資機會時仍回購。
- 回購前股東沒有獲得足夠資訊（內部人可能以低價從不知情的股東手上買回）。
- 「回購不是不道德，只是愚蠢」——當價格高於價值時。只為提升股價的回購極不道德；以公平價格、對現有股東公平的回購是高度道德的。

### 「money mind」測試
觀察一位管理者如何思考「是否應該回購股票」，是判斷他是否懂資本配置最好的單一測試。

### 實務細節
- 預告回購會推高股價、讓回購變得昂貴；好的資本配置者通常不預告具體數量。
- 小規模、小折價的回購對內在價值的提升有限（校準用，不是門檻：例如回購 2% 股份、折價 25%，只增加約 0.5% 的每股價值）。
- 回購規模取決於：可用現金、其他機會的吸引力、相對內在價值的折價程度；保留現金底線後才做。

## 五、股利

- 以「留存是否創造超過一美元價值」決定股利，而不是以固定配息率。不以固定配息率（如盈餘的 10%、20%、30%）配息，要嘛大量配發，要嘛不配。
- 企業預期盈餘超過可有利再投資的金額時，就應該配發；本業無法吸收資本的優秀企業（輕資產、低成長）應該幾乎全數配發或回購。
- **股利一旦建立就很難收回**，因為股東依賴其規律性；所以建立股利政策前要想很久。回購則較有彈性。
- 股利政策應該清楚、一致、理性；突然改變對依原預期持有的股東不公平。
- 對股東而言，配息 vs 自己賣掉一部分股票：後者讓每個股東自行決定現金需求，而且稅負通常較低。
- 一家公開宣稱「複利機器」的公司開始大量配息，等於承認它失去了繼續高報酬再投資的能力。
- 受監管、資本需求大的業務（例如需要持續擴建的公用事業）不配息、全數再投資可能合理，前提是監管保障合理報酬。

## 六、併購

### 原則
- 只在價格合理、得到的價值明顯超過付出的價值時才做。「希望每投入一美元創造三、四美元價值，但一點一美元也可以接受」；不做「九十分的決策」。
- 為了「必須成長」、「把資金用掉」、「建立版圖」而併購，是價值毀滅的主要原因。大型併購平均而言違反買方股東利益。
- **綜效多半不實**：預期被收購者在收購後以和過去相同的方式經營。不把綜效計入價格。
- 不以控制權價格買下會忽略長期經濟後果的業務。
- 寧可買到「兩美元不必揭露的盈餘」，也不要「一美元可揭露的盈餘」：會計上能不能並表，不決定價值。
- 收購好經理人旗下的補強業務（bolt-on），是低風險、高報酬的擴張方式。

### 以股票作為支付工具
- **只有在收到的內在價值與付出的一樣多時，才發行股票**（不論是併購、增資、可轉債或選擇權）。
- 自己的股票被低估時，以股票收購等於「付出兩美元的價值，換到一美元的價值」。「你不能用被低估的股票換一個被完整定價的股票，而不傷害你的股東。」
- 高估的股票是收購方的「假鈔」，對收購方有利，但對被收購方股東不公平。
- 會計上的每股盈餘稀釋常被過度關注；真正重要的是內在業務價值的稀釋。
- 避免價值毀滅的三條路：(1) 業務價值對業務價值的合併；(2) 收購方股價大於或等於內在價值時才用股票；(3) 收購後回購等量股份，等於把股票交易轉成現金交易。
- 常見的錯誤合理化：「被收購公司未來會值更多」「我們必須成長」「部分現金、部分股票讓賣方免稅」——都要逐一檢驗。
- 「幾乎每一次發行股票都是錯誤。」以自己優秀企業的股份去換平庸企業，會不可挽回地摧毀價值。

### 評估一家公司的併購紀錄
- 過去併購用的是現金還是股票？用股票時股價相對內在價值如何？
- 被收購業務在收購後的資本報酬是否達到預期？是否經常認列大額減損？
- 併購是否擴大了管理層的版圖與薪酬，卻沒有提高每股價值？
- 管理層是否誇大綜效？
- 管理層是否在市場最熱的時候大量併購？

## 七、現金

- **現金是等待時的預設選項，不是目標。** 持有現金，是因為沒看到值得用現金交換的東西，不是因為預測市場會跌。
- 不設固定的現金比例目標；「60/30 股債配置」之類的固定規則是胡說。
- 現金的兩個功能：
  1. 應對負債與危機的流動性（不依賴任何人的善意）；
  2. 危機時的選擇權：「願意付一點代價，換取在困難時刻有大筆資金可用的確定性」。
- 現金的機會成本很真實：長期持有的現金會被通膨侵蝕，「不會讓人流口水」。長期目標是擁有生產性企業，而不是國庫券；大量現金不代表撤退。
- 不為了多賺一點利息而降低現金的品質或延長期限（只持有最短期、最高品質的工具）。
- 現金累積太多時，要持續尋找機會，但「我們不喜歡現金過多，更不喜歡做爛交易，因為那會永遠待在那裡」。
- 挑戰在於「產生點子的速度要跟上產生現金的速度」。

## 八、給自己組合的資本配置順序（給 agent）

1. **先照顧已持有的最佳企業**：若既有核心持股現價仍低於買價上限，加碼它們通常是最好、最確定的用途。
2. **新機會**：通過完整篩選（能力圈、品質、管理、安全邊際）且在 G8 勝出的新標的（procedure/06 §2；已持有 10 檔時只記 `switch_candidate`，換股由人工決定，D12）。
3. **特殊情境**（若在能力圈內）：困境債券、有保護條款的優先股、明確的事件套利（見 17）。（宿主不做，SKILL §9、rulebook G0）
4. **現金與短期國庫券**：在找不到符合標準的機會時。

每個用途都以「次佳選項的報酬」作為門檻；達不到就不動。

## 九、資本配置檢查清單（評估一家公司）

- [ ] 過去十年，每保留一美元，創造了多少市值？
- [ ] 本業的增量資本報酬是多少？本業還能吸收多少資本？
- [ ] 管理層是否區分維持性與成長性支出？
- [ ] 回購是否只在股價明顯低於內在價值時進行？有沒有在高點大量回購、低點發股？
- [ ] 股利政策是否與再投資機會一致？
- [ ] 併購是否用現金、以合理價格、買理解的業務？有沒有用被低估的股票去收購？有沒有大額減損？
- [ ] 有沒有把好業務的錢持續投入爛業務？
- [ ] 現金是在等機會，還是被浪費、被囤積而沒有回饋股東？
- [ ] 管理層談到資本配置時，用的是「每股內在價值」的語言，還是「規模、版圖、每股盈餘」的語言？
