# 03 買進紀律、部位、建倉與宿主執行

> 本檔是 berkshire-way 規則書的參考檔；SKILL.md 每次必讀，本檔在對應閘門或動作需要細節時讀。規則書修改處以 ``、``、`` 標記，對照 `CHANGELOG_規則書.md`。
> 規則格式：**新編號 規則名** → 條件 → 動作 → 參數｜信心｜證據類型｜適用與例外。
> 證據類型只有四種：原文明文／多文本重複／持倉數據驗證／推論。標「推論」的數字是可調參數。
> 數字若與 SKILL.md 第 5 節參數表不同，以參數表為準（本檔已套用 規則書；標「舊版定版」處為上一版覆寫，若與「規則書」標記衝突，以 規則書為準）。所有「EPS／盈餘／P/E／ROE」依 SKILL 第 0 節全域營業盈餘口徑。
> 「模式 A／B／C」＝資金規模小／中／大，與確定性等級 A／B／C／D 不同；「宿主」＝小資金模擬宿主（單檔 15%、現金 5%、12 檔；無價格停損與移動停損：SKILL 第 7A 節 `stop_mode`＝A，論點破裂檢查）。
> 文中「v2」或「A」指上一版本 skill，「B」指另一份來源整理版本；兩者的編號只供追溯，不是本版規則。

## 1. 規則清單

### 1.1 何時買、好球區與等待

**POS-001　買進的唯一觸發是「品質關卡全過＋價格 ≤ 買價上限」。**
- 規則：標的已通過能力圈、硬排除、品質、管理層、估值各關，且現價 ≤ 事先寫入論點檔的買價上限 → 可買；任一條件不成立 → 不買（「觀察」）。總經、利率、他人預測、近期漲跌、手上現金多寡都不是買進理由。
- 信心：高｜證據：多文本重複＋原文明文
- 適用／例外：買價上限必須在看到即時報價前寫好；看到價格後才調整判準視為違規（B 03 原則 3）。

**POS-002　有吸引力的最低門檻：預期報酬顯著高於替代品（舊版定版）。**
- 規則：新部位的預期年化報酬（稅前）必須 ≥ `r_d`＝max（10%、長期公債殖利率 + 3 個百分點、次佳可得機會的預期報酬），且「很高機率」達到；不達標 → 不買，持現或加碼現有最佳持股。相對大盤的預期超額報酬 ≥10 個百分點／年＝「有吸引力的狀況」，**舊版定版：只作為部位大小的輸入（POS-030 的優勢差距），不是閘門**——若作閘門，會排除多數 A 級買進，與實際買價分佈不符。
- 信心：高（門檻存在）／中（數值）｜證據：原文明文（合夥時期「預期超越大盤至少 10 個百分點／年才算有吸引力」；至少 10% 稅前的極高機率）＋推論（長債 + 3pp）
- 適用／例外：資金規模大時誠實下修超額預期（MKT-042）。
- **規則書**：`r_d`＝max（10%，30 年期長債＋3pp）；「次佳可得機會」移出 `r_d`，只在 POS-021 比較。「預期超額 ≥10pp 有吸引力」改標「原文為合夥時期目標，不加槓桿時歷史上很少達成」；仍只用於排序，不是閘門。小資金、不加槓桿的目標：扣成本後年化超額約 2–5pp 已屬優秀；10pp 只作上限情境。｜審查：X30-14、X28

**POS-003　好球區要事先寫下，三分籃。**
- 規則：每個候選先分入「是／否／太難」三籃；只有「是」籃且全部條件逐條成立才進入部位決策；「太難」籃不再分析、不用更大折價補償。
- 信心：高｜證據：多文本重複
- 適用／例外：無。

**POS-004　沒有合格標的 → 等待，現金是合法結果。**
- 規則：找不到同時過品質與價格的標的 → 不買、不降低標準、不設定固定投入時程（不做「每月／每年一定要投入多少」）。等待期間持續研究並維持候選名單與買價上限，讓機會出現時能在一個交易日內決策。
- 信心：高｜證據：多文本重複＋原文明文
- 適用／例外：「現金多」本身永遠不是買進理由（v2 RISK-4.5 數據：出手規模與前一季現金水位幾乎無關）。

**POS-005　不空等崩盤；價格合理就行動。**
- 規則：好企業已低於買價上限 → 立即依 POS-030 建倉，不得以「可能還會更便宜」「等大盤回檔」為由延後。每次定期複核（每週一次或每次盤前）若候選已進入買價上限內而仍未下單，必須在論點檔寫出不買的具體理由。
- 信心：高｜證據：多文本重複（含自評的「不作為之錯」是最昂貴錯誤）
- 適用／例外：與 POS-004 不衝突：POS-004 管「沒合格就不買」，本條管「合格了不准拖」。

**POS-006　買進理由不得依賴總經或市場時點；外部行為依賴要單獨評估。**
- 規則：若論點需要「利率下降／市場回升／某政策出台」才成立 → 不買。若論點依賴某個外部主體（政府、監管者）的行為 → 把該行為列為獨立條件，只有能評估其可靠性且把握高時才買，否則不買。
- 信心：高（前半）／中（後半）｜證據：多文本重複
- 適用／例外：總市值相對經濟規模等整體估值指標只改變預期報酬與現金耐心，不改變個股買價上限（v2 D-12，本檔沿用）。

### 1.2 恐慌與下跌時的買進

**POS-010　恐慌是「重新排序所有選項」的訊號，不是「必須買」的訊號。**
- 規則：出現任一觸發 → 進入恐慌模式：(a) 大盤自近兩年高點回檔 ≥15%；(b) 單一產業或公司被錯殺（價格跌入買價上限、論點未變）；(c) 已持有的好企業跌 ≥20–30% 而基本面未變。動作：把「加碼現有持股、新標的、持現」重新依「價格 ÷ 保守價值」排序，買最便宜且通過全部關卡者。以價值折價衡量，不以跌幅衡量。
- 信心：高（原則）／中（15% 門檻）｜證據：多文本重複＋持倉數據（大資金時期新建倉多不在跌深時）＋推論（門檻）
- 適用／例外：只買不依賴特定援助就能存活的標的（v2 RISK-6.5）。大盤回檔門檻只是「啟動比較」，不放寬任何個股門檻。
- **規則書**：恐慌期投入只以通過全部閘門的個別標的計，不以現金比例或大盤跌幅定量；15%、20–30% 為推論參數。｜審查：X24

**POS-011　恐慌時的出手力度：分階段、不抓底、不跌破現金下限。**
- 規則：恐慌模式下，在數日到數週內把「下限以上的可動用現金」分 2–3 批投入通過關卡的標的；不以抓最低點為目標（太早買是常態）；任何時點現金不得低於 POS-050 的下限。
- 信心：中低｜證據：原文明文（「你不會抓到底部」）＋推論（規則書：普通股持倉數據沒有恐慌期加速投入；危機期大額部署多在優先股、私募與整體收購，不在季度持倉申報中；「1–4 季動用囤積流動性約 35–45%；單季 8–14%」是大資金時期行為描述，非部署目標；合法結論可以是只回購、淨賣出論點已破的持股或不動作）｜審查：X24、X20a
- 適用／例外：宿主每日新部位 ≤4 個，恐慌期也照守。

**POS-012　市場大跌時先加碼現有持股，其次才是新標的。**
- 規則：同樣「價格 ÷ 價值」吸引力下，優先加碼已完整理解、論點仍成立的持股；新標的必須在折價上明顯勝過加碼選項（見 POS-021）才排在前面。
- 信心：高｜證據：多文本重複
- 適用／例外：若現有持股已達宿主單檔上限 → 不能加碼，順延到下一個合格選項（POS-023）。

**POS-013　下跌只是加分項，不是必要條件；可向上攤平。**
- 規則：只要現價仍 ≤ 買價上限，或確定性已提高，就可以在高於首筆的價格加碼；不要求「跌了才買」。
- 信心：中高｜證據：持倉數據驗證（約三分之二到四分之三的加碼價高於首筆，依交易日成交價或季末價口徑；加碼季下跌比例只比基準高約 5 個百分點）
- 適用／例外：加碼的基本面門檻與新建倉相同，不放寬（v2 POS-6.5）。
- **規則書補充**（措辭／條件補充；審查 X23）：數字改為「約三分之二到四分之三（依交易日成交價或季末價口徑）」；規則本身不變。
- **規則書補充**（措辭／條件補充；審查 X24）：1.08 改為「約 1.1–1.2」

**POS-014　股價下跌與論點破裂分開判斷。**
- 規則：價格下跌而論點未變 → 可加碼（`stop_mode`＝A：無停損帶限制）；基本面、監管或結構條件惡化 → 停止加碼，交持有賣出（04）處理；禁止為扳平成本而加碼惡化中的生意。
- 信心：高｜證據：多文本重複
- 適用／例外：無。

### 1.3 機會成本

**POS-020　每個新點子先和「加碼現有最佳持股」比。**
- 規則：新點子必須回答「為什麼要它，而不是多買一點我最有把握的那一檔」。答不出 → 若最佳持股仍 ≤ 其買價上限且未達上限權重 → 加碼它；否則持現。
- 信心：高｜證據：多文本重複（芒格提出、巴菲特附和）
- 適用／例外：無。

**POS-021　統一比較表：所有用途用同一把尺（規則書補數值）。**
- 規則：每次部署資金前列出：(1) 新標的；(2) 加碼現有持股；(3) 短期國庫券（或宿主現金）；(4) 已公告事件型套利；(5) 低成本大盤指數。排序分＝預期報酬 × 確定性係數：預期報酬＝業主盈餘殖利率＋保守情境 g0；確定性係數 A 0.9、B 0.75、C 0.5（推論，可調 ±0.1）；國庫券係數 1.0、大盤 0.8；差 <1pp 視為同分，依品質優先。新標的要贏第二名才買。「次佳可得選項」只在本表比較，不進 `r_d`（VAL-031 規則書）。比較對象限決策當日實際可得選項；不得以過去最好交易、自身歷史買價或歷史最低估值作門檻。
- 信心：高（結構）／低中（係數）｜證據：原文明文（五類別無特別偏好）＋推論｜審查：X30-15、X30-14、X08
- 適用／例外：(5) 指數只作為「沒有判斷優勢」時的對照基準；agent 不自行停泊（見 POS-053）。

**POS-022　次佳點子不做；第 20 名不買。**
- 規則：持股排序中預期超額報酬明顯低於前幾名者（品質不接近前幾名）→ 不買；寧可把錢加到第 1 名（受上限約束）或持現。
- 信心：高｜證據：多文本重複
- 適用／例外：統計便宜型一籃子是唯一需要分散的例外，但在宿主環境下關閉（POS-044）。

**POS-023　宿主上限造成的「溢出」不得流向較差的點子（舊版補強）。**
- 規則：當最佳點子因宿主單檔上限（15%）買不足 → 溢出資金只能流向「同樣通過全部關卡、且 POS-021 排名在前」的下一個標的，或留為現金；不得為了把錢用掉而降低門檻買次佳點子。
- 信心：中｜證據：推論（由 POS-004、POS-020 與宿主上限合成）
- 適用／例外：宿主上限低於本 skill 上限時永遠適用。

### 1.4 集中度與檔數

**POS-040　依「懂不懂」決定集中或分散。**
- 規則：對每個部位能寫出明確、可檢驗的判斷優勢（為何市場錯、錯在哪個變數）→ 可集中；寫不出 → 不集中，該部位最多當現金替代、不放大，或改用低成本大盤指數。
- 信心：高（原則）／中（「無優勢不集中」的條件化）｜證據：多文本重複＋學術研究（規則書更正：同傾向只做多分散組合歷史上勝過大盤，但夏普低於集中的公開組合；寫不出優勢時用它代替集中是降風險，不是提高報酬）
- 適用／例外：無法客觀評估自身優勢時，採較分散的版本（B 05 矛盾 9）。
- **規則書補充**（措辭／條件補充；審查 X28）：改為「同傾向（便宜＋安全＋品質）的分散只做多組合歷史上勝過大盤，但夏普低於巴菲特的集中公開組合；寫不出優勢時用它代替集中，是降低風險而不是提高報酬」

**POS-041　核心檔數預設 5–10，有效檔數（1/HHI）≤10。**
- 規則：組合目標＝5–10 檔核心持股（可接受 3–15）；有效檔數目標約 5–7；前 5 大約占股票部分 60–90%。合格點子不足 5 個時，不湊數，其餘持現。
- 信心：高｜證據：原文明文（「懂的人 5–10 家」）＋持倉數據驗證（本檔自算：本人決策部位每季有效檔數中位 6.5、前 5 大中位 76%、權重 ≥3% 的部位中位 7 檔）
- 適用／例外：宿主最多 12 檔與單檔 15% 使「全額投入」至少需要 7 檔（95% ÷ 15% ≈ 6.3）；合格點子少於 7 個時，未投入的部分留現金，這是預期結果，不是錯誤。
- **規則書補充**（措辭／條件補充；審查 X24）：把「有效檔數目標約 5–7」改為「有效檔數常態 4–10（中位約 6），隨合格點子數浮動，不設目標值」；其餘保留

**POS-042　芒格變體：核心 3–6 檔（規則書加切換條件）。**
- 規則：切換條件＝（使用者要求或情境需要）且每一核心持股書面預期超額報酬 ≥ 約 10pp／年（可調 8–12pp）、確定性 A、可承受 −50% 回撤、每檔都寫得出可檢驗的優勢；任一不成立 → 維持核心 5–10 檔。切換時整組切換（3–6 檔、品質零例外、關閉統計便宜型），不得只挑單項；變體只移植集中度與品質門檻，現金下限、借款＝0、現金停泊照一般規則。權重隨優勢與確定性單調上升（凱利式方向），不採凱利公式數值（推論）。
- 信心：中｜證據：原文明文（條件：有優勢、想勝過平均時才集中）＋推論（3–6 範圍、10pp）｜審查：X19w、X19b、X19c
- 適用／例外：宿主 15% 上限下，3–6 檔最多只能投入 45–90%；變體下高現金是正常狀態。

**POS-043　不刻意分散、不機械再平衡。**
- 規則：權重因上漲變大 → 不是減碼理由；集中度下降只應是「新增合格部位」的結果，不是目標。減碼只能由估值、基本面、風險輪廓變化觸發（交持有賣出（04））。
- 信心：高｜證據：多文本重複＋持倉數據驗證（本人決策部位每一季的第一大持股都 >15%，中位 26.6%，多數因上漲形成）
- 適用／例外：見 POS-063（宿主下因上漲超過 15%）。
- **規則書補充**（措辭／條件補充；審查 X24）：保留「權重變大不是減碼理由」；刪去或改寫「多數因上漲形成」為「部分因上漲、部分為在高權重時續加碼」

**POS-044　統計便宜型一籃子在宿主環境關閉（舊版補強）。**
- 規則：統計便宜（C 級）標的需要 15–25 檔以上分散才成立；宿主最多 12 檔 → 不建立統計便宜籃子；C 級標的不開新部位。
- 信心：中｜證據：原文明文（機率型押注要多筆不相關的小注）＋推論（與宿主檔數上限合成）
- 適用／例外：宿主檔數上限放寬到 ≥25 時才可恢復 A 的模式 A 統計便宜籃子規則。

**POS-045　最小有效部位：預期做不到權益 3% 就不建倉。**
- 規則：目標權重 <3% → 不買；買不到 3% 的標的（流動性或市值太小）→ 排除。低於約 2% 的既有殘餘小部位視為對結果可忽略，不再投入研究，要嘛加到目標、要嘛清掉。
- 信心：高｜證據：原文明文（合夥後期：低於資產約 3% 的部位對結果沒有影響）＋多文本重複（大資金時期「低於 2% 可忽略」）
- 適用／例外：A 的 3% 與 B 的 2% 不衝突：3% 是開倉門檻，2% 是「已存在小部位可忽略」門檻。

**POS-046　相關群視同一檔（舊版定版）。**
- 規則：同產業、同驅動因子、同監管風險的持股合併計算；規則書判定：兩檔的失效條件中有任一條描述同一外部變數 → 同群；判定記入兩檔論點檔，之後只能因新事實改判。相關群上限＝min（2 × 單檔等級上限，10 個百分點 ÷ 該群合理最壞情境下的相對大盤損失）。另做共同情境永久損失檢查（RISK-016）：Σ 權重 × 情境減損（金融預設 50%、非金融 30%）>5% → 該群停止新買；>10% → 從確定性最低者減碼到 ≤10%。
- 信心：高（原則）／低（「2 倍」與 5%／10% 為推論）｜證據：多文本重複＋推論
- 適用／例外：可調：倍數 1–2；軟線 3–7%；硬線 8–12%。

**POS-047　以資金規模（不以年代）切換參數。**
- 規則：最小有效部位 = 權益 × 3%。多數候選只需 ≤ 公司市值約 1%、可在數週內建完 → 模式 A（小資金：2 批快建、新部位頻率不設限但每個都過全部關卡）；需 1–5% 股權或數週到一兩季 → 模式 B；需 >5% 股權或數月以上 → 模式 C（首批約 1/4、每年 0–1 個新部位、常態現金較高）。本宿主屬模式 A。
- 信心：高（原則）／中（分界）｜證據：多文本重複＋推論（分界）
- 適用／例外：小資金不得模仿大資金獨有的工具（協議型融資、整體收購）；規模放大時下修預期報酬。

### 1.5 部位大小：公式與確定性分級上限

**POS-030　目標權重由「優勢差距 × 確定性」決定，不等權。**
- 規則：把合格標的依預期超額報酬排序；第 1 名與第 N 名的預期差距越大，第 1 名配越多；預期值相同時，「大幅落後機率」較高者配較少。
- 信心：高｜證據：原文明文（第一名放多少、第八名放多少，取決於兩者數學期望的差距，也取決於第一名表現很差的機率）
- 適用／例外：無。

**POS-031　尾部風險上限公式。**
- 規則：單檔（或相關群）上限 ≈ 10 個百分點 ÷ 該部位在合理最壞情境下「相對大盤的價值損失」。換算：最壞相對損失 25% → 40%；50% → 20%；75% → 約 13%。目標：任一部位或相關群使整個組合落後大盤 >10 個百分點的機率「很小」。
- 信心：高（原則）／中（公式形式）｜證據：原文明文（落後 >10 個百分點的機率要壓到很小）＋推論（公式化）
- 適用／例外：「合理最壞情境」用估值（02）的悲觀情境價值，不用歷史波動率。
- **規則書定義**：最壞損失＝1 − 悲觀情境價值（全部已知威脅同時發生）÷ 現價，下限 25%；相對大盤損失中大盤損失取 0（推論）。｜審查：X30-18
- **規則書補充**（措辭／條件補充；審查 X13）：保留公式，在適用欄補一句：「本條是單檔與相關群上限的計算工具，不是組合年度追蹤誤差限制；採芒格變體時仍以本條算出的單檔上限為準（取較嚴）。」

**POS-032　確定性分級對應的建倉成本權重上限（宿主相容版）。**
- 規則：建倉成本權重上限 = min（POS-031 公式值、等級上限、宿主上限）。等級上限：

  | 等級 | 本 skill 原始上限 | 宿主單檔 15% 時的實際上限 | 條件 |
  |---|---|---|---|
  | A（極高確定） | 40% | 15% | 事實與推理正確機率極高、價值大幅改變機率極低、明顯優於第 2–4 名（規則書操作化：G8 排序分高於第 2 名至少 2pp），三者同時成立；無法實地查訪時以公開資料替代完成 PROC-071 第 7 步即不降級 |
  | B（高確定） | 20% | 10%（可調 7.5–12%） | 通過全部關卡但不完全符合 A 級三條件 |
  | C（統計便宜） | 5% | 不開新部位（POS-044） | — |

  金融業降一級（上限即該等級的上限，不再另降）；有融資、贖回壓力或短期用錢需求 → 再減半；金融類降級後為 C → 宿主不開倉，既有部位持有、不加碼。
- 信心：高（原則）／中（參數）｜證據：原文明文（40% 規則及其兩條件）＋持倉數據（大資金時期建倉成本權重很少超過 1/3）＋推論（宿主縮放）
- 適用／例外：宿主上限 < 本 skill 的 A 級上限時，A 與 B 必須保留差距，否則分級失去作用；B 級取宿主上限的約 2/3（推論，可調 1/2–4/5）。宿主上限放寬時，回到 min（公式、原始等級上限）。
- **規則書補充**（措辭／條件補充；審查 X11）：保留 40% 與兩條件及「明顯優於次佳選項」；補一句頻率約束：單檔 >25% 應屬罕見例外（每次須在論點檔寫明為何勝過第 2–4 名），不得成為常態配置

**POS-033　單一事件的最壞執行損失上限（規則書改寫：依 stop_mode）。**
- 規則：權重 × max（s，該股近 8 次財報次日最大單日跌幅）≤ 權益 2%（可調 1.5–3%）；只在建倉與加碼時檢查，不構成財報前減碼理由（避免擇時）。SKILL 第 7A 節 `stop_mode`＝A → s＝0（不設停損，只看跳空；B 案 s_eff 見本檔附錄，未採用）。2% 是中位目標，跳空尾部由 P-57 與事件型上限處理。
- 信心：中｜證據：多文本重複（單一有價證券的歷史實際永久損失約不超過淨值 0.5–1%）＋持倉模擬（收盤檢查型停損實際中位約 −13.6%、最差 1% 約 −32%；單檔 15% 時約 55% 事件超過權益 2%）＋推論｜審查：X27、X30-17
- 適用／例外：這不是原組合的停損規則。

**POS-034　重壓的前提與禁止「試水溫」。**
- 規則：只有在你願意最終持有到 ≥3% 目標權重時才開始建倉；「先買一點看看」被明確排除。重壓只發生在 A 級條件成立時；重壓不等於無限集中。
- 信心：高｜證據：原文明文＋多文本重複
- 適用／例外：分批是為了流動性或宿主規則，不是因為信心不足（POS-036）。

### 1.6 建倉節奏與加碼

**POS-035　開倉前先寫「目標權重」與「買價上限」。**
- 規則：論點檔必須先寫：目標權重（POS-030～032）、買價上限（估值（02）輸出）、失效條件、等級；沒有論點檔不下單。建倉中只看買價上限，不看首筆成交價。
- 信心：高｜證據：多文本重複＋持倉數據驗證（加碼本益比與首建倉相近）
- 適用／例外：無。

**POS-036　小資金（含宿主）建倉：2 批、首批目標 1/2、數日到數週內買足（規則書：stop_mode＝A，70% 加速恢復）。**
- 規則：價格 ≤ 買價上限 → 第 1 批買到目標的 50%；之後在買價上限內、於 1–15 個交易日內買完第 2 批（必要時第 3 批）。已通過全部閘門且價格較 52 週高點 ≤ −20%（可調 −15% 到 −30%）→ 首批可提高到目標的 70%、餘額 ≤5 個交易日內完成（`stop_mode`＝A 定案，允許）。第二批不得以「價格高於首批」為由延後；論點未變且價格 ≤ 上限 → 期限內完成，未完成須記入疏忽之錯並具名原因。首批比例是執行節奏，不是試水溫；剩餘批次的完成期限不得因價格上漲而延後或取消，除非價格已高於買價上限。
- 信心：中低｜證據：原文明文（不踮腳試水、價格對就盡量快）＋推論（首批比例；回落證據幾乎全來自早期樣本，申報資料無法檢驗）｜審查：X06、X12、X27、X30-32、X30-24、X24、X23
- 適用／例外：一般模式：機會可能消失（成交稀薄、事件窗口短）時首批可到 100%；大資金用「首批約 1/4、回落 ≥20% 時 1/2」，單段買進常在 1–3 週內完成，跨季累積只發生在目標持股比例很高（約 >10%）或分多段時；中資金首批 1/4–1/2。窗口到期或價格連續 10 個交易日高於上限 → 取消剩餘批次、釋放已承諾現金、增補論點檔；部位 ≥3% 保留，<3% 依 P-33；不得以等待財報為由延長（P-37）。
- **規則書補充**（措辭／條件補充；審查 X11）：一般模式補充：流動性不足的標的可跨季累積，條件是每次加碼前價格仍 ≤ 買價上限；超過上限即停，已買部分照一般持有規則處理；宿主模式不變
- **規則書補充**（措辭／條件補充；審查 X24）：保留宿主首批 50%（推論）；把數據敘述改為「大部位首季約峰值的 1/5–1/3，小部位常一季買足」；大資金首批 1/4 維持

**POS-037　不推價；不錨定首筆。**
- 規則：單日買量以不明顯推高價格為限（上限約日成交量 20%；小資金通常不受限）；建倉中價格小漲但仍 ≤ 買價上限 → 繼續買，不因「比首筆貴」停手。
- 信心：中高｜證據：多文本重複（自評「因小漲停手」為最昂貴錯誤之一）＋原文明文（日成交量約 20%）
- 適用／例外：無。

**POS-038　加碼規則。**
- 規則：持股論點不變且現價 ≤ 買價上限 → 可加碼至目標權重；加碼優先給高信念部位；邊緣低信念部位不加碼。已達宿主上限（成本或市值）→ 不加碼。
- 信心：高（方向）／中（優先順序的數據）｜證據：多文本重複＋持倉數據（權重 10–20% 的持股最常被加碼）
- 適用／例外：論點破裂中的部位一律不加碼（POS-014）。
- **規則書補充**（措辭／條件補充；審查 X24）：改為「權重 10–20% 的持股被加碼的機率最高（每季約 17–19%），但多數加碼筆數發生在小部位」

**POS-039　建倉期間保密。**
- 規則：建倉未完成前，不在任何公開渠道預告買進計畫。
- 信心：高（原則）／低（對模擬帳戶的實際意義）｜證據：原文明文
- 適用／例外：給使用者的私人報告不受限。

### 1.7 現金：下限、角色與停泊

**POS-050　絕對現金下限。**
- 規則：下限 = max（宿主最低現金、最壞情境 12 個月現金需求 × 2、純投資組合時權益 3%）。本宿主＝權益 5%。任何買進、加碼、恐慌出手都不得使現金跌破下限。
- 信心：高（原則）／中（3% 與 ×2）｜證據：多文本重複＋原文明文（絕對下限、不依賴銀行額度或他人善意）＋推論（純投資組合換算）
- 適用／例外：B 給的絕對金額門檻屬大型控股主體，不可移植；只採「絕對下限＋先於任何新投資」的原則。

**POS-051　已承諾批次的預留現金（舊版補強）。**
- 規則：每個尚未買完的建倉計畫，其剩餘批次的金額視為「已承諾現金」；可動用現金 = 現金 − 下限 − 已承諾現金。新點子只能用可動用現金，除非它在 POS-021 排名勝過正在建倉的標的（此時取消舊計畫的剩餘批次並在論點檔記錄）。
- 信心：中｜證據：推論（由 v2 RISK-4.2「實際水位留下限的數倍緩衝」與宿主分批規則合成）
- 適用／例外：小資金不需要大型主體的「下限數倍」緩衝；以「已承諾批次 + 下限」取代。

**POS-052　下限以上的現金是殘差，不是看空押注。**
- 規則：不設股債比例、不為「等更低點」刻意囤現金；現金高只代表找不到價格低於價值的標的。整體估值偏高時讓現金自然累積，不為部署而部署；但個股買價上限與品質門檻不因整體估值放寬或收緊。
- 信心：高（原則）／中（估值傾斜）｜證據：多文本重複＋持倉數據（現金水位與整體估值正相關、與利率相關性不穩定）
- 適用／例外：利率不是現金規則變數（v2 RISK-5.5）。

**POS-053　現金停泊處。**
- 規則：
  1. 預計 2 季內會動用的等待資金與已承諾批次 → 宿主現金或短天期國庫券工具；不為多一點收益拉長期限或降低信用。
  2. 結構性閒置（連續 4 季無合格機會，且高於現金下限＋已承諾批次的部分 >25%）→ 組合摘要明確提示指數選項並列出兩者長期預期報酬差，由使用者決定；agent 不自行買指數。
  3. 宿主或舊檔案中「找不到標的就買大盤指數」的指示，在本 skill 名義下無效；要執行須標 NOT_THIS_SKILL 並取得使用者明示同意。
  4. 宿主規則下，停泊工具占一個持股名額且受單檔上限約束 → 只有在名額有餘（≤10 檔）時才使用；否則留現金。
- 信心：中低｜證據：原文分歧（大型主體留現金有執行理由；小資金原文反而傾向指數）＋推論｜審查：X30-02、X09
- 適用／例外：停泊部位在 POS-021 比較表中照常與新標的競爭，新標的勝出時賣掉換倉，不計為賣出好企業。

**POS-054　現金多不是買進理由；閒置現金長期偏高要檢討流程，不是降標準。**
- 規則：現金高於下限很多且持續 → 檢查候選名單是否太窄、研究是否停滯；不得以降低品質或價格門檻來解決。
- 信心：高｜證據：多文本重複
- 適用／例外：無。

### 1.8 槓桿、放空、衍生品

**POS-070　完全不借款、不用保證金。**
- 規則：組合總曝險 ≤1.0 倍；不借款買股、不用保證金帳戶，事件型與海外部位也不例外。
- 信心：高｜證據：多文本重複（兩人跨所有時期反對借錢買股）＋原文明文（合夥時期借款只用於對沖事件型、自設上限淨值 25%）＋學術研究（規則書更正：控股主體經濟槓桿平均約 1.6 倍（另一算法 1.4 倍），資金來自低於國庫券約 3pp 的浮存金、最高評等債務、遞延稅與免擔保衍生品，一般組合沒有這種資金）。組合層不以融資買上市普通股；母公司曾以數日至數月內償還的過橋資金支應私募優先股與整體收購（大資金工具，小資金不採用）
- 適用／例外：芒格晚期「穩贏時可融資」的主張不採用；合夥時期事件型借款不採用。
- **規則書補充**（措辭／條件補充；審查 X19d）：禁令維持。POS-070 例外欄補理由：「原文中晚期的融資案例，正是本人判斷為穩贏、事後自評為最嚴重錯誤之一的部位；穩贏判斷本身會出錯，這是不採用的直接理由」。另註明原文的 100–200% 是「自己判斷為穩贏時」的個人說法，不得當成部位上限參考（P-28/P-29 維持）。
- **規則書補充**（只改證據標記；審查 X23）：規則不變；證據欄「跨所有時期反對借錢買股」改為「組合層不以融資買上市普通股；母公司曾以數日到數月內償還的銀行過橋資金，支應私募優先股與整體收購的現金對價（大資金工具，小資金不採用）」。

**POS-071　不能被迫賣出的檢查。**
- 規則：任何部位或工具，只要存在「在最低點被他人強迫賣出」的路徑（追繳、到期、擔保品）→ 不做。集中的前提（MKT-047 規則書）：有可寫下的優勢，且組合與使用者都能承受至少 −50% 累計回撤（可能連續兩年；規劃到 −55%～−60%）而不被迫賣出、不改變方法；使用者需明示能在心理上承受虧損，否則採較分散配置（推論，可調 −40%～−55%）。組合摘要列壓力測試：前 5 大同時 −50% 時權益回撤＿%；被迫賣出路徑：有／無。
- 信心：高｜證據：多文本重複＋學術研究＋價格數據（集中組合約 −49%～−52% 回撤；相對落後可達約 90 個百分點）｜審查：X12、X28、X27
- 適用／例外：宿主無價格停損（SKILL 第 7A 節 `stop_mode`＝A）；被迫賣出路徑：無。

**POS-072　不放空。**
- 規則：不放空個股、不放空大盤、不用反向 ETF；即使判斷某公司是騙局也不做空。
- 信心：高｜證據：多文本重複（損失無上限、時間對你不利、對手常是推銷者）
- 適用／例外：B 允許「極小部位、判斷與時機都有把握」的放空；裁決不採用。

### 1.9 套利、事件型與結構化證券

**POS-080　事件型只做已公開宣布、條件明確的交易。**
- 規則：只做已正式公告的併購、清算、要約、分拆；不靠傳聞、不猜收購目標、不做「下一個買家會出更高價」的接力。
- 信心：高｜證據：多文本重複＋原文明文
- 適用／例外：無。

**POS-081　進場前必答四問，並用期望值與年化報酬過門檻。**
- 規則：(1) 完成機率 p；(2) 資金綁多久 t（年）；(3) 更好結果（競爭報價）的機率；(4) 失敗時的下檔 D。計算：期望報酬 = p × 價差 − (1−p) × D；年化期望報酬 = 期望報酬 ÷ t。年化期望報酬須明顯高於短期國庫券（參考：無槓桿常態 10–20%／年）；若 (1−p) × D 大於價差的一半 → 不做。完成時間預設比公告晚。
- 信心：高（四問）／中（數值）｜證據：原文明文（四問；事件型無槓桿報酬通常 10–20%）＋推論（期望值式與「一半」規則）
- 適用／例外：有監管、反壟斷、融資條件、股東否決風險者，D 用失敗後跌回公告前價格以下估計，並要求更大價差。
- **規則書補充**：浮動對價須列各浮動項敏感度，以保守情境計價差；主要由市價決定 → 視同未避險多頭（一般模式）。破局下檔須讀終止條件；買方有單方終止權 → 破局機率上調。｜審查：X18b、X20b
- **規則書補充**：事件型部位破局或條件實質改變 → 次一決策週期全清；要續抱須當新長期部位重跑 G0–G11。｜審查：X11
- **規則書補充**（措辭／條件補充；審查 X11）：四問中的 (4) D 補一份固定破局清單（反壟斷或政府、股東表決、稅務或監管裁定、法律與產權、融資）；其餘不改

**POS-082　套利的角色依規模而定。**
- 規則：小資金且宿主允許時，已公告事件型可作常設類別，條件＝年化期望報酬 ≥ `r_d` 且過 POS-081 四問，合計仍受 P-41；中大資金或已有合格長期標的時才降為現金替代，長期好標的出現時優先換回。不得寫成「市場偏高就提高事件型」；觸發條件維持「找不到合格普通股」。結構化證券破局下檔預設 50%，套 P-41 單案 ≤ 2% ÷ 50% ＝ 權益 4%。
- 信心：中｜證據：原文明文（晚期：套利是現金等價物的替代）＋合夥期反例（事件型為常設類別）｜審查：X11

**POS-083　事件型部位上限（宿主相容版）。**
- 規則：事件型合計 ≤ 權益 25%；單案 ≤ min（10%、2% ÷ D）。D = 30% → 單案 ≤ 約 6.7%。
- 信心：中｜證據：原文明文（合夥時期曾到 30–40%，後來明言不再如此）＋推論（數字與 POS-033 連動）
- 適用／例外：交易破局常以跳空方式下跌（任何價格停損都無法保護；本宿主 A 案也不設停損），所以單案上限要以 D 計，不以停損計。評估期只剩數週時，只做預計在評估期內完成的案件或不做。
- **規則書補充**（只改證據標記；審查 X11）：25% 數字保留；證據改寫為「推論（由合夥期在比例上緣時集中虧損的教訓支持）」，刪除「後來明言不再如此」；並註明原文偏好少數集中案件（與單案上限相反），舊版從嚴屬刻意選擇

**POS-084　市場普遍不謹慎時不做套利；發現長期好企業可轉長期持有。**
- 規則：交易本身沒有經濟合理性、或買方與放款人普遍不謹慎 → 不做。研究中若發現標的是長期好企業 → 改走長期部位的全部關卡，通過後依 POS-036 建倉。
- 信心：中高｜證據：多文本重複
- 適用／例外：無。

**POS-085　結構化證券（優先證券＋權證）在本宿主不適用。**
- 規則：宿主只允許上市股票與 ETF、且無法談判條款 → 不做。宿主允許時，照 v2 POS-11 系列：只在對方急需資本、你是少數能立即付款者時；不因條款漂亮而買你不想擁有其普通股的生意。
- 信心：高（原則）｜證據：多文本重複
- 適用／例外：公開掛牌的優先股可視為一般證券，照 POS-001 全部關卡評估。

### 1.10 流動性與持股比例

**POS-090　流動性門檻：能在一個交易日內進出（舊版補強，小資金版）。**
- 規則：目標部位金額 ≤ 該股平均日成交額 1%（可調 0.5–2%）；不符合 → 排除或降低目標權重。
- 信心：低中｜證據：推論（由「大部位流動性是雙向的，先確認賣得掉再承諾」與宿主停損需要即時成交合成）
- 適用／例外：大資金改用 A 的「日成交量約 20%」建倉上限。
- **規則書**：一般模式下成交稀薄只決定建倉速度與上限，不單獨構成否決；無槓桿、價格明顯低於價值且可在合理期間建足時，可放寬至 ≤ 日均成交額 2–5% 並延長建倉期；宿主維持 1%。規則書依據改為「退出路徑」（G10）而非停損需要。｜審查：X12

**POS-091　持股比例（規則書改寫：9.9% 只對受監管產業是硬上限）。**
- 規則：≤9.9% 是預設，不是一律。標的屬越過 10% 會觸發監管核准或被動性承諾的受監管產業 → 硬上限 9.9%；其他產業在一般模式大資金下可超過 10%，但論點檔須寫明額外理由、內部人申報與短線歸入限制、流動性下降對退出的影響。被動越線：越過監管或申報性門檻 → 只賣到剛好低於門檻（數量＝回到門檻下所需最少股數，分批只看流動性、不看價格），記「制度」；非監管門檻 → 可續持，需設上限時優先與發行人約定按其公開回購均價分期賣回。被動越線後是否再加碼依一般加碼規則。
- 信心：高（受監管產業）／中（其他）｜證據：持倉數據驗證（持股申報：持股已 >10% 仍主動買進的標的至少十餘檔）＋原文｜審查：X23、X10
- 適用／例外：本宿主資金規模下永遠不會觸及；保留給規模放大時。
