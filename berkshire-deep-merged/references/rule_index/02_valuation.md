# 02 估值與安全邊際

> 本檔是 berkshire-way 規則書的參考檔；SKILL.md 每次必讀，本檔在對應閘門或動作需要細節時讀。規則書修改處以 ``、``、`` 標記，對照 `CHANGELOG_規則書.md`。
> 規則格式：**新編號 規則名** → 條件 → 動作 → 參數｜信心｜證據類型｜適用與例外。
> 證據類型只有四種：原文明文／多文本重複／持倉數據驗證／推論。標「推論」的數字是可調參數。
> 數字若與 SKILL.md 第 5 節參數表不同，以參數表為準（本檔已套用 規則書；標「舊版定版」處為上一版覆寫，若與「規則書」標記衝突，以 規則書為準）。所有「EPS／盈餘／P/E／ROE」依 SKILL 第 0 節全域營業盈餘口徑。
> 「模式 A／B／C」＝資金規模小／中／大，與確定性等級 A／B／C／D 不同；「宿主」＝小資金模擬宿主（單檔 15%、現金 5%、12 檔；無價格停損與移動停損：SKILL 第 7A 節 `stop_mode`＝A，論點破裂檢查）。
> 文中「v2」或「A」指上一版本 skill，「B」指另一份來源整理版本；兩者的編號只供追溯，不是本版規則。

## 1. 規則清單

### 1.1 定義與估值閘門

**VAL-001｜內在價值的定義**
- 規則：內在價值＝企業剩餘壽命內所有能取出的現金（流入減流出）折現回今天的值。帳面價值、清算價值、市價、倍數都只是間接線索。→ 動作：每次估值的最終產出必須是「現金流金額與時點＋折現率」推出的區間，不得只交一個倍數。
- 信心：高｜證據：原文明文、多文本重複（全時期一致）
- 適用／例外：所有資產類別同一套定義。

**VAL-002｜五問閘門（答不出任一題 → 不估、不買）**
- 規則：(1) 現金流有多確定？(2) 何時出來、出來多少？(3) 用什麼利率比？(4) 最壞情況剩多少？(5) 誰會來搶、買下後還要再投入多少？→ 任一題只能用「不知道」回答 → 歸入「太難」，動作＝不買（不觀察、不設買價上限）。
- 信心：高｜證據：原文明文、多文本重複
- 適用／例外：無例外。

**VAL-003｜看不清就不做，不用加大折價補償**
- 規則：估不出未來 10 年現金流的合理區間 → 不做；不得以「價格夠低」或「折現率加高」去補償看不懂。風險＝永久損失或被迫賣出的機率，不是股價波動；股價大跌不使同一企業變得更危險。
- 信心：高｜證據：原文明文（多次）
- 適用／例外：只靠財報、生意理解有限者，不是「看不清」，而是 C 級，走 VAL-040 的嚴格統計折價與分散；超過 C 級的不確定（多個獨立變數須同時順利）＝D 級，不做。

**VAL-004｜成長、股利、P/E、P/B 都不是價值本身**
- 規則：它們只在提供現金流金額與時點線索時有用。只有增量資本報酬高於 `r_d` 的成長才創造價值；需追加低報酬資本的成長會減少價值。→ 不把標的分成成長股／價值股處理；評估成長時一律同時估「每多賺 1 元要再投入多少資本」。
- 信心：高｜證據：原文明文、多文本重複
- 適用／例外：無。

**VAL-005｜輸入合理保守，安全邊際只在價格端套一次**
- 規則：每個輸入取「保守但合理」的值（不取最壞值），不得每一層再打折；安全邊際只在最後以價格／價值比（第 1.8 節）套用一次。
- 信心：高｜證據：原文明文
- 適用／例外：保守情境（VAL-030）本身就是「合理保守」，不得再對保守情境的結果另乘折扣。

### 1.2 業主盈餘、正常化與穿透盈餘（現金流輸入）

**VAL-010｜業主盈餘公式（估值唯一的現金流起點）**
- 規則：`OE`＝報告盈餘＋折舊、耗竭、攤銷等非現金費用－維持長期競爭地位與既有單位量所需的**平均**資本支出－維持所需的營運資金增加。最後兩項只能估，但必須估，不得省略。華爾街的「現金流」（只做前兩項）不得直接拿來估值。
- 信心：高｜證據：原文明文、多文本重複
- 適用／例外：只有「前期一次性大投入、後期幾乎不需再投入」的長壽命資產型業務，現金流才可明顯高於盈餘；製造、零售、採礦、公用事業等一律不可忽略折舊。
- 費用化的成長性支出（取得新客戶的行銷、刻意前置認列的長期合約成本）可自業主盈餘中分離加回，只在同時成立時：(a) 每單位客戶價值可由公司揭露的續約率、成交率或留存資料估出且連續 ≥3 年穩定，且能分出維持現有客戶量所需部分、公司為低成本供應者；(b) 新增單位價值 ÷ 取得成本 >1.2（推論，可調 1.1–1.5）；(c) agent 自行以保守值計算（維持性支出取估計區間上緣），不採管理層調整後數字（NEVER-06 不變）。任一不成立 → 不加回。加回只可提高 `IV_base`，不得提高 `IV_cons`；賣出 V 的倍數項使用同一調整後盈餘。（中｜原文明文＋推論｜審查 X08b、X07）

**VAL-011｜維持性資本支出（規則書改寫：公式取代固定係數區間）**
- 規則：
  - 一般企業 ≥ 折舊 ×1.0；輕資產 ×1.0–1.2。
  - 重資產（重置成本遠高於帳面、需持續汰換的網路或設備型資產）＝ max（折舊 ×1.2，折舊 × 自身近 5 年「資本支出 ÷ 折舊」中位 ×0.8）；計算中位前先扣除可辨識的擴建、收購與受管制核准的費率基礎成長投資（後者可由費率回收，不算維持性），可另以近 7–10 年量大致持平年度交叉核對。
  - 係數（維持性資本支出 ÷ 折舊）上限 1.6；公司揭露維持性支出或其他證據明示折舊嚴重低估時可到 2.0（可調 1.2–2.0）。
  - 高通膨（CPI 年增 ≥4% 或 3 年年化 ≥3.5%）另算「折舊 ×（1＋資產平均剩餘年限內累積通膨）」，上限 1.4，與上式取高者（總上限仍 2.0）；MKT-023 引用本條。
  - 法規強制的安全、環保支出一律算維持性。計算前把新增營業租賃使用權資產加入資本支出、使用權資產攤銷加入折舊。
  - 快速近似（一般通膨、輕資產）：`OE` ≈ 報告盈餘＋收購產生的客戶關係類無形資產攤銷（約八成可加回）；軟體與技術類攤銷是真實成本，不加回。
  - 警訊：調整後連 5 年 < 折舊 ×0.8（單一衰退年跌破不觸發），且無「資產壽命延長」或「業務縮小」的明確理由 → 視為盈餘被高估，`OE` 以折舊 ×1.0 重算，並在品質評分扣分。
- 信心：中（方向高、係數推論）｜證據：原文明文（折舊低估）＋原型分部申報校準＋推論（0.8、1.2、上限）｜審查：X04、X16c、X21-05、X21-07、X21-08、X21-10、X28
- 適用／例外：雙向調整：通膨與重資產往下調，確實的輕資產業務不得為了好看而虛增扣項。

**VAL-012｜正常化盈餘：用常態年度出價**
- 規則：定價以常態年度盈利能力為準：無巨災、景氣中性、利率正常、剔除一次性利得與損失、還原母公司給的信用或其他補貼。→ 週期性企業一律用「至少涵蓋一個完整景氣循環（不少於 7 年，推論）」的平均利潤率乘以當前營收或資產規模，再把客戶產業進入衰退的機率算進去；景氣好的年份要付**較低**倍數。拿單一好年度出價 → 違規，重做。
- 信心：高｜證據：原文明文、多文本重複
- 適用／例外：有偶發巨額損失的業務（保險、再保、長尾責任），要把多年平均的巨災損失從好年份扣掉；「排除巨災」的盈餘一律不接受。
- **規則書補充**：需求綁定新創／融資熱度、招聘與遷移、資本市場活動等景氣敏感來源，而可得歷史未涵蓋至少一次衰退 → 視為週期性：保守情境以衰退年營業利益 −60%～−100% 計，不得以單調上升的近幾年資料當常態。（中｜原文＋推論｜審查 X18b、X18w）

**VAL-013｜成長率先查起訖點與增量資本**
- 規則：計算歷史成長率前，先確認基期不是接近損益兩平、終點不是景氣高點；任一成立 → 改用 7–10 年回歸斜率或跨週期平均對平均的成長（推論方法）。同時算「增量資本報酬」＝（期末－期初正常化盈餘）÷ 期間累計再投入資本（保留盈餘＋新增負債－已分配）；低於 `r_d` 的盈餘成長不計為成就。
- 信心：高（原則）／中（替代算法）｜證據：原文明文＋推論
- 適用／例外：低配息企業即使不成長，每股盈餘也會因保留盈餘而上升，每股盈餘成長不是績效指標。

**VAL-014｜已知的未來衰退現在就算進去**
- 規則：競爭者即將進入、合約到期將被殺價、替代品吃掉定價權 → 立即下修 `OE` 與成長路徑，不等事實發生。區分結構性侵蝕（內在價值永久下降）與週期性波動（內在價值不變）；分不出 → 當作結構性。
- 信心：高｜證據：原文明文
- 適用／例外：無。
- **規則書補充**（只改證據標記；審查 X18w）：規則不改（較嚴的預設在本資料的結果上是對的）；把「分不出 → 當作結構性」的證據標記改為「推論（保守預設）」，信心中。

**VAL-015｜穿透盈餘：組合層與控股層的經濟盈餘**
- 規則：穿透盈餘＝自身營業盈餘（排除收購會計調整、資本利得、非經常項目）＋依持股比例應享的被投資公司**保留**營業盈餘－這些保留盈餘若以股利發放時要繳的增量稅（用投資人實際適用的股利稅率）。→ 用途：(a) 評估控股型或組合型主體的經濟盈餘；(b) 組合層目標＝「10 年後每股穿透盈餘最高」，以每股穿透盈餘成長率（依股數稀釋調整）當內在價值成長的代理。精度只要求趨勢正確。
- 信心：高｜證據：原文明文、多文本重複
- 適用／例外：被投資公司保留盈餘的價值以「保留 1 元是否創造 ≥1 元市值／內在價值」逐家檢驗（檢驗本身屬資本配置主題）；不合格者，其未分配盈餘打折計入價值（建議折到 50%–80%，推論，依差距大小）；受限盈餘（無法分配、無法自由移轉）不得計入可分配的 `OE`。

### 1.3 會計口徑調整（把財報重編成估值用的數字）

**VAL-020｜禁用 EBITDA 與調整後盈餘作估值或償債依據**
- 規則：折舊是真實費用（先付現、後認列）。估值倍數只用稅前或稅後盈餘、`OE`；償債能力用「稅前盈餘 ÷ 利息」。管理層或中介以 EBITDA、「調整後」盈餘做估值或償債論述 → 管理層可信度扣分，且該公司估值一律以報告盈餘重編；論述中若把常態性重組費、股權薪酬排除 → 加回成本。調整項只有在它「確實會在別處以費用形式完整認列」時才接受。
- 信心：高｜證據：原文明文、多文本重複（各時期反覆）
- 適用／例外：無例外；連續把常態費用列為「一次性」者，見 VAL-024。

**VAL-021｜選擇權與股權薪酬是成本**
- 規則：股權薪酬按授與時市價從盈餘扣除（不論財報是否已費用化）；`IV` 一律以「完全稀釋後」股數換算每股。選擇權成本可用「公司若把同條件權證賣給外部投資人能收到的價格」估計；不得用標準短期評價模型去評價十年以上的超長期選擇權（會高估價值或低估成本），超長期部位改用到期情境法估最終現金。
- 信心：高｜證據：原文明文、多文本重複
- 適用／例外：選擇權評價假設（波動度、期限）明顯偏低 → 會計警訊，扣分。
- **規則書補充**（措辭／條件補充；審查 X08b）：VAL-021 補：「股權薪酬成本以稅後計（扣除公司可得的稅盾）；稀釋以「行使款＋稅盾全數按當時價回購」後的淨增股數計，並同時列出未回購情境；兩者都要寫進訊號卡 missing_data／inferred 欄。」

**VAL-022｜攤銷與商譽：評估事業與評估交易用兩種口徑**
- 規則：(a) 判斷「事業本身好不好」：看無槓桿的淨有形資產報酬，忽略商譽與收購攤銷；(b) 判斷「這筆買賣划不划算」：用含商譽的總買價（含承接債務）算報酬。分部盈餘若把收購攤銷移到「其他」項目，估值時要把兩者加總看；排除後的分部盈餘快速成長、而收購費用同步增加 → 成長有一部分來自收購而非營運改善。
- 信心：高｜證據：原文明文
- 適用／例外：見 VAL-023。

**VAL-023｜靠持續收購維持成長的企業：收購支出視為資本支出（舊版補強）**
- 規則：若過去 5 年累計收購對價 ≥ 同期累計 `OE` 的 30%（推論門檻，可調 20%–50%），且收購屬於維持成長的常態行為 → (a) `OE` 扣除「維持現有成長率所需的平均年收購支出」；(b) 歷史成長率改用「內生成長」（剔除收購貢獻）去做 VAL-050 的比較；(c) 商譽減損緩衝（報告單位公允價值高於帳面不到 20%）反覆出現 → 視為過去收購付太多的證據，管理層資本配置扣分。
- 信心：中｜證據：推論（由「收購會計費用加回但成長來自收購」與「商譽稀釋」兩條原文規則合成）
- 適用／例外：一次性、非常態的大型收購不適用 (a)，改走整體收購估值（VAL-090～093）重算買方報酬。

**VAL-024｜投資損益、一次性項目與口徑變動要剝離（舊版補強，部分取自 B）**
- 規則：估值用的盈餘必須剔除證券損益、衍生品公允價值變動、合併帳面利得、稅率變動造成的遞延稅一次性重估、會計準則變動影響。若投資與衍生品損益占淨利的比例連續多期 >20%（B 的建議門檻，非原文）→ 只用營業盈餘估值，並另以 VAL-082 的分部／兩欄法把投資部分單獨估價。同一類「一次性」費用 5 年內出現 ≥3 次 → 改當常態成本，取平均值扣入 `OE`。
- 信心：中高（原則高，門檻推論）｜證據：原文明文（剔除證券損益、拒絕調整後盈餘）＋推論（20%、5 年 3 次）
- 適用／例外：以交易或衍生品為核心本業的子業務，不得用「投資損益無意義」剝離其損益。
- **規則書**：本條即 SKILL 第 0 節全域營業盈餘口徑的剝離清單；另加外幣債務與資產匯兌重估（擺盪不設門檻，一律剔除）；股權薪酬是成本；每股數字經拆股與股票股利調整。只有 GAAP 數且證券損益占淨利 >20% → 該指標 MISSING_DATA。
- **規則書補充**（措辭／條件補充；審查 X21-04）：VAL-024 加金額門檻：只計「單次 ≥ 正常化營業盈餘 2%」的項目；未達門檻的小額同類項不計次數；大額一次性項目以 10 年平均攤提而非 5 年
- **規則書補充**（措辭／條件補充；審查 X21-10）：VAL-024 剝離清單直接加「外幣債務／資產匯兌重估」，不設 10% 門檻（計算成本低、方向無經濟意義）；與 X21-04 該列合併。

**VAL-025｜遞延稅：不是現金，也不是權益的全額**

### 1.4 折現尺度與報酬門檻

**VAL-030｜兩種折現率分工：`IV_rf` 只當量尺，`IV_d` 才決定買賣**
- 規則：
  1. 量尺：以長期（約 20 年以上）政府公債殖利率折現得 `IV_rf`，下限 4%（推論，避免極低利率讓現值發散）。用途只限：跨資產、跨時間比較，以及持有中企業「為什麼倍數上升」的解釋。**`IV_rf` 不得用來設定買價上限，也不得用來計算價格／價值比。**
  2. 決策：以決策折現率 `r_d`（VAL-031）折現得 `IV_d`；所有買價上限、價格／價值比、隱含成長反推、賣出判準一律用 `IV_d`。
- 信心：高（分工）｜證據：原文明文（「用公債利率折現不代表那就是該付的價」「只是共同量尺」「心中有最低門檻，不論利率 6–7% 或 3–4%」）、持倉數據驗證（Q1：以 max(10 年債, 4%) 折現時，實際買價只有價值的約 0.15 倍，該比值失去區辨力；以 10% 折現時實際買價中位數約 0.8–0.9 倍）
- 適用／例外：無例外。這是對 A「相對保守基準估值」語意不明的修正（舊版補強）。

**VAL-031｜決策折現率 `r_d` 的唯一公式與可調範圍（規則書改寫：解循環）**
- 規則：`r_d` ＝ max（a, b），且要「很高機率」達到：
  - (a) 絕對下限：名目 10%，以「投資人稅前、被投資公司稅後」口徑計。可調範圍 9%–12%；低於 9% 不得使用。
  - (b) 相對利率：長期公債（30 年期，與 P-18 同一期別）殖利率＋3 個百分點（推論）。可調範圍 2–4 個百分點。
  - (c) **已移出 `r_d`（規則書）**：「次佳可得選項的預期報酬」只在 G8／POS-021 比較，不再進入折現率（原寫法使 `r_d` 與機會成本互相定義，形成循環）。
- 註：長期間長債 +3pp 很少高於 10%，`r_d` 實際常等於 10%；利率上升只在長債 >7% 時提高門檻。
- 整體收購（以稅前盈餘計價）時，(a) 改以稅前盈餘殖利率表達：約 10%–11%（≈ 9–10 倍稅前盈餘）。
- 動作：預期報酬（內部報酬率，或 `OE` 殖利率＋可持續成長）< `r_d` → 不買；放進觀察名單並記下以 `r_d` 推出的買價上限（VAL-070）。
- 信心：高（a 與 max 結構）／中（b 的 3pp 為推論）｜證據：原文明文（約 10% 稅前；最低門檻不隨利率改變）＋持倉數據驗證（買進 P/E 中位數在長債大幅下降期間維持約 13.5–16 倍）＋推論｜審查：X30-14、X28
- 適用／例外：芒格變體以機會成本為主濾網（在 G8 執行），但 (b) 永遠保留。

**VAL-032｜折現率對所有標的相同；確定性用現金流與價格端處理**
- 規則：不同企業用同一個 `r_d`，不加 CAPM 式風險溢酬、不用 beta。確定性差異只透過兩處反映：(1) 保守情境的現金流假設（VAL-041）；(2) 確定性等級的價格／價值上限（VAL-060）。不得同時又調低高確定性企業的折現率（會重複計入）。
- 信心：高｜證據：原文明文（「理論上所有證券用同一折現率，對某些企業的現金流估得更保守」）；另有原文說法「極確定的現金流可用略低折現率」，已由本條吸收
- 適用／例外：無。

**VAL-033｜利率下降：持有放寬、新買不降**
- 規則：低利率可以解釋持有中好企業的倍數上升，所以不因倍數上升就賣；但新建倉與加碼仍須通過 VAL-031 的 (a)。對低利率環境最多「有限度地多付」，上限＝`r_d` 不低於 9%（VAL-031 可調範圍下緣）。以 max（當前長債，過去 20 年中位）＋2pp 重算仍成立才可買（原問句在高利率期必過、無約束）。
- 信心：中高｜證據：原文明文（低利率會推高願付價格但不應多付；巴菲特後期承認低利率期收購多付）＋持倉數據驗證（公開市場買價不隨利率下降而上升）
- 適用／例外：持有容忍度的上限屬持有賣出（04）（荒謬級估值仍須減碼）。
- **規則書補充**（措辭／條件補充；審查 X28）：改為「以 max（當前長債，過去 20 年中位）＋2pp 重算仍成立」，或直接併入 VAL-034 的壓力測試

**VAL-034｜利率壓力測試（規則書改寫，即 P-18／P3）**
- 規則：長期利率＝最近一個交易日 30 年期公債殖利率。P3 以 r_stress＝max（10%，長期利率＋P-14 當期利差＋3pp）計；起始長期利率低於自身過去 20 年中位時改 +4pp（推論，可調 +2～+4／+3～+5）。+4pp（低利率起點 +5pp）只作敏感度欄記錄，不參與上限。訊號卡記錄所用期別、數值與日期。現價距買價上限 <5% 且敏感度欄重算會翻轉結論 → 本週期 WATCH。
- **規則書刪除**：「小幅利率差異（<1 個百分點）不改變結論」一句——與演練矛盾。
- 信心：中｜證據：原文明文（利率是估值重力）＋利率數據（長債 36 個月內最大升幅 >2pp 約占 22.6%、>3pp 約占 12.1%）＋推論｜審查：X30-06、X28
- 適用／例外：不預測利率，以當前長期利率為基準。

**VAL-035｜門檻下修條件（芒格條款）**
- 規則：只有在判斷長期利率結構「永久性」改變，且重新評估過未來可得機會後，才可把 (a) 下修，最低到 9%；(b) 永遠保留。短期利率波動不構成下修理由。
- 信心：中｜證據：原文明文（芒格：門檻是對未來機會成本的猜測，可修正）＋推論（9% 底）
- 適用／例外：下修須寫成文件化理由，並在每年複核時重新檢查。

**VAL-036｜不買只比無風險利率高一點的資產**
- 規則：預期報酬－長期無風險利率 < 3 個百分點（即未過 (b)）→ 即使高於短期利率也不買；持現是預設選項，不是失敗。

- 適用／例外：現金停泊與下限屬現金主題。

### 1.5 成長外推

**VAL-040｜長期成長假設的上限與遞減結構**
- 規則：
  - 任何情境的成長率都必須遞減，且永遠 < `r_d`（成長 ≥ 折現率會算出無限大）。
  - 第 1 年成長 `g0` 上限：保守情境依 VAL-046 規則書（min（8%，10 年與 5 年內生業主盈餘年複合較低者 ×0.75）；只有一期 ×0.6）；基準情境 ≤ min（已證明成長, 10%）；樂觀情境 ≤ 15%（只用來看天花板）。
  - 基準情境：第 10 年遞減到 ≤ 名目 GDP 長期成長（預設 4%，可調 3%–5%）；之後永續成長 ≤ 3%（可調 2%–3%）。**保守情境第 10 年後永續成長 0%**（可調 0–2%；只有護城河三測全強且方向變寬時可用 ≤3%）。
  - 大型企業長期盈餘年增 >10% 幾乎不用；15% 已是極少數企業能長期維持的「稀薄空氣」。
- 信心：高（遞減、上限方向）／中（具體數字為推論）｜證據：原文明文（有限世界的高成長必然自我毀滅；成長率高於折現率得到無限大；長期 15% 極罕見）＋推論（8%／10%／4%／3%）
- 適用／例外：只有能指出具體再投資機會來源與所需規模的成長才可放進基準情境；說不出來源 → 只能放樂觀情境。

**VAL-041｜成長的價值取決於增量資本報酬**
- 規則：成長只在增量資本報酬 > `r_d` 時加價值；增量資本報酬 ≈ `r_d` 時，成長不加價值（只用 `IV0`）；< `r_d` 時，成長扣價值（保守情境改用「全額分配、不成長」的 `IV0`，或更低）。
- 信心：高｜證據：原文明文
- 適用／例外：無。

**VAL-042｜倍數與品質的對應（以 10% 折現的經驗尺）**
- 規則：只在常態盈利附近波動、成長需要追加資本的普通企業 → 約 10 倍稅後（約 6.5 倍稅前）；不需追加資本、能長期成長中個位數的好企業 → 可到約 25 倍稅後（約 16 倍稅前）；每年衰退約 5% 的企業，看似不高的倍數也可能「不合理地高」。倍數溢價只能來自「不需追加資本的成長」。
- 信心：高｜證據：原文明文（股東信、股東會兩處以上）
- 適用／例外：這是交叉檢查用的尺，不是買點（VAL-070）。

**VAL-043｜不採用賣方、中介與管理層的預測**
- 規則：估值不使用任何利害關係人編的預測（投資銀行、賣方、管理層指引）。若必須參考，先要求其過去預測與實際結果的對照；無法提供 → 完全不用。
- 信心：高｜證據：原文明文、多文本重複
- 適用／例外：無。

### 1.6 價值區間、三情境與「不用精算」

**VAL-045｜內在價值一律給區間（規則書：結論測試可執行化）**

**VAL-046｜三情境的定義（規則書改寫：保守情境＝侵蝕情境）**

**VAL-047｜區間太寬（規則書改寫，即 P-21）**

**VAL-048｜「不用精算」判準**

  - 價格 ≤ `IV_cons` ×0.40 → 機會明顯，不必細算，進入 VAL-060 與部位決策。

- 適用／例外：無。

### 1.7 反向檢查：價格隱含的成長與「整家買下」檢驗

**VAL-050｜反推隱含成長（安全邊際的量化版本，非金融必做；規則書修正路徑公式）**
- 規則：以 `OE`（無法可靠估時用正常化營業 EPS，並註明）為起點，折現率＝`r_d`（預設 10%），成長路徑：第 t 年成長＝g＋（min（g, 4%）− g）×（t−1）/9，g ≤4% 時全程持平（修正低成長企業被免費加速的錯誤）；之後永續 3%。解出價格隱含的起始成長 `g_impl`。買進必須同時成立：
  - (a) `g_impl` ≤ 8%（可調 6%–10%）；
  - (b) `g_impl` ≤ 過去 5 年內生營業盈餘（或 `OE`）年複合成長率（「內生」＝收購期剔除收購貢獻）；A 級企業要求 ≤ 該成長率的一半（推論）；
  - (c) 自己的保守情境成長 ≥ `g_impl`；
  - (d) 基本率檢查（規則書）：價格隱含的 5–10 年後盈餘規模需躍升至母體前列而歷史躍升比例 <10% → `g_impl` 視為不切實際，P2 用保守成長（推論）。
  任一不成立 → 不買；列入觀察並記下使條件成立的價格。宿主工具須依此重寫並在訊號卡記錄口徑。
- 信心：中高｜證據：持倉數據（行為：歷史買進的隱含成長中位數約 3%、非金融約 4%）＋推論（A 級一半、內生、基本率）｜審查：X29、X30-11、X05
- 適用／例外：歷史成長的基期失真時依 VAL-013 改算；歷史成長為負或接近零 → (b) 無法通過，只能以 `IV0` 判斷，價格須 ≤ `IV0` ×該等級上限。金融股不做此檢查（改用 VAL-080）。

**VAL-051｜零成長地板 `IV0`（舊版補強）**
- 規則：`IV0` ＝ 正常化 `OE` ÷ `r_d`。(1) 價格 ≤ `IV0` 且企業無結構性衰退 → 成長是免費的，視為強訊號（仍須過等級與品質關）；(2) 價格 > `IV0` 的部分全靠成長支撐，該部分必須由 VAL-041 的高增量資本報酬證明；(3) `IV0` 也是 C 級與衰退型企業唯一可用的價值基礎。

- 適用／例外：週期股的 `OE` 必須是跨週期平均。

**VAL-052｜「整家買下」檢驗（大型、熱門、高倍數標的必做）**
- 規則：市值（含淨負債）X、要求報酬 `r_d`、現金要延後 n 年才開始回到股東 → 企業需要每年永續交出約 X·`r_d`·(1+`r_d`)^n 的現金。比較：產業內曾有幾家企業賺到這個量級？占產業總利潤、占 GDP 的比例是否合理？需要前所未見的獲利 → 不買；持有中則交由持有賣出（04）的高估警報處理。
- 觸發條件（推論）：本益比 > 25、或 `g_impl` > 8%、或市值進入市場前 1%。
- 信心：高（說法明確）｜證據：原文明文（股東會、股東信多次）
- 適用／例外：無獲利、無法建立現金流區間的資產 → 不做，也不因別人獲利而追價。

**VAL-053｜用「目標市值需要的數字」檢驗故事**
- 規則：要到心中估值，需要每年幾 % 的成長、多少單位、每單位多少利潤？所需的量增若超出公司歷史與產業天花板（量增超過中個位數、或需要價格與量同時長期高成長）→ 故事不成立，回到保守情境。定價權量化：每單位可多收的價格 × 銷量 ＝ 新增稅前盈餘，拿去跟買價比。
- 信心：中｜證據：多文本重複（原文的推理方式）＋推論（門檻）
- 適用／例外：無。

### 1.9 倍數的角色：交叉檢查與警報，不是買賣理由

- **規則書補充**（只改證據標記；審查 X27）：改為「早期中位約 −20%，晚期約 −5%」。信心中。

### 1.10 帳面價值

**VAL-075｜非金融企業：帳面價值不是價值，也不是門檻**
- 規則：帳面＝放進去的錢；內在價值＝能拿出來的錢。非金融企業不設 P/B 門檻；帳面只在「帳面與內在價值的關係長期穩定」時，才可把每股帳面成長當作內在價值成長的粗略代理。高溢價發行股票會推高每股帳面但不增加每股內在價值。低報酬事業的帳面可能遠高於內在價值 → 企業稅後 ROE 長期低於長債殖利率時，典型企業不值帳面。
- 信心：高｜證據：原文明文、多文本重複（帳面角色隨時期由「保守代理」降為「相關性下降」）
- 適用／例外：鐵路、公用事業、保險客戶關係等的經濟價值常不在帳面上，不得把帳面當上限。

**VAL-076｜帳面倍數只在帳面能代表價值時當輔助上限**
- 規則：受管制公用事業、資產以市價計的金融與保險主體，帳面可作為估值起點；回購自家股票的上限以「低於保守內在價值區間下緣」為準，帳面倍數只作輔助。
- 信心：高｜證據：原文明文＋多文本重複（回購上限由帳面倍數改為內在價值）
- 適用／例外：回購的完整規則屬資本配置主題。

### 1.11 金融、保險與控股型主體的估值尺度

**VAL-080｜銀行與放款機構：P/B 與 P/E 為主尺度**
- 規則：營業利益率、EV/EBIT、自由現金流對銀行無意義。估值帶（歷史買進分佈）：P/B ≤ 約 2.1（中位約 1.65）、P/E ≤ 15（中位約 13）、約為同年大型股 P/E 中位數的 0.67 倍。價值基礎＝常態 ROE（槓桿下降後用新的常態 ROE）× 帳面 ÷ `r_d` 的關係：常態 ROE ≥ `r_d` 才值帳面以上。估值前先調整：用歷史損失率提列呆帳卻承作更高風險放款 → 盈餘高估，往下調；收購產生的核心存款類非現金攤銷 → 加回。整個產業遭恐慌拋售、且分辨得出誰的放款紀律好時，價格可低到約 5 倍稅後盈餘以下。「便宜」不足以構成買進理由，必須先通過金融品質關（屬選股（01）），等級自動降一級。
- 信心：中｜證據：持倉數據驗證（買賣 P/B 分佈集中）＋原文明文（相對 P/E 取決於 ROE 與增量資本報酬）
- 適用／例外：無。
- **規則書**：金融 P4′＝min（同年大型股中位 ×1.0，同年金融類中位 ×1.1）× 正常化 EPS（可調 1.0–1.2），並受本條 P/B 帶約束（金融買進：÷金融類中位 中位約 0.94、≤1.0 只約 68%）。｜審查：X25

**VAL-081｜保險：浮存金成本決定價值**
- 規則：浮存金成本＝（－稅前承保損益）÷ 平均浮存金，看多年平均（至少一個承保週期）。承保損益要先扣除追溯再保遞延費用攤銷與準備金折現增值，並把「前期準備金釋放」與「當期事故年結果」分開；承保利益主要來自前期釋放 → 視為可能反轉。
  - 長期成本 ≤ 0 且能合理預期浮存金成長 → 價值明顯高於「淨值＋浮存金」；浮存金年利益 ≈ 浮存金 ×（無風險利率－浮存金成本）。
  - 長期成本 > 無風險利率 → 保險業務負價值，保險商譽歸零。
  - 保險公司整體估值帶：約 1.0–1.3 倍帳面，前提是浮存金成本合理。
  - 準備金只是「最佳誠實猜測」，長尾、再保、新責任類型要打折看；不接受「排除巨災」的正常化盈餘；不把投資收益分攤進承保績效。
- 信心：高（原則）／中（倍數帶）｜證據：原文明文、多文本重複
- 適用／例外：無。
- **規則書可計算版**：保險 `IV_cons`＝每股有形帳面＋每股平均浮存金 ×（長期利率 − 多年浮存金加權成本 − 1pp）÷ `r_d`；浮存金成本 ≥ 長期利率 − 1pp 時第二項取 0。P4′ 的 P/B 帶：保險 1.3 倍（浮存金成本 ≤0 且 5 年平均綜合率 <95 時可到 1.6 倍）；銀行用 VAL-080。浮存金成本口徑依 RISK-034 規則書（加權、10 年窗、剔除合格時間價值成本另列）。（低中｜推論（原則依浮存金價值原文）｜審查 X30-08）
- **規則書投資收益正常化**：正常化利息收入＝短天期資產 × 過去 10 年平均短期利率（雙向調整，可調 7–15 年）＋長天期債券 × min（帳面殖利率，目前再投資殖利率）；舊高息組合到期後不得外推。｜審查：X21-05、X21-10、X04

**VAL-082｜多元企業與控股型主體：分部加總或兩欄法**
- 規則：內在價值 ≈ 每股投資（現金＋證券，以市值計，扣未實現利得的遞延稅；遞延稅處理依 VAL-025）＋每股營業稅前盈餘（排除投資收益，避免重複計算）× 合理倍數（依 VAL-042 與 VAL-090），再加減質性因素（保留盈餘未來的運用效率）；或各事業價值加總。管理層資本配置能力或動機可疑 → 今天的價值打折（建議 10%–30%，推論）。合併盈餘可能很少反映真實績效 → 改看主要事業的分部經濟績效。
- 信心：中高｜證據：原文明文
- 適用／例外：控股主體折價的具體幅度無原文數字，只能當推論參數。

### 1.12 整體收購與大額部位的估值

**VAL-090｜整體收購：全權益、無槓桿、只用已證明的獲利**
- 規則：估值不靠槓桿灌大每股盈餘、不算綜效、不看賣方預測，只用已證明的穩定獲利（不碰轉機）。價格參考帶（大資金、利率中等環境）：優質企業約 9–10 倍稅前盈餘（≈13–15 倍稅後，稅前收益率約 10%–11%）；工業與配銷約 10–13 倍稅後；受管制公用事業接近帳面；高報酬特許企業約 2 倍有形淨值或更高；保險依 VAL-081。豐厚報酬只出現在資本市場嚴重受限、普遍悲觀時。
- 信心：中（樣本少）｜證據：原文明文＋多文本重複
- 適用／例外：小資金與無法控制企業的投資人不適用整體收購工具，但此倍數帶可作「私人買家價值」的上限參考。
- **規則書**：倍數帶與買方報酬只能用跨週期正常化盈餘；最近 3 年利潤率高於 7–10 年中位者，以中位利潤率重算後仍須通過，否則不買。｜審查：X18b、X18w

**VAL-091｜不為自己帶進去的價值付錢**
- 規則：對市價的溢價本身不是判準，不得作為否決或便宜的證據；判準只有總買價（含承接債務）對保守價值與 `r_d` 的關係（VAL-092）。綜效、改善計畫、自身管理能力不計入價格。整體收購報酬不如公開市場少數股權 → 不收購（保留）。
- **規則書刪除**：「投資銀行慣用的 20%–50% 控制溢價一律不付」與「整家成交價常為零股比例價的約 2 倍」兩句（獨立實例中公開目標溢價常在此區間仍成交；「2 倍」無依據）。
- 信心：中｜證據：原文明文＋持倉與收購實例｜審查：X20b、X18b（收購文件不在語料，屬資料缺口）

**VAL-092｜買方報酬用總買價算，必須過 `r_d`**
- 規則：買方報酬＝預期稅後正常化盈餘 ÷ 總收購價（含承接債務與商譽）；此數字必須 ≥ VAL-031 的 `r_d`（稅後口徑時對應約 6.5%–7% 以上，且不低於長債＋3pp 換算值）。不能因企業有形報酬很高就合理化高價（有形報酬 20%–25% 的企業，含商譽後常只剩 8%–11%）。資本密集或受管制事業（只限大資金）可接受的增量報酬下限約 11%–12% 稅前、無槓桿，前提是監管契約持續有效。
- 信心：高（原則）／中（數字）｜證據：原文明文
- 適用／例外：監管或法律責任框架改變 → 前提失效，重做估值。
- **規則書統一口徑**：受管制資本密集事業以稅後、含槓桿的留存權益報酬衡量，約 11–12% 算不錯（推論；原文為核准權益報酬約 9–9.3%，槓桿後口徑）；稅收抵免另列並適用 RISK-075；不得以稅前無槓桿 11–12% 為門檻。本條「稅前、無槓桿」限定為非受管制事業。買方報酬只能用跨週期正常化盈餘。｜審查：X17d、X10

**VAL-093｜以股票支付時，成本按付出股份的內在價值計**
- 規則：發股成本＝付出股份的內在價值，不是市價。自家股票被低估時，全股票交易不可能合理；只有換到的內在價值 ≥ 付出的內在價值時才發股，否則一律付現。此規則適用所有發行形式（併購、增資、換股、選擇權、可轉換證券）。
- 信心：高｜證據：原文明文（股東手冊）
- 適用／例外：評估被投資公司的發股併購時，同一規則用來檢查其每股內在價值是否被稀釋。

### 1.13 機會成本比較、買價上限輸出與重算

**VAL-095｜每次都和次佳選項比**
- 規則：新點子必須回答「為什麼要它，而不是多買一點我最有把握的那一檔？」。比較清單：(1) 公開市場最好企業的少數股權（含現有持股加碼，若仍在其買價上限內）；(2) 長短期無風險資產稅後報酬；(3) 整體收購（若可行）；(4) 已公告事件套利；(5) 低成本指數基金。選稅後期望值最高、而且看得懂的那一個；對資產類別不設偏好。新標的的預期報酬未高於次佳選項 → 不開新部位，改做勝出的選項（含持現）。
- 信心：高｜證據：原文明文（資本成本＝第二好點子的報酬；即使折現結果為正，報酬不超過機會成本也放棄）
- 適用／例外：換股（賣舊買新）的門檻屬持有賣出（04）（沿用 v2 的 D-08）。

**VAL-096｜股票與債券的稅後比較**
- 規則：股票預期稅後報酬（股利殖利率＋可持續盈餘成長，或 `OE` 殖利率＋成長）低於債券稅後殖利率 → 偏向債券或現金；對長期股票報酬不得假設兩位數（長期預期以名目約 6%–10% 為合理範圍，推論）。
- 信心：中高｜證據：原文明文（股債以稅後報酬比較；期望兩位數報酬是大錯；芒格要求降低期望）
- 適用／例外：只用於設定預期與選擇資產類別，不改變個股的 `r_d` 公式。

**VAL-097｜買價上限的唯一輸出公式（規則書定版：四項取最小，P5 移出）**
- 規則：每檔通過品質關的標的輸出：
  `買價上限 = min(P1, P2, P3, P4′)`（已被覆寫：自動買進上限 = min(P2′, IV_base)，見 SKILL §3）
  - P1 等級價＝等級上限（VAL-060）× `IV_cons`（以 `r_d` 折現、VAL-046 規則書保守情境）。
  - P2 隱含成長價＝使 `g_impl` 同時滿足 VAL-050 (a)–(d) 的最高價格。
  - P3 壓力價＝以 r_stress＝max（10%，30 年期＋3pp＋3pp；低利率起點 +4pp）重算後，等級上限 × 新 `IV_cons`（VAL-034）。
  - P4′ 相對倍數價（軟上限）＝1.0 × 同年大型股 P/E 中位 × 正常化營業 EPS（非金融）；A 級且 P1–P3 全過、5 年增量資本報酬 > `r_d` 時可到 1.2（推論，可調 1.1–1.3）。金融：min（大型股中位 ×1.0，金融中位 ×1.1），並以 VAL-080／081 的 P/B 帶約束。母體統計檔缺 → P4′ 不適用。
  - **P5 絕對倍數價（規則書已移出上限）**：改為警示 W-PE——正常化 P/E >20（ROE ≥18% 且 5 年營業 EPS 年複合 ≥10% 時 >25）→ 訊號卡寫明 P2 已過與正常化盈餘算法，列入 G9 反方，排序 −1；不得單獨阻擋買進或構成賣出。理由：原文明言沒有任何固定本益比切點；整體高估的防護由 P2、P3、P-66 分區與 G9 承擔。
  - 價格 ≤ 買價上限，且 VAL-095 勝出 → 「可買」，交部位（03）決定大小。
  - 價格 > 買價上限 → 「觀察」，記下上限與日期。
  - 等級 D、閘門不過、區間 >4（VAL-047）→ 「不買」，不設上限。
- 信心：中（組合方式為推論；P4′ 依 EVID-001 持倉數據；W-PE 依 EVID-005）｜證據：推論＋持倉數據｜審查：X06、X29、X02、X25、X30-12
- 適用／例外：加碼也用同一上限（接受高於首筆成本的加碼，只要在上限內）。達到上限即可買，不額外等待更便宜（EVID-011）。舊版上限一律作廢。

**VAL-098｜何時重算 `IV` 與買價上限**
- 規則：(1) 每年一次；(2) 出現重大新事實（競爭格局、管理層、資本配置、會計重編、監管）；(3) 長期無風險利率較上次估值變動 ≥ 1 個百分點（推論）；(4) 股價單季下跌 ≥ 25%（只為檢查新事實，不因跌而調高 `IV`）。重算後 `IV_cons` 下修 → 買價上限隨之下修，不得維持舊上限。
- 信心：中｜證據：原文明文（利率或現金流預測修正時內在價值必須改變）＋推論（門檻）
- 適用／例外：無。

**VAL-099｜賣出端的估值接口（細節屬持有賣出（04））**
- 規則（舊版定版，細節見 SELL-031、SELL-032）：賣出判準用的價值是 `IV_base`（以 `r_d` 計），不是 `IV_rf`。**規則書**：V（P-45 規則書）與 F（P-46 規則書，須結構性或連 2 年）同時成立 → 普通／良好全清、頂級先重估 IV 再依 3c；只有 V：普通、良好、統計便宜型且價格 ≥ `IV_base` → 全清（純利率造成者除外）；頂級複利型：價格 ≥ `IV_base` ×1.3 **且** 倍數類警報 ≥3（舊版原文：×1.2 且警報 ≥2，已改） → 分批減碼（每次 ≤1/4、保留 ≥ 峰值 2/3，所得須有用途）；V 只由倍數觸發而價格 < `IV_base` → 重估後仍低於則持有、不加碼。持有容忍度可以高於新買上限，但兩者不得混用。
- 信心：中｜證據：持倉數據（「貴＋轉弱」3 年賣對約 72%、5 年約 81% 只是已決定賣出樣本中的條件命中率，對全部持股機械套用無區分力；「只有貴」只有 9 筆、約 44%，無法定論，EVID-015、EVID-017）＋原文明文（沒有任何有價證券不論價格永遠不賣）
- 適用／例外：控股子公司「幾乎不賣」，不適用此條。

**VAL-100｜依資金規模切換估值方法，不依時代**
- 規則：小資金（多數候選只需 ≤ 公司市值約 1%）可同時保留「好企業合理價」與 C 級統計便宜籃子：市值 ≤ 懂行私人買家價值約 1/3，或價格 ≤ 淨流動資產約 2/3；淨流動資產採清算折扣（現金 100%、應收約 85%、存貨約 60%、預付約 25%、固定資產用拍賣淨值，再扣退休金與員工義務）；價格回到買價與私人買家價值中間就賣。大資金只用好企業合理價與整體收購，停用統計便宜法，接受較小安全邊際但以確定性補足，預期報酬下修到長期約 10% 稅前。
- 信心：高（切換原則）／中（參數）｜證據：原文明文、多文本重複、持倉數據驗證（早期邊際買價 P/E 約 4.6–7、P/B ≤ 1.35；中期品牌股 P/E 16–25；大資金期 P/E 約 15）
- 適用／例外：統計便宜法的容量有限，市場效率提高後此類機會主要出現在拍賣式或冷門市場。

**VAL-101｜芒格變體（使用者要求更嚴格、更集中時整組切換）**
- 規則：以機會成本為主濾網（VAL-031 (c)），但 (b) 永遠保留；品質零例外，不碰 C 級統計便宜；可接受「數字幾乎叫你別買、但對產品與地位信心極強」的 A 級交易，仍受 VAL-060 硬上限 0.95 約束；估值最後一步可以有判斷成分，但必須寫成文件化理由。
- 信心：中｜證據：原文明文（芒格：機會成本主導、像橋牌的判斷、以質換價）
- 適用／例外：不得只挑變體中對自己有利的單項。
