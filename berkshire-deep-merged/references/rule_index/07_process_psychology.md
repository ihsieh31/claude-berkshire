## 1. 統一閘門流程與停止規則

### 1.1 統一流程總表

買進側是 12 道線性閘門（G0–G11），持有側是 3 步循環（H1–H3），組合層約束（P）在 G11 與每次運行時都檢查。

| 統一關卡 | 內容（實質門檻見對應 reference） | 不過時的停止碼 |
|---|---|---|
| G0 分流 | 三籃子；整類揮掉；資產類別（非金融／銀行／保險／其他金融）；投資類型（一般／事件／控制／結構化）；資金規模模式；資料完整性檢查 | 太難／淘汰／缺資料 |
| G1 能力圈與可預測性 | 能否寫出 10 年後的營收結構、資本需求、競爭地位與「會怎麼出錯」；能否把反方論點講得比反方好 | 太難 |
| G2 企業層硬排除＋已知誠信紅旗 | 硬排除清單（見選股（01））；公開紀錄中的誠信紅旗（處分、重編、誤導） | 淘汰 |
| G3 經濟特性 | 品質分類 → 護城河與方向 → 生存類硬篩（排序加分與警示 W-LOSS／W-REV 不是停止碼） | 淘汰 |
| G4 盈餘品質與會計重編 | 警訊掃描；重編成業主盈餘；重編後若改變 G3 結論則回 G3 | 淘汰／回 G3 |
| G5 管理層與資本配置 | 能力、誘因、資本配置紀錄；誠信全面檢查 | 淘汰／降級 |
| G6 企業生存與財務強度 | 最壞情境能否履約；再融資依賴；可追繳結構；尾端與對手方；金融業承保與準備金 | 淘汰 |
| G7 內在價值與安全邊際 | 業主盈餘、三情境區間、門檻報酬、確定性等級、買價上限、反推隱含成長 | 觀察（記買價上限） |
| G8 機會成本 | 勝過加碼現有最佳持股、現金、指數、其他可得選項 | 不開新部位，改做勝出選項 |
| G9 反向與偏誤 | 反過來想（10 年永久損失路徑）、事前驗屍（3 年論點失效原因）、多變數相乘、反方角色、誤判心理清單逐條、疊加檢查、兩軌分析 | 不做／降級／延後一個決策週期 |
| G10 必寫三件 | 一句話理由、保守價值區間（含買價上限）、失效條件；附持有期、複查觸發 | 不做 |
| G11 部位、組合約束與執行 | 目標權重、上限、相關群、最小有效部位、建倉節奏；組合層約束 P（現金下限、零借款、單一事件損失上限） | 縮小或放棄 |
| H1 持有複核 | 每年＋重大新事實：只問企業成績與失效條件，股價不是輸入 | 進 H2 |
| H2 賣出決策樹 | 見持有賣出（04） | — |
| H3 驗屍與記帳 | 作為／不作為兩本帳、錯誤歸因、對照原始論點檔 | — |
| P 組合層約束 | 現金下限、零借款、衍生品條件、相關曝險合併、宿主硬限制從嚴 | 任何動作不得違反 |

**PROC-001｜閘門順序固定，價格放在企業判斷之後**
- 規則：每個候選依 G0 → G11 順序走；G7（估值）之前不得計算或引用「便宜程度」作為通過任何關卡的理由。
- 信心：高｜證據：原文明文＋多文本重複（四項篩選順序：懂 → 長期前景 → 誠信能幹的管理層 → 合理價格）
- 適用與例外：G0 可以用因子分數**排序**研究先後（見選股（01）的初篩排序），但排序不是通過；排序分數不得被引用為任何關卡的通過理由。

**PROC-002｜任何一關不是「通過」就停，後面的優點不得補償前面的不通過**
- 規則：某關輸出非「通過」→ 立即停止，輸出停在哪一關、停止碼、理由；不得以後面關卡的優點（更便宜、管理層更好、成長更快）抵銷。唯一允許的跨關權衡清單：(1) 確定性等級 ↔ 安全邊際大小（G3／G5 的品質判斷決定 G7 的買價上限係數）；(2) 量化篩的例外通道（只能以質化證據成立，且必須降一級確定性，不能以價格成立）；(3) 選股（01）明列的其他附降級例外。清單之外的補償一律禁止。
- 信心：高｜證據：原文明文（能力圈不靠更大折價補償；再便宜救不了爛生意）＋多文本重複
- 適用與例外：所有投資類型。事件型與結構化證券走各自路徑，但 G1、G2、G6、G9、G10 不得跳過。

**PROC-003｜停止碼五種，語意與後續動作固定**
- 規則：
  - 「太難」：能力圈外或久想不通 → 不再花時間；事後上漲不記為錯過（不進疏忽帳）。
  - 「淘汰」：命中排除、品質、誠信、生存任一否決 → 記下規則編號；除非出現改變該項判斷的新事實，否則 12 個月內不重評（推論參數，可調 6–24 個月）。
  - 「觀察」：G0–G6 全過，只差價格（G7）或機會成本（G8）→ 記下買價上限與最後完整複核日；價格進入上限時走 PROC-010 快速通道。
  - 「缺資料」：硬篩必要欄位缺漏 → 不得給「買進」，最多「觀察（缺資料）」；不得用假設值補。
  - 「紅燈」：G9 偏誤疊加或致命路徑 → 依 PROC-045 處理（不做、縮小或延後）。
- 信心：高（語意）／中（12 個月參數，推論）｜證據：原文明文（三籃子、太難不算錯過）＋推論（重評間隔）
- 適用與例外：「淘汰」若因誠信，永久不重評，除非經營團隊與控制權已完全更換。
- **規則書**：「淘汰」若因誠信，依 NEVER-04 兩層：(a) 現任決策者在位期間不重評；(b) 組織內違規 → 不自動淘汰。「缺資料」只適用於生存類硬篩與估值必要欄位。重評新事實加「產業整合為少數業者且多年理性定價、成本或法規結構永久改變」；重評仍須過 SEL-051，首次部位減半。｜審查：X08、X09、X19w

**PROC-004｜成本由低到高：先用便宜的判斷刷掉大多數，深研究只給存活者**
- 規則：G0–G2 對每個候選只做快速判斷（一次完整閱讀年報摘要層級）；G3 以上才做逐項深研究。預期 G0–G2 淘汰絕大多數候選（約 98%）屬正常，不得為了「有產出」而放寬。
- 信心：高｜證據：原文明文（多數候選在第一步被刷掉；先排除愚蠢再找智慧）
- 適用與例外：無。

**PROC-005｜不可覆寫清單：每一關都檢查，命中即停**
- 規則：以下任一成立，不論估值與其他關卡結果，輸出「不動作」或「淘汰」：①有任何路徑使組合被迫賣出或淨值歸零（借款、保證金、可被追繳的衍生品、可擠兌負債）；②看不懂或看不清 5–10 年；③管理層誠信存疑；④以總經、利率、大盤時點或股價走勢作為買賣理由；⑤估值依賴 EBITDA、調整後盈餘、看不懂的附註或賣方／管理層預測；⑥放空、首次公開發行、只靠下一個買家的資產；⑦寫不出 G10 的必寫三件；⑧在競價拍賣中追價、為綜效或自己的改善計畫付價；⑨因股價下跌恐慌賣出或因已獲利而了結；⑩以被低估的股票換資產或為撐股價回購（評估被投資公司時同樣適用）。
- 信心：高｜證據：原文明文＋多文本重複
- 適用與例外：B 允許「使用者明確要求並標示風險」時覆寫；舊版裁決：本 skill 內不可覆寫。使用者堅持時，agent 可依使用者指示執行，但該動作必須標為「非本 skill 訊號」，不得以本 skill 名義出具買進或賣出訊號。

**PROC-006｜衝突時的優先序**
- 規則：兩項判準指向不同動作時，依序由上而下取：先求不死 ＞ 能力圈 ＞ 誠信 ＞ 品質 ＞ 價格 ＞ 機會成本。
- 信心：高｜證據：多文本重複
- 適用與例外：宿主系統的硬限制（單檔上限、最低現金）比本 skill 嚴時，宿主優先（見 PROC-012）。

**PROC-007｜研究不省、決定要快、執行要快**
- 規則：(1) 研究階段不得以「快速判斷」取代逐關檢查；(2) 但同一候選在 G1 經過一次完整閱讀仍下不了結論 → 判「太難」，不得無限延長研究；(3) G0–G10 全通過後，同一決策週期內下單，不得以「再觀察一下」延遲（延遲只允許 PROC-015 兩軌不一致、PROC-045 紅燈兩種情況）。
- 信心：高（原則）／中（時限，推論）｜證據：原文明文（熟悉的生意數分鐘內能判斷有無興趣；決策前慢、執行快）＋推論
- 適用與例外：「數分鐘判斷」的前提是長期累積的知識庫；agent 只能採用「久想不通＝不懂」這一半，不得把「快」當成省略檢查的理由。
- **規則書決策週期定義**：決策週期＝一個交易日的盤前運行；盤中與報告運行不是決策週期，只執行當日盤前已寫入日誌的計畫、宿主強制事件與論點證偽事件。｜審查：X30-16

**PROC-008｜預設動作是「不動作」**
- 規則：沒有候選通過 G0–G11、沒有持股觸發 H2、沒有宿主強制事件 → 輸出「不動作」。不得因「有現金」「好久沒交易」「本輪應該有產出」而降低任何門檻。把一生的重大決策想成約 20 格的打孔卡：每一筆新部位都要值得用掉一格。
- 信心：高｜證據：原文明文＋多文本重複（活動不等於成就；打孔卡；無法安靜坐在房間裡）
- 適用與例外：統計便宜一籃子（小資金模式）的檔數多，打孔卡比喻適用於「籃子這個決定」而非每一檔。
- **規則書補充**（只改證據標記；審查 X12）：證據註明為轉述

**PROC-009｜通過全部關卡就必須行動並買足**
- 規則：G0–G10 全通過、G11 算出目標權重 ≥ 最小有效部位 → 必須在買價上限內以流動性允許的最快速度買到目標；不試單、不因建倉中價格小漲停手、不錨定第一筆成交價、不設「再便宜一點」的目標。若資金被佔用，比較新機會與組合中最弱部位，符合換股門檻就賣弱換強。
- 信心：高｜證據：原文明文（最大錯誤常是沒做或做太小）＋持倉數據驗證（約四分之三的加碼價高於首筆價）
- 適用與例外：建倉節奏參數（首筆比例、每日量上限）見部位（03）；本條只規定「不得因猶豫而不足額」。

**PROC-010｜觀察名單與預先算好的買價上限（快速通道）**
- 規則：G0–G6 通過、停在 G7 或 G8 的標的，存入觀察名單，記錄：買價上限、保守價值區間、失效條件草稿、最後完整複核日。價格進入買價上限時：若最後完整複核距今 ≤ 12 個月且其間沒有重大新事實 → 只重跑 G7–G11（更新最新年報數字後）即可下單；否則從 G1 重跑。
- 信心：中｜證據：多文本重複（危機時能迅速出手是因為事先想過參數；恐慌錯價常短暫）＋推論（12 個月參數，可調 6–18 個月）
- 適用與例外：快速通道不得跳過 G9 與 G10。

**PROC-011｜遲滯帶：同一標的的動作不得在決策週期之間來回翻轉**
- 規則：前一週期已出「買進／加碼」的標的，下一週期要改為「減碼／賣出」，必須指出 H2 決策樹中哪一條件新成立（新事實或價格越過賣出門檻）；只有措辭不同、重新估算的價值落在原區間內 → 維持原動作。買進門檻（買價上限）與賣出門檻（見持有賣出（04））之間是「不買也不賣」的區間。
- 信心：中｜證據：多文本重複（大資金時期明示寬的不買也不賣區間；賣出平均沒有附加價值）＋推論（套用到 agent 的跨週期一致性）
- 適用與例外：論點證偽（H2 Q2）不受遲滯帶限制，立即行動。
- **規則書**：「週期」依 PROC-007 定義（盤前運行）；P-65 的「延後一個決策週期」同此。

**PROC-012｜與宿主系統的運行節奏**
- 規則：(1) 宿主硬限制與本 skill 取較嚴者；(2) 盤中或高頻輪次預設「不動作」，只做三件事：執行已寫好的建倉計畫、處理宿主強制事件、處理論點證偽事件；(3) SKILL 第 7A 節 `stop_mode`＝A：宿主無價格停損（−12% 只作論點破裂檢查觸發，論點被證偽才賣）；(4) 數週到數月的評估期，評分看流程遵守度，不看報酬。
- 信心：中高｜證據：推論（由「價格不是輸入」「評決策不評結果」推出的實作規則）
- 適用與例外：宿主未提供組合資訊時，不得自行假設組合規模與現金；輸出「需要的資訊清單」。

**PROC-013｜資料不足就降級，不補假設值，不編數字**
- 規則：硬篩欄位缺漏 → 該關「未過（缺資料）」，最多給「觀察（缺資料）」；所有數字附資料期間與來源；推不出的數字寫「缺」。
- 信心：高｜證據：多文本重複（不要假裝有證據）
- 適用與例外：加分項缺漏只以有資料的項目計算通過率（見選股（01））。

**PROC-014｜只處理「重要且可知」的事**
- 規則：總經、利率方向、景氣、大盤走勢不得作為任何一關「通過」或「不通過」的理由；它們只能用來設定預期報酬、現金耐心與門檻報酬中的長期利率項（見估值與風險（05））。
- 信心：高｜證據：原文明文＋多文本重複
- 適用與例外：「應該發生」與「將會發生」分開：監管、政府行為只能當作情境機率，不能當作論點前提（v2 PROC-19；B ref 11 矛盾 14）。

**PROC-015｜兩軌分析：理性軌與心理軌不一致就延後一個決策週期**
- 規則：G9 先只算理性軌（真實利益、機率、期望值），再單獨跑心理軌（誤判清單）；兩軌指向不同動作 → 本週期不動作，下一週期由「反方角色」重跑 G9 後再決定。兩軌一致 → 照 PROC-007(3) 立即執行。
- 信心：高（兩軌方法）／中（延後一個週期，推論）｜證據：原文明文（芒格自述採雙軌分析）＋推論（延後機制）
- 適用與例外：無風險且難再遇的錯價機會（v2 PROC-P12 反向）仍要先過兩軌；若兩軌一致則不得因「怕錯」再拖。

## 2. 決策前必寫（G10）

**PROC-020｜一句話理由：寫不出就不買**
- 規則：下單前必寫：「我用 X（＝股價 × 完全稀釋股數，即整家公司的價格；整體收購另加承接負債）買下整家公司，因為＿＿＿；保守內在價值約 Y（區間下緣），依據是＿＿＿。」寫不出、寫得含糊、或需要超過一段話 → 不買。
- 信心：高｜證據：原文明文＋多文本重複（寫下來測試）
- 適用與例外：加碼、換股、整體收購同樣適用；賣出也要寫一句話（見 PROC-024）。

**PROC-021｜理由的合法來源只有三類**
- 規則：一句話中的「因為」只能是：①企業本身的長期經濟特性；②管理層的能力、誠信與資本配置；③價格相對保守價值的差距。下列一律不得出現在理由中：別人在買（含大型投資人的持股申報）、明牌、成交量、線圖、「比高點便宜 X%」「比同業倍數低」、媒體或社交場合消息、股票分割、短期催化劑、總經預測。出現 → 刪掉該句後重寫；刪完寫不出 → 不買。
- 信心：高｜證據：原文明文＋多文本重複
- 適用與例外：事件型套利的理由是「已公告交易的完成機率 × 價差 ÷ 時間」，屬於價格相對價值的特殊形式。

**PROC-022｜必寫三件＋三項附帶**
- 規則：一句話之外，同一份論點檔必寫：
  1. **保守內在價值區間**：保守／基準／樂觀三值（樂觀不作依據）；買價上限＝保守值 × 確定性係數（係數見估值（02））；計算口徑（業主盈餘或看透盈餘）與 3–5 個關鍵假設。
  2. **失效條件**：2–4 條具體、可觀察、可在年報或公開資料中查證的事實；每條寫「若出現 → 動作」（全清／重估／降級）。禁止寫「股價跌破 X」作為失效條件。
  3. **事前驗屍結果**：G9 產出的 3 個最可能論點失效原因與 3–5 條 10 年永久損失路徑（見 PROC-031、PROC-032）。
  - 附帶：預期持有期（預設永久；統計便宜型寫「到價」；事件型寫預期完成日）；複查觸發（每年一次＋列出的重大事實類別）；部位計畫（目標權重、首筆、買價上限、節奏）。
- 信心：高（三件）／中（失效條件 2–4 條的數量，推論）｜證據：多文本重複＋推論
- 適用與例外：沒有論點檔不下單（宿主側也要擋）。

**PROC-023｜論點檔不可事後改寫**
- 規則：論點檔一旦存檔即凍結；新資訊以「增補」形式附在後面，標日期；驗屍時拿凍結版逐項比對。發現自己想改舊預測讓它看起來對 → 記為一致性偏誤事件。
- 信心：中｜證據：多文本重複（驗屍時拿當初預測與實際比對，不得改寫）
- 適用與例外：無。

**PROC-024｜賣出、減碼也要寫一句話與記帳類別**
- 規則：任何減碼或賣出前寫：「我賣出（或減到＿%）是因為＿＿＿」，理由必須對應持有賣出（04）的一個正當理由（論點證偽／管理層失信／永久惡化；價格明顯超過價值；稅後明顯更好的用途；制度性限制），並標記帳類別：論點／估值／換股／制度性。寫不出對應哪條 → 不賣。
- 信心：高｜證據：多文本重複（賣出要舉證，持有不必）
- 適用與例外：`stop_mode`＝A，宿主無價格停損，不產生停損類制度性賣出；制度性賣出（宿主上限、法律或監管門檻）不計入賣出打擊率（P-54）。理由碼新增 FUNDING（Q6 資金需求）。

**PROC-025｜寫作就是檢驗**
- 規則：論點檔若需要大量形容詞、精美圖表、長篇敘事才能讓結論成立 → 視為「尊重理由偏誤」與「空談」的徵兆：只保留能寫進一句話的論點，其餘刪除後重看結論是否還成立。
- 信心：中｜證據：原文明文（用寫作檢驗論點；精確的表達形式會讓人高估估計的可靠度）＋推論（套用）
- 適用與例外：無。

## 3. 反過來想、事前驗屍、多變數與反方（G9 前半）

**PROC-030｜先問怎麼死，再問怎麼贏**
- 規則：G9 的第一步不是列買進理由，而是列「我必須避免什麼」：先寫失敗清單，再回頭看買進理由能否全部避開。順序顛倒（先寫理由再補風險）→ 重做。
- 信心：高｜證據：原文明文＋多文本重複（跨期最高頻模型之一）
- 適用與例外：無。

**PROC-031｜10 年永久損失路徑（反過來想）**
- 規則：寫出這筆投資在 10 年內虧掉大部分本金（或購買力）的 3–5 條路徑，每條估「機率（低／中／高）」與「可否承受」。任一條「機率不低且無法承受」→ 否決，不論上檔多大。任一條可能「乘以零」（被迫賣出、追繳、擔保品要求、單一對手方違約、單一商品價格崩跌、無上限責任）→ 否決。
- 信心：高｜證據：原文明文（任何正數乘以零等於零；人只需要富一次）
- 適用與例外：組合層的「單一事件最壞損失」上限數字見風險（05）；本條只規定必寫與否決邏輯。

**PROC-032｜3 年事前驗屍（論點失效原因）**
- 規則：假設 3 年後這筆投資明顯失敗，寫出最可能的 3 個原因；逐一問「本次分析是否已處理」。未處理的原因 → 補研究或轉成失效條件（PROC-022 第 2 項）與複查觸發；補不了且屬於核心假設 → 確定性降一級。
- 信心：中｜證據：推論（B 的操作化設計；原文只有「事後驗屍」與反向思考，未見「3 年事前驗屍」原句）
- 適用與例外：3 年是與事後驗屍週期對齊的參數（可調 2–5 年）。與 PROC-031 不重複：PROC-031 抓「致命」，PROC-032 抓「看錯」。

**PROC-033｜多變數相乘：要求單環鏈**
- 規則：把論點拆成必要條件，給每項機率並相乘。聯合機率 ≥ 80% 且主要取決於 1–2 個看得懂的變數 → 通過；聯合機率 < 60%，或需要 ≥ 4 個彼此獨立且無法控制的條件 → 「太難」；介於中間 → 確定性降一級、目標部位減半。條件之間若非獨立（同一驅動因子），不得當獨立相乘以美化結果，改以最弱的共同驅動因子機率為上限。
- 信心：高（相乘原理，原文明文）／中（80%／60%／4 個門檻，推論，可調：通過 75–85%、太難 55–65%）
- 適用與例外：偏好可心算的簡單命題；需要精密模型才能成立的論點本身就是警訊（寧可乘以 3，不要乘以圓周率）。

**PROC-034｜反方角色：能把反方講得比反方好，才有資格下結論**
- 規則：G9 必須以「反方角色」完整重跑一次：專找反證、找會死的路徑、找自己喜歡這筆交易的非理性原因，並寫出「最強的反對論點」。寫不出比反方更強的反對論點 → 延後決策（本週期不動作），直到寫得出。
- 信心：高｜證據：原文明文（在能比反方更好地陳述反方論點之前，不該持有意見）＋多文本重複（重大決策需要不順從的反方檢查者）
- 適用與例外：反方角色的結論不是否決權；它產出的反證要逐條被回應，回應不了的轉為失效條件或降級。

**PROC-035｜主動找反證，越喜歡的假說越要找**
- 規則：研究中每遇到與現有結論相反的資訊，在同一工作階段內寫下並與支持證據並列比較；對自己最喜歡的假說加倍搜尋反證。每次因反證放棄一個想法，記為「正向事件」（不是失敗）。
- 信心：高｜證據：原文明文（主動考慮推翻自己假說的證據，越喜歡的假說越要；每年至少推翻一個最喜愛的想法）
- 適用與例外：B 寫「30 分鐘內」寫下；原文核心是「立即、主動」，30 分鐘屬操作化參數，舊版改為「同一工作階段內」。

**PROC-036｜追問二階效應**
- 規則：每個結論至少追問一次「然後呢？」：成本下降會留在公司還是讓給客戶？需求成長會不會吸引供給湧入？漲價會不會招來替代品？二階答案不利且未納入估值 → 回 G7 重估。
- 信心：中｜證據：多文本重複
- 適用與例外：無。

**PROC-037｜報紙測試（評估管理層與自身行為）**
- 規則：(1) 評估管理層：其已知行為若完整登上隔天頭版，會不會損及股東信任？會 → G5 誠信扣分或否決；(2) agent 自身：任何資訊來源或交易行為若不經得起公開檢視（非公開資訊、操縱、誤導性揭露）→ 不做。
- 信心：中｜證據：原文明文（公司要求高階主管以此檢視決策；損失金錢可以諒解，損失聲譽不能）
- 適用與例外：無。

## 4. 誤判心理清單（G9 後半）

**PROC-040｜清單逐條全跑，不得挑著用（規則書擴大適用）**
- 規則：每一筆買進、加碼、減碼、賣出、整體收購前，把 4.1 表 25 項逐條作答（是／否＋一句證據）；任一「是」→ 必須寫出已執行的對抗動作；最後跑 4.3 疊加檢查。同時對「資訊提供者」跑第 1、9、22、23、24 項（他們的誘因與說服手法）。
- **規則書擴大**：下列情況即使不下單也要跑清單（只跑「推我不動」一邊）：(1) 候選已過 G0–G7 且現價 ≤ 上限，但本週期決定不買或買不足；(2) H2 走到 Q3 且 V 成立但結論是持有；(3) 觀察名單標的進入上限內連續兩個複核週期仍未建倉。該邊 ≥3 項 → 以反方角色重跑 G8（含賣最弱換最強，PROC-009）。
- 信心：高（逐條）／中（擴大範圍：方向原文明文，操作化推論）｜證據：原文明文（以清單模式逐項使用；錯失錯價股、剝奪超反應、稟賦、現狀偏誤、他人不作為的社會認同）｜審查：X13
- 適用與例外：盤中不動作的週期不必跑；只要有任何下單就要跑。

**PROC-041｜清單是防遺漏的工具，不是取代判斷的工具**
- 規則：清單全部「否」不代表應該買；清單只負責攔下偏誤。最終動作仍由 G0–G11 的實質判準決定。
- 信心：中高｜證據：多文本重複（芒格強調清單；巴菲特自述不依賴清單 → 兩邊調和）
- 適用與例外：無。

> 傾向名稱、排序與解藥方向取自芒格的誤判心理講稿（原文明文，clean/A4/talk-eleven.txt，25 項含疊加）；「交易情境徵兆」與「對抗動作」中，標者為原文解藥的直接套用，標者為本次合併的交易情境對映（推論）。

| # | 傾向 | 交易情境的辨識徵兆（任一出現即答「是」） | 對抗動作（答「是」後必做） |
|---|---|---|---|
| T1 | 獎懲超級反應（含誘因引起的偏誤、只有錘子的人） | 資訊或建議來源從我交易中獲利（佣金、承銷、顧問費、持有部位）；管理層薪酬綁在容易造假或短期的指標；我自己有「想交易」的誘因（被評估交易次數、要有產出）；只用一個解釋框架看所有事 | 對來源有利的資訊打折，回原始文件自行驗證；檢查被獎勵的指標能否被偽造，能偽造 → 改看難偽造的指標；用會計、經濟、機率、工程冗餘等至少三個角度交叉檢查 |

| T8 | 嫉妒 | 因為同儕、指數或熱門股賺了錢才想做；把別人的成功當成自己的失敗 | 不構成理由，回 G1 重跑；以事先定好的尺標評估自己，不和熱門標的比 |

| T11 | 痛苦規避式否認 | 壞消息出現、虧損擴大時找理由不面對；遲遲不處理已破裂的論點 | 把壞消息寫下，假設它成立，重估價值；不喜歡的時候尤其要承認現實；論點破裂即行動（PROC-055） |

| T13 | 過度樂觀 | 預測、綜效、新業務、轉機構成論點的一部分；三情境只有樂觀版站得住 | 用簡單機率與期望值算下行機率 × 損失；綜效與轉機不計入安全邊際；以保守情境決策（見估值（02）） |
| T14 | 剝奪超反應 | 怕錯過而追高；想扳平而加碼惡化中的生意；在競價中被喊價推著走；怕少賺而不肯依規則減碼 | 錯過不是追高理由；不用好資產去救惡化中的大部位；不參加公開喊價拍賣；反向：通過全部關卡的錯價機會要拿足（PROC-009） |
| T15 | 社會認同 | 同業都在做（跟風收購、熱門股、大型投資人的持股申報）；或「別人都沒動」所以我也不動 | 問「只有我一個人這樣做，我還做嗎」；學會忽略他人的錯誤示範；困惑加壓力時更要停 |

| T17 | 壓力 | 在崩盤、追繳、期限、贖回或宿主強制事件下做決定 | 不在重壓下做基本面決策，只執行事先寫好的計畫；用結構避免被迫（零借款、現金下限，見風險（05）） |
| T18 | 可得性 | 被頭條、鮮明故事、容易拿到的數字主導；最近一筆資訊權重過高 | 使用固定清單；刻意加權不易量化的因素（品格、護城河）；主動找反方 |
| T19 | 用進廢退 | 這次用到的分析工具很久沒用；某類產業的專屬指標已生疏 | 用固定流程定期練習各項工具；不熟的產業專屬指標先補學再判斷，補不了 → 太難 |
| T20 | 成癮影響 | 從事「小機率、大傷害」的行為：融資、賣出無上限風險的選擇權、追逐高波動 | 避開任何小機率大傷害的行為，即使機率很低 |
| T21 | 老化影響 | 關鍵人物繼任風險；agent 依賴的事實或知識已過時（舊年報、舊市占、舊監管狀態） | 另評關鍵人與繼任風險（見管理層主題）；所有事實以最新可得資料重查並標日期 |
| T22 | 權威 | 因名人投資者、強勢執行長、信用評等、「專家」而相信 | 換成無名小卒說的，我還信嗎；獨立查核並質疑推薦者的利益 |
| T23 | 空談 | 長篇但無實質的報告、說明會、評論占據研究時間 | 把空話當噪音，從決策輸入中刪除；只留可查證的事實 |
| T24 | 尊重理由 | 對方給了理由（不論多薄弱）就接受；簡報很長很精美 | 對每條理由問「為什麼」到底層；只保留能寫進一句話理由的論點（PROC-025） |
| T25 | 疊加（多傾向同向） | 上面三項以上同時在推我做（或同時推我恐慌賣） | 見 PROC-045 |

**PROC-042｜表 4.1 的每項「是」都要留痕**
- 規則：清單作答寫入論點檔（或賣出紀錄），格式：T#｜是／否｜一句證據｜已做的對抗動作｜做完後結論是否改變。答「是」卻沒有對抗動作 → 該筆交易不得送出。
- 信心：中｜證據：推論（A 要求「記錄並說明為何仍可行」的操作化）
- 適用與例外：無。

### 4.2 補充偏誤（巴菲特版）與 agent 專屬偏誤

**PROC-043｜補充偏誤六項（與 4.1 合用）**
- 規則：下列任一出現 → 對應動作：
  - 先有答案再倒推理由（願望是毒藥）→ 回 G1 重跑。
  - 手上現金多、交易熱情高漲時為任何價格找理由 → 等，或加碼已懂的好公司；不因「有錢」買一門不想擁有其普通股的生意的證券。
  - 在意掌聲、在意看起來聰明 → 接受長期看起來平庸，只要沒做蠢事；不以「被認同」作為輸入。
  - 後照鏡：環境劇變仍沿用歷史倍數 → 以當前競爭結構重估。
  - 「應該發生」混入「將會發生」→ 把願望與社會觀點從機率中拿掉。
  - 專長盲點：在相鄰領域過度自信 → 降低部位一級。
- 信心：高（前三項）／中（後三項）｜證據：原文明文＋多文本重複
- 適用與例外：無。

**PROC-044｜agent 專屬偏誤（規則書增一項，推論）**
- 規則：投資 agent 另有七種結構性偏誤，G9 一併作答：
  1. **產出壓力**（T1＋PROC-008）：因為被要求「給出結論」而傾向給買或賣 → 「不動作」與「太難」是合法且常是正確的輸出，與買賣訊號同等完整地輸出。
  2. **附和使用者**（T2＋T22）：使用者已表態看好或看壞 → 先在不看使用者觀點的情況下跑完 G1–G8，再對照；結論相同才可引用使用者論點。
  3. **提示錨定**（T16）：使用者或上下文給了目標價、成本價、前高 → 估值時不得讀取這些數字，價值區間獨立算完後才對照。G8 比較對象不得是過去最好交易、自身歷史買價或歷史最低估值。
  4. **上下文近因**（T18）：最新一則新聞在推理中權重過高 → 問「這件事會不會改變 5 年後的盈餘能力」，不會 → 不作為輸入。
  5. **跨週期自我一致與翻轉**（T5＋PROC-011）：沿用前一週期結論不重新推導，或反過來每週期換一種說法就換動作 → 每次都從事實重推，但動作改變必須指出新成立的條件。
  6. **數字虛構**（PROC-013）：缺資料時以「合理估計」補上 → 一律寫「缺」並降級。
  7. **逆向偏誤**（規則書）：理由含「大家都不看好／跌很多」→ 刪該理由後重跑 G7，仍過才續行（冷門≠便宜）。
- 信心：中｜證據：推論（由原文的誘因、權威、對比、可得性、一致性傾向對映到 agent 的運作方式）＋原文明文（冷門不等於便宜）｜審查：X02、X08
- 適用與例外：無。

### 4.3 多偏誤疊加

**PROC-045｜疊加規則：同向的「是」計數決定動作**
- 規則：把 4.1（T1–T24）與 PROC-043、PROC-044 中答「是」的項目，依「推我做」與「推我賣／推我不動」分兩邊計數。
  - 同一邊 0–2 項：照常，留痕。
  - 同一邊 3–4 項：**紅燈**。本週期不送單；下一週期以反方角色重跑 G9；重跑後若仍 ≥ 3 項 → 目標部位減半（或確定性降一級，取較嚴者）；若其中包含剝奪超反應、社會認同、壓力三者中的任兩項（典型的競價、泡沫、恐慌組合）→ 不做。
  - 同一邊 ≥ 5 項：不做（賣出側：不做「恐慌型賣出」，但論點證偽型賣出照做，見 PROC-055）。
- 信心：高（疊加會產生非線性極端結果；3–4 項即可能出現）／中（計數門檻與動作對應，推論，可調：紅燈 3–4、否決 4–6）
- 證據：原文明文（芒格：多個傾向同向作用產生極端後果；泡沫、詐騙、搶標常是這種組合）＋推論（計數規則）
- 適用與例外：疊加檢查也適用於「全部因素都在說好」的情況：企業面所有好條件同時出現是品質證據，但心理面所有傾向同時推我做是警訊；兩者要分開計，不得互抵。

## 5. 錯誤型態與記帳（H3）

**PROC-050｜兩本帳：作為錯誤與不作為（疏忽）錯誤**
- 規則：每筆決策都記帳，包含「決定不做」但已通過 G0–G6 的候選（觀察名單）。作為帳記：買、加碼、減碼、賣、換股。疏忽帳記：通過關卡卻沒買、買不足、過早賣出優秀企業。疏忽帳要特別記，因為它不出現在損益上，但代價常大於作為錯誤的總和。
- 信心：高｜證據：原文明文＋多文本重複（跨期一致自承）
- 適用與例外：「太難」籃子不進疏忽帳。

**PROC-051｜疏忽錯誤的判定範圍**
- 規則：
  - 算錯：通過 G0–G10、寫得出必寫三件，卻因猶豫、錨定舊價格、等更低價、怕看起來蠢、資金被較差部位佔用而沒買或沒買足；觀察名單標的進入買價上限卻沒執行快速通道；頂級企業因價格以外的理由被過早賣出。
  - 不算錯：能力圈外或「太難」的東西上漲；價格從未進入買價上限的標的上漲。
- 信心：高｜證據：原文明文（只後悔錯過懂了卻沒做或做太小的）
- 適用與例外：無。
- **規則書補充**（措辭／條件補充；審查 X02）：改為「頂級企業因任何非論點理由（含估值、換股）被過早賣出或修剪」均計入驗屍錯誤帳。

**PROC-052｜錯誤歸因：一個主因類別＋若干型態標籤**
- 規則：每個錯誤必須歸到一個**主因類別**：①管理層判斷錯；②企業未來經濟特性判斷錯（最常見）；③價格付錯（含高估成長）；④風險判斷錯（槓桿、對手方、監管、單一變數、尾端）；⑤流程未遵守（跳關、清單未跑、論點檔不完整）。另加**型態標籤**（可多選）：遺漏／買不足、超價、過早賣出、退出延遲、以證券形式保護代替企業分析、能力圈外、單一變數或尾端假設、會計或資訊誤讀、歸因於運氣的成功、對競爭者反應的低估、注意力分散。
- 信心：中｜證據：多文本重複（三類自承錯誤＋風險類由彙整補上；型態由自承錯誤抽象分類）＋推論（第⑤類為 舊版新增，使流程錯誤與判斷錯誤分開）
- 適用與例外：B 的 E5 證券形式、E6 支付方式、E9 併購整合、E13 治理、E18 激勵屬於評估被投資公司管理層時的檢查項，轉入管理層主題，不列為 agent 自身錯誤標籤。

**PROC-053｜評決策品質，不評結果**
- 規則：每筆決策以「當時的資訊、機率估計、流程是否完整」打分；好結果不代表好決策，壞結果不代表壞決策。績效以至少 3 年、完整市場週期為單位，與事先選定的含息大盤指數比較；一生只有數十個重大判斷，單一年度看起來很蠢不構成修改方法的理由。
- 信心：高｜證據：原文明文＋多文本重複
- 適用與例外：**規則書**：方法層檢討的觸發＝至少一個完整市場週期（谷到谷，通常 ≥5 年，可調 5–7）累積落後含息指數，且同期 H3 驗屍顯示流程違規或論點錯誤率 >50%；只是年數落後、且落後集中在多頭年或價值型整體失寵期 → 不改方法，只檢查流程是否被遵守（MKT-037 規則書）；改用指數由使用者決定。這是方法層判斷，不是單筆決策評分。

**PROC-054｜驗屍：買進與賣出都要做**
- 規則：(1) 每筆重大買進或整體收購，在 2–3 年後拿凍結的論點檔（一句話、價值區間、關鍵假設、失效條件）與實際結果逐項比對，標記哪個假設對、哪個錯、錯在主因類別何處；(2) 每筆賣出或減碼（論點類除外的估值、換股類），在 2–3 年後比對賣出後的企業成績與價格，計入「過早賣出」統計；(3) 驗屍不得改寫原預測。
- 信心：中｜證據：多文本重複（對收購做驗屍、比較預測與結果；多數自承的賣出錯誤是賣太早）＋推論（賣出驗屍與 2–3 年參數）
- 適用與例外：驗屍不必公開；記入 H3 帳即可。

**PROC-055｜處理問題的速度：論點一破就行動**
- 規則：持股出現論點證偽、管理層失信、會計問題、或已知的壞業務 → 在發現的同一決策週期內依持有賣出（04）執行，不得以「再等等」「等反彈」延後。壞消息常成串出現；發現一個問題即擴大檢查範圍。
- 信心：高｜證據：原文明文（芒格速度；吸拇指是不作為錯誤）＋多文本重複（巴菲特自承多次拖延）
- 適用與例外：「便宜＋轉弱」但只有一兩季證據的情況，依持有賣出（04）規則先證明永久損傷，不適用本條的立即行動。

**PROC-056｜承認、分析、不沉溺；不用「除了……之外」**
- 規則：錯誤確認後立即記帳並寫原因；不以「除了某個意外因素」解釋損失；不把自己的錯誤歸入「一次性」；每個錯誤寫一行「下次哪一關要怎麼攔下它」，然後停止回顧。
- 信心：高｜證據：原文明文
- 適用與例外：無。

**PROC-057｜錯誤型態的反例庫：每次決策前快速掃過**
- 規則：下單前對照下列 14 條已知錯誤型態，命中任一 → 回到對應關卡重審：①以便宜價買爛生意；②因優先證券或保護條款而放鬆對企業經濟的分析；③進入經濟特性正在惡化的高成本企業，以為好管理層能救壞產業；④（評估被投資公司）以被低估的股票支付收購；⑤過早賣出優秀企業；⑥能力圈內看懂卻沒買或買太少；⑦相信對方管理層或投資銀行的預測；⑧以為多年前的聲譽與文化今天仍然成立；⑨下檔綁單一變數而低估其機率；⑩資產負債表看不透的「便宜」金融機構；⑪對自己喜愛的產業低估其衰退速度；⑫知道問題卻拖延處理；⑬把罕見情境當成不可能、假設某一環境條件會持續；⑭以偶然成功為根據放寬標準。
- 信心：高｜證據：原文明文＋多文本重複（自承錯誤）
- 適用與例外：無。

**PROC-058｜事先定靶**
- 規則：績效尺標、評估週期、預期形狀（強多頭年落後、空頭與盤整年領先）在開始前寫定；讀數變差時才換尺標 ＝ 自欺，禁止。
- 信心：高｜證據：原文明文
- 適用與例外：尺標數字見風險（05）。

**PROC-059｜同一錯誤反覆出現 → 收緊對應關卡**
- 規則：H3 帳中，同一主因類別在最近 5 筆錯誤中出現 ≥ 2 次 → 對應關卡收緊一級（①→ G5 管理層加分項不得抵銷扣分；②→ G3 品質「可」不得續行；③→ 確定性係數降一級；④→ G6 與 PROC-031 由「機率不低」改為「機率非極低」即否決；⑤→ 下一筆交易前完整重跑清單並由反方角色覆核）；收緊持續到該類別在其後 5 筆中出現 ≤ 1 次。
- 信心：低～中｜證據：推論（由「追蹤哪一類反覆出現」「過往有延遲認錯紀錄 → 縮短檢視週期並預設退出條件」推出）
- 適用與例外：樣本少於 5 筆時不啟動。

## 6. 條件式規則（只有當／除非／若…則）

**PROC-060｜條件語必須連同條件一起執行**

## 7. 讀財報與研究資訊來源的流程

**PROC-070｜資訊來源分四級，排除級不得進入任何關卡**
- 規則：
  - 一級（決策依據）：年報全文含附註與審計意見、委託書（薪酬與董事持股）、主要競爭者年報、產業統計；季報只用來觀察營運趨勢，不作為估值依據。
  - 二級（驗證用）：向客戶、競爭者、供應商、前員工的第三方查訪（只取公開或非內線資訊）。
  - 三級（參考，與數字衝突時以數字為準）：管理層公開說明、股東信、說明會。
  - 排除級（不得作為輸入）：賣方報告與分析師預測、管理層的盈餘預測與指引、投資銀行的「調整後」指標、媒體報導、社交場合消息、傳聞、任何非公開重大資訊、他人的持股申報。分析師過去的預測只能作為「測試其準確度」的對象，不作為估值輸入。
- 信心：高｜證據：原文明文＋多文本重複
- 適用與例外：無。

**PROC-071｜研究步驟順序（對應閘門）**
- 規則：依序執行，每步完成前不進下一步：
  1. （G1）讀最新年報的業務描述、分部資料、管理層討論：用一段話寫出「怎麼賺錢、誰是競爭者、哪 2–3 個變數決定成敗、什麼會出錯」，並指出這門生意的產業專屬關鍵指標（單位量、留存率、同店、承保損益、費率等）。寫不出 → 太難。
  2. （G3）拉 8–10 年財務：營運盈餘（排除證券與衍生性損益）、分部盈利、累計資本支出 − 累計折舊、增量盈餘 ÷ 增量資本、股數變化、負債與利息保障。
  3. （G4）讀附註：準備金、退休金假設、股權薪酬、非一般公認會計原則指標、重組與一次性費用的頻率、附註可讀性；發現一個問題 → 擴大檢查範圍（廚房裡很少只有一隻蟑螂）。
  4. （G3、G4）讀至少一家主要競爭者年報，用同口徑比較；同一會計框架下的差異較能反映經濟實質。
  5. （G5）讀委託書與多年股東信：薪酬結構、董事持股、資本配置紀錄（回購價格相對價值、收購事後檢討、是否提及反向綜效）、壞消息是否主動揭露、是否用自己的話解釋業績。
  6. （G6）最壞情境：利息保障趨勢（以稅前盈餘為分子）、到期結構、可追繳條款、對手方集中、表外承諾；金融業看淨額而非毛額、準備金一年後修正方向、承保多年平均。
  7. （G1–G5 驗證）第三方查訪：先用公開文件形成約八成的論點，再用查訪驗證或推翻；問「哪個競爭者最讓它擔心」「若只能打擊一家對手會選誰」，答案與財報的競爭描述是否一致。**規則書**：無法實地查訪時，以公開第三方資料（主要競爭者年報、產業統計、客戶留存或續約等可查證數字）完成同一組問題並逐條附出處；完成 → 確定性上限不受影響；完成不了 → 上限降一級。
  8. （G7）最後才估值。
- 信心：高（順序與項目）／中（八成與兩成的比例）｜證據：多文本重複
- 適用與例外：單一業務企業可省略分部比較。**規則書刪除**：「agent 無法做實地查訪時……確定性不得為最高級」——否則交易 agent 永遠無 A 級，連帶使宿主 A 15%、Q3c 全部失效；改由第 7 步公開資料替代；確定性等級以建倉時論點檔為準，持有中不因無法查訪而降級。｜審查：X30-04

**PROC-072｜時間預算與「看不懂就停」**
- 規則：一份年報約以一次完整閱讀（約一小時量級）為預算，同業比較數小時量級；附註讀數次仍看不懂 → 視為風險訊號（會計排除級），停在 G4，不得略過繼續估值。
- 信心：中｜證據：原文明文（年報閱讀時間的自述；看不懂的附註代表管理層可能不想讓你懂）
- 適用與例外：時間只是預算，不是通過條件；讀得快不代表懂。

**PROC-073｜數字優先於說法，現金優先於帳面**
- 規則：管理層說明與財務數字衝突 → 以數字為準並回查說明；盈餘與現金流長期背離 → 查明原因前停在 G4；看起來精確的估計（小數點多位、特定攤銷年限）不代表真實知識，估計的誤差範圍比位數重要。
- 信心：中高｜證據：多文本重複
- 適用與例外：成長期應收增加可合理解釋背離，需逐項說明。

**PROC-074｜選期與近期數字的陷阱**
- 規則：計算成長率不得只看自選的首末年度，要用全期間與滾動區間；最近一年的數字估計成分最高，不得賦予最大權重；季度或年度盈餘常剛好湊到整數 → 視為盈餘被管理的警訊（交給會計主題計分）。
- 信心：中｜證據：原文明文
- 適用與例外：無。

**PROC-075｜他人的持股申報不是買進訊號**
- 規則：大型投資人（含本 skill 所蒸餾的對象本身）的公開持股申報不得作為任何關卡的輸入或理由；即使要研究其持股，也必須從 G0 起完整重跑，且不得引用「他們持有」來提高確定性。
- 信心：高（原則）｜證據：原文明文（不應因他人持股申報而行動，申報有延遲）＋持倉數據驗證（申報時滯）
- 適用與例外：無。

**PROC-076｜所有事實標日期，用最新可得資料重查**
- 規則：論點檔中每個數字標「資料期間＋來源」；依賴的事實若超過 12 個月未更新，或期間內有新年報 → 重查後才可沿用；記憶中的舊印象（舊市占、舊監管狀態、舊管理層）不得當作現況。
- 信心：中｜證據：多文本重複（以為多年前的聲譽與文化今天仍然成立是自承錯誤）＋推論（12 個月參數）
- 適用與例外：無。

## 8. 輸出格式與訊號（完整模板見 `assets/templates.md`）

**PROC-080｜訊號集合統一為七種，單選**
- 規則：每檔標的每次判斷只輸出一個訊號：
  - **買進**：G0–G11 全通過，論點檔已存。
  - **加碼**：已持有；H1 無惡化；價格 ≤ 買價上限（或確定性提高）；仍勝過 G8 的其他選項；未達目標權重且不破任何上限；G9 清單已跑。
  - **持有**：H1 三要件成立，H2 無觸發。
  - **減碼（至＿%）**：H2 判定估值分批、換股部分、或制度性減碼。
  - **賣出（全清）**：H2 判定論點類（證偽、失信、永久惡化），或依持有賣出（04）屬全清的估值情況。
  - **觀察（買價上限＿）**：G0–G6 通過，停在 G7 或 G8。
  - **不動作**：其他一切情況（預設值），必附理由碼：太難／淘汰（規則編號）／缺資料／紅燈／無新事實／非本 skill 訊號。
- 信心：高（集合）｜證據：多文本重複＋推論（合併 A 的七訊號與 B 的六結論）
- 適用與例外：B 的「不買」「太難」併入「不動作＋理由碼」，因為兩者對宿主的動作相同（不下單），差別只在記帳（太難不進疏忽帳）。

**PROC-081｜訊號必須等於閘門結果，不得出現模糊措辭**
- 規則：輸出的訊號必須能從閘門紀錄機械推得；不得輸出「可考慮」「逢低布局」「中性偏多」等不屬於七種訊號的措辭；不得給價格目標或短期走勢預期。
- 信心：高｜證據：推論（可執行性要求）
- 適用與例外：無。

**PROC-082｜輸出順序：結論在前，證據在後**
- 規則：每份判斷依序輸出：①結論（訊號＋一句話理由）；②閘門紀錄（G0–G11 每關：通過／不通過／不適用＋停止碼＋關鍵事實與資料日期）；③估值（三情境區間、門檻報酬、確定性等級、買價上限、現價 ÷ 保守值、隱含成長）；④風險與反方（10 年永久損失路徑、3 年驗屍前三原因、最強反方論點、失效條件）；⑤心理清單結果（「是」的項目與對抗動作、疊加計數）；⑥部位與執行（目標權重與各上限、首筆、節奏、與現金下限的關係）；⑦追蹤（下次複查時點與觸發事件）；⑧誠實標示（哪些是本 skill 明確規則、哪些是推論門檻、哪些資料缺失或過期）；⑨機器可讀訊號卡。
- 信心：中高｜證據：多文本重複（A 評分卡與 B 輸出格式的聯集）
- 適用與例外：停在早期關卡的標的只需輸出①②⑧⑨，不必填後面各節（寫「未進入」）。

**PROC-083｜每次運行附組合層摘要**
- 規則：每一運行週期輸出一次組合摘要：總資產、現金與下限、借款（必須為 0）、有效檔數、前五大占比、最大單檔、相關群最大合計、事件型合計、本期決策（作為筆數、疏忽候選筆數、待驗屍筆數）、觀察名單中距買價上限最近的標的。
- 信心：中｜證據：推論（A 組合層摘要＋PROC-010 觀察名單）
- 適用與例外：宿主未提供組合資料 → 列出所需資料，不自行假設。

**PROC-084｜不以歷史個案類比作理由**
- 規則：輸出中不得以「這跟過去某筆交易很像」作為論證；只用抽象條件論證。
- 信心：高｜證據：原文精神＋多文本重複（過去成功的聯想是誤判來源）
- 適用與例外：無。
