# 04 持有、複查、賣出與換股

> 本檔是 berkshire-way 規則書的參考檔；SKILL.md 每次必讀，本檔在對應閘門或動作需要細節時讀。規則書修改處以 ``、``、`` 標記，對照 `CHANGELOG_規則書.md`。
> 規則格式：**新編號 規則名** → 條件 → 動作 → 參數｜信心｜證據類型｜適用與例外。
> 證據類型只有四種：原文明文／多文本重複／持倉數據驗證／推論。標「推論」的數字是可調參數。
> 數字若與 SKILL.md 第 5 節參數表不同，以參數表為準（本檔已套用 規則書；標「舊版定版」處為上一版覆寫，若與「規則書」標記衝突，以 規則書為準）。所有「EPS／盈餘／P/E／ROE」依 SKILL 第 0 節全域營業盈餘口徑。
> 「模式 A／B／C」＝資金規模小／中／大，與確定性等級 A／B／C／D 不同；「宿主」＝小資金模擬宿主（單檔 15%、現金 5%、12 檔；無價格停損與移動停損：SKILL 第 7A 節 `stop_mode`＝A，論點破裂檢查）。
> 文中「v2」或「A」指上一版本 skill，「B」指另一份來源整理版本；兩者的編號只供追溯，不是本版規則。

## 1. 總綱（給 agent 的五句話）

1. **預設持有；賣出要舉證。** 長期紀錄中主動賣出平均沒有附加價值（3 年賣對約 52%、5 年約 51%，按金額加權反而略差），所以賣出門檻必須高於買進門檻。
2. **賣出的正當理由只有四類**：①論點／經濟特性／管理層出問題（業務類）；②價格明顯超過價值（估值類）；③有稅後明顯更好的用途或必要資金需求（機會成本類）；④監管門檻、比重相對風險、現金下限（制度類）。四類分開記帳。
3. **價格本身永遠不是理由**：漲多、跌多、持有久、賺多、賠多、成本價、新聞、總經預測，都不能單獨觸發賣出。
4. **最常賣對的是「貴＋轉弱」，最常賣錯的是「便宜＋只有財報轉弱」與「剛買就跑」。**
5. **業務類理由一律全清、快清；估值、稅、資金、制度類才可分批。**「全賣不修剪」是看法改變時的執行紀律，不是所有賣出的執行方式。

## 2. 規則清單

### 2A. 持有預設與持有前提

**SELL-001｜持有前提三要件 → 持有，不設持有期與目標價**
- 規則：(a) 未來資本報酬仍令人滿意且護城河未變窄；(b) 經營者仍能幹、誠實、把報酬導向股東；(c) 市價沒有明顯高於內在價值。三者同時成立 → 持有，不設持有期上限、不設目標價。任一失效 → 進入第 2E 節決策樹（不是自動賣出）。
- 信心：高｜證據：原文明文＋多文本重複
- 適用與例外：只適用於可交易股票的持有判斷；整體擁有的事業見 SELL-052。

**SELL-002｜買進測試就是持有測試**
- 規則：每次複查都重問：「市場關閉五年無法報價，我仍樂意持有嗎？」「股價五年不動，我仍願意持有嗎？」答案從是變否，且原因在企業本身（不是價格）→ 進入決策樹；原因只是價格 → 持有。不願持有十年的東西，十分鐘都不該持有。
- 信心：高｜證據：原文明文＋多文本重複

**SELL-003｜用企業成績評分，不用股價評分**
- 規則：複查只看盈餘是否改善（考量景氣位置）、護城河變寬或變窄、資本配置、價格相對價值；當期股價漲跌不進評分。
- 信心：高｜證據：原文明文

**SELL-004｜時間是好企業的朋友、平庸企業的敵人 → 持有期由企業品質決定**
- 規則：高資本報酬、能再投資的企業 → 長抱，買價溢價／折價隨時間變得不重要；低資本報酬或靠重估獲利的便宜股 → 價值實現（價格回到內在價值附近）就賣，持有越久越吃虧。
- 信心：高｜證據：原文明文＋多文本重複

**SELL-005｜可交易股票沒有永久持有承諾**
- 規則：所有可交易股票都「隨時可賣」，但門檻高；「幾乎永不賣」只適用於整體擁有的事業。不得把「最喜歡的持有期是永遠」解讀成無條件持有。
- 信心：高｜證據：原文明文（後期正式修訂）

**SELL-006｜部位類型只決定複查深度**
- 規則：建倉時標記部位類型（核心／戰術／統計便宜／事件型）。核心部位預期持有以十年計（已結束者中位約 8 年；含仍持有者存活中位 ≥13 年）。**部位類型只決定複查深度，不改賣出決策樹**；舊版以持有期參數作為「小部位／戰術部位價格回到 IV 即賣」依據的寫法刪除。統計便宜（SEL-124）與事件型（P-41）依各自規則出場。
- 參數：小部位歷史持有期約 1.5–3.5 年（依歸屬口徑）。
- 信心：中｜證據：持倉數據（19 個大部位中 6 個左截斷、8 個仍持有）｜審查：X24

### 2B. 持有期複查（節奏與清單）

**SELL-010｜複查節奏**
- 規則：每季財報出來時做「輕複查」（只看 R2、R4、R5、R7 有無新惡化訊號，10 分鐘級）；每年做一次「完整複查」（R1–R10 全跑並更新內在價值）；出現重大新事實（管理層異動、會計問題、產業規則改變、重大併購、監管行動）時立即做完整複查。不看每日報價做決策。
- 信心：中｜證據：原文明文（年度檢討、不需看每日報價）＋推論（季度輕複查為合併兩版後的參數；B 寫「每月或每季」，A 寫「每年及重大事實時」）

**SELL-011｜完整複查清單 R1–R10（任何一題惡化 → 記錄並進決策樹；全部無惡化 → 持有，不動作）**
| # | 題目 | 惡化訊號 |
|---|---|---|
| R1 | 買進時寫下的 3–5 個關鍵假設仍成立？ | 任一條被事實否定 |
| R2 | 護城河變寬或變窄？ | 市占持續下滑、毛利結構性收縮、定價權消失、低成本優勢被追平 |
| R3 | 產業結構有無永久改變？ | 替代技術、管制改寫報酬上限、外部資金湧入使供給大增而需求不變 |
| R4 | 資本報酬仍令人滿意？ | 營業 ROE（證券按成本計的權益）／ROIC **趨勢**連續數年下滑且非景氣循環所致；需大量追加資本才能維持 |
| R5 | 管理層仍能幹、誠實、專注？ | 拿本業現金亂買平庸企業、承諾平滑的兩位數成長（規則書：警訊，依 SELL-027(C)）、遮掩或怪罪、會計激進、出事後懲罰客戶而非修正激勵 |
| R6 | 保留資本增量報酬滾動 5 年 ≥ `r_d`（規則書：以 R_IV 為主；市值版只作輔助，見 MKT-061） | 長期不達標 |
| R7 | 價格相對內在價值？ | 高估警報（SELL-031） |
| R8 | 有稅後明顯更好的用途？ | 符合換股門檻（SELL-040） |
| R9 | 風險輪廓改變？ | 地緣、所在地法規、責任無上限而報酬受限、負債或衍生品曝險變大（「最壞損失無上限而報酬有上限」→ SELL-030a 可單獨成立） |
| R10 | 部位相對「可能出錯範圍」過大？ | 關鍵變數變得無法預測，且部位大到出錯會傷及整體 |
- 信心：高（R1–R5、R8）／中（R6、R7、R9、R10）｜證據：多文本重複；R4 的「看趨勢不看水準」為持倉數據驗證

**SELL-012｜區分週期性與結構性**
- 規則：惡化先分類。週期性／暫時性（產業實物量、長期市占、單位經濟仍完好）→ 持有，可視價格加碼；結構性（長期需求萎縮、護城河被永久侵蝕、產業規則改變）→ 進入賣出評估。某些產業的景氣循環很長，循環長本身不構成賣出理由。
- 判準：要能指出**具體的結構性因素**；只有一兩季的獲利下滑不算。
- 信心：高｜證據：原文明文＋多文本重複
- **規則書**：落後競爭者先分「可修的執行落後」與「結構性喪失」；前者只觀察，不構成 Q4 證據。已發生的負面事實 → P-50 觀察；尚未發生、時點不明的遠期威脅 → 寫入 10 年出錯路徑與可觀察失效條件，不進 P-50。｜審查：X10、X08b

**SELL-013｜單一事件測試**
- 規則：醜聞、訴訟、單季虧損等單一事件，只問一題：「會不會改變企業的基本動態與 5 年後的盈餘能力？」不會 → 不賣；會 → 進入賣出評估。同時評估管理層處理是否快速、坦白。
- 信心：中｜證據：原文明文

**SELL-014｜威脅分級**
- 規則：把威脅分為小／大／致命並估機率；只有「大或致命，且機率不低」才動作。買進時本就預期有競爭，優勢略減不換股。
- 信心：高｜證據：原文明文

**SELL-015｜賣前求證**
- 規則：因護城河疑慮想賣之前，若能取得懂該產業者的資訊（產業數據、通路、客戶行為），先確認特許權是否真的受損；管理層的樂觀說法不能當作護城河仍在的證據。
- 信心：中｜證據：原文明文

**SELL-016｜「不舒服」要具名**
- 規則：持有不舒服時，寫下具體是哪個前提（R1–R10 哪一題）失效；寫不出來 → 持有。
- 信心：中｜證據：推論（由多處「把不安與論點破裂分開」的原文與危機中賣出多半賣錯的數據合成）

**SELL-020｜不賣清單**
| # | 衝動 | 指令 | 信心／證據 |
|---|---|---|---|

### 2D. 賣出理由（依優先序；任一成立才進入執行）

**SELL-025｜業務類 1：論點被證偽 → 全清**
- 規則：買進時寫下的關鍵假設被新事實否定，且無法修復（先評估能否修復與時程；可修復且時程 ≤ 一個完整複查週期 → 觀察，見 SELL-060）→ 承認錯誤、整筆出清。不降低標準重新合理化，不為扳平而續抱或加碼。
- 信心：高｜證據：原文明文＋多文本重複

**SELL-026｜業務類 2：經濟特性永久惡化 → 重估後處理**
- 規則：重估後認為競爭優勢不如買進時、產業被外力永久改變、監管讓報酬永久受限、產業競爭動態惡化 → 依 SELL-012 確認為結構性後：回 G3 重新分類，以結構性情境（成長歸零或起伏型）重算 `IV_base`：重分類為可怕型或價格 ≥ 新 `IV_base` → 全清；否則持有、確定性降一級、停止加碼，並以 Q6 換股門檻比較。判斷依據是「重估後的預期」，不必等公司虧損或股價崩跌。前景根本改變、會持續燒錢者，停止追加資金。
- 明文禁止以「等待優勢恢復」為續抱理由；第一個年度出現市占下滑＋定價權流失同時成立 → 停止加碼並以結構性情境重估（**不**自動減碼，與原文處理一致：重估、確定性下降、仍持有）。
- 信心：高（原則）｜證據：原文明文（原作者以新經濟特性重估價值、確定性下降，再依價值與機會成本處理；同一受影響企業仍被描述為優於一般企業）＋多文本重複｜審查：X02、X05、X06

**SELL-027｜業務類 3：管理層失信或品質變差（規則書改寫：拆兩支＋警訊）**
- (A) 立即全清（任一）：管理層本人說謊、欺騙、掩蓋已知問題；會計問題（造假、刻意誤導）；當初買進的核心理由（經營者、文化、激勵）被事實證實錯；資本配置確定轉向為規模或自尊擴張。
- (B) 先觀察後全清：子公司或基層層級的不當行為 → 停止加碼，進 P-50 觀察，期內查三項：誘因制度已改、受害者已補償、可量化的監管處分已入帳；管理層發現問題後選擇壓制客戶或員工而不修正制度 → 視同文化問題，全清；三項任一逾期未成立或出現第二個獨立負面事實 → 全清。
- (C) 警訊（不單獨觸發賣出）：對外承諾平滑而高的長期盈餘成長率 → G4 會計警訊加一級並做 R5 複查；若為了達成承諾而擴張到新的風險業務、提高槓桿或改變資產負債結構 → 依 (A)「論點被證偽」全清。
- 少數股東無法撤換管理層，「等他們改」只在 (B) 的觀察期限內成立。誘因設計失誤且已修正，不等於誠信存疑；發現後掩蓋或懲罰受害者才是（NEVER-04）。
- 信心：中高（A）／中（B、C）｜證據：原文明文（A）＋原文與實際出清紀錄（B）＋原文暗示（C 後段）｜審查：X06、X08b、X19w、X19c、X19b

**SELL-028｜估值類：價格明顯超過價值 → 依企業等級分級處理**
- 規則：見決策樹 Q3 與 SELL-031 的參數；「漲很多」不等於高估，必須有內在價值估計做比較。
- 信心：中高｜證據：原文明文（後期自承泡沫期沒賣是錯）＋持倉數據驗證（估值型賣出命中率高）

**SELL-029｜機會成本類：換股或必要資金需求**
- 規則：(a) 換股：見 SELL-040；(b) 為抓住罕見的大機會或維持現金下限而需要資金 → 賣組合中**最不吸引人**的持股（即使它仍合理甚至被低估），設底價、分批；這類賣出記為「非負面判斷」，不代表看壞該企業。
- 信心：高｜證據：原文明文＋多文本重複

**SELL-030a｜風險輪廓改變**

### 2H. 稅負與交易成本

**SELL-045｜稅的定位：換股的過路費，不是持有或賣出的獨立理由**
- 規則：比較持有與換股一律用稅後數字；遞延稅等於無息、無到期日的貸款，提高換股門檻。但：(a) 論點破裂時寧可繳稅也要賣；(b) 稅不能單獨觸發賣出，也不能單獨阻止賣出；(c) 預期稅率明顯上升時，可把「已決定要減的部位」提前實現；(d) 就算沒有資本利得稅，也不會更頻繁交易——長抱的主因是企業品質；(e) 目標是稅後複利最大化，不是少繳稅；(f) 有免稅的退出路徑（以股換資產、免稅合併）時優先。

- 信心：高｜證據：原文明文＋多文本重複
- **規則書補充**（措辭／條件補充；審查 X02）：(d)補一句：原文承認長抱有非財務理由；agent不得以「長抱必然報酬較高」為持有理由，持有仍需通過SELL-001三要件。
- **規則書補充**（措辭／條件補充；審查 X20b）：(b) 加例外：「已承認判斷錯誤、且帳上虧損可在法定期限內抵用已繳稅款的部位，可為實現稅損提前賣出；不得把稅損當作新買理由」。

### 2I. 不賣的條件與「不買不賣」區

**SELL-050｜「不買不賣」寬區間**
- 規則：價格高於自己的買價上限、但未達 Q3 賣出觸發 → 持有，不加碼、不減碼。部位已大、稅與交易成本高、又找不到通過 SELL-040 的替代 → 即使價格明顯偏離價值（未達荒謬級），也維持現狀。
- 信心：中｜證據：原文明文（頻率低）＋推論（區間界線取 SELL-031 與買價上限）

**SELL-051｜明確「不賣」的情況（全部成立時持有，不受任何價格變化影響）**
- 三要件成立（SELL-001）；R1–R10 無結構性惡化；未達 Q3 觸發；沒有通過 SELL-040 的替代；沒有制度限制 → 持有。
- 頂級複利企業：賣太早的代價遠大於賣太晚；原文多次自承的賣出錯誤幾乎都是「賣太早」與「修剪了好企業」。對這類企業，只有 Q2 或 Q3c 的荒謬級／警報條件能觸發賣出。
- 信心：高｜證據：原文明文＋多文本重複＋持倉數據（高品質只因貴而賣 ≈ 拋硬幣）
- **規則書**：頂級的確定性等級以建倉時論點檔為準，持有中不因無法查訪而降級；Q3c 參數改為 ×1.3、警報 ≥3、≤1/4、保留 2/3（原文多次自評修剪頂級企業是錯）。

**SELL-052｜整體擁有的事業（多數 agent 不適用）**
- 規則：整體擁有的營運事業幾乎不賣，出價高也不賣；只在 (1) 可預見的持續虧損或燒錢、(2) 根深蒂固無法解決的勞資衝突、(3) 聲譽風險、(4) 已不再產生營業現金流時才出售或結束。先試賣給他人，無人接手則在一段時間內逐步結束。退出需一年以上，所以買前審慎度要更高。
- 信心：高｜證據：原文明文＋多文本重複
- 適用：只在宿主系統持有「整體控制」型資產時使用；純股票帳戶跳過。

### 2J. 論點失效處理與錯誤承認速度

**SELL-060｜「觀察」狀態必須有期限（舊版補強）**
- 觸發：Q2 只有疑似、尚未確認；Q4 只有財報轉弱；R9／R10 出現但未定性。
- 動作：(1) 立即停止加碼；(2) 寫下 1–3 個可被證偽的檢查點（具體指標與方向）；(3) 期限＝接下來兩次季報或 6 個月，以先到者為準；(4) 到期必須結案為「持有」或「全清」，不得無限延長、不得只延長一次以上；(5) 期限內出現第二個獨立的負面事實（壞消息成串）→ 視為確認，依 Q2 全清。
- 信心：中｜證據：原文明文（「看到一隻蟑螂就有同伴」「慢慢賣代價很高」「不要等完全確定」）＋推論（期限參數）
- 可調：期限 1–3 次季報。
- **規則書**：只有已發生的負面事實才進觀察；尚未發生、時點不明的遠期威脅寫入 10 年出錯路徑與失效條件，不進觀察。

**SELL-061｜錯誤承認的速度：一律採芒格速度**
- 規則：論點破裂、壞業務、或有負債一經確認 → 當下處理，不等回本、不等「再看一季」。買錯可以接受，明知錯了還不賣是更大的錯。不為扳平加碼；也不因怕錯過未來漲幅而永遠不肯讓部位變小（兩個方向的剝奪超反應都要防）。
- 信心：高｜證據：原文明文＋多文本重複

**SELL-062｜壞業務停止注資**
- 規則：前景根本改變、會持續燒錢的持股或事業，停止任何追加資金（不把好錢丟進壞錢），能退出就退出；以優先股或其他保護性形式「救」業務不佳的發行人也算追加資金。
- 信心：高｜證據：原文明文＋自承錯誤分類

**SELL-063｜事後驗證（驗屍）與賣出打擊率回饋（舊版補強參數）**
- 規則：每筆賣出記下類別（業務／估值／估值＋業務／換股／資金／制度）、當時的內在價值、觸發的決策樹路徑。每年計算：被賣股票之後 3 年、5 年相對「同期留下持股」的表現與賣對比率，按類別分開。累積 ≥20 筆非制度類賣出後：某類別 3 年賣對比率 <50% → 該類別門檻收緊一級（Q3c 倍數 +0.1、Q4 再加一道非財報證據、換股差距 +0.1）；>65% → 維持。制度類不計入。同時把賣出與買進的後續結果並列，賣出明顯較差 → 提高所有賣出門檻。
- 信心：中｜證據：原文明文（巴菲特與芒格都主張驗屍、「打擊率太差就交出決策權」）＋推論（20 筆、50%、65% 參數）

**SELL-064｜用雙視窗檢討，避免被單一結果誤導**
- 規則：每筆賣出同時看 3 年與 5 年；避開災難型（避險、金融、高槓桿）賣出另看是否在壓力事件中被證明；單一賣出的事後結果不能推翻規則，只能用決策當時的資訊判斷是否該賣。
- 信心：中｜證據：持倉數據驗證（部分自承錯誤 5 年內是賣對、10 年才變賣錯）＋原文明文

### 2K. 加碼條件（持有中部位）

**SELL-070｜加碼的必要條件（全部成立）**
- (1) 三要件仍成立、R1–R10 無結構性惡化、不在「觀察」狀態；(2) 價格 ≤ 買價上限（與新建倉相同的估值與品質門檻，不放寬）；(3) 加碼後權重不超過等級上限與尾部上限（屬 M3）；(4) 通過機會成本測試：「加碼這檔」與「開新部位」「加碼其他持股」比較，選期望超額報酬×確定性最高者。
- 信心：高｜證據：原文明文＋多文本重複

**SELL-071｜下跌是加分，不是條件；可以向上攤平**
- 規則：基本面未變而價格下跌 → 優先加碼（市場大跌時先加碼現有持股，其次才是新標的）。價格高於首筆也可加碼，只要仍在買價上限內或確定性提高；不錨定首筆價。
- 參數：實際約四分之三的加碼價高於首筆，加碼價中位約首筆的 1.08 倍；已持有的好企業跌 25–30% 且有資金 → 加碼。
- 信心：高（原則）／中（參數）｜證據：持倉數據驗證＋原文明文

**SELL-072｜禁止加碼的情況**
- 為扳平而加碼正在惡化的生意；觀察狀態中的部位；低信念的邊緣部位（不行就清掉）；估值減碼後價格尚未回到買價上限以下；比重已因上漲而在複查中（宿主 >25%、一般 >40%）；H0 轉換未完成的舊部位（A 案無停損，「距停損 ≤3%」條款已刪除）。
- 信心：高｜證據：原文明文＋推論（後兩項為合併規則的一致性要求）

**SELL-073｜賣出後可以再買**
- 規則：賣出不代表永久放棄；價格重新回到買價上限以下且論點成立 → 照新建倉流程再買，不錨定當初賣價。但禁止「先賣等更低再買回」作為操作意圖（SELL-020 N6）。
- 信心：高｜證據：原文明文

### 2L. 規模、市場狀態與芒格變體

**SELL-080｜規模切換**
- 模式 A：換股是主要賣出理由；統計便宜型到價即賣；可快速全清。模式 C：主要賣出理由是「重估經濟特性」與估值；存在「不買不賣」寬區間；大額出清需預先規劃路徑（分批、賣回公司、免稅交換），越過持股門檻有制度成本。
- 信心：高｜證據：原文明文＋多文本重複

**SELL-081｜市場整體偏貴時，不以大盤預測賣，但允許個股紀律加總成現金**
- 規則：不因看空大盤賣好企業；但市場整體偏貴、又找不到便宜標的時，允許「高估警報已成立」的持股依 Q3 賣出，所得留為現金、不急著再投入。這是個股紀律的加總，不是擇時。

**SELL-082｜危機中**
- 規則：危機中不因價格賣好企業；可以賣次佳持股換更好的機會（SELL-040／SELL-043），或因產業結構永久改變而賣（SELL-026）。危機中賣出不代表看空大盤。
- 信心：中｜證據：原文明文＋持倉數據驗證（危機中低股價淨值比賣金融股多半賣錯）

**SELL-083｜芒格變體（切換時整組套用）**

- 信心：中高｜證據：原文明文
