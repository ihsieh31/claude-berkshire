## 1. 風險的定義與生存優先

**RISK-001 風險＝持有期內永久損失資本或購買力的機率，不是波動。**
- 規則：評估任何部位時，主要風險量尺是「永久損失的機率與幅度」（含稅與通膨侵蝕），依序問：企業長期經濟能否可靠評估 → 管理層能力 → 管理層會不會把報酬留給股東 → 買價 → 稅與通膨。β、標準差、VaR、常態分布模型不得作為買／不買的主要依據；價格下跌而內在價值未永久受損時，視為安全邊際變大（可加碼），不是風險變高。
- 動作：風險評估欄位必須寫「會導致永久損失的路徑」與「每條路徑的觸發條件」；只填波動數字者視為未完成，不得下單。
- 信心：高。證據：多文本重複（早期到晚期的信、股東會、芒格演講）。
- 適用與例外：組合或被投資公司有槓桿、短期必須付現的負債、追繳條款時，波動會轉成實質風險（被迫在低價賣出）→ 此時波動必須納入（見 RISK-004）。

**RISK-002 先求不死：任何一條會讓淨值或持續經營歸零的路徑，不論機率多低都拒絕。**
- 規則：一長串好報酬乘上一個零仍是零。若一個方案存在「歸零或存續受威脅」的路徑，即使期望值為正、機率估計極低，也不做或縮到該路徑不再致命。不為「無關緊要的額外報酬」承擔致命風險；99:1 或 1000:1 的勝率都不構成理由。
- 動作：被投資公司的商業模式或資本結構存在致命路徑 → 不買；持有中出現 → 賣（論點類，全清快清，v2 D-18）。
- 信心：高。證據：多文本重複（兩人一致，跨所有時期）。

**RISK-003 業務風險先於市場風險；能想出很多條出錯路徑就直接放棄。**
- 規則：先看企業本身的風險來源：過多負債、長前置期與大額資本投入、非低成本的商品型業務、5–15 年內可能削弱經濟優勢的事。若列出的可信出錯路徑多到無法逐條判斷，不去替每一條定價，直接放棄。
- 動作：可信出錯路徑 ≥ 4 條且其中任一條會讓內在價值永久下修 ≥ 30% → 不買（推論參數：數字由「多條路徑無法逐條判斷」的原文轉成可執行門檻；可調 3–5 條、25–40%）。
- 信心：高（原則）／低（數字）。證據：原文明文（原則）；推論（數字）。

**RISK-004 只用別人抽不走的資金承擔風險；被迫賣出是最主要的實質風險來源。**
- 規則：承受價格下跌的能力，取決於資金不會在最壞時點被抽走：沒有追繳、沒有短期到期、沒有評等觸發條款、沒有隨時可要求還款或追加擔保的對手。財務耐力三要素：龐大且可靠的盈餘、大量流動資產、沒有大額近期現金需求；缺一就降低風險承擔。
- 動作（組合）：完全不借款、不用保證金、不賣出可被追繳的合約（v2 D-10，此處只重申）。動作（被投資公司）：見第 3 節財務強度檢查。
- 信心：高。證據：多文本重複。

**RISK-005 組合必須事先寫下可承受的回撤，且承受時不會被迫賣出。**
- 規則：組合設計須能承受至少 −50% 絕對回撤（規劃到 −55%～−60%）與約 −75% 相對大盤落後；3 年內 20–30% 的下跌、10 年內 35–40% 的下跌都應視為會發生。承受不了的資金，改用更分散、更保守的版本。
- **動作（規則書：`stop_mode`＝A）**：宿主無價格停損，「宿主有強制停損 → 分散版本」不再觸發；回撤規劃為至少 −50%，規劃到 −55%～−60%（B 案寫法見 SKILL 附錄 7A-B，未採用）。宿主有回撤清算線且高於 −50% → 分散版本照用。
- 信心：高。證據：原文明文＋持倉數據（持有期最大回撤中位約 −22%，約 24% 部位曾 ≤ −50%）＋學術研究（集中組合實際最大回撤約 −51.5%）｜審查：X27、X28

**RISK-006 風險管理不可外包；看不懂就等於不知道風險。**
- 規則：決策者本人兼任首席風險官，不依賴評等、模型、委員會或管理層聲明。看不懂的帳冊、合約、附註，推定其風險未知且可能是故意的，直接走開。
- 動作：任何關鍵數字只有管理層自評、沒有可驗證來源（第三方、長期實際結果）→ 以保守假設替代；替代後仍無法估值 → 不買。
- 信心：高。證據：多文本重複。

**RISK-007 問題一出現就處理（芒格速度）。**
- 規則：發現或有負債、壞業務、會與危機正相關的暴險、資料開始對不上時，立刻縮減或退出，不等待「再看一季」。這類問題會在最需要資本時把資本吞掉；小問題不處理會演變成系統性腐敗。
- 動作：持有中命中第 9 節任一「論點破裂級」訊號 → 當期內減碼至少一半，查證後未解除 → 全清。
- 信心：高。證據：原文明文（芒格稱拖延為「吸手指」，巴菲特自承多次拖延）。

**RISK-008 不靠預測代替準備；模型與歷史資料系統性低估尾端。**
- 規則：「預期會更好」不是風險控制；必須以資本與流動性實際準備。歷史損失資料在長期順風後最危險；模型「大多時候有效，從不 100% 有效」；聽到「這是 5–6 個標準差事件」就把模型打折。以最壞情境為起點，再判斷能否承受。當估計誤差可能讓結果翻倍時，不得用點估計做決策。
- 動作：被投資公司的風險控制依賴模型機率、動態避險或「歷史從未發生」的論述 → 以最壞情境重算；重算後不能承受 → 不買。
- 信心：高。證據：多文本重複。

**RISK-009 通膨與稅是實質風險；帳面零波動的資產可能是高風險資產。**
- 規則：用實質、稅後報酬判斷是否真的賺到。長期持有的名目資產（現金、長債）在通膨與財政失序下會實質縮水；需要持續大量資本投入的企業在通膨中吃虧，資本需求低、有定價權的企業較耐通膨。
- 動作：被投資公司「維持性資本支出 ÷ 折舊」長期 > 1.3 且無定價權 → 通膨情境下的業主盈餘下修，估值降一級（推論門檻，可調 1.2–1.5）。
- 信心：高（原則）／低（門檻）。證據：多文本重複（原則）；推論（門檻）。

**RISK-010 不救失敗的投資；不以「別人也在做」為理由。**
- 規則：不用好資產去補已失敗的部位（追加資金救援是常見且危險的錯誤）；「別人也在做」是最危險的理由（承保、放款、投資皆同）。
- 動作：加碼前必須能寫出「與首次買進時相同或更強的論點」；若加碼理由是攤平虧損或同業都在做 → 不加碼。
- 信心：高。證據：多文本重複。

## 2. 尾端、累積與相關暴險、單一事件損失上限

**RISK-011 依「暴險」而非「近期經驗」估尾端；看似無關的暴險在危機中會一起出事。**
- 規則：把所有暴險依「共同失敗原因」分群（同一信用循環、同一商品價格、同一監管者或法律理論、同一地理巨災、同一融資市場、同一對手方），每群在壓力情境下視為相關係數接近 1。牛市後期以過去損失經驗定價最危險；以暴險為基礎的正確費率可能是經驗費率的數倍。
- 動作：分析被投資公司時，列出前三大暴險群與其最壞情境損失；只列單一暴險、未做相關情境者，風險檢查視為未完成。
- 信心：高。證據：多文本重複。

**RISK-012 單一事件（含相關事件群）最壞**稅後**損失 ÷ 股東權益（規則書改寫，即 P-57）。**
- 規則：適用於承擔巨災、信用、衍生品或其他尾端風險的被投資公司（保險、再保、擔保、放款、賣出選擇權者）。分子：有政策上限者用揭露上限換成稅後（×（1 − 有效稅率）；未揭露稅率用法定稅率並標「代理」）；無上限者用自估最壞稅後損失；兩者皆無 → 不買。市場連動型衍生品不放本條（依 RISK-029 併入 RISK-044 市場情境）。同時記錄「揭露的上限」與「揭露的實際暴險估計」。
- 動作：≤3% → 通過；3–6% → 只有在該稅後損失 ≤ 一年正常化稅後盈餘（RISK-013 ≤1.0）時通過並降一級，否則不買；>6% 或無法估計 → 不買（推論，可調 2.5–3.5%／5–7%）。持有中：升破 6% 或 RISK-013 >1.0 → 完整複查走 Q2，**不自動減碼**（舊版「持有中 >5% 減碼一半」已刪除：原文無依據，且原型自身會被觸發）。
- 稅前對照（只作註）：35% 稅率下稅後 3%／6% ≈ 稅前 4.6%／9.2%；21% 稅率下 ≈ 稅前 3.8%／7.6%。原型晚期稅後約 1.6–2.9%（全部通過），早期約 3.6–5.6%（中間帶，須以盈餘吸收）。主要巨災險種近期損失頻率或強度顯著高於長期紀錄時，本條與 RISK-013 以頻率或強度 ×1.5（可調 1.3–2.0）重算；同期費率下降而該公司巨災暴險上升 → 降一級。
- 信心：中高（原則與 3% 原文錨點）／中（6% 與中間帶）。證據：原文明文（稅後 3%）＋原文數字換算＋推論｜審查：X02、X16、X16b、X17a、X17b、X17c、X17w、X03
- 適用與例外：上限只涵蓋「單一事件」，不涵蓋長尾累積、新責任理論擴張與除外條款被推翻 → 這三項另用 RISK-014、RISK-024、RISK-042 處理。

**RISK-013 存活緩衝：最壞合理單一事件**稅後**損失 ≤ 一年正常化稅後盈餘（含非保險盈餘）。（規則書統一稅後）**
- 規則：好的承擔者在最壞合理巨災年仍大致損益兩平或小幅獲利；可承受損失與威脅償付能力的損失約差一個數量級。
- 動作：最壞合理單一事件稅後損失 ÷ 正常化年度稅後盈餘 ≤ 1.0 → 通過；1.0–2.0 → 降一級（且 RISK-012 中間帶不通過）；> 2.0 → 不買。長期壽險、年金、長照、失能業務的大流行壓力（綜合率 110% 持續 2 年）計入本條尾端。
- 參數依據：比例門檻為推論，可調 0.8–1.5。
- 信心：中（原則）／低（倍數）。證據：原文明文（原則）；推論（倍數）｜審查：X02、X21-10

**RISK-014 無法估計暴險的尾端；條款不等於保護（規則書改寫：開放式長尾拆兩塊）。**
- 規則：核、化、生物、大規模網路攻擊累積、疫情類責任等無法估計暴險上限的尾端，不得以「模型機率低」或「已有除外條款」視為已處理；除外與限額條款可能被法院或立法推翻。
- 動作：開放式長尾負債拆兩塊：(a) 有合約總賠付上限者 → 剩餘上限（上限 − 已付 − 已提）列入 RISK-042 的「長尾上限缺口」；(b) 無上限者 → 已提列淨額 ÷ 權益：≤5% 且生存比率不低於產業 → 不扣分；5–10% → 降一級並做 RISK-041；>10% 或未揭露金額 → 不買（推論，可調 4–6%／8–12%）。「無法可靠估計合理可能的額外損失」是產險常態揭露用語，不單獨構成排除。持有中新出現 → 降一級並觀察一季，期間不加碼。
- 信心：高（原則）／中（門檻）。證據：原文明文＋年報附註校準｜審查：X16a、X15、X16c

**RISK-015 不承擔無上限責任；結構上要能讓一部分失敗而整體存活。**
- 規則：任何需要承擔無限連帶責任、無上限保證、無上限賠付的業務或交易不做。母公司對子公司的保證會改變實際追索範圍：「非追索」必須逐項以附註確認，母公司「絕對、無條件、不可撤銷」的保證視同母公司負債。
- 動作：被投資公司有無上限保證或對金融子公司的全額擔保 → 把被擔保債務併入母公司償債能力計算（第 3 節）；責任無上限且金額無法估計 → 不買。
- 信心：高（無上限責任）／中（保證併算）。證據：原文明文。
- **規則書**：求償對象為無追索、獨立融資且母公司未保證的子公司（逐項確認）→ 損失上限＝母公司對該子公司的權益帳面（RISK-076）。分段收購的賣方賣權或可贖回少數股權 → 最可能行使金額計入負債與 12 個月現金需求。｜審查：X21-05
- **規則書補充**（措辭／條件補充；審查 X17c）：RISK-015 動作補：「母公司對子公司的資本承諾、維持協議、集團內放款，視同有條件保證，逐年確認金額與到期日；承諾到期或放款收回時重算」。

**RISK-016 組合層的相關暴險群：共同情境永久損失 >5% 停止新買、>10% 減碼。（舊版定版，推論）**
- 規則：把組合持股依 RISK-011 的共同失敗原因分群（金融股在信用危機中、同一商品價格驅動者、同一監管裁決驅動者）。對每群設一個「論點錯誤」情境，估計各持股的永久減損比例（金融類預設 50%、非金融預設 30%，可改用估值的悲觀情境），加總權重 × 減損。
- 動作：任一情境永久損失 ≤ 5% → 通過；5–10% → 該群停止新買與加碼；> 10% → 從該群中最弱（確定性最低）的持股開始減碼，直到 ≤ 10%（記「制度」）。
- 參數依據：保險單一事件上限 3–5% 的移植＋有價證券歷史實際永久損失約淨值 0.5–1%（原文自述）。屬推論，可調：軟線 3–7%、硬線 8–12%；與 POS-046 相關群上限並用，取較嚴者。
- 信心：低。證據：推論。
- **規則書**：賣出股價指數尾端的合約損失併入本條同一市場情境（RISK-029）；主要抵押品價格 ÷ 收益價值 >2 倍且漲幅遠超通膨 → 視為同一共同失敗群以壓力重算（推論）。｜審查：X17c、X14

**RISK-017 長期承諾只和最強的對手方往來；分散的信用暴險在危機中同時出事。**
- 規則：再保人、衍生品對手、擔保提供者、存款或融資來源的履約能力不能假設；再保人倒閉時原承保人通常同時受重創；降評觸發擔保追繳會引發流動性螺旋。
- 動作：被投資公司的關鍵對手方應收（再保可回收款、衍生品應收、擔保）÷ 股東權益 > 50%，且對手方強度不明 → 降一級（推論門檻，可調 30–100%）。
- 信心：高（原則）／低（門檻）。證據：多文本重複（原則）；推論（門檻）。

## 3. 被投資公司的財務強度檢查（非金融為主；金融業另見第 5、6 節）

**RISK-018 償債判準是「最壞情境下確定能履約」，不是常態覆蓋倍數。**
- 規則：1% 的困境機率不能用額外報酬抵銷；要問的是衰退、利率上升、融資市場關閉同時發生時，公司能否不靠外部資金撐過去。
- 動作：以「營業利益下修 30%、再融資利率 +300bp、24 個月無法發新債」的壓力情境重算（推論情境，可調）；壓力下利息保障 < 2 倍或須出售核心資產才能還債 → 不買。
- 信心：高（原則）／中（情境參數）。證據：原文明文（原則）；推論（情境）。

**RISK-019 利息保障（非金融；規則書改寫，即 P-06）。**
- 規則：分子＝稅前息前營業盈餘（剔除證券與衍生品損益、一次性利得；受管制業務的稅額抵減若有持續性證據可加回）；分母＝對母公司有追索的經常性利息（外幣債重估、提前清償損失不計；配對融資子公司的利息與收入同時剔除，另以 RISK-026／RISK-052 檢查期限錯配）。只用完整會計年度或近 4 季滾動。多元控股：非金融、非受管制分部單獨計算；母公司未保證的受管制或融資子公司各自計算。禁用 EBITDA。
- 判定：5 年中位 ≥5 倍通過（可調 3–7 年窗口）；最近一年 <5 但 5 年中位 ≥5、下降可歸因於單一危機年 → 降一級續行（driver_id 利息保障），不直接不買；5 年中位 <5 → 不買。趨勢：同一合併範圍內連 3 年下降且最近一年 <8 倍 → 降一級（推論）；範圍因收購改變的年份重算前期或跳過。
- 受管制放寬：同時符合 (a) 盈餘來自多個彼此不相關的受管制轄區或資產、(b) 允許報酬所對應的風險有界（侵權與非經濟損害有上限、成本可回收、監管機關未推翻既有成本回收）、(c) 近 10 年無重大不利監管裁決且通過 RISK-025 最壞情境（可分配現金下降 ≤30%）→ 下限 2.5 倍（可調 2–3.5）；2.0–2.5 → 降一級並跑 RISK-018；任一條件不成立 → 回到 ≥5 倍，P-07 例外取消；持有中條件 (b) 失效 → 視為 Q2 結構性證據（不需等兩個年度）。舊版「受管制 2–3 倍無前置條件」與「受管制 ≥5 倍」兩提案均否決。
- 保險、再保主體不適用本條（改走 P-57～P-59）。
- 信心：中。證據：原文（原則與受管制多元化理由）＋原型申報數字校準＋推論（門檻）；被買公司中位約 15–30 倍、母體約 8 倍（舊版「7.7 倍」無法重現，已更正）｜審查：X21-01、X21-02、X21-03、X21-07、X21-08、X21-09、X21-10、X03、X04、X10、X26、X29

**RISK-020 不依賴持續再融資才能存活。**
- 規則：需要持續再融資、或需要「明天早上付現金」的結構，是生存風險，不是財務技巧。期限短或浮動本身不扣分；只看 24 個月到期額是否被現金與已承諾長期融資覆蓋；偏好長期固定（非硬條件）。
- 動作：未來 24 個月到期債務 >（現金及約當現金 + 2 × 正常化自由現金流）且無已承諾的長期融資 → 不買；持有中出現且管理層無可信計畫 → 完整複查 → 依 H2 Q2 處理（確認論點證偽、會計或誠信問題 → 全清；疑似 → P-50 觀察、停止加碼；否則持有；不自動部分減碼）（推論門檻，可調 18–36 個月）。控股結構另算母公司層：24 個月到期債 ≤ 母公司現金＋子公司可分配股利上限 ×2，否則降一級並查保證。
- 信心：高（原則）／中（門檻）。證據：原文明文（原則）；推論（門檻）｜審查：X16、X21-06、X21-07

**RISK-021 會被追繳擔保、有評等觸發、可擠兌負債、或大量「賣給客戶的選擇權」無法量化 → 排除。**
- 規則：可提前清償、保證利率、需要在降評時立即追加擔保的負債，會在危機中同時引爆。
- 動作：附註顯示此類條款，且最壞情境下的追加擔保或提前償付 > 現金及未動用承諾額度的 50% → 不買（推論門檻，可調）；條款存在但無法量化 → 不買。
- 信心：中高。證據：多文本重複。

**RISK-022 負債比不是硬篩；只排除高槓桿且沒有穩定現金流者。**
- 規則：被買公司的負債／權益與母體無差異，不設負債比上限；償債能力一律用 RISK-018～RISK-021。
- 動作：負債／權益 > 3 倍且無穩定、受管制或特許現金流 → 不買；其餘不因負債比本身扣分。
- 信心：中高。證據：持倉數據驗證（被買公司約 64% vs 母體 67% 的 D/E ≤ 1；後期負債偏高主要因金融股占比高）。

**RISK-023 拆 ROE：營運報酬 vs 槓桿；靠資產增值或轉售回收的資產極度危險。**
- 規則：高 ROE 先排除三種非經營來源：景氣高峰、一次性壟斷收益、槓桿。槓桿不製造危機但放大任何危機。只能靠資產增值或轉售（而非資產本身產出或借款人收入）回收的放款或投資，視為高度危險。
- 動作：去槓桿後的資產報酬（ROA 或無槓桿有形資本報酬）不優於同業中位數 → 高 ROE 不算加分；回收依賴資產增值 → 不買。
- 信心：高。證據：多文本重複。

**RISK-024 開放式長期負債（退休金、退休後醫療、環境與石棉類責任）要以保守假設重算。**
- 規則：退休金預期報酬 − 長期公債殖利率 >2pp → 一律重編（費用用期初 20–30 年公債殖利率、負債用期末殖利率）。重編後費用差 ≥ 正常化稅前盈餘 5%，或重算淨缺口 ≥ 權益 5% → 才記 RISK-061 W5；未達 → 只列重編級、不扣分；重算缺口 > 權益 20% → 降一級（推論，可調 3–10%／15–30%）。受管制事業可經費率回收、以監管資產列示的退休金缺口，重算時扣除；回收不確定不扣。福利與最終薪資或物價無上限連動或有多雇主退出責任 → 通膨 +3pp、薪資 +2pp 壓力；缺口 > 權益 10% 且無定價權 → 降一級（推論）。
- 長尾責任：有合約總賠付上限者 → 剩餘上限列入 RISK-042「長尾上限缺口」（不與單一事件損失相加）；無上限者依 RISK-014 規則書分級；「無法估計」揭露用語不單獨構成排除。
- 信心：高（原則）／中低（切點）。證據：原文明文（原則）＋原型子公司申報校準（差距 3.4–4.5pp 但重編影響只占盈餘約 2%、權益 <0.5%）＋推論｜審查：X17d、X16a、X16c、X17c

**RISK-025 「受監管」不等於「風險穩定」。**
- 規則：監管可直接限制股利、併購、資本支出與資產處置；資本支出失敗不一定能經費率回收；安全、環保與責任法規是獨立的尾端成本（天然災害引起的責任可能超過保險範圍）。
- 動作：受監管事業的估值要附「最壞情境下監管限制對可分配現金的影響」；無法量化、且可分配現金可能 −30% 以上 → 降一級（推論門檻）。
- 信心：中。證據：原文明文（公司風險揭露）＋推論（門檻）。
- **規則書補充**（措辭／條件補充；審查 X15）：規則保留；在適用欄加「監管也可限制持股與表決權結構，評估時把控制權安排列入」。

**RISK-026 純融資型業務且對手資金更便宜者排除；以短債支撐長期資產、殘值風險大的業務排除。**
- 動作：不買。
- 信心：中。證據：原文明文。

## 4. 衍生品與不透明工具

**RISK-027 組合本身：預設不碰衍生品；只在四條件同時成立時允許（重申 v2 D-29）。**
- 規則：① 起始時明顯錯價且對我方有利；② 預收現金或不需提供擔保品；③ 數量少到能逐份理解（每份只需兩三個判斷）；④ 部位有上限且最壞損失可承受（RISK-016）。任何可能在危機中要求追加擔保的合約一律拒絕，寧可少收權利金。宿主系統不支援無擔保結構時 → 視同不成立。

- **規則書補充**（措辭／條件補充；審查 X15）：在 ④ 補參數：單一非核心衍生品／商品部位名目 ≤ 權益 3%（原文自述量級），最壞損失以名目計。
- **規則書補充**（只改證據標記；審查 X17c）：保留從嚴寫法，證據欄改為「原型絕大多數合約免擔保（少數例外）；舊版從嚴為推論」；另補「不可提前解約＋不避險＋到期前不得增加同類部位」為第⑤項可觀察條件。

**RISK-028 被投資公司有大型、不透明的衍生品帳冊 → 不買。**
- 規則：衍生品的危險來自不透明的槓桿、對手應收應付累積、交割期極長、公式決定支付；入場易、退出難，損失會延遲暴露；以年度獎金計酬的交易員會把部位標在有利價格。合約數量大到逐筆無法理解時，增派人手也管不了，唯一答案是退出。
- 動作：附註看不懂、合約數以萬計、或衍生品名目金額 > 權益數倍且以模型估值 → 不買（排除級，對應 RISK-061 A1）。持有中發現 → 賣。
- 信心：高。證據：多文本重複＋自承錯誤（清理看不懂的衍生品帳冊代價高）。
- **規則書補充**（只改證據標記；審查 X16a）：「數倍」改為「≥3 倍（可調 2–5）且以模型估值或第三級公允價值為主」；保留排除級。證據類型標「原文明文（清理決定）＋數字換算」

**RISK-029 被投資公司有賣出尾端的合約（賣權、信用違約保障）時，用情境付款估損，不用公允價值（規則書改寫：市場型尾端改歸市場情境）。**
- 規則：權利金已收不等於不會賠；檢查擔保條款、降評觸發、到期年度集中度、權益與信用同時惡化的相關性。
- 動作：賣出股價指數尾端的合約，損失併入 RISK-044／RISK-016 的同一市場情境（指數 −30% 與 −50% 兩檔，稅後），與持股跌幅相加後套 RISK-044 門檻；信用類合約以違約率情境估。名目金額（指數歸零或全部違約）只作最壞上限揭露，不直接當單一事件損失；理論最大暴險 ÷ 權益 >20%，或同一到期年度名目 > 全部名目 50% → 降一級（推論，可調 15–25%／40–60%）。到期 ≥10 年且無擔保追繳者，以名目現值計。有擔保追繳條款 → 適用 RISK-021。看不懂附註、合約數以萬計或以模型估值的大額名目仍依原條排除。以自身高評等為他人提供信用保障且收費相對名目極低 → 視同賣出尾端；名目 > 權益 1 倍 → 不買（推論）。
- 信心：中高。證據：原文明文（公司揭露的處理方式）＋推論（門檻）｜審查：X16a、X17c、X14

**RISK-030 模型估值（第三級公允價值）不是可實現價值。**
- 規則：無獨立成交資料的模型值，錯誤多半有利於持有人或管理層；長期無成交支持的模型值會退化成「自我感覺的價值」。合約條款（無擔保）可能使其無法轉讓。
- 動作：以到期情境的實際付款估計當保守值；模型值與情境值差距 > 20% → 以保守值重編並標記估值風險；第三級資產 ÷ 權益 > 50% 且無敏感度表 → 不買（50% 為推論門檻）。
- 信心：中。證據：原文明文（管理層承認可能顯著不同）＋推論（門檻）。
- **規則書補充**（只改證據標記；審查 X16c）：改寫 RISK-030 規則句：模型誤差方向依合約而異，不預設「有利於持有人」；動作：同時算情境（到期）付款與模型值，自身信用利差調整一律剔除（加回負債），差距 >20% 取對投資人較保守者並標記估值風險

**RISK-031 營運避險長期不省錢；平滑盈餘不是價值。**
- 規則：燃料、匯率避險只是用摩擦成本換平滑；自動化避險（動態對沖、組合保險）在壓力時同步執行會加速下跌。
- 動作：避險帶來的盈餘平滑不加分；以避險損益撐起的盈餘 → 重編剔除。
- 信心：中。證據：原文明文。

## 5. 保險、再保與其他「預收款」業務

**RISK-032 保險公司的分析總則：承保與投資分開看；金融類整體降一級。**
- 規則：保險績效 = 承保結果 + 浮存金投資結果。承保績效不得分攤投資收益，也不得用投資收益抵銷承保虧損來評「承保好不好」；投資結果另評。保險類不排除，但必須全數通過本節門檻，確定性等級與部位上限比非金融降一級（v2 D-15）。
- 動作：先算承保（RISK-034～RISK-036）→ 再算準備金可靠度（RISK-038～RISK-041）→ 再看尾端與資本（RISK-012、RISK-044）→ 最後才合併估值。任一關不過即停。
- 信心：高（承保與投資分開）／中（降一級）。證據：多文本重複＋持倉數據驗證（金融股占巴菲特本人買進約母體 2 倍，EVID-006）。

**RISK-033 承保紀律四原則：缺一即不買（規則書量化第④項觀察）。**
- 規則：① 理解所有可能損失的暴險；② 保守估計機率與成本，含罕見與長尾、相關情境；③ 定價使扣除損失與費用後的平均結果獲利，且在罕見相關情境下仍成立；④ 價格不足時願意放棄承保。另加：限制單一與相關事件累積（RISK-012）；不與不誠實的對象簽約。
- 判讀第④項的可觀察證據：價格不足期保費主動下降、管理層明說拒絕低價業務、不以保費量或市占設預算、激勵不懲罰縮量、事先承諾不因業務量下降而裁員。
- 動作（規則書）：「以保費成長或市占為目標」→ 不買（保留）。剔除收購後簽單保費年增 >15%（推論，可調 10–20%）且事故年綜合率較前 3 年平均惡化 >3pp，兩者連 2 年同時成立 → 不買；單年 → 觀察，先拆「新件取得成本／廣告」與「既有保單損失率」：既有保單損失率穩定且管理層事先揭露成長期利潤率下降 → 不動作；既有保單損失率惡化 → 降一級，管理層一年內未漲價或收緊承保 → 完整複查 → 依 H2 Q2 處理（確認論點證偽、會計或誠信問題 → 全清；疑似 → P-50 觀察、停止加碼；否則持有；不自動部分減碼）。加分：虧損年內即提高平均保費並接受保單數下降、削減廣告，1–2 年內綜合率回到 <95；費率明顯改善且產能不足時擴量 → 不觸發。
- 信心：高（原則）／中（量化）。證據：多文本重複＋原型子公司實證｜審查：X15、X21-05、X16

**RISK-034 浮存金成本門檻（規則書改寫：加權口徑、四級去矛盾，即 P-58）。**
- 規則：多年成本＝Σ 稅前承保損失 ÷ Σ 平均浮存金（加權，不用年成本簡單平均）；窗口 10 年，資料不足才用 5 年並降信心；窗口內有重大收購 → 收購單位與原有單位分開計算各自判定；扣除通過 RISK-042 的預期時間價值損失後另列一欄。浮存金 = 損失與理算費用準備 + 未賺保費 + 其他保戶負債 − 應收保費 − 再保可回收款 − 遞延取得成本 − 相關遞延項目。
- 動作（與同期多年平均基準殖利率比）：
  - 成本 ≤ 0 → 品質優；
  - 0 < 成本 < min（短期國庫券，長債 −1pp）→ 合格；
  - min（短期國庫券，長債 −1pp）≤ 成本 < 長債 −1pp → 降一級；
  - 成本 ≥ 長債 −1pp → 不買。
  - 短期利率 <4%（可調 3–5%）時，「合格」收緊為成本 ≤0（有明確投資收益補償且有總賠付上限的追溯型業務另依 RISK-042）。（舊版四級在「國庫券 ≥ 長債 −1pp」的年份會同時判合格與不買，已去矛盾。）
- 投資收益正常化：被投資保險公司浮存金大量放在 1 年內到期工具 → 估值與 ROE 篩選時，利息收入以「短天期資產 × 過去 10 年平均短期利率」重算（雙向；可調 7–15 年）；長天期債券 × min（帳面殖利率，目前再投資殖利率）；RISK-036 兩平公式的投資收益率同用正常化值。追逐收益紅旗：另類投資＋低評等債占投資資產 3 年上升 ≥5pp 且同期承保未改善 → W（計 1 項），該增量收益不計入正常化盈餘（推論）；另查投資資產 ÷ 權益與存續期間。
- 參數依據：原文以長期政府公債殖利率為比較基準；學術研究樣本中約 60% 年份為負成本、平均低於國庫券約 3pp，但個別子期間曾高於國庫券（期間與本條統計不同）。
- 信心：中高（原則）／中（切點）。證據：原文明文＋多年度數據複算＋學術研究｜審查：X15、X03、X28、X21-05、X21-10、X04、X10

**RISK-035 單年成本暴衝：先診斷，再動作。**
- 規則：單年成本轉正常見於巨災年、匯兌重估年、準備金不利發展年。
- 動作：單年浮存金成本 > 3% → 先扣除通過 RISK-042 四條件的預期時間價值成本（追溯攤銷、刻意以承保虧損換取浮存金的合約），以扣除後成本判斷：
  - 已揭露上限內的巨災 → 持有，不動作；
  - 惡化集中於近 3 年內收購的單位、其餘單位承保獲利、且已揭露具體重新定價與不續保動作 → 降一級並觀察 2 年（可調 1–3 年），期間不加碼、不減碼；
  - 其他準備金不利發展或定價不足 → 降一級並啟動 RISK-038；
  - 扣除後成本 > 5%（推論，可調 4–6%）連續 3 年，或收購單位重新定價後事故年綜合率仍未改善 → 視為紀律失守：不買；持有中 → 完整複查 → 依 H2 Q2 處理（確認論點證偽、會計或誠信問題 → 全清；疑似 → P-50 觀察、停止加碼；否則持有；不自動部分減碼）。
- **規則書刪除**：原「單年 >10% 或近 3 年 2 年為正 → 減碼一半」（重算：原型在成本重回 1% 前兩年即會被觸發，觸發時價格約 1.0 倍帳面）。
- 信心：中（原則）／低（切點）。證據：原文明文（以長期平均判斷）＋推論（切點）｜審查：X15

**RISK-036 綜合率（規則書改寫：剔除追溯再保與年金，即 P-59）。**
- 規則：綜合率以剔除追溯再保、分期給付年金、結構化結算等「設計上以承保虧損換浮存金」業務的保費與承保損益計算（該部分只依 RISK-042 評估），看 ≥ 5 年平均與當年，不看單年；以合併剔除後口徑判通過；季度數據易被單一合約主導，用年度或多年口徑。損益兩平綜合率 ≈ 100% +（平均浮存金 ÷ 已賺保費）× 正常化稅前投資收益率（推論公式）。但「兩平點高於 100%」不是可接受的經營目標。
- 動作：
  - 5–10 年平均剔除後綜合率 < 100 且優於同期產業平均 → 加分；
  - ≥ 100 → 回到 RISK-034 以浮存金成本判斷（P-58 必過），且不得以兩平綜合率為定價目標；
  - 長尾業務定價或實績以 105–115 為常態 → 不買；
  - 分部連 ≥4 年 >100 但合併剔除後 <100 → 不淘汰，列該分部觀察並查是否為市況擴量。
- 信心：高（原則）／中（公式）。證據：原文明文（「除追溯再保與分期給付年金外，預期長期承保獲利」；長尾 110–115 為自殺）；公式為推論｜審查：X02、X15、X21-09、X21-08、X21-06

**RISK-037 浮存金三要素：量、成本、持久性；成長只在成本合格時是好事。**
- 規則：浮存金像油田，流出要能補回；規模、保費量、市占都不是目標。浮存金成長要拆「內部成長」與「收購／大額追溯交易」；收購得來的浮存金另評其成本。
- 動作：
  - 近 5 年浮存金成長主要來自收購或大額追溯交易，且其承保成本未揭露 → 降一級；
  - 常態年份浮存金淨流出 > 每年 3% 且非主動縮量 → 降一級（3% 為晚期原文自述的年降幅上限量級）；
  - **規則書**：浮存金成長同時承保虧損擴大（虧損增速 > 浮存金增速）以扣除已揭露上限內巨災與 RISK-042 合格時間價值損失後的承保虧損比較，連續 2 年成立才不買；單年成立 → 觀察。單一合約保費 > 年度已賺保費 10% → 成長以剔除該合約後判斷，另評成本。
- 信心：高（原則）／中（3%）。證據：原文明文。

**RISK-038 準備金誠信：系統性低估 → 排除（規則書改寫：估計誤差口徑、兩層制）。**
- 規則：準備金是管理層自己批改的考卷，可連報多年虛假利潤；巨災初期估計方向不穩定，首年數字不可視為定案。不採管理層「合理且足夠」的聲明。該線事故年發展表偏低紀錄 ≥2 個事故年者，當年巨災損失先加 10–20% 再評估（推論）。
- 口徑：一律用「估計誤差」——前期準備金修正剔除 (1) 追溯再保遞延費用攤銷、(2) 折現負債增值、(3) 外幣換算；剔除項未揭露時，以公司揭露的追溯／結構化結算承保損失為上限代理並標「代理」。分母＝檢視窗口第一年期初淨準備；窗口內收購使準備增加 >50% 時，收購單位另行計算。長尾業務以 ≥5 年累計為主判，「一年後修正方向」只作輔助。
- 動作（合計層，任一命中 → 不買；持有中 → 完整複查：確認系統性低估 → 屬 Q2 會計問題，全清；查證中 → P-50 觀察、停止加碼，一季內未解除 → 全清）：
  - 純估計誤差連續 3 年不利且每年 ≥ 期初準備 0.5%，或 5 年累計不利 > 窗口首年期初準備 5%（推論，可調 3–8%；單一來源十年表校準）；
  - 發行新股或大額融資前，準備金比率可疑下降；
  - 以委婉語包裝過去低估，或審計意見對數字準確性保留；
  - 未揭露的折現、在盈餘不佳年度提高折現率或擴大折現範圍、或以準備金釋放平滑盈餘。
- 動作（分部層，降一級＋觀察兩期年報，不直接排除）：任一長尾分部 (a) 事故年齡 2–7 年的事故年中 ≥2 個的累積發展超出「該線自身 ≥5 個成熟事故年在同一年齡的平均累積發展」>3pp（推論，可調 2–5pp），且這些事故年最近一年的發展仍為不利或持平；該線成熟事故年不足 5 個時，改以「自初估上修 >3%」計，但同樣須最近一年仍不利；(a) 成立但最近一年已轉為有利 → 只記觀察，下一份年報再判；或 (b) 曆年純估計誤差連 2 年不利且合計 ≥ 該分部期初準備 2%（推論，可調 1.5–3%）。資料隔一層的再保意外險，前 2–3 個事故年齡的上修不單獨觸發；該分部準備 < 總準備 25% → 只記 W1。和解利益與巨災準備釋放不得抵銷長尾分部的不利修正。有總賠付上限的追溯／結構化合約：以毛額最終損失估計變動計，適用分部層處理。長尾定義：公司揭露賠付型態中前 3 年累計賠付 <60% 的業務線（無揭露時依險種清單；推論，可調 50–70%），分母淨未付、不含追溯再保。
- 條件式：已揭露且符合法定會計、隨利率下調的既有折現 → 以未折現值重算，不扣分。收購後立即增提 → 警訊 W；其後 3–5 年內以有利發展把增提額 ≥50% 釋放回盈餘 → 升排除級（推論，可調 30–70%）。
- 財務困境（GAP-X03-01）：保險或其他長尾負債企業出現財務壓力（連續虧損、評等下調、資本適足接近監管下限、緊急增資）→ 準備金可靠度自動降一級，以「近 10 年最差累計不利修正率 ×1.0–1.5」加提後重算權益與估值，重算後仍在上限內才續行（RISK-092）。
- 費率下降期（GAP-X15-1）：最近 3–4 個事故年處於費率下降或條款放寬 → 推定準備金不足，估值預扣該等事故年淨準備 ×5%（可調 3–10%），觀察期延到這些事故年發展滿 3 年（RISK-093）。
- 反方向：長期有利發展本身不扣分；有利釋放集中在本業不佳年度、使盈餘異常平順 → W1。
- 信心：高（原則）／中（口徑與門檻）。證據：原文明文＋多文本重複（原則）；單一公司十年表與年報附註校準（門檻）｜審查：X15、X16、X16a、X16b、X17a、X17b、X17c、X17w、X21-05、X21-08、X21-10、X03

**RISK-039 承保利益若主要來自前期準備金釋放。**
- 動作：前期釋放 ÷ 當年承保利益（分母用剔除追溯再保與年金後的承保利益）>50%（可調 40–70%）時，只有在下列任一成立才以當期事故年口徑重編：(a) 有利發展連續 <5 年；(b) 近 5 年內曾有不利發展；(c) 未付準備 ÷ 已賺保費或生存比率同期下降；(d) 同期事故年綜合率 >100。長期（≥5 年）持續有利且準備比率未降 → 用 10 年平均承保結果（含前期發展）判斷，單獨 >50% 只記觀察。分部檢查：任一主要分部前期增提而合併為釋放 → 備註，不以合併數字當準備金充足證據。管理層明言有利發展不應假設延續 → 正常化時剔除最近 3 年有利發展的一半以上（推論）。
- 信心：中。證據：原文明文（管理層提醒不應假設延續）＋年報數字（有利發展占承保利益比例跨年度差異極大）＋推論（50%）｜審查：X16、X16b、X21-09、X17b

**RISK-040 準備金敏感度。**
- 規則：稅前損失 ≈ 未付損失準備 × 估計變動率；未付損失準備 ÷ 股東權益是放大因子。
- 動作：（未付損失準備 × 5%）÷ 5 年平均稅前營業盈餘 > 100%（推論，可調 50–150%），或 ÷ 股東權益 > 10% → 標記高敏感，安全邊際要求加大一級；優先採公司揭露的敏感度數字，與自算差 >30% 時記錄；管理層揭露的敏感度數字大幅變動而未解釋 → 觀察。（單年盈餘分母在巨災年失去鑑別力，已改。）
- 信心：中（原則高）。證據：原文明文（公司揭露的敏感度表）＋推論（門檻）｜審查：X15

**RISK-041 長尾業務要更保守、要更大的安全邊際。**
- 規則：責任險、工傷、醫療責任、石棉與環境、大規模侵權、追溯再保的結果要數年到數十年才確定；社會通膨與新責任理論可擴張既有賠付；不能以近期理賠經驗推論。
- 動作：長尾準備金占總準備 > 50% → 確定性等級降一級；潛在侵權類準備金的「生存比率」（未付準備 ÷ 近年平均年度支付）低於產業平均 → 推定準備不足，不買（舊版將公司自用指標轉為通用檢查）。
- 信心：中。證據：原文明文＋推論（50% 門檻）。
- **規則書**：長尾定義＝公司揭露賠付型態中前 3 年累計賠付 <60% 的業務線（推論，可調 50–70%）；長尾占比 >50% 降級須加「且長尾線有不利發展或生存比率低於產業」。長期壽險、年金、長照、失能 → 死亡率／罹病率對定價假設連 2 年同向不利或解鎖 → 視同 RISK-038 分部層命中；大流行壓力（綜合率 110% 持續 2 年）計入 RISK-013（RISK-041b，推論）。｜審查：X21-10、X16c
- **規則書補充**（只改證據標記；審查 X16）：補參考值：潛在侵權類生存比率 < 產業值（約 8–10 年）→ 推定不足；標「粗略指標」，不宜單獨否決
- **規則書補充**（只改證據標記；審查 X17a）：50% 改為只作標記；降級條件改用長尾準備的發展方向（RISK-038）與生存比率，或把門檻提高到 70–80% 並與同業比。
- **規則書補充**（措辭／條件補充；審查 X17b）：同 X17w：長尾占比只作加大安全邊際，不單獨降級；生存比率保留。
- **規則書補充**（只改證據標記；審查 X17c）：改為「長尾 >50% 且（無單約總賠付上限，或生存比率低於產業，或 RISK-038 分部連續不利）→ 降一級」；單看占比只作標記。
- **規則書補充**（措辭／條件補充；審查 X17w）：改：長尾占比 >50% 且（長尾事故年連續 2 年不利發展，或生存比率低於產業）→ 降一級；只有占比高 → 安全邊際加大一級
- **規則書補充**（措辭／條件補充；審查 X21-10）：RISK-041 動作句補定義：「長尾＝公司揭露的賠付型態中前 3 年累計賠付 <60% 的業務線（無揭露時依險種清單）」（60%／3 年為推論，可調 50–70%）；占比計算以淨未付（扣再保）為分母、不含追溯再保（另走 RISK-042）。降級條件依 X17w 建議加「且長尾線有不利發展或生存比率…

**RISK-042 接受「預期承保虧損換浮存金」的業務（追溯再保、長期年金、結構化結算）：四條件全過才可視為合理。**
- 規則：此類業務的經濟利益來自時間價值；承保虧損不是失敗，但必須證明。
- 動作：同時滿足才接受：① 每份合約有總賠付上限，且最大剩餘賠付 ÷ 毛未付損失有揭露；② 遞延費用攤銷與折現增值已計入承保結果；③ 以保守投資報酬（長債殖利率）估算，浮存金收益 > 承保虧損；④ 支付時程假設沒有在承保利益增加的同期被放慢。任一不成立 → 該業務的承保虧損視為一般虧損併入 RISK-034；無上限 → 不買（RISK-015）。
- 信心：中。證據：原文明文（公司揭露的會計處理與經濟理由）＋推論（四條件組合）。
- **規則書長尾上限缺口**：剩餘總限額與已提列準備之差另列「長尾上限缺口」，不與單一事件損失相加：缺口 ÷ 權益 ≤10% 且分散於 ≥5 份合約 → 不扣分；10–20% → 降一級；>20% 或集中於 <5 份合約 → 不買（推論，可調 8–15%／15–25%）。否決「剩餘限額併入 RISK-012」（原型自身會被判不買）。｜審查：X16c、X16a

**RISK-043 再保政策與分出人資料：不能依賴再保人履約，也不能把分出人資料當獨立核驗。**
- 規則：低價再保是傻瓜交易；一年期合約較穩健（可重新定價或退出），多年期、難退出的合約風險高；轉分保鏈要壓力測試。再保人收到的資料至少隔一層，報告延遲可達數月，稽核權不等於資料可靠。
- 動作：分出比例快速上升且再保人強度不明 → 降一級；再保業務主要依賴分出人報告、無獨立評估差異揭露 → 準備金可靠度降一級；應收再保款帳齡惡化或爭議金額上升 → 觀察。
- 信心：中高。證據：原文明文。

**RISK-044 保險人股票部位敏感度（規則書改寫：稅後口徑＋資本強度＋正向檢查）。**
- 規則：保戶買的只是一個承諾；遠高於同業的資本強度讓公司接得到只有它承接得起的單、能在危機中逆週期漲價與擴張。但股票占投資比重高時，股市下跌同時壓低權益、法定盈餘與評等，進而限制承保。
- 動作：
  - 敏感度＝股票部位（含權益法入帳但有市價者）在 −30% 情境下的**稅後**減少額 ÷ 股東權益（可用公司揭露的情境表；市場連動型衍生品與股價連動負債依 RISK-029 併入）。≤20% 通過；資本強度條件成立→ 上限放寬到 30%（可調 25–35%）；> 適用上限 → 降一級；稅後 >30% → 不論資本強度一律降一級。逆週期擴張後比率仍 ≤ 產業 1/4 → 不視為搶量。
  - −50% 情境（股票、權益法上市持股、賣出的股價尾端合約、股價連動負債一併、稅後）÷ 權益 >35% → 不買（推論，可調 30–40%）。
  - 資本下降期仍擴張承保 → 不買（保留）；法定盈餘一年下降 >15% 且簽單保費仍增 → 降一級。
  - 正向檢查：權益下降或大額資本支出期間主動縮減巨災／尾端承保量 → 加分；尾端上限以當期權益重算。
  - 同業出現「已無力償付但仍有現金」的承保人以任何價格搶業務 → 對整個產業的新買進暫停，持有者觀察承保紀律是否守住。
- 信心：高（原則）／低（門檻）。證據：原文明文（原則）；原型申報校準（稅後約 12–16%、稅前 17.5–21.5%；稅後 ÷ 稅前 ≈0.65）＋推論｜審查：X15、X16b、X17a、X17c、X18a、X18w、X21-02、X21-04

**RISK-044b 未實現增值歸零存活檢查。**
- 規則：被投資公司未實現增值 ÷ 權益 >50% 或前三大持股 > 股票組合 75% → 以「所有證券跌回成本」重算權益、法定資本與償債能力；仍符合 → 通過；不符合 → 降一級；需靠增值才能履約 → 不買（推論，可調 40–60%／60–90%）。
- 信心：低中。證據：原文明文（資本強度原則）＋推論｜審查：X18w

**RISK-045 承保週期：資本湧入、費率下滑時預期惡化；有紀律者此時縮量。**
- 規則：新資本湧入壓低費率時，有紀律的公司減量而不是跟價；產業保費成長低於損失成本通膨時，次年綜合率傾向惡化（早期原文以產業保費年增約 10% 為維持綜合率的量級，需以當期損失通膨校準）。
- 動作：產業處於「費率下滑 + 資本湧入」期 → 只買能證明在縮量的公司；保費連續下降且管理層歸因於拒絕低價業務、綜合率穩定或改善 → 加分；保費下降同時承保虧損擴大 → 拆原因，不得直接視為紀律。
- 信心：中高。證據：多文本重複。
- **規則書補充**（只改證據標記；審查 X21-04）：RISK-037「浮存金淨流出 >3%／年且非主動縮量 → 降一級」須明文：主動縮量可深達原量的約 1/4、持續近十年仍屬紀律；判定「主動」的證據＝管理層同期歸因於費率不足＋綜合率未惡化。不加新門檻

**RISK-046 保險盈餘要正常化：沒有巨災的年份往下調；「排除巨災」的說法是欺騙。**
- 動作：估值用的正常化承保結果 = 至少 10 年平均（含巨災年）；最近 3 年無重大巨災 → 以長期平均巨災負擔下修；管理層以「扣除巨災」的盈餘談估值 → 重編並扣分。
- 信心：中高。證據：原文明文。
- **規則書**：承保利潤率明顯高於管理層揭露的定價目標或長期平均 → 正常化承保結果以「定價目標或 10 年平均，取低者」計；有利發展比率連 2 年下降且近 3 年綜合率優於 10 年平均 → 用 10 年平均。非巨災險種理賠頻率／嚴重度異常有利 → 承保利益以長期平均或週期中值下修。｜審查：X15、X17w、X21-04
- **規則書補充**（措辭／條件補充；審查 X21-02）：標題改為「以扣除巨災後的盈餘當作常態盈餘或估值基礎是欺騙」；動作不變（10 年含巨災平均；最近 3 年無巨災 → 下修）；補一句：「附條件的前瞻說明（如「若無巨災」）且同時揭露巨災暴險者不扣分」。

**RISK-047 評等是結果不是目標；激勵不得以保費量或帳面利潤為基礎。**
- 規則：最高評等不會改變承保紀律；把評等當經營目標會誘使不當承保。以年度帳面承保利潤或保費量發獎金，會誘發低估準備與搶量。
- 動作：薪酬以保費成長或年度帳面利潤為主、無長期回補機制 → 扣分；同時有 RISK-038 任一訊號 → 不買。
- 信心：中。證據：原文明文。

## 6. 銀行、類存款放款機構與其他金融類

**RISK-048 銀行預設放進「太難」堆，只挑例外；「便宜」本身不是買進理由。**
- 規則：金融機構的麻煩很晚才看得到（產品型與零售業早期就看得出）；任何資本水準都擋不住真正的擠兌；約 20 倍槓桿會把管理好壞放大，管理差的高槓桿機構再便宜也不買；看起來便宜的金融股常是價值陷阱。
- 動作：必須全數通過 RISK-049～RISK-054 才可進估值；確定性等級與部位上限降一級（v2 D-15）；任何一條不過 → 不買。
- 信心：高。證據：多文本重複＋自承錯誤（看起來便宜的金融股事後大幅減記）。

**RISK-049 銀行量化硬篩。**
- 規則：ROE ≥ 同年金融業中位數（晚期約 10%、早期約 15%）；ROA ≥ 1%；權益 ÷ 資產 ≥ 8%（常見 8–12%）；近 10 年無虧損；股數不增；配發率約 25–45%。
- 動作：全過 → 進入 RISK-050；任一不過 → 不買（例外：整個產業恐慌期，ROE 低於中位數但其他條件全過，且能證明放款紀律 → 可走例外通道，再降一級）。
- 信心：中（樣本小）。證據：持倉數據驗證（金融股買進時 ROE 中位約 12.6%）＋推論（組合門檻）。

**RISK-050 出事永遠在資產端：先看放款文化與授信品質。**
- 規則：保守、懂當地客戶、厭惡壞放款與高成本、不追潮流的放款文化 → 通過；同業降價時為維持成長去承接更高風險 → 排除。授信品質看償付能力（月付相對實際收入、真實頭期款、收入查證），不看表面信用分數；不依賴資產增值或再融資回收的放款；「發起即轉售」、與資產來源脫鉤的結構風險較高。
- 動作：放款成長率連續 2 年 > 同業中位數 2 倍且淨利差或授信標準同時放寬 → 不買；持有中出現 → 完整複查 → 依 H2 Q2 處理（確認論點證偽、會計或誠信問題 → 全清；疑似 → P-50 觀察、停止加碼；否則持有；不自動部分減碼）（推論門檻）。**規則書**：營建與土地開發放款 ÷ 權益與占總放款比例超過同業中位 2 倍或占權益 >100%（可調 75–150%）→ 不買；RISK-051 對此類放款另以問題率 30%、損失率 50%（推論）重算。新放款類別用舊組合損失率提列並前期認列高收益 → 以該類最壞情境重算。授信錨點見 SEL-101 第 5 項。
- 信心：高（原則）／低（門檻）。證據：多文本重複。

**RISK-051 銀行壓力測試：假設全部放款 10% 出問題、平均損失 30% 本金，一年約損益兩平即可接受。**
- 規則：上述情境等於放款損失約為放款總額的 3%。可執行的換算（舊版補強）：撥備前稅前盈餘 ÷ 平均放款 ≥ 約 3% → 通過；壞資產 2–3% 就能吃光權益的機構（權益 ÷ 資產 < 5%）→ 排除。
- 動作（規則書，即 P-60）：撥備前稅前盈餘 ÷ 平均放款 ≥ 2.75% → 通過；2.25–2.75% → 降一級；< 2.25% 或權益 ÷ 資產 < 5% → 不買（推論，可調 2.5–3.25%；單一出處）。營建與土地開發放款另以問題率 30%、損失率 50% 重算。
- 信心：中（原文情境為單一時期的明文；換算為推論，可調 2.5–3.5%）。證據：原文明文＋推論。

**RISK-052 負債端：期限錯配、可擠兌資金、賣給客戶的選擇權。**
- 規則：負債期限短、易被擠兌的機構，資本比率再高也不安全；大量可提前清償或保證利率等「給出去的選擇權」使負債無法量化；穩定、低成本的核心存款是銀行的護城河。
- 動作：短期批發融資 + 無保障存款 > 負債 50%，或有根本性期限錯配 → 降一級；給出去的選擇權無法量化 → 不買（RISK-021）（50% 為推論門檻，可調 40–60%）。
- 信心：中高（原則）／低（門檻）。證據：原文明文。

**RISK-053 銀行會計要雙向重編。**
- 規則：用歷史損失率提列準備後轉做更高風險貸款，會虛報利潤（會計允許保守銀行改做大量愚蠢貸款後盈餘暴增）；收購產生的核心存款等非現金攤銷，會讓好銀行看起來比實際差。
- 動作：放款組合轉向高風險類別而準備率不升 → 以同業較高損失率重提準備後重編；核心存款攤銷而存款持續成長 → 加回。
- 信心：中。證據：原文明文。

**RISK-054 金融機構管理層與併購紅旗。**
- 規則：承諾穩定兩位數成長、總是剛好達標、蓋豪華總部、看不懂的衍生品帳冊、會「對自己說謊」的文化 → 排除；決策者在出事時沒有實質下檔、以帳面利潤分紅 → 扣分；自身股價接近帳面卻以數倍帳面用股票收購其他銀行 → 價值毀滅；無法判斷對方放款組合就合併 = 自殺協議。
- 動作：命中排除級任一 → 不買；持有中出現以高倍數發股併購或無法審查資產的大型合併 → 降一級並複核，論點破裂即賣。
- 信心：高。證據：多文本重複。

**RISK-055 金融股的進場時機：整個產業被恐慌拋售、你能分辨誰的放款紀律好時；標的必須不依賴特定救援就能存活。**
- 規則：不假設政府救援會保護股東（救市中股東與經理人應承受損失）；危機中大額押注的前提是系統層級穩定機制會出手，但個別標的本身必須能獨立存活。
- 動作：金融類新建倉只在 RISK-048～RISK-054 全過時；壓力測試須在「無外部援助」假設下通過；只靠救援才能存活 → 不買。
- 信心：中高。證據：多文本重複＋持倉數據（金融股新建倉多在大跌後，季內低點較前 52 週高點約 −21%）。
- **規則書補充**（只改證據標記；審查 X27）：改為「約 −15%～−20%（樣本 <10）」，信心中。

**RISK-056 其他金融類分流。**
- 規則：輕資產支付網路、評等、資料服務、薪資處理 → 歸非金融，走一般選股關卡（評等類抗壞事能力強可加分）；純租賃、消費融資等對手資金更便宜者 → 排除（RISK-026）；只能回答「會不會倒」、看不懂股權上檔者 → 不買普通股（組合不做結構化工具，除非宿主支援且另有規則授權）。
- 信心：中。證據：原文明文。

**RISK-057 監管持股門檻會限制買進與持有。**
- 規則：持有銀行或受監管機構股權達一定比例（常見約 10%）可能觸發控制權監管。
- 動作：與 v2 D-28 一致：被動持股預設 ≤ 9.9%；越過前先確認監管後果。
- 信心：中。證據：原文明文（公司風險揭露）＋持倉數據（被動持股堆積在 10% 下方）。

## 7. 會計警訊與財報閱讀紅旗

**RISK-058 會計是起點不是終點；有疑慮就放棄。**
- 規則：把財報重編成自己的經濟模型（業主盈餘、正常化盈利能力），再用重編後的數字回到品質門檻與估值。從來沒有從會計可疑的公司賺到大錢；能用筆創造盈餘的地方就會聚集不誠實者；很多不是蓄意詐欺而是自我欺騙，但對投資人結果相同。
- 動作：依 RISK-061 分級計數後依 RISK-063 處置。
- 信心：高。證據：多文本重複。

**RISK-059 讀表順序：先資產負債表（8–10 年）→ 分部 → 營運盈餘 → 附註。**

## 9. 持有期間的風險監控與動作（金融與保險持股為主）

**RISK-081 金融持股：把「不舒服」和「論點破裂」分開。**
- 規則：對金融機構要特別敏感，因為看到的往往是冰山一角；但數據顯示在危機中、股價低於帳面時賣出金融股，是最常賣錯的一類。
- 動作：
  - 論點破裂級訊號（任一）→ 完整複查 → 依 H2 Q2 處理（確認論點證偽、會計或誠信問題 → 全清；疑似 → P-50 觀察、停止加碼；否則持有；不自動部分減碼）；一季內查證未解除 → 全清（RISK-038 只計合計層命中）：資產品質惡化超過 RISK-051 壓力情境；RISK-038 準備金任一命中；融資來源出現擠兌或期限錯配惡化（RISK-052）；會計排除級或警訊 ≥ 2（RISK-063）；管理層誠信事件；放款或承保策略轉向追量（RISK-033、RISK-050）；資本下降期仍擴張（RISK-044）。
  - 只有價格下跌、產業恐慌、市價低於帳面、媒體負面，且上述訊號皆無 → 持有；若重新通過全部金融門檻且價格／價值更低 → 可加碼（仍受部位上限）。
- 信心：中。證據：原文明文（芒格對金融機構較早不舒服）＋持倉數據驗證（危機中低 P/B 賣出多半賣錯）。

**RISK-082 局部、可切除的一次性打擊可以是買點，前提是核心經濟完好且問題可量化。**
- 規則：優秀特許權因錯誤激勵、準備金不足、一次性醜聞受打擊時，不等於轉機股；關鍵在發現問題後怎麼處理。
- 動作：同時滿足才可列為機會（警示處理、降一級）：① 核心業務的定價權與客戶留存數據未受損；② **規則書**問題金額可量化，且從 `IV_cons` 扣除後（視同一筆遺失的股利，VAL-110）價格仍 ≤ 等級上限〔宿主：此「等級上限」是 P-16 等級係數 × `IV_cons`，只影響報告欄 P1；自動買進上限 min(P2′, k×IV_base) 照 SKILL §3、k 不改，D94〕；損失 ≤ 權益 50% 且 ≤ 核心業務 2 年正常化稅後盈餘（推論，可調 1–3 年），公司不需外援即可吸收；③ 管理層已承認、量化並處理（換人、改激勵、一次提足準備）；④ 不依賴外部援助就能吸收。任一不滿足 → 不買；若問題是誠信性、系統性（RISK-038 連續低估、A 級會計紅旗）→ 不適用本條。
- 信心：中。證據：多文本重複（多次在此類情境買進且成功）＋推論（門檻）。

**RISK-083 前提一變，看管理層能否快速退出整條業務線。**
- 規則：好的經營者在業務前提改變時，即使要砍掉大塊營收也立即退出，且先確認單一事件最大損失已封頂。
- 動作：被投資公司管理層在前提改變後仍維持或擴大該業務 → 記資本配置扣分；能快速縮減並封頂損失 → 加分。
- 信心：中高。證據：原文明文。
- **規則書**：承擔交易對手信用風險者須有單一對手上限、弱體名單、可單方不續約；缺 → 降一級（推論）。｜審查：X18a

**RISK-084 年度風險複核清單（每檔持股每年一次，重大新事實時立即）。**
- 動作：重算並記錄 RISK-012（單一事件 ÷ 權益）、RISK-013（最壞事件 ÷ 正常化盈餘）、RISK-016（組合相關暴險群）、RISK-019～RISK-021（償債、再融資、擔保條款）、RISK-034～RISK-041（保險）、RISK-049～RISK-052（銀行）、RISK-061 紅旗表、第 8 節檢查表。任何一項由「通過」轉為「不通過」→ 依該條動作執行，不得以「持有中」為由放寬。
- 信心：高（流程）。證據：推論（流程化）。

## 規則書新增規則（風險）

**RISK-090 司法管轄與控股股東。**
- 規則：被投資公司主要營運或註冊地的法治、對外資態度、徵收紀錄、外資持股上限、控股股東為政府或單一家族 → 先判可否承擔：公司治理、少數股東保護、稅制看不懂，或有徵收紀錄、外資權利無保障 → 太難／排除；可承擔 → 要求更低價格：等級上限再減 0.10（推論，可調 0.05–0.15；宿主覆寫：此係數作用在 P-16 等級係數 × `IV_cons`，只影響報告欄 P1，不改 k 與自動買進上限 min(P2′, k×IV_base)，D94；本條的價格要求移到 G7 起），並於 `IV_cons` 加入機率 × 損失情境（機率 5–20%、損失 50–100%，推論），且要求多項指標明顯低於同業；不得因「看得懂業務」而沿用本國等級上限；持股比例上限使部位無法達最小有效部位 → 不建倉。
- 信心：中（原則：原文明文）／低（數字）。證據：原文明文（股東會）＋推論｜審查：X07、X06

**RISK-091 槓桿型財務買家持有或轉售。**
- 規則：發行人近 3–7 年曾由槓桿型財務買家控制、上市前 3 年內由財務投資人持有並出售、或主要股東為此類買家且正在出售 → G4 警訊加一級；上市或轉售前後各 2 年盈餘列重編級檢查（費用遞延、資本支出壓低、營運資金拉抬），以 5 年現金轉換率與一次性剝離重編後才可進估值；資料不足 → 觀察。
- 信心：中。證據：原文明文＋推論｜審查：X06、X07

**RISK-092 財務困境中的長尾負債企業。**
- 規則：保險或其他長尾負債企業出現財務壓力（連續虧損、評等下調、資本適足接近監管下限、緊急增資）→ 準備金可靠度自動降一級，以「近 10 年最差累計不利修正率 ×1.0–1.5」加提後重算權益與估值，重算後仍在上限內才續行。
- 信心：中。證據：原文明文（求生存的公司常嚴重低估準備）＋推論｜審查：X03

**RISK-093 費率下降期的事故年。**
- 規則：被投資保險公司最近 3–4 個事故年處於費率下降或條款放寬 → 推定準備金不足，估值預扣「該等事故年淨準備 ×5%」（可調 3–10%），並把 RISK-038 觀察期延到這些事故年發展滿 3 年。
- 信心：中低。證據：原文明文＋推論｜審查：X15

**RISK-094 未合併高槓桿個體的看穿。**
- 規則：對未合併個體投資其負債 ÷ 被投資公司權益 >10% → 逐項確認無保證、無流動性支持；無法確認 → 該負債併入計算（推論）。
- 信心：中低。證據：年報附註＋推論｜審查：X16a

**RISK-095 非營運部位的壓力損失（一般模式）。**
- 規則：被投資公司的非營運部位（貨幣、利率、指數衍生品）±20% 標準衝擊稅前損失合計 ≤ 權益 3%；超過 → 降一級（推論）。本組合宿主衍生品為 0，不適用於組合本身。
- 信心：低。證據：推論｜審查：X21-01
