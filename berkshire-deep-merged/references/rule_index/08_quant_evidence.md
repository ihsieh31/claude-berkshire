# 08 量化證據與訊號校準

> 本檔是 berkshire-way 規則書的參考檔；SKILL.md 每次必讀，本檔在對應閘門或動作需要細節時讀。
> 規則格式：**新編號 規則名** → 條件 → 動作 → 參數｜信心｜證據類型｜適用與例外。
> 證據類型只有四種：原文明文／多文本重複／持倉數據驗證／推論。標「推論」的數字是可調參數。
> 數字若與 `../rulebook.md` 第 5 節統一參數表不同，以參數表為準（標「舊版定版」處為上一版覆寫，若與「規則書」補充衝突，以規則書為準）。所有「EPS／盈餘／P/E／ROE」依全域營業盈餘口徑（SKILL §1 鐵律 3、§3 業主盈餘定義）。
> 「模式 A／B／C」＝資金規模小／中／大，與確定性等級 A／B／C／D 不同；「宿主」＝小資金模擬宿主（單檔 15%、現金 5%、12 檔；無價格停損與移動停損：rulebook 第 7A 節 `stop_mode`＝A，論點破裂檢查）。
> 文中「v2」或「A」指上一版本 skill，「B」指另一份來源整理版本；兩者的編號只供追溯，不是本版規則。

## 共用方法（所有量化結論的口徑）
1. **歸屬**：只用巴菲特本人決策部位。歸屬分界點後用 `decision_maker=buffett`；分界點前資料全標 buffett，但扣除被標為其他經理人代理的持有期（31 筆新建倉、51 筆加碼、63 筆減碼、35 筆清倉被剔除）。其他經理人（分界點後兩位投資經理、未知、接班人總部）全部排除。結果：巴菲特新建倉 78、加碼 288、減碼 349、清倉 94（季度持倉申報 全樣本期，111 季）。
2. **時點**：每筆事件用「事件季末之前已申報」的最近一份年報（首報值，不用重編值）；基準財年落後 >2 年者剔除。對照母體＝事件當年任一天在 大型股指數 的成分股（每年約 500–530 家），用其上一財年首報值。成分股歷史最早一段為假設名單，但持倉事件起點晚於該段，影響小。
3. **估值**：事件價＝季度持倉申報 隱含季末價（市值÷股數），再用 大盤指數 把時點調回財年末，和母體同口徑比較（母體價＝財年末日收盤，缺日線時用年報印的第四季高低價中點）。季度持倉申報 價和母體財年末價差 >1.67 倍視為拆股／類別錯配，估值設為缺值（44 筆）。
4. **報酬**：還原權息總報酬；下市／被併購者以最後價格轉入 大盤指數（之後超額為 0）。「相對留下持股」＝被賣股相對同季仍持有的巴菲特持股（市值加權、排除該股）；<0 ＝賣對。
5. **期間標記**：早期樣本＝季度持倉申報 樣本期前約 10 年（選股與報酬分析）或前約 12 年（賣出分析）；晚期樣本＝之後。三段穩定性檢驗把樣本期切成約 8／9／10 年三段，稱早段／中段／晚段。

---

6. **歸屬敏感度（規則書）**：以事件計數為基礎的結論（EVID-007～019）須在 舊版歸屬口徑、寬鬆代理口徑（gmean ≥0.5 或 gmed ≥0.9）、對稱 1% 口徑三者方向一致才標「持倉數據驗證」；只在一種口徑成立者標「持倉數據（歸屬敏感）」，信心最高「中」。對稱口徑下：新建倉約 78→33、單季出清約 39%→19%、小部位持有中位約 6→14 季、恐慌季新建倉占比約 15%→9%（集中度不變）。新建倉依歸屬規格約 109 筆、剔除推定代理部位後約 78 筆，主要數字以兩口徑區間呈現。每條並列「新建倉口徑」與「含加碼口徑」，兩口徑同向才標中以上。所有分佈一律排除事件型／套利部位與特別股；本幣未換算或存託憑證比例未知 → 估值設缺值。**以上重跑交量化切片，未完成前相關條目信心不升**。
7. **每股序列（規則書）**：所有「EPS 成長／年複合」一律用拆股與股票股利調整後的每股序列；資料不足時改用淨利年複合；EPS 依 SKILL §1 鐵律 3／§3 營業盈餘口徑。

## 重現結論摘要
- 穩定成立：集中度、持有期分層、買進時本益比約為同年中位的 0.7 倍、盈餘殖利率在較便宜的一半、隱含成長遠低於歷史成長、負債比無區分力、高品質門檻後財報無法再區分、「貴＋轉弱」賣對率最高、「便宜＋轉弱」與「建倉 <2 年出清」常賣錯、賣出平均無附加價值。
- 需修正：近五年無虧損的差距（被買 80–84% vs 母體 75%，不是 87% vs 68%）；四項篩選的提升倍數約 1.3–1.5 倍（不是 2–3 倍）；金融業比重約 2 倍（不是 3 倍）；「只有貴」類賣對率無法重現；ROE 百分位 0.68–0.75 只在非金融、含加碼口徑成立。

## 第二節　量化初篩與訊號校準（給交易 agent 的規則）

> 格式：發現 → 對交易規則的含義 → 建議參數與可調範圍 → 樣本數 → 信心 → 限制。
> 「提升倍數」＝通過篩選的公司在當年被巴菲特買進（新建倉或加碼）的機率 ÷ 母體基準機率；「涵蓋率」＝實際買進中通過篩選的比例。母體：同年 大型股指數成分股公司年度約 13,000 個（有值者），其中被買進的公司年度約 120–150 個。百分位門檻一律用同年同母體。95% 以外的區間為年度區塊 bootstrap 90% 區間（未處理同公司跨年重複，區間偏窄）。原始數字：`quant/screens.csv`、`q12_table.txt`、`q15_out.txt`。

### EVID-001　相對估值是最強、最穩定的單一入選特徵
- **發現**：本益比 ≤ 同年母體中位數 → 提升 1.54 倍（區間 1.44–1.65），涵蓋 77%；≤ 0.8 倍中位數 → 1.90 倍（1.66–2.13），涵蓋 61%；隱含 10 年成長 ≤8% 且 ≤ 過去 5 年淨利成長 → 1.69 倍（1.51–1.87）。三段期間都成立且逐段上升（中位數門檻 1.30／1.73／1.62；0.8 倍門檻 1.42／1.94／2.37）。
- **含義**：候選名單第一道量化門應是「相對便宜」，不是「最高品質」。
- **參數**：本益比 ÷ 同年大型股中位數 ≤1.0（必要）；≤0.8 為優先區；可調 0.7–1.0。隱含成長 ≤8% 且 ≤ 歷史 5 年淨利 CAGR（必要），可調 6–10%。（宿主覆寫：P/E ÷ 中位只是 P4′ 軟上限〔P-19〕；隱含成長硬條件只有 ≤10%，「≤ 歷史成長」改 G9 反方必答〔P-17〕；見 SKILL §3）
- **樣本數**：母體約 13,000 公司年度；通過且被買的公司年度 88–115。
- **信心**：高（作為「是否像他會買的」）；對「之後是否賺錢」為低（見 EVID-004）。
- **限制**：估值只到成分股；金融股本益比口徑不同；早期母體價格約 32% 用年報印的第四季高低價中點（晚期約 1%）。
- **規則書**：倍數以合併中位計；改用分類中位時，0.8 倍門檻在早期無提升，嚴篩提升約 1.1–2.5 倍、依期間而定。本條支持 P4′ 相對倍數軟上限（≤1.0；A 級可 1.2），不支持作為買進理由。｜審查：X26
- **規則書補充**（只改證據標記；審查 X26）：信心「高」改「中高」，並註明「中後段的穩定主要來自少數公司的重複加碼；新建倉口徑約 1.3–1.6 倍」。

### EVID-002　品質門檻：規則書改寫——「近五年無虧損」只作警示；5 年盈餘成長 ≥ 中位約 1.3 倍、三段穩定
- **發現**：近五年無虧損 → 提升約 1.20 倍，涵蓋 90%；早中段約 1.3 倍、晚段無區分力（三段約 1.34／1.27／1.01），不提高事後勝率（3 年勝率差約 −0.2pp）。五年最差 ROE ≥ 同年中位 → 早段 1.58、中段 1.15、晚段 0.86（不穩定）。5 年盈餘成長 ≥ 中位 → 約 1.3 倍、三段穩定。
- **含義（規則書）**：品質門檻是風險控制選擇，不是行為複製；「近五年無虧損」由必要條件改為警示 W-LOSS（P-02）；最差 ROE、營業利益率作為可選加分；負債比不設門檻（用利息保障或資本結構判斷）。
- **參數**：P-02（0 年 +1；1 年 W-LOSS；≥2 年降一級並須具名原因）；五年最差 ROE ≥ 同年中位（加分，可調第 40–60 百分位）；營業利益率 ≥ 同年中位（加分，非金融）。
- **樣本數**：同 EVID-001。
- **信心**：中（無虧損警示）／低（最差 ROE、營業利益率；公司群集區間）；高（負債比無區分力）。
- **限制**：營業利益欄覆蓋率約一半；金融業無營業利益率可比；晚期大資金時期品質區分力下降。｜審查：X26、X25、X29

### EVID-003　最佳組合：「無虧損＋（品質或成長）＋相對便宜」，提升約 1.7–2.1 倍
- **發現**：
  - 無虧損＋最差 ROE ≥中位＋本益比 ≤0.8 倍中位：提升 2.09 倍（1.64–2.54），三段 1.99／2.50／1.75；母體通過 18%，涵蓋 38%。
  - 無虧損＋五年 EPS 成長 ≥中位＋本益比 ≤中位：1.68 倍（1.44–1.95），三段 1.60／1.68／1.71（最穩定）；通過 26%，涵蓋 45%。
  - 無虧損＋本益比 ≤中位：1.66 倍，涵蓋 70%（寬鬆版）。
  - 再加「市值 ≥ 同年中位」：2.34 倍（1.89–2.78），但這反映大資金的容量限制。
  - B 的四項（五年均 ROE ≥15%＋無虧損＋負債低＋本益比低）：1.24 倍、只涵蓋 16%，早期只有 0.71 倍 → 不採用。
- **含義**：量化初篩採兩層：寬篩（無營業虧損＋相對便宜）留下約四成母體、保留七成實際買進；嚴篩（再加最差 ROE 或拆股調整後 EPS 成長）留下約兩成、保留四成。嚴篩名單仍有每年約 50–115 家大型股（規則書更正；提升約 1.5–2.6 倍，早段最低，新建倉約 1.9 倍） → 財報無法替你做最後選擇。
- **參數**：寬篩＝營業虧損年數 0 ＋ 本益比／中位 ≤1.0；嚴篩＝寬篩＋（五年最差 ROE ≥中位 或 拆股調整後五年 EPS CAGR ≥中位）＋本益比／中位 ≤0.9（規則書：0.8 改推論、預設 0.9，可調 0.8–1.0）。資金小者不加市值條件。缺值者列未評，不算不通過（SEL-070b）。
- **樣本數**：通過且被買的公司年度 44–100。
- **信心**：中高（行為複製）；低（報酬）。
- **限制**：「被買進」是標籤，不是成功；同公司重複加碼使有效樣本更小。
- **規則書補充**（措辭／條件補充；審查 X26）：把「每年約 90–130 家」改為「每年約 50–115 家」。

### EVID-004　這些篩選本身幾乎不提高大型股的 3 年超額報酬
- **發現**：大型股指數母體 3 年相對 大盤指數 為正的基準比例 47%（早期 60%、晚期 42%）。所有單項與組合篩選的通過者只有 47–51%，中位超額差 ≤ +4 個百分點；早期樣本中便宜類篩選約 +5 個百分點，晚期接近 0。
- **含義**：篩選是「縮小名單、對齊巴菲特偏好」，不是獨立的賺錢訊號；買不買必須靠護城河、管理層、能力圈與估值區間的質化判斷。交易 agent 不得以「通過量化篩」作為買進理由。
- **參數**：無（規則性含義）。
- **樣本數**：母體 3 年報酬可得約 9,200 公司年度。
- **信心**：中。
- **限制**：已剔除的成分股約四成缺日線（倖存者偏差，會讓母體報酬偏高）；等權、年度起點固定；只看大型股，小型股可能不同。
- **規則書補充**（措辭／條件補充；審查 X26）：限制改寫：「早期剔除成分股約六成缺 3 年報酬（被併購者八成以上）；補值估計母體早期勝率高估約 2pp，界限寬」；共用方法第 4 點註明母體與事件的下市處理不同。

### EVID-005　買進時的估值分佈（可直接當買價上限的參照）
