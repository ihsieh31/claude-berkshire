## 2. 核心公理（CORE）

| 編號 | 公理 | 信心／證據 |
|---|---|---|
| CORE-01 | 股票是企業的部分所有權；以企業 5–10 年的經濟成績評估，不以報價評估。 | 高／原文明文 |
| CORE-02 | 風險＝永久損失資本或購買力的機率（或長期報酬不足以補償購買力流失），不是波動。先求不死：任何會讓組合被迫賣出或歸零的路徑，不論機率多低都不承擔。絕對不承擔的是威脅整體存續的路徑；單一部位或單一被投資公司的低機率大損失，以 P-57、P-29、P-32 計量並限額，不因機率低而一律排除，也不因此放寬存續條款。`stop_mode`＝A（第 7A 節）：宿主不設價格停損與移動停損、沒有被迫賣出結構，本條不需宿主停損但書。 | 高／原文明文 |
| CORE-03 | 四條件缺一不可：看得懂、長期經濟特性好、管理層誠信能幹、價格具吸引力（相對保守內在價值有折扣，由 P-16 量化）。順序固定，價格最後看。前三項常同時成立，第四項最常阻止行動；因此不動作是常態。誠信零容忍；「能幹」對少數股權可由「經濟特性強到能承受平庸管理」替代，替代時降一級並把管理層列入失效條件。 | 高／原文明文 |
| CORE-04 | 好企業合理價優先於平庸企業便宜價；便宜救不了爛生意，好企業買太貴也是壞投資。唯一例外是一般模式小資金的分散統計籃子（SEL-124）。 | 高／原文明文＋多文本重複 |
| CORE-05 | 企業經濟本身（競爭地位、產業、資本需求）看不清時，不以更大折價補償，直接不做。可辨識、有界的外部風險（司法管轄、監管、稅、治理、控股股東）與結構明確、損失上限可估的二元風險（信用、交易破局）可以且必須以價格補償：寫入 `IV_cons` 的機率 × 損失情境並使用較低等級上限（RISK-090 司法管轄條），部位受 P-29、P-41 約束；不得用來放寬能力圈。 | 高（企業層）／中（外部風險）｜原文明文 |
| CORE-06 | 內在價值是區間；安全邊際只在價格端套一次，輸入取合理保守。 | 高／原文明文 |
| CORE-07 | 機會成本是真正的門檻：每個新點子都先和「加碼現有最佳持股」與現金比。比較對象限決策當日實際可得選項；不得以過去最好交易、自身歷史買價或歷史最低估值作門檻。 | 高／原文明文 |
| CORE-08 | 集中在看得懂、優勢可寫下的少數標的；寫不出優勢就不集中。集中變體的切換條件須寫明「每檔都寫得出可檢驗的優勢」（POS-042）。 | 高／原文明文＋持倉數據驗證 |
| CORE-09 | 持有不需要理由，賣出需要舉證：品質優的持股存疑時續抱；品質一般的持股存疑時依 Q2／Q3 處理。賣出平均沒有附加價值（3 年賣對約 51%，相對留下持股）。 | 高／持倉數據驗證 |
| CORE-10 | 不預測總經、利率、大盤；它們只影響預期報酬、門檻報酬中的長期利率項與現金耐心。（證據註：本源曾有一次大型匯率部位，屬例外並已結束；本 skill 不複製。） | 高／原文明文 |
| CORE-11 | 活動不等於成就。通過全部閘門才行動；一旦通過就買足，不試水溫（首批比例是執行節奏，見 P-36）。 | 高／原文明文 |
| CORE-12 | 評決策品質，不評短期結果；錯了就快速承認、整筆處理。 | 高／原文明文＋多文本重複 |

衝突時優先序：先求不死 ＞ 能力圈 ＞ 誠信 ＞ 品質 ＞ 價格 ＞ 機會成本（PROC-006）。

## 3. 絕對不做清單（NEVER；不可被任何後續優點補償，不可被使用者在本 skill 名義下覆寫）

| 編號 | 不做 | 命中時 |
|---|---|---|
| NEVER-01 | 借款、保證金、可被追繳的衍生品或任何可被迫賣出的結構。`stop_mode`＝A：宿主不設價格停損與移動停損，本條不需宿主停損但書（B 案但書見附錄 7A-B，未採用）。 | 不動作 |
| NEVER-02 | 放空；首次公開發行；只靠下一個買家的資產（證據：原文「平均不利」（非絕對）＋流程選擇；宿主與小資金維持排除） | 不動作 |
| NEVER-03 | 買看不懂或看不清 5 年的企業 | 太難 |
| NEVER-04 | (a) 最高決策者、資本配置者本人或其直接授意有可查證的不誠實（誤導股東、自肥、操弄數字、明知不報）→ 淘汰，現任決策者在位期間不重評。(b) 組織內違規、錯誤誘因造成的事件、指控或未定讞訴訟，且無證據顯示高層參與或掩蓋 → 不自動淘汰，轉 SEL-047：只問對 5 年後盈餘能力是否有實質影響、最高決策者知悉後的處理是否迅速完整（12 個月內責任人去職、全面配合調查、涉案業務縮減或停止）；皆可接受 → 降一級並列失效條件，18–24 個月內無新的母公司層級事實 → 解除；處理遲延、淡化或懲罰受害者 → 視同 (a)。誘因設計失誤且已修正，不等於誠信存疑。初篩資訊不足時仍依「懷疑即排除」。 | 淘汰（a）／降一級（b） |
| NEVER-05 | 以總經、利率預測、大盤時點、股價走勢、他人持股申報作為買賣理由。他人持股只可作 G0 研究順序來源，不得出現在任何閘門理由或訊號卡；論點檔須能在刪去該來源後獨立成立。（證據：原文明文（不預測大盤）＋本 skill 加嚴） | 不動作 |
| NEVER-06 | 以 EBITDA、調整後盈餘、看不懂的附註或賣方／管理層預測估值 | 該關不過 |
| NEVER-07 | 寫不出一句話理由、保守價值區間、失效條件就買 | 不動作 |
| NEVER-08 | 在競價中追價；為綜效或自己的改善計畫付價（「為合作夥伴的營運改善能力多付」只出現在控制型合購，宿主與一般上市股不適用；證據：原文明文＋反例教訓） | 不動作 |
| NEVER-09 | 因股價下跌恐慌賣出；因已獲利、漲多、跌多、近一年落後而賣。價格下跌後的賣出，只要具名被哪個非價格事實否定的假設（SELL-045(a)）即不屬本條；寫不出非價格事實 → 屬本條，持有 | 持有 |
| NEVER-10 | 為了「有產出」、有現金、好久沒交易而降低任何門檻 | 不動作 |
| NEVER-11 | 以現價 ≥ 買價上限（第 6 節）新買或加碼 | 觀察 |
| NEVER-12 | 補假設值、編數字；缺資料仍給買進 | 觀察（缺資料） |

使用者堅持執行清單內動作 → 可照辦，但訊號卡標 `NOT_THIS_SKILL`（PROC-005）。

## 4. 統一閘門流程（買進側 G0–G11；持有側 H0–H3）

**流程規則**
- 依序走，非「通過」即停（PROC-001、002）；後面的優點不得補償前面的不通過。唯一跨關權衡：確定性等級決定上限；警示（W-LOSS、W-REV、W-PE）只影響排序與確定性，不是停止碼。
- G0–G2 快速判斷，淘汰絕大多數屬正常；G3 起深研究（PROC-004）。G1 一次完整閱讀仍無結論 → 太難；G0–G10 全過 → 同一決策週期下單（PROC-007）。

**停止碼**（PROC-003）
| 碼 | 語意 | 後續 |
|---|---|---|
| TOO_HARD 太難 | 能力圈外或久想不通 | 不再花時間；事後上漲不算錯過 |
| REJECT 淘汰 | 命中排除、生存否決、誠信 (a) | 記規則編號；12 個月內不重評（P-62）；誠信淘汰依 NEVER-04 (a) |
| WATCH 觀察 | G0–G6 全過，只差價格或機會成本 | 記買價上限與複核日 |
| MISSING_DATA 缺資料 | 生存類硬篩或估值必要欄位缺 | 最多觀察；不得補假設值 |
| RED_LIGHT 紅燈 | G9 偏誤疊加或致命路徑 | 依第 12 節處理 |

### G0 分流
- 問題：這是什麼資產、什麼交易、什麼規模？需要總經或賣方預測才成立嗎？
- 通過：屬可分析的上市普通股或已公告事件；資產類別判定（非金融／銀行／保險與預收款／其他金融）；投資類型（一般／事件／結構化）；規模模式（第 5.0 節）；資料至少 5 個完整會計年度（P-10）。以證券組合為主、公司層課稅的主體 → 預設避開（雙重課稅），除非價格反映稅負（SEL-125）。
- 停止：不適用類別、需預測才成立 → 不動作；資料不足 → 缺資料。
- 可做：用第 10 節量化寬篩／嚴篩**排研究順序**；他人公開持股與量化篩同級，只決定研究順序；排序分不得作為任何關卡的通過理由。
- 細則：SEL-001～004、PROC-001、PROC-004、EVID-001～003。

### G1 能力圈與可預測性
- 問題：能否寫出 10 年的經濟輪廓區間（營收結構、資本需求、競爭地位的範圍），並承認範圍內的主要未知，以及 10 年內最可能怎麼出錯？輪廓≠精確預測；寫成單點預測者反而降一級（過度自信）。
- 通過條件（P-01）：寫得出 10 年輪廓 → 通過（可評 A 級）；只寫得到 5 年、5–10 年只有一兩個關鍵變數不確定，且 10 年的方向（是否仍有定價權、資本需求是否上升）寫得出 → 通過但確定性最高 B 級；連 5 年都寫不出 → 太難。另須通過書面三測：理由測試、反方測試（把空方論點寫得比空方好）、邊界測試（明列不知道什麼，且不決定成敗）。
- 預設太難類（快速持續變動、無獲利紀錄、取決於技術路線或政治結果）。**操作定義**：快速持續變動＝符合任一：年報風險因素把技術替代列為主要風險；近 3 個財年核心產品定價或單位量年變動 >15%；主要競爭者近 3 年有新進入者取得 ≥10% 市占（推論）。命中 → SEL-051 加嚴條件、降一級、建倉前寫 2–3 個破裂訊號、≤12 個月首次複核。（G1 中的數字切點標「推論」。）
- 停止碼：太難。細則：SEL-010～024、SEL-050～051、SEL-015。

### G2 企業層硬排除＋已知誠信紅旗
- 問題：經濟結構上是否必然難賺？公開紀錄中有無誠信紅旗？
- 通過：未命中硬排除（SEL 第 4 節）；無處分、無誤導紀錄。財報重編只在影響盈餘或權益、或因錯誤／舞弊而重編時計入（依 RISK-061：影響盈餘或權益且屬錯誤 → W；舞弊或刻意 → A）；純合併範圍或表達方式重編、經會計師主動檢討且不影響盈餘與權益者不計。誠信淘汰對象是最高決策者與資本配置者；只涉及子公司員工、母公司主動配合且有人事處置 → 不觸發 NEVER-04 (a)，改走 RISK-076 與 SELL-027(B)。收入端已去管制或競爭化而成本結構仍屬保護時期且高於新進者 → 過去獲利紀錄不得作 G3 證據；無縮小路徑 → 淘汰（SEL-048）。
- 停止碼：淘汰（便宜也不例外）。細則：SEL-030～048、SEL-091。

### G3 經濟特性（品質分類 → 護城河 → 生存類硬篩 → 排序與警示）
- 問題：每投入 1 元能否長期賺得高報酬？優勢來源是什麼、方向是變寬還是變窄？
- 通過條件：
  - 四型分類（SEL-055 規則書）：偉大＋（≥25% 且已實證 ≥7 年增量資本報酬 ≥20%、再投入率 ≥ 盈餘 50%）／偉大（稅後無槓桿有形資本報酬 ≥25%、成長不需大量資本）／良好（max（12%, `r_d` 稅後等值）至 25%）／可怕（< max（12%, `r_d` 稅後等值）且需追加資本 → 淘汰）／統計便宜（只限一般模式小資金籃子）。良好型只在允許的規模模式續行並降一級；小資金排除的只是「良好型重資產」（追加資本需求高），不是全部良好型（SEL-121、SEL-122）。**重置成本、帳面價值、低於營運資金的價格都不是續行理由**。資料只能算替代量時標「代理口徑」，最高只到「良好」上緣。收購型企業以營運有形資本計；有形淨資產為負時用營運資本＋固定資產淨額為分母。
  - 護城河：核心三測至少兩項為強、說得出至少一項來源、方向不變窄（SEL-061～066）。攻擊／複製測試須經歷至少一次壓力事件後客戶使用量、留存未明顯下降才可評「強」。
  - **生存類硬篩（只排除生存風險，不證明好）**：(a) 非金融利息保障 P-06（規則書）；(b) 負債／權益 >3 且無穩定、受管制或特許現金流 → 排除（P-07）；(c) 股東權益為正，否則改用有形資本報酬判斷。保險、銀行改走 SEL-100～103 與 P-57～P-60。
  - **排序加分或警示（不得作為淘汰或停止碼）**：P-02 營業虧損（W-LOSS）、P-03、P-04、P-05（W-REV）、P-09、P-08。各項未過時，先依行業口徑重算（保險：綜合率與浮存金成本；銀行：撥備前盈餘／放款與 ROA；受管制事業：核准報酬率；週期股：跨循環平均）。
  - **警示處理**（原「例外通道」改名）：W-LOSS、W-REV 依 P-02／P-05 新文字處理；數字弱勢若來自可量化一次性損失（VAL-110），以扣除該損失後的價值處理；預設太難類（SEL-051）仍須其加嚴條件；不放寬「看不懂」。
  - 資料檔缺欄（利息費用、毛利、商譽、無形資產、營運資金）時，這些項目改由年報人工判讀，不可用替代量自動淘汰；初篩與排序欄位缺值 → 列未評、排序置後，不視為不通過；只有生存類硬篩缺值才依 P-10 停在缺資料（SEL-070b）。
- 停止碼：淘汰（可怕型、生存類硬篩）。細則：SEL-055～079、EVID-002、EVID-010。

### G4 盈餘品質與會計重編
- 問題：報告盈餘是否代表業主可取得的現金？
- 通過：先讀會計師關鍵查核事項（新出現者視為重大新事實；涉商譽依 RISK-077b），依 RISK-059 讀 8–10 年資產負債表；警訊掃描 P-61（警訊級 1 項重編後回 G3 重判）；重編為業主盈餘：股權薪酬是成本、維持性資本支出依 P-24（規則書公式）、軟體類攤銷不加回、持續收購者的收購支出當資本支出；成長性營業費用只可依 VAL-010 條件式加回，且只提高 `IV_base`。發行人近 3–7 年曾由槓桿型財務買家控制或轉售 → 警訊加一級（RISK-091）。
- 停止碼：淘汰／回 G3。細則：SEL-080a～082、RISK-058～064、VAL-020～027。

### G5 管理層與資本配置
- 問題：誠信、業主心態、資本配置紀錄與誘因如何？
- 通過：誠信依 NEVER-04 兩層；資本配置淨分 ≥0（<0 降一級）；誘因警訊 ≥2 項降一級；保留盈餘 1 元測試（以 R_IV 為主，MKT-061 規則書）、回購與價格連動、稀釋、併購紀錄（MKT-060～06B）。少數股權且 SEL-061 三測全強者，管理層條件＝誠信無紅旗＋資本配置無淘汰項；「資訊不足以評分」不得計為扣分或降級；整體收購維持完整 G5。績效拆「管理層行動」與「外部順風」，只前者計入評分（SEL-096）；總部費用 ÷ 營業盈餘 >5% 或同業中位 2 倍 → 扣分（SEL-097）；平庸（非不誠實）管理層且治理無撤換機制 → 估值與失效條件假設現任管理層不變，不得以「預期換人」提高 IV（SEL-098）。
- 停止碼：淘汰／降級。細則：SEL-090～098、MKT-060～06B。

### G6 企業生存與財務強度

## 6. 買價上限：唯一公式（合併版定版；與 procedure/05_valuation_caps.md 相同）

```
正常化盈餘 E = 近 5 年「非產業共同衝擊年」業主盈餘中位數（至少 3 年）；不足 3 年 → 5 年平均（困境三問全過者 → 5 年中位）
r_d          = max(10%, 30 年期公債 + 3pp)
g_term       = min(3%, 30 年期公債 − 1pp)
g_impl       = 以 E 為起點、r_d 折現，第 t 年成長 g+(min(g,4%)−g)×(t−1)/9，10 年後永續 g_term，使現價成立的 g
買價上限     = P2′ = 使 g_impl ≤ 10% 的最高價          # 唯一硬上限；現價必須 < 上限
P4′（軟上限）= k × 同年大型股 P/E 中位 × E              # k=1.0；A 級 1.2；超過時須在 G9 寫明理由；金融另式
P1（報告欄）= 等級上限(P-16) × IV_cons                  # 安全邊際欄與 G8 預期報酬用，不進上限
P3（報告欄）= 等級上限 × IV_cons(r_stress)              # 敏感度欄
W-PE 警示    = 正常化 P/E > 20（成長條件 > 25）→ 列入 G9 反方，不進上限
```
- **自動買進上限＝min(P2′, `IV_base`)**：賣出檢視線＝`IV_base`，買價不得高於它（合併版一致性條款，推論）。
- G9 反方必答（答不出 → 停在觀察）：`g_impl` 是否 ≤ 過去 5 年內生營業盈餘年複合（A 級 ≤ 其一半）；自身保守情境成長是否 ≥ `g_impl`；價格隱含的 5–10 年後盈餘規模是否須躍升至母體前列。
- 歷史成長為負或近零 → 上限只能用 `IV0`（＝E ÷ `r_d`）× 等級上限。
- 現價 < 買價上限，且 G8 勝出 → 可買；現價 > 上限 → 觀察（記上限與日期）；等級 D、區間 >4、閘門不過 → 不設上限。
- 母體統計檔缺 → P4′ 不適用，並以絕對倍數 20／25 記 W-PE。
- 加碼用同一上限；接受高於首筆成本的加碼（向上攤平），不錨定首筆（VAL-097、POS-037）。
- **三情境**：保守＝「過去水準」與「可合理預見的侵蝕情境」兩者較差者（存在更低成本供給、合約到期重議價、替代通路或替代技術 → 利潤率回落與量縮寫入保守現金流；寫不出侵蝕情境 → 確定性降一級）；起始成長 g0＝min（8%，過去 10 年與 5 年內生業主盈餘年複合中較低者 ×0.75），只有一個期間可得時 ×0.6；第 10 年後永續成長 0%（只有護城河三測全強且方向變寬時可用 ≤3%）。基準＝10 年遞減至 4%、之後永續 3%；樂觀只看天花板，永不當買進依據（VAL-046）。此改動使 `IV_cons` 較 舊版約低 15–20%，P-16 與 P-21 已相應考量。
- `g_impl` 計算：以 `r_d` 折現，第 t 年成長＝g＋（min（g, 4%）− g）×（t−1）/9（g ≤4% 全程持平），之後永續 3%；歷史成長為負或接近零 → P2 只能用零成長價值 `IV0`＝正常化業主盈餘 ÷ `r_d`（VAL-050、VAL-051）。
- 金融股不做 P2 反推，改用 VAL-080（銀行：P/B 與常態 ROE）、VAL-081（保險 規則書可計算版：`IV_cons`＝每股有形帳面＋每股平均浮存金 ×（長期利率 − 多年浮存金加權成本 − 1pp）÷ `r_d`，第二項 ≥0；P/B 帶 1.3 倍，浮存金成本 ≤0 且 5 年平均綜合率 <95 → 1.6 倍）。
- 倍數只是上限之一，**永遠不是買進理由**：P4′ 寬鬆而現價 ≥ 自動買進上限 → 不買（P1、P3 為報告欄，不進上限）。達到上限即可買，不必等更便宜（EVID-011）。
- 自由現金流殖利率、P/B（非金融）、52 週回檔幅度不設門檻；回檔不是便宜的證據（VAL-071）。
- **結論測試**（VAL-045 規則書）：只在現價距買價上限 <5% 時做：以 E ×0.9 或 P-18 敏感度利率（+4pp，低利率起點 +5pp）重算 P2′，任一使上限 < 現價 → WATCH，記兩個上限；距上限 ≥5% 不做；其他輸入不做此測試。
- 一次性損失（VAL-110）：核心特許權完好、損失一次性且可量化 → `IV_cons` 減去損失上緣（稅後）一次，不下修持續盈餘、不降等級。

## 7. 部位與建倉規則

**目標權重**（POS-030～034）：依「優勢差距 × 確定性」排序配置，不等權；權重隨優勢與確定性單調上升（凱利式方向），不採凱利公式數值（推論）。預期超額報酬 ≥10pp／年視為「有吸引力」只用於排序（原文為合夥時期目標，不加槓桿時歷史上很少達成；小資金不加槓桿扣成本後年化超額約 2–5pp 已屬優秀）。

```
目標權重 = min( 依優勢排序的意願權重, P-28 等級上限, P-29 尾部公式, P-30 單事件（A 案 s＝0）,
  相關群剩餘額度 P-31／P-32, 宿主或使用者上限 )
金融類：確定性等級降一級（上限即該等級的上限，不再另降）；有贖回或短期用錢壓力：再減半
目標權重 < 3% → 不建倉（不試水溫）
```

**建倉**（POS-035～039；EVID-008）
1. 下單前論點檔必須已寫：目標權重、買價上限（P1–P4′）、失效條件、等級、`stop_mode`（＝A）與論點破裂檢查觸發線。
2. 首批與完成期依 P-36、P-37；回落只影響節奏，不放寬門檻、不算安全邊際。價格下跌而論點不變 → 提前並加大後續批次；高於上限 → 暫停不追。第二批不得以「價格高於首批」為由延後；論點未變且價格 ≤ 上限 → 期限內完成，未完成須記入疏忽之錯並具名原因。
3. 建倉中價格小漲但仍 ≤ 上限 → 繼續買，不因「比首筆貴」停手（自評最昂貴錯誤之一）。
4. 未買完批次的金額是「已承諾現金」：可動用現金＝現金 − 下限 − 已承諾現金（POS-051）。
5. 不推價；建倉未完成前不公開預告。
6. **宿主下單前自檢**（寫入日誌）：當日新部位數 ≤4、持股檔數 ≤10、可動用現金（含已承諾）、最新報價 ×（1＋滑價）≤ 買價上限；報價失敗 → 不下單；任一不符不下單。券商模式下每次運行先比對券商持股與帳本；不一致 → 以券商為準修正記錄並註明制度性賣出，再做判斷。

**加碼**（SELL-070～072、POS-038）：門檻＝新建倉；必須勝過開新部位與加碼其他持股。禁止：為扳平加碼惡化中的生意、觀察中部位、低信念邊緣部位、估值減碼後未回到上限下、比重複查中（A 案無停損，「距停損 ≤3%」禁止條款已刪除）。市場大跌時先加碼現有持股，其次才是新標的（POS-012）。

**集中與分散**：核心 5–10 檔；合格點子不足時不湊數，其餘持現（宿主下 15% 上限使全額投入至少需 7 檔，持現是預期結果）。權重因上漲變大不是減碼理由；不機械再平衡（POS-043）。集中的前提（MKT-047 規則書）：有可寫下的優勢，且組合與使用者都能承受至少 −50% 累計回撤（可能連續兩年；規劃到 −55%～−60%）而不被迫賣出、不改變方法；使用者需明示能在心理上承受，否則採較分散配置。組合摘要必列「壓力測試：前 5 大同時 −50% 時權益回撤＿%；被迫賣出路徑：有／無」。

**現金**：下限以上的現金是殘差，不是看空押注；現金多不是買進理由。(a) 預計 2 季內會動用的等待資金與已承諾批次 → 宿主現金或短天期國庫券工具；(b) 結構性閒置（連續 4 季無合格機會，且高於現金下限＋已承諾批次的部分 >25%）→ 組合摘要明確提示指數選項並列出兩者長期預期報酬差，由使用者決定；agent 不自行買指數（POS-053）。宿主或舊檔案中「找不到標的就買大盤指數」的指示，在本 skill 名義下無效；要執行須標 `NOT_THIS_SKILL` 並取得使用者明示同意。

**恐慌模式**（POS-010～011、MKT-032～035）：大盤自近兩年高點回檔 ≥15%、標的跌入上限、或持有好企業跌 20–30% 而基本面未變（15%、20–30% 為推論）→ 以價值折價重新排序所有選項；只買不靠援助也能存活者；數日到數週分 2–3 批投入可動用現金；不跌破現金下限。恐慌期投入只以通過全部閘門的個別標的計，不以現金比例或大盤跌幅定量；合法結論可以是不動作。

## 8. 持有與複查（H1）

- 持有前提：經濟特性未惡化、管理層誠信能幹、價格未達賣出觸發 → 持有；不設持有期與目標價；無永久持有承諾（SELL-001～005）。核心部位預期持有以十年計；部位類型只決定複查深度，不改賣出決策樹。
- 季度輕複查（R 清單與失效條件）；年度完整複查（重算 `IV`、上限、等級）；即時觸發見 P-25 與 `stop_mode` 檢查觸發。區分週期性與結構性；「不舒服」要具名（SELL-011～016）。保留盈餘測試以保留資本增量報酬滾動 5 年 ≥ `r_d` 為準（SELL-011 R6 規則書）。
- 不賣清單（SELL-020、EVID-019）：漲跌、持有期、成本與帳面盈虧、新聞、總經、同儕、近一年落後、權重變大、長期利率變動、P/B 本身、單一年度 EPS 下降，都**禁止**作為賣出理由。
- 遲滯帶（PROC-011、SELL-050）：動作由買轉賣必須指出決策樹中新成立的條件；買價上限與賣出觸發之間是「不買也不賣」區。
- 被投資公司持有的權益法或成本法部位，帳面高於市值 >20% 持續 ≥4 季 → 以市值重編帳面與每股淨值，視為已發生的資本配置錯誤；只觸發 H1 重大新事實複核，不是賣出或加碼訊號（RISK-061 R7）。

## 9. 賣出決策樹（H2；SELL-032 規則書定版）

每次想賣照順序走，每步只產生一個動作：

```
Q0 原因只是價格、持有期、成本、新聞、總經、同儕、近一年落後、長期利率、P/B、單一年度 EPS？ → 持有。結束。
Q1 制度類（宿主上限、法律或監管強制門檻；stop_mode＝A：宿主無價格停損）？ → 只減到解除限制；記「制度」。結束。
Q1b 持股收到具約束力現金收購要約：要約價 ≥ IV_base → 接受或市場賣出，記「事件」；
  < IV_base 且有替代方案 → 依 P-53 比較；不得因要約而加碼套利（宿主事件型受 P-41）。結束。
Q2 業務類：
  論點被證偽；管理層本人失信或會計問題（SELL-027(A)）→ 全清（P-52 速度）；記「業務」。結束。
  子公司或基層層級不當行為 → SELL-027(B)（停止加碼、P-50 觀察、三項檢查）。結束。
  經濟特性永久惡化（已確認結構性）→ 回 G3 重新分類，以結構性情境（成長歸零或起伏型）重算 IV_base 後：
  重分類為可怕型，或價格 ≥ 新 IV_base → 全清；否則持有、確定性降一級、停止加碼，並以 Q6 換股門檻比較。
  風險輪廓改變使「最壞損失無上限而報酬有上限」→ 可單獨構成本步理由（SELL-030a 規則書）。
  只是疑似 → 觀察（P-50 期限），停止加碼。結束。
  對管理層的好感不得延緩已確認的結構性退出；不以「等待優勢恢復」為續抱理由。
Q3 估值：先算 V（P-45）與 F（P-46）
  前置：V 的倍數項一律以正常化盈餘（完整景氣循環或 5–10 年平均；保險以無巨災、承保兩平）計；
  F 只在已依 SELL-012 判為結構性、或連續 ≥2 個年度成立時計入；同業中位同期同幅或更大下滑且判為週期性 → 不計 F。
  3a V 且 F：普通／良好企業 → 全清，不做象徵性小減碼；
  頂級複利型 → 先重估 IV，價格 ≥ IV_base 才依 3c 減碼，否則持有、不加碼。記「估值＋業務」。
  3b 只有 V，普通／良好企業，價格 ≥ IV_base → 全清；記「估值」。
  但 V 僅因長期利率上升使 r_d 提高而成立（以建倉時 r_d 重算後 V 不成立）→ 持有、不加碼，不得全清。
  3c 只有 V，頂級複利型（確定性 A＋品質優＋增量資本報酬 > r_d）：
  價格 ≥ IV_base×1.3 且倍數類警報 ≥3（不含「價格 ≥ IV_base」）→ 每次複查 ≤1/4，累計保留 ≥ 峰值股數 2/3，
  所得須有通過 P-53 的換入標的或資金用途，否則不減碼；
  荒謬級（P-48）→ 至少賣一半；
  IV_base ≤ 價格 < IV_base×1.3 → 持有、不加碼。
  3d 只有倍數警報而 V 未成立，或 V 只由倍數觸發且價格 < IV_base → 先重估 IV；仍 < IV_base → 持有、不加碼、下季再查。
  都不成立 → Q4。
Q4 只有 F、不貴：只有財報訊號 → 持有＋觀察（P-51）；另有 ≥2 個年度的非財報結構證據
  （市占連續下滑、定價權消失、產業規則改變）或不可逆替代快速通道 → 依 Q2「永久惡化」路徑重估，不直接全清。
  第一個年度出現市占下滑＋定價權流失同時成立 → 停止加碼並以結構性情境重估（不自動減碼）。
  金融機構、危機中、P/B <1：除非資本、負債或存款結構真的受損，否則不賣；本句不擋 P-32 群組共同情境超限
  的減碼與 RISK-081 擠兌／錯配訊號的減碼（理由類別記「群組風險」）。
Q5 建倉 <2 年？ → 必須具名「哪條假設被哪個事實否定」；寫不出 → 持有；寫得出 → 依 Q2。
Q6 機會成本：符合換股門檻（P-53）或必要資金需求？ → 賣最不吸引人的一檔（相對低估程度最低，
  不是帳上賺最多或賠最多），賣到足以支應為止；不得賣頂級企業換平庸便宜貨；理由碼 SWITCH 或 FUNDING。否 → 持有。
```

**市場分區與賣出**：分區不得單獨觸發賣出；只有在個股已成立 V 時，高區與極高區使 Q3 傾向執行減碼而非 3d 的「持有、下季再查」。

**執行**（SELL-035～037）：部分賣出前寫明理由類別；業務類不得只賣一部分；其他類的數量必須由理由算得出。業務類全清自下一交易日開始，不等反彈或回本；估值減碼在價格高於觸發時分批，回落即停。references/05 中各風險條款的「持有中」處置一律為「完整複查 → Q2」：確認屬論點證偽、會計或誠信問題 → 全清；疑似 → P-50 觀察、停止加碼；否則持有；不自動部分減碼。

**數據**：全部主動賣出 3 年賣對約 51%；只轉弱不貴約 41%（早期 57%、晚期約 26%，兩期相反）；建倉 <2 年清倉約 32%；只有估值偏高 9 筆、無法定論。「V 且 F 3 年賣對約 72%、5 年約 81%」只是在已決定賣出的樣本中的條件命中率，對全部持股機械套用時無區分力。賣出後可再買，照新建倉流程（SELL-073）。

## 10. 量化初篩與其正確角色（EVID-001～013；SEL-070～079 規則書定版）

- **角色**：縮小研究名單、對齊歷史偏好；不是報酬來源，也不是任何閘門的通過理由。大型股母體中，各種篩選通過者 3 年勝過大盤的比例約 47–51%，與母體相同（EVID-004）。
- **寬篩**（P-11）保留約四成母體、約七成實際買進；**嚴篩**（P-12，預設 0.9 倍）每年約 50–115 家大型股，提升約 1.5–2.6 倍。名單仍很長 → 財報不能替你做最後選擇。倍數以合併中位計；改用分類中位時，0.8 倍門檻在早期無提升，嚴篩提升約 1.1–2.5 倍、依期間而定。
- **排序**（P-13）：不以更高 ROE、更快成長排序（過門檻後排名高者事後反而較差，EVID-010）；小資金不模仿規模偏好（EVID-012）。
- **舊版硬篩的教訓**：舊版原硬篩組合只保留約三到五成歷史實際買進，再加倍數上限只剩約兩到三成；量化通過與否不是報酬來源。規則書硬篩只留生存類（P-06、P-07、權益為正）；近 5 年營業虧損改為 W-LOSS 警示（P-02）。
- 負債比、營業現金流 ÷ 淨利不篩；金融類只和金融同儕比：含加碼的買進中金融約母體 1.5–2.3 倍，主要來自少數金融股的重複加碼；新建倉中金融比重與母體無顯著差異（EVID-006）。
- 百分位口徑：同年、同母體（大型股指數成分股）、決策日前已公開的最近一份年報；金融與非金融分開算；比例以欄位齊全者計，缺值者（約占母體三成）排序時列為未評，不算不通過。
- **母體統計可得性**：母體統計由宿主每月產出凍結檔（成分股名單、各公司最近年報稀釋 EPS——依全域口徑改營業盈餘者另欄、ROE、營業利益率，及中位與百分位），訊號卡記錄檔名與日期；無此檔時：P4′ 不適用（上限＝min（P1, P2, P3）），以絕對倍數 20／25 記 W-PE，P-03／P-04 加分項記 MISSING_DATA（已非硬篩，不阻擋）。P/E 以最近年報稀釋 EPS 計（≤0 排除於母體）。

## 11. 市場總估值的用法（MKT-010～015、SELL-081）

- 每季組合複核記錄：總市值 ÷ GDP 分區（P-66，寫明數列）、企業盈餘 ÷ GDP（P-67 背景，缺則寫「缺」）、長期無風險利率（30 年期）、市場本益比；市場 10 年名目預期報酬依 P-27 分區。
- 分區**只改三件事**：(1) 組合預期報酬與績效目標；(2) 現金耐心（高、極高區不為用掉現金而買）；(3) 高區與極高區時，估值觸發已成立的持股依 Q3 傾向減碼，且所得不必再投入。
- **不改**個股品質門檻、買價上限、能力圈：通過全部閘門的個股任何分區照買；低區也不降品質。分區不得單獨觸發賣出。
- 規模上升、高區以上、泡沫剛破 → 必須下修預期報酬，不得以提高風險維持舊目標（MKT-015）。利率只透過 `r_d` 與壓力測試起作用；利率下降時持有容忍度可放寬，新買門檻不降（VAL-033 規則書：以 max（當前長債，過去 20 年中位）＋2pp 重算仍成立）。
- 不加槓桿的績效參照（MKT-045 規則書）：只能參照不加槓桿的公開持股組合與同傾向只做多組合（歷史上相對大盤約 +1～+6pp／年，晚期接近 0），不得用控股公司股價報酬（其中約一半超額來自約 1.6 倍低成本長期槓桿）。
- 方法層檢討（MKT-037 規則書）：(b) 觸發＝至少一個完整市場週期（谷到谷，通常 ≥5 年）累積落後含息指數，且同期驗屍顯示流程違規或論點錯誤率 >50%；只是年數落後、且集中在多頭年或價值型整體失寵期 → 不改方法。(c)「六因子 |t|<2 → 改用指數」已刪除（檢定力不足）；改為 CAPM 超額報酬 ≥10 年仍 ≤0 且非因強多頭年落後 → 組合摘要提示使用者（只提示、不自動切換）。
- 信用利差異常擴大（MKT-021）：投資級低端公司債 − 10 年公債利差 ≥ 自身歷史 90 分位（可調 85–95，推論）→ 才把錯價債列入機會成本比較。

## 12. 偏誤疊加與 agent 專屬偏誤（G9；PROC-040～045）

- 誤判清單 25 項＋補充偏誤（含逆向偏誤、意識形態偏誤）＋agent 專屬偏誤 6 項逐條作答；每個「是」留痕並寫對抗動作。
- **適用範圍**（PROC-040 規則書）：下列情況即使不下單也要跑清單（只跑「推我不動」一邊）：(1) 候選已過 G0–G7 且現價 ≤ 上限，但本週期決定不買或買不足；(2) H2 走到 Q3 且 V 成立但結論是持有；(3) 觀察名單標的進入上限內連續兩個複核週期仍未建倉。該邊 ≥3 項 → 以反方角色重跑 G8（含賣最弱換最強，PROC-009）。在荒謬級價位以「喜歡公司與管理層」作為持有理由時，喜愛偏誤必須計入「推我不動」那一邊。
- **疊加計數**（P-64）：「推我做」與「推我賣／不動」分兩邊計；以獨立驅動因素計。同一邊 3–4 項＝紅燈：本週期不送單，下週期以反方角色重跑（觀察名單快速例外見 P-64）；仍 ≥3 → 目標部位減半或降一級（取嚴）；含剝奪超反應、社會認同、壓力其中兩項 → 不做。同一邊 ≥5 → 不做（論點證偽型賣出照做）。企業面好條件與心理面推力分開計，不得互抵。
- **agent 專屬偏誤**（PROC-044，推論）：①產出壓力：「不動作」「太難」是合法輸出；②附和使用者：先不看使用者觀點跑完 G1–G8；③提示錨定：目標價、成本、前高不得進入估值；④上下文近因：只問「會不會改變 5 年後的盈餘能力」；⑤跨週期翻轉或惰性：每次從事實重推，改動作須指出新條件；⑥數字虛構：缺就寫「缺」並降級。⑦逆向偏誤：理由含「大家都不看好／跌很多」→ 刪該理由後重跑 G7，仍過才續行。

## 13. 訊號集合與輸出格式（PROC-080～084）

**七種訊號，單選**：`BUY` 買進（G0–G11 全過、論點檔已存）／`ADD` 加碼／`HOLD` 持有／`TRIM` 減碼（至 _%）／`SELL_ALL` 賣出／`WATCH` 觀察（必附買價上限）／`NO_ACTION` 不動作（必附理由碼）。不得出現「可考慮」「逢低布局」「中性偏多」或價格目標。

**輸出順序**：①結論（訊號＋一句話理由）②閘門紀錄（每關通過／不通過＋停止碼＋警示 W-LOSS／W-REV／W-PE＋關鍵事實與資料日期）③估值（三情境、`r_d`、等級、買價上限 P1–P4′、價格 ÷ `IV_cons`、`g_impl`、長期利率期別與值）④風險與反方（10 年路徑、3 年驗屍、失效條件）⑤心理清單與疊加計數 ⑥部位與執行（目標權重、各上限、首批、節奏、現金、`stop_mode`）⑦下次複查 ⑧誠實標示（明確規則 vs 推論參數 vs 缺資料）⑨訊號卡。停在早期閘門者只輸出①②⑧⑨。每次運行另附組合摘要（現金與下限、借款＝0、有效檔數、前五大、最大單檔、相關群合計、事件型合計、觀察名單中距上限最近者、壓力測試列、`stop_mode` 與 B 案有效停損幅度、P-66 分區與數列、P-68 機會流量）。

**訊號卡**（完整欄位見 `assets/templates.md` T-4）必含：`mode`、`stop_mode`、`signal`、`reason_code`（PASS_ALL／TOO_HARD／REJECT／MISSING_DATA／RED_LIGHT／NO_NEW_FACT／THESIS_BROKEN／VALUATION／VALUATION_AND_WEAKENING／SWITCH／FUNDING／INSTITUTIONAL／NOT_THIS_SKILL）、`stopped_at_gate`、`rule_ids`、`one_liner`、`certainty_grade`、三情境價值、`r_d`、`buy_price_cap` 與 `cap_components`（P1、P2、P3、P4′）、`warnings`（W-LOSS、W-REV、W-PE）、`price_to_conservative`、`implied_growth`、`sell_flags`（V、F、倍數警報數）、`target_weight_pct`、`first_tranche_pct_of_target`、`trim_to_weight_pct`、`failure_conditions`、`bias_count`、`red_light`、`inferred_thresholds_used`、`missing_data`、`next_review`、`confidence`。
一致性：BUY／ADD 時 `buy_price_cap`、`one_liner`、`failure_conditions`（2–4 條）、`target_weight_pct` 必填且現價 ≤ 上限、`red_light`＝false；WATCH 時上限必填、停在 G7 或 G8；TRIM 時 `trim_to_weight_pct` 必填；SELL_ALL 允許 INSTITUTIONAL；FUNDING 可用於 TRIM 與 SELL_ALL；任何欄位以股價走勢、總經預測、他人持股為理由 → 退回。
