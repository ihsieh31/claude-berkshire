# 07｜偏誤、必寫三件、結論卡、失效條件與執行（步 12、13、15）

## 1. 結論卡（每支必出；放在報告最前面）

```
結論：買 / 觀察 / 觀察（缺資料） / 不買 訊號：BUY / WATCH / NO_ACTION（理由碼）
一句話理由：
停在哪一關：（不買、觀察時必填；規則編號）
確定性等級：A / B / C / D（降級事項清單）
三情境價值：IV_cons ＿ / IV_base ＿ / IV_opt ＿（每股；r_d ＿%，30 年期 ＿%＠日期）
自動買進上限：＿（= min(P2′ ＿, k ＿ × IV_base ＿)，k＝A 0.95／B 0.85；P4′ 軟上限 ＿；P1 ＿、P3 ＿ 報告欄） 不買者寫「不設：規則編號」；缺資料者寫「待補後重算：缺項」；C 級的上限只是報告值；IV_base 缺者寫報告上限並註明「不設自動買進上限」

自動買進三閘門：初篩未刪 是/否｜現價 < 上限 是/否｜固定問卷 通過/不過（作答檔：＿）
```

|---|---|---|

| 不買 | `TOO_HARD`、`REJECT`、`RED_LIGHT`（本週期）、D 級、區間 >4、G10 寫不出 | 「不設」＋規則編號 |

## 2. G10 必寫三件（PROC-020～025；T-1）
1. **一句話理由**：為什麼這是好生意、為什麼現在的價格有安全邊際（不得含股價走勢、他人持股、總經預測、初篩排名）。
2. **保守價值區間**（含自動買進上限與 P1–P4′）。
3. **失效條件 2–4 條**：可觀察、有期限，例如「連續兩個財年核心產品實物量下降 >X%（推論值須寫明）」「核心經營者離任且無已公告接班」「浮存金成本連 3 年 > 長債 −1pp」。附預期持有期、複查觸發、退出路徑（宿主下即 P-38 流動性）。每條失效條件附 `due`＝判斷所需證據可得後的檢查日（例如「連續兩個財年」→ 第二個財年年報預期申報日之後），寫進登錄表 `kill_criteria_due`；到期由 review_due 排 THESIS，THESIS 檢查後框架記 `checked_on`、`status`，並依輸出 `next_due` 前移下一次檢查日（或結案）。
論點檔存後凍結，只能增補（H3 驗屍對照用）；持股年度完整複查另立新版 `{T}_{決策日}_v{n}.md`（記 predecessor），舊檔不動（SKILL §0）。

失效條件的來源：G9 的 3 年驗屍前三原因、產業手冊的典型陷阱、`09_postmortem_signals.md` 的「當時忽略的訊號」。

## 3. G9 反向思考與偏誤（第 12 節；PROC-030～045）
- 10 年永久損失路徑：逐條寫，無致命者才通過。
- 3 年驗屍：假設 3 年後論點錯了，最可能的前三個原因 → 轉成失效條件。
- 反方論點寫得比反方好；W-PE 時必須把「倍數偏高」列入反方；**困境標記（T1–T5）一律列入反方作答，並完成步 4A ⑤：刪掉所有「跌很多」類句子後理由仍成立**（不成立 → 下一條處理；`11_distress_check.md` ⑤）。
- 誤判清單 25 項＋逆向偏誤、意識形態偏誤＋agent 專屬偏誤 7 項（產出壓力、附和使用者、提示錨定、上下文近因、跨週期翻轉、數字虛構、逆向偏誤）逐條作答。
- 疊加（P-64）：同一邊 0–2 照常；3–4 紅燈（本週期不送單、下週期以反方角色重跑）；≥5 不做。以獨立驅動因素計。
- 兩軌不一致（P-65）：延後一個決策週期重跑 G9。
- 理由含「大家都不看好／跌很多」→ 刪該理由後重跑 G7，仍過才續行（rulebook §12 agent 專屬偏誤⑦；`rule_index/07_process_psychology.md` 逆向偏誤）；不過 → 結論 `WATCH`（`stopped_at_gate` G9），不另降級、不用停止碼（SKILL §0 WATCH 來源）。

## 5. 執行
- **冷靜期**：由價格大幅波動或新聞觸發、且不屬於論點證偽的決定，延後一個交易日（一個決策週期）執行；先重讀論點檔與失效條件。不適用：論點證偽型全清（P-52 自下一交易日開始，不等反彈）、已寫入日誌的建倉批次。（推論流程條款；與 規則書P-49、P-65 相容。）
- **限價單**：一律以 < 自動買進上限的限價下單（框架取上限 ×0.9999 捨去）；避開開盤與收盤前後的劇烈時段（推論，未在原文找到「限價單」字句；紙上交易以隔日典型價〔高＋低＋收〕÷3 記成交，`13_forward_validation.md`）。
- **不推價**：大資金單日買量 ≤ 日成交量約 20%（原文 ）；宿主依 P-38。
- 建倉中價格小漲但 < 上限 → 繼續買，不因「比首筆貴」停手（規則書第 7 節第 3 點）。

## 6. 持有側銜接（H0／H1）
- 既有持股：先依 規則書H0 以 T-1 補寫增補段；轉換未完成前只能 HOLD；轉換本身不得產生賣出訊號。
- 持有後：季度輕複查（R 清單與失效條件）、年度完整複查（重算 IV、上限、等級）、重大新事實即時；任一失效條件出現 → H2 Q2：論點證偽 → 全清；疑似 → P-50 觀察（兩次季報或 6 個月）、停止加碼；否則持有。跌價本身不是理由（NEVER-09）。
- 荒謬級（P-48）：正常化 P/E ≥50（可調 40–60）或估值須假設前所未見的獲利水準 → 至少賣一半（頂級亦同；宿主：建倉第一年內只停止加碼並完整複查，價格回到線下前只減一次；SKILL §6）。原文錨點：50 倍「是荒謬的價格，你可以怪我沒賣」；「如果看到 60 或 70 倍，盯著我」；泡沫期沒賣幾檔大持股是大錯。40 倍找不到原文錨點。

## 7. 兩週檢查的觸發判準（`scripts/review_due.py`；推論參數，鍵見 `inferred_thresholds.md`）
規則書只給名詞（P-25／P-55「單季跌幅 ≥25%」、P-55 (e)「財報或重大事件申報」、P-63「無重大新事實」），以下為腳本實際採用的操作定義（推論，未回測）。**申報窗口**（新年報、新季報、8-K、新聞標題共用）＝申報日 ≥ 上次分析日（當天申報者上次分析未讀，本次要算）且 < 決策日。

| 觸發 | 操作定義 | 層級 |
|---|---|---|
| 單季跌 ≥25%（只限持股） | 近 92 個曆日（不早於上次分析日）的最高收盤 → 最新收盤跌 ≥25%；狀態型觸發為邊緣觸發 | THESIS |
| 成本 −12%、單日 ±4%（只限持股） | 最新收盤較平均成本 −12%（上次分析時已成立者不再觸發）；上次分析日起任一日收盤對收盤 ±4% | THESIS |
| 新年報 | 申報窗口內的 10-K、20-F、40-F（20-F／40-F 視同年報） | FULL |
| 新季報與修正 | 申報窗口內的 10-Q、10-Q/A、10-K/A（10-K/A 多半只補封面或 Part III，只到 THESIS；原始 10-K 仍是 FULL） | THESIS |
| 延遲申報通知 | 申報窗口內的 NT 10-K、NT 10-Q、NT 20-F（含 /A）：規則書 W14 延遲申報 → W，補齊前只觀察；不算新年報或新季報 | THESIS |
| 重大 8-K | 申報窗口內、項目碼 1.01 重大合約、1.03 破產或接管、2.01 完成重大收購或處分、2.06 重大減損、3.01 下市或不符上市規定、4.01 更換會計師、4.02 財報不可依賴、5.02 董事或高階經理人異動 | FULL |
| 不需初判的 8-K | 只有 9.01（展品）、5.07（股東會投票結果） | — |
| 其他 8-K 與框架提供的新聞標題 | 進 `triage` 初判（只在 action 為 PRICE／NONE 時列出；依日期取最近 20 筆）；任一項「是」或「不確定」→ THESIS | TRIAGE |
| 完整複查到期 | 距上次完整分析 ≥365 個曆日；登錄表 `next_full_review_due` 晚於上次完整分析且 ≤ 決策日；持股 P-50 觀察期（`observe_until`）到期；持股權重 >25%（上次完整分析時已 >25% 者不再觸發） | FULL |
| 失效條件到期 | 登錄表 `kill_criteria_due` 任一條的 `due` 晚於上次分析日且 ≤ 決策日（§2） | THESIS |
| 長債 | 30 年期較上次估值變動 ≥1pp（觀察名單只限 A／B 級） | PRICE |
| 價格線 | 觀察名單 A／B 級現價 < 自動買進上限；持股現價 ≥ `sell_review_above` 或 ≥ `absurd_price_line`；持股未達目標權重且現價 < 上限 | PRICE |
| 價格過期 | 最後收盤早於決策日 >5 個交易日（只扣週末、不扣假日）→ 上表價格類觸發（單季跌、成本 −12%、單日 ±4%、價格線）一律不檢查，記「未檢查」；上次分析日前最後一筆收盤早於上次分析日 >5 個曆日 → 視為資料缺口，不當上次分析時的基準（只用登錄表記的上次分析價） | 不升級 |
| 申報抓取失敗 | 只略過申報類觸發（新年報、新季報與修正、延遲申報通知、8-K），不因申報升級 action，標「重大申報未檢查」；價格類、完整複查到期、長債、失效條件到期、新聞標題 triage 等其餘觸發照查。框架在登錄表記 `filings_fail`（連續次數與首次失敗前的窗口起點）：同檔連續 3 次觸發檢查抓取失敗 → 開異常 `trigger_fail_streak`（不暫停交易，需人工排查 CIK 或連線）；恢復成功的那次，申報窗口自首次失敗前的起點重算，失敗期間的申報不漏看（M2-RS8-03） | 申報類不升級 |

淘汰類（TOO_HARD／REJECT）只看上表「重大 8-K」；誠信淘汰（NEVER-04 (a)）只看 8-K 5.02；`MISSING_DATA` 只看新年報／新季報（SKILL §7）。P-63 的「無重大新事實」＝上次任何一次分析（登錄表 `last_review_date`，不限完整分析）後沒有上表 FULL／THESIS 類觸發，且 triage 初判全為「否」。

**缺資料持股的重試節流**（設計決策 D74；框架 `trader/pipelines/review.py`，鍵 `missing_data_retry_weeks`）：持股最近一次完整分析以 `MISSING_DATA` 停止（含使用者拒絕強模型、保險／銀行生存類前置檢查不過、輸出不合格；不推進上次完整分析日）後 13 週（91 個曆日）內，上表「完整複查到期」的滿 12 個月、`next_full_review_due`、權重 >25% 以該次嘗試日為基準，不每兩週重排 `FULL`；新年報照常 `FULL`，新季報由 THESIS 升 `FULL`（同 D27）；PRICE、THESIS 其餘觸發照常。滿 13 週後恢復一般判準。
