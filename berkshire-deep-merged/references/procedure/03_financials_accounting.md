# 03｜盈餘品質、會計紅旗與財務強度（步 5、7）

> 規則編號沿用 規則書（RISK-058～064、RISK-001～057、P-24、P-57～P-61、VAL-020～027）。紅旗總表只作對照清單，**P-61 計數規則不變**。

## 1. 讀表順序（RISK-059；G4）
1. 先讀會計師關鍵查核事項（新出現者視為重大新事實）。
2. 資產負債表 8–10 年 → 分部 → 現金流量表 → 損益表 → 附註。
3. 蟑螂原則：發現一個問題，假設還有別的（RISK-060）。
4. 看不懂就是紅旗（RISK-061 A1）；有疑慮就放棄（RISK-058）。

## 2. 重編為業主盈餘（全域營業盈餘口徑＋VAL-020～027）

| 步 | 做什麼 |
|---|---|
| 1 | GAAP 淨利剔除：已實現／未實現證券損益、衍生品期間損益、外幣債務與資產重估、稅率變動遞延稅重估、準則變更影響、合併或交換帳面利得、一次性項目；逐項列出處 |
| 2 | 股權薪酬是成本：GAAP 淨利已列費用 → 不加回、不重複扣；起點若是排除股權薪酬的調整後數字 → 按市價扣回 |
| 3 | 維持性資本支出依 P-24：一般 ≥ 折舊 ×1.0；輕資產 ×1.0–1.2；重資產＝max(折舊 ×1.2，折舊 × 近 5 年「資本支出 ÷ 折舊」中位 ×0.8)，上限 1.6（明證折舊嚴重低估可到 2.0）；通膨偏高時另算 |
| 4 | 軟體類攤銷不加回；持續收購者的收購支出當資本支出；客戶關係類攤銷預設加回約 80%（R5） |
| 5 | 保險另以無巨災、承保兩平正常化；週期股以完整循環平均 |
| 6 | 成長性營業費用只可依 VAL-010 條件式加回，且只提高 `IV_base` |
| 7 | 只有 GAAP 數且證券損益占淨利 >20% → 該指標 `MISSING_DATA`，不得直接判虧損年 |
| 8 | 發行人近 3–7 年曾由槓桿型財務買家控制或轉售 → 警訊加一級（RISK-091） |

原文錨點：EBITDA 不可用（：管理層以為資本支出是牙仙子付的嗎）；選擇權是薪酬。

## 4. G6 財務強度（RISK-001～057、RISK-090～099）

- P-06 利息保障（見 `01_competence_moat.md` §5）；不依賴持續再融資；無評等觸發的追繳結構。
- **P-57 單一事件或相關事件群最壞稅後損失 ÷ 股東權益**：有政策上限者用揭露上限換稅後；無上限者自估；皆無 → 不買。≤3% 通過；3–6% 只有在該稅後損失 ≤ 一年正常化稅後盈餘時通過並降一級；>6% 或無法估計 → 不買。
- 司法管轄與控股股東（RISK-090）：可辨識、有界的外部風險以機率 × 損失寫入 `IV_cons` 並用較低等級上限；不得用來放寬能力圈（CORE-05）。
- 債務到期表：未來 3 年到期額 ÷（現金＋未動用承諾額度＋一年正常化自由現金流）偏高 → 寫入 10 年出錯路徑。

## 5. 金融類口徑（只降一級；上限即該等級上限）

| 類別 | 必過 | 估值 |
|---|---|---|
| 保險 | P-58 浮存金成本（照 rulebook P-58）：多年浮存金加權成本（Σ 稅前承保損失 ÷ Σ 平均浮存金；10 年窗，不足才用 5 年）與同期多年平均基準殖利率比：≤0 優；0 < 成本 < min(短期國庫券, 長債 −1pp) 合格；min(短期國庫券, 長債 −1pp) ≤ 成本 < 長債 −1pp 降一級；≥ 長債 −1pp 不買。短期利率 <4% 時「合格」收緊為成本 ≤0（追溯型另依 RISK-042）。窗口內重大收購 → 分開計算。P-59 前瞻綜合率多年平均 <100 且優於產業加分；≥100 依 P-58，長尾以 105–115 為常態 → 淘汰 | VAL-081：`IV_cons`＝每股有形帳面＋每股平均浮存金 ×（長期利率 − 浮存金加權成本 − 1pp）÷ `r_d`（第二項 ≥0）；P/B 帶 1.3 倍（浮存金成本 ≤0 且 5 年平均綜合率 <95 → 1.6 倍） |
| 銀行 | P-60：放款 10% 出問題、平均損失 30%：撥備前稅前盈餘 ÷ 平均放款 ≥2.75% 通過；2.25–2.75% 降一級；<2.25% 或權益 ÷ 資產 <5% 不買 | VAL-080：P/B 與常態 ROE；拆 ROA × 槓桿看（ROE＝ROA × 資產 ÷ 權益）；資產常為權益二十倍左右時，小比例資產出錯就能毀掉大部分權益 |
| 其他金融 | 依 規則書SEL-100～103 | P4′ 用 min(大型股中位 ×1.0, 金融中位 ×1.1) |

金融類降級後為 C → 宿主不開倉（P-28）。
