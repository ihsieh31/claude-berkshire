# 01｜能力圈、企業層排除、經濟特性與護城河（步 2、3、4）

> 數字與規則編號沿用 規則書（SKILL 第 4–5 節、rule_index/01_selection.md）。本檔只整理成逐檔作答格式；為新增。

## 1. G1 能力圈（P-01；SEL-010～024、SEL-050～051）

**作答**：
1. 寫出 10 年經濟輪廓**區間**：營收結構、資本需求、競爭地位的範圍，主要未知，以及 10 年內最可能怎麼出錯。寫成單點預測者降一級（過度自信）。
2. 判定：10 年寫得出 → 通過（可 A）；只寫得到 5 年、5–10 年只有一兩個關鍵變數不確定且 10 年方向（定價權是否還在、資本需求是否上升）寫得出 → 通過（最高 B）；連 5 年都寫不出 → `TOO_HARD`。
3. 書面三測：理由測試（一句話寫得出為何賺錢）、反方測試（把空方論點寫得比空方好）、邊界測試（明列不知道什麼，且不決定成敗）。
4. **預設太難類**（快速持續變動、無獲利紀錄、取決於技術路線或政治結果）。快速持續變動的操作定義（推論；與規則書 G1 同文）：符合任一：①主要競爭者近 3 年有新進入者取得 ≥10% 市占；②核心產品單位價格近 3 個財年中 ≥2 年下降 >15%，且不是商品價格循環；③年報風險因素具名某替代技術，且該技術已在侵蝕核心營收（泛用樣板句不算）。單位量變動與一般技術替代字樣不算；商品循環改由 SEL-050 清單與 SEL-051 第 4 點處理；SEL-051 第 3 點的 W-LOSS 依 P-02 口徑（週期谷底、可切除的一次性虧損不算）。命中 → SEL-051 加嚴條件全部成立才續行、降一級、建倉前寫 2–3 個破裂訊號、≤12 個月首次複核。
5. A 級在無法實地查訪時可達：以主要競爭者年報、產業統計、客戶留存或續約等可查證數字，完成同一組問題並逐條附出處 → 等級上限不受影響；完成不了 → 上限降一級（P-01）。

**研究提問（補充；不改門檻）**：「如果只能投資一家競爭對手，會選哪家、為什麼？」「哪家競爭對手最讓你擔心？」用來檢驗護城河來源是否說得清（：兩者並存，作為 規則書PROC-071 第 7 步的問題集）。

## 2. G2 企業層排除（SEL-030～048；命中任一 → `REJECT`，便宜也不例外）

逐條作答「是／否／缺」：
| 編號 | 條件 |
|---|---|
| SEL-030 | 無差異化商品＋資本密集＋產能過剩（例外：可量化且擴大中的最低成本差距） |
| SEL-031 | 被迫持續大額投入才能留在牌桌上，而增量報酬低 |
| SEL-032 | 轉機股、靠大額資本支出救回爛產業（優秀特許權受一次性打擊不算，走 SEL-047） |
| SEL-033 | 勞動成本遠高於海外對手、產品易進口的國內製造 |
| SEL-034 | 結構性衰退（看實物量，不看漲價撐住的金額）；例外：稅後盈餘殖利率約 ≥10% 且折讓遠大於一般標的 → 進估值、降一級。**分階段**（價格隔離）：前半只判「是否結構性衰退」，命中時在報告寫「SEL-034 待 G7 判例外」（前半不列 `downgrades`、不判例外、不 REJECT），續行到問卷存檔；後半看價後判例外：成立 → 降一級續行，不成立 → `REJECT`（停在 G7） |
| SEL-035 | 優勢主要在人而非結構 → 不排除，但最高 B 級，核心經營者離任列失效條件 |
| SEL-036／037 | 只靠下一個買家的資產；首次公開發行與新發行證券 |
| SEL-038 | 以高估股票換資產推升每股盈餘的連鎖成長 |
| SEL-039 | 扣除充足維持性資本支出後的現金流付不出全部利息；以 EBITDA 論述償債 |
| SEL-040～042 | 純融資且對手資金更便宜；可被追繳擔保或可擠兌負債；開放式長期負債過重 |
| SEL-043 | 潛伏、無上限、擴大中的侵權責任 |
| SEL-044／045 | 無補貼即不成立；獲利以傷害客戶為主（低信心） |
| SEL-048 | 收入端已競爭化而成本仍是保護時期結構且高於新進者，無縮小路徑 |

誠信紅旗在此先查公開紀錄（處分、誤導），判層依 `02_management.md` §1。

## 3. G3 經濟特性：四型分類（SEL-055 規則書）

| 型 | 判準（稅後無槓桿有形資本報酬） | 動作 |
|---|---|---|
| 偉大＋ | ≥25% 且已實證 ≥7 年增量資本報酬 ≥20%、再投入率 ≥ 盈餘 50% | 續行 |
| 偉大 | ≥25%、成長不需大量資本 | 續行 |
| 良好 | max(12%, `r_d` 稅後等值) 至 25% | 非小資金模式：續行並降一級；小資金（宿主模式）：排除「良好型重資產」，其餘良好型續行、不因此降級（設計決策 D18） |
| 可怕 | < max(12%, `r_d` 稅後等值) 且需追加資本 | `REJECT` |
| 統計便宜 | — | 只限一般模式小資金籃子；宿主關閉 |

- 重置成本、帳面價值、低於營運資金的價格都不是續行理由。
- 只能算替代量時標「代理口徑」，最高到「良好」上緣。收購型企業以營運有形資本計；有形淨資產為負時用營運資本＋固定資產淨額為分母。
- 基本率說明（不作門檻）：一段十年期間的千大企業中，十年平均 ROE >20% 且沒有一年低於 15% 的只有 25 家（約 2.5%）。偉大型本來就稀少；寫到「偉大」時先問自己是否高估。

## 4. 護城河（SEL-061～066）

**核心三測，至少兩項為「強」**：
| 測試 | 強 | 弱 |
|---|---|---|
| 定價權 | 不必猶豫就能漲價；「每單位漲 10%」銷量不明顯下滑；漲價後留存不降（先扣成本轉嫁型附加費、排除總體需求因素） | 漲一點都猶豫；漲價後量掉 |
| 攻擊／複製 | 給對手充足資本與人才也傷不了；**須經歷至少一次壓力事件後使用量與留存未明顯下降才可評強** | 有錢就能複製 |
| 砍價 | 對手砍價一半也搶不到客戶 | 搶得到 |

- 說出至少一項來源（消費者心佔率、持久最低成本、規模與網路效應、政府特許或天然寡占、承諾者財力、商標專利地點、可用實物指標證明的服務品質）並說明為何持久；說不出 → `REJECT`。
- 方向：變窄 → `REJECT`；持平 → 通過；變寬 → 加分。侵蝕訊號見 SEL-064（漲價開始猶豫、通路自有品牌、品類可被線上取代等）；分不清結構性或週期性 → 當結構性。
- 補充測試（加減分）：缺貨測試、未開發定價權、平庸管理也能賺、逆境成長、實物量、成本轉嫁方向、自然存在 vs 需持續重建（SEL-063）。

## 5. 生存類硬篩（只排除生存風險，不證明好）

| 項 | 規則 | 停止 |
|---|---|---|
| P-06 利息保障（非金融） | 分子＝稅前息前營業盈餘（剔除證券、衍生品、一次性利得）；分母＝對母公司有追索的經常性利息。5 年中位 ≥5 通過；最近一年 <5 但 5 年中位 ≥5 且屬單一危機年 → 降一級續行（driver_id 利息保障；procedure/06 §1）；5 年中位 <5 → 不買。連 3 年下降且最近一年 <8 → 降一級。受管制放寬（多元不相關＋風險有界＋10 年無重大不利裁決）下限 2.5 | `REJECT` |
| P-07 負債／權益（**有息負債／權益**） | 不設一般門檻；>3 倍且無穩定、受管制或特許現金流 → 排除（推論，可調 2–4）。<0.5 且利息保障 ≥10 → 品質加分；ROE 主要靠槓桿 → 不加分。口徑理由：以總負債計會誤排除大量正常企業，以有息負債計才反映生存風險 | `REJECT` |
| 權益為正 | 否（舉債回購或併購使權益為負或極小）→ 依 SEL-076b 改用有形資本報酬判斷，不直接排除；P-07 比率此時不適用，生存性看 P-06 利息保障 | — |
| 保險、銀行 | 改走 `03_financials_accounting.md` §5（P-57～P-60） | — |

初篩標的「G3 生存待核」旗標在此以年報人工判讀確認；資料檔缺欄時不可用替代量自動淘汰。

## 6. 加分與警示（只影響確定性與排序，不是停止碼）

- P-02 近 5 年營業虧損：0 → 加分；1 → W-LOSS：以正常化盈餘重算 G3、G7；≥2 → 降一級，且須寫明「同一具名可切除的一次性打擊、核心指標在虧損期仍維持、已恢復至少一個完整獲利年度」或「週期谷底且谷底年通過 G6」；寫不出 → `TOO_HARD`。
- P-03／P-04 ROE、P-09 最差 ROE 與利益率：加分。
- P-05 營收：≤0 → W-REV：先判是否結構性衰退（SEL-034）；實物量年降 <2% 或非結構性 → 續行，但估值不得給成長（P2 只用 `IV0`）。（初篩已把營收 >0 的排序加分改 0；本處警示規則不變。）
- P-08 加分通過率（SEL-078；以有資料項目計）：≥60% 品質優；40–60% 可；<40% 降一級。宿主可計集合 7 項（下表標「作答」的 5 項＋B7、B11），門檻按可計項比例換算（設計決策 ASK-3＝B）：有資料 <4 項 → 最高「品質可」（原 <8/13）；前半 5 項有資料 <3 項 → `MISSING_DATA`（原 <5/13；只在因**財報**缺而不足時適用；因母體檔或價格項記「缺」而不足者不適用，推論）。
