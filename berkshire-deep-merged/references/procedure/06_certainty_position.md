# 06｜確定性等級、機會成本與部位（步 10、11、14）

> 沿用 規則書VAL-060、P-01、P-16、G8（POS-021）、P-28～P-44、第 7 節。確定性只由證據決定；全部閘門通過不提高等級（規則書第 0 節第 9 點）。

## 1. 確定性等級

## 3. 部位（G11；第 7 節）

```
目標權重 = min( 依優勢 × 確定性排序的意願權重,
  P-28 等級上限（宿主：A 15%／B 10%／C 0）,
  P-29 尾部公式：10pp ÷ 合理最壞相對損失（最壞損失＝1 − 悲觀價值 ÷ 現價，下限 25%）,
  P-30 單事件：權重 × 近 8 次財報次日最大單日跌幅 ≤ 權益 2%（stop_mode＝A，s＝0）,
  P-31／P-32 相關群剩餘額度,
  宿主或使用者上限 )
金融類：等級降一級（上限即該級上限）；有贖回或短期用錢壓力再減半
目標權重 < 3% → 不建倉（不試水溫；P-33）
```

| 項 | 宿主模式 | 出處 |
|---|---|---|
| 檔數 | 核心 5–10；最多 12；保留 2 空名額；≥10 檔時新點子須勝最弱持股 | P-34 |
| 現金 | ≥ 權益 5%；計畫水位 ≥ 下限 ×1.2；可動用現金＝現金 − 下限 − 已承諾現金 | P-35、POS-051 |
| 每日新部位 | ≤4（恐慌期也不例外） | P-44 |
| 首批 | 目標 50%；已過全部閘門且距 52 週高點 ≤ −20% → 可到 70% | P-36 |
| 完成期 | 1–15 個交易日；回落 ≥20% 時 ≤5 日；窗口到期或連 10 日高於上限 → 取消剩餘批次 | P-37 |
| 流動性 | 目標部位金額 ≤ 平均日成交額 1% | P-38 |
| 槓桿、放空、衍生品 | 0／0／0 | P-40、NEVER-01 |
| 事件型 | 合計 ≤ 權益 25%；單案 ≤ min(10%, 2% ÷ 破局下檔) | P-41 |
| 比重過高 | >15% 不加碼；>25% 完整複查 | P-43 |
| 持股比例 | 宿主無影響；一般模式只有受監管產業 9.9% 硬上限 | P-39 |

集中的前提（MKT-047）：組合與使用者都能承受至少 −50% 累計回撤而不被迫賣出；組合摘要必列「前 5 大同時 −50% 時權益回撤＿%；被迫賣出路徑：有／無」。

**自動買進的首批與加碼**：目標照上表算出後，首批＝0.5 × 目標（P-36；自動模式不用 70% 加速）；之後每一批與每次加碼都要先過加碼許可（論點完好、三閘門重新全過、價格 < 上限、權重 ≤15%），細則與原文出處見 `12_auto_buy_gates.md` §2。

**不得**：start_small 或任何「高於上限先小額買」的部位；以 13F 新部位占比（大型組合的極小比例）推論小帳戶的試探部位。
